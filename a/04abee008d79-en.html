Hermes: Open-Source ESP32 Voice Assistant

An open-source project turns an ESP32 into a push-to-talk voice assistant using WiFi and cloud transcription.

Read the article on the TRMNL Leaderboard →

Hermes, an open-source project by ROHITCRAFTSYT released under the MIT license, turns an ESP32 into a push-to-talk voice assistant by pairing it with a Windows PC. The user presses a button to record a voice message, which is sent over WiFi to the computer. The PC processes the request using online transcription services (Groq or NVIDIA) and returns a spoken response, either through the computer’s speakers or an optional I²S amplifier (MAX98357A) connected to an 8Ω speaker on the ESP32.

The required hardware includes a standard ESP32 or an ESP32-S3 (with a provided schematic), a digital INMP441 microphone, a push-to-talk button, and optionally the I²S amplifier. The firmware, available on GitHub, targets Python 3.11 or later for PC-side processing. Hermes supports local commands like opening apps or websites, as well as interactions with smart home devices. However, it lacks local wake-word detection and relies entirely on cloud services for transcription and language processing.
