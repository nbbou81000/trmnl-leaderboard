An Open-Source Emulator for the Philips Velo 1 Windows CE Handheld

A developer releases an emulator for the Philips Velo 1, a 1997 Windows CE PDA, featuring advanced features.

Philip Howard releases velo-emu, an open-source emulator for the Philips Velo 1, a 1997 Windows CE PDA. The emulator simulates the backlit LCD screen, CompactFlash cards, and the period’s desktop connection tools. It builds on the CERF project but runs on macOS, Linux, and Android.

The emulator loads the official Windows CE 1.0 and 2.0 ROMs, though these are not included in the software. Each emulated instance has a fixed screen size and memory, and saves its state on exit and every minute. Upon launch, the state is restored with the clock advanced by the time spent outside the emulator.

For connectivity, the emulator includes a PPP server over the serial port, enabling network access. A host-side web proxy allows Pocket IE to reach modern HTTPS sites. The RAPI remote API is exposed as a socket, or optionally over TCP, enabling a command-line tool to push files and registry keys. A GDB server with per-process breakpoints is available, along with a deterministic headless mode for testing. A patch addresses a write bug in Windows CE 1.0’s fatfs.dll.

The project is released under the MIT license and available on GitHub.
