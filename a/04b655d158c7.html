Un émulateur open source du Philips Velo 1 sous Windows CE

Un développeur recrée un émulateur du Philips Velo 1, un PDA Windows CE de 1997, avec des fonctionnalités avancées.

Philip Howard propose velo-emu, un émulateur open source du Philips Velo 1, un assistant personnel sous Windows CE 1.0 sorti en 1997. L’émulateur simule l’écran LCD rétroéclairé, les cartes CompactFlash, ainsi que les outils de connexion de l’époque. Il repose sur le projet CERF mais est compatible avec macOS, Linux et Android.

L’émulation charge les ROMs officielles de Windows CE 1.0 et 2.0, mais celles-ci ne sont pas fournies avec le logiciel. Chaque instance émulée est configurée avec une taille d’écran et une mémoire fixes, et sauvegarde son état à la fermeture ainsi que toutes les minutes. À chaque lancement, l’état est restauré avec l’horloge avancée du temps écoulé hors émulation.

Pour la connectivité, l’émulateur intègre un serveur PPP via le port série, permettant une connexion réseau. Un proxy web côté hôte permet à Pocket IE d’accéder à des sites modernes en HTTPS. L’API RAPI de Windows CE est exposée en socket, voire en TCP, pour pousser des fichiers ou des clés de registre depuis un outil en ligne de commande. Un serveur GDB avec des points d’arrêt par processus est également disponible, ainsi qu’un mode headless déterministe pour les tests. Une correction est appliquée pour un bug d’écriture dans fatfs.dll de Windows CE 1.0.

Le projet est distribué sous licence MIT et accessible sur GitHub.
