A Hackable Analog Phone System for Retro Handsets

An open-source project turns vintage landline phones into a customizable standalone phone system powered by an ESP32-C6.

Read the article on the TRMNL Leaderboard →

Vintage landline phones from the 1980s to 2000s—whether rotary dial or touchtone—can get a second life with Analog Redial, a project by Scott Dylewski. This open-source system turns these devices into a standalone phone network that operates without a traditional landline connection.

The core of the system is an ESP32-C6, paired with an ES8388 audio chip to handle voice signals. Up to two phones can be connected, enabling internal calls, SIP server integration, and built-in answering machine features. A web interface simplifies configuration, while custom dial codes allow integration with smart home systems like Home Assistant.

A Bluetooth module can be added to use an analog phone as a wireless handset for a modern smartphone. All necessary files are available on GitHub, and a partially pre-assembled version can be ordered from a PCB manufacturer. The system includes a SLIC (Subscriber Line Interface Circuit), which simulates the high voltages (60-90 VAC) required for classic phone ringers.

Features and constraints

The project enables the creation of a local phone network, with the option to connect to an external SIP server for outgoing calls. Users can also set up custom dial codes to trigger smart home actions, such as turning on a sauna or activating a heating system. However, the lack of native support for Bluetooth Classic on newer ESP32 models limits the use of advanced features like the HFP (Hands-Free Profile).
