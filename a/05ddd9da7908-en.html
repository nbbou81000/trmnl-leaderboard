vESP Cloud: A Visual Editor for Home Assistant Dashboards on ESP32 Displays

An open-source web editor streamlines the creation of Home Assistant interfaces for ESP32 displays without manual coding.

Building a dedicated dashboard to control a Home Assistant smart home can be expensive. Low-cost ESP32 touchscreen displays, such as the Guition ESP32-S3-4848S040 module (480 × 480 pixels, RGB screen driven by an ST7701S display controller and GT911 touch controller), offer an affordable alternative under $25. However, configuring these displays often requires editing configuration files or writing code, which can be daunting for non-technical users.

vESP Cloud provides an open-source, browser-based visual editor to design interfaces by dragging and dropping widgets onto a virtual representation of the physical screen. Users can resize, reposition, and customize widgets without manually defining coordinates or styles. Supported widgets include clocks, buttons, icons, HVAC controls, weather forecasts, calendars, and to-do lists. Widgets can be grouped into tabs or displayed conditionally based on Home Assistant entity states, time, or other rules.

To integrate smart devices, the editor relies on the HA Metadata Exporter extension, which generates a JSON file listing Home Assistant entities. This file is imported into vESP Cloud to link widgets to actual devices. After designing the layout, the tool automatically generates ESPHome-compatible firmware. Deployment is handled via USB-C or Wi-Fi, with a simplified network setup process. Future updates can be installed directly from Home Assistant, eliminating the need to reconnect the display to a computer.

The editor itself is free, but cloud-based firmware compilation requires purchasing credits. Alternatively, users can export the generated configuration files (YAML and C++) and compile them locally using ESPHome. The project currently supports only the Guition ESP32-S3-4848S040 module, and the Home Assistant entity export must be manually refreshed when devices are modified.
