vESP Cloud : un éditeur visuel pour tableaux de bord Home Assistant sur écran ESP32

Un éditeur web open source simplifie la création d'interfaces pour écrans ESP32 dédiés à Home Assistant, sans coder.

Construire un tableau de bord dédié pour contrôler son installation domotique via Home Assistant peut vite devenir coûteux. Les écrans tactiles ESP32 à moins de 25 €, comme le module Guition ESP32-S3-4848S040 (480 × 480 pixels, écran RGB piloté par un ST7701S et un contrôleur tactile GT911), offrent une alternative économique. Cependant, leur configuration nécessite généralement de manipuler des fichiers de configuration ou du code, ce qui rebute les utilisateurs moins techniques.

Le projet vESP Cloud propose une solution open source sous forme d’éditeur visuel accessible depuis un navigateur. L’outil permet de concevoir une interface en glissant-déposant des widgets sur une représentation graphique de l’écran, sans avoir à définir manuellement les coordonnées ou les styles. Plusieurs types de widgets sont disponibles : horloges, boutons, icônes, thermostats, prévisions météo, calendriers ou listes de tâches. Les widgets peuvent être redimensionnés, organisés en onglets ou affichés conditionnellement selon l’état des entités Home Assistant, l’heure ou d’autres critères.

Pour intégrer les appareils connectés, l’éditeur utilise une extension dédiée, HA Metadata Exporter, qui génère un fichier JSON contenant les entités Home Assistant. Ce fichier est importé dans vESP Cloud pour associer les widgets aux dispositifs réels. Une fois la mise en page terminée, l’outil génère automatiquement le firmware ESPHome compatible avec l’écran. Le déploiement s’effectue via un câble USB-C ou en Wi-Fi, avec une configuration réseau simplifiée. Les mises à jour ultérieures peuvent être installées directement depuis Home Assistant, évitant de reconnecter l’écran à un ordinateur.

L’éditeur est gratuit, mais la compilation cloud du firmware est payante via un système de crédits. Une alternative consiste à exporter les fichiers de configuration (YAML et C++) pour les compiler localement avec ESPHome. Le projet cible principalement le module Guition ESP32-S3-4848S040, et l’export des entités Home Assistant doit être relancé manuellement en cas de modification des appareils.
