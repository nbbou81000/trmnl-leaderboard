OpenRB-338: Open-Source ReBirth RB-338 Revival for Modern Computers

A developer revives the 1997 ReBirth RB-338 software as an open-source project for current desktop systems.

Read the article on the TRMNL Leaderboard →

The OpenRB-338 project, created by pingw33n and featured by synthhead on Synthtopia, offers a free and open-source recreation of Propellerhead’s ReBirth RB-338. Originally released in 1997, this software emulated classic Roland instruments within a virtual studio environment. The modern version runs on current desktop operating systems while maintaining audio output faithful to the original.

OpenRB-338 supports loading original ReBirth song files, ensuring compatibility with legacy projects. It operates as a standalone application. However, some advanced features from the original are not yet implemented: pattern editing, undo functionality, as well as MIDI input, MIDI sync, VST, AU, and ReWire support.

The project is distributed free of charge, with source files and installation instructions available on GitHub. Additional details can be found in the article published on Synthtopia.
