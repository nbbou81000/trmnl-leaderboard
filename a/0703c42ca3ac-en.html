Self-Hosted Web Proxy to Compress Pages and Save Data

A self-hosted HTTPS proxy compresses images and code, blocks ads, and reduces mobile data usage by optimizing web pages.

Read the article on the TRMNL Leaderboard →

As web pages grow increasingly bloated, one developer built a self-hosted HTTPS proxy to compress content before it reaches the user’s device. The goal is to reduce mobile data usage while maintaining a functional browsing experience, especially on small screens.

The project leverages mitmproxy, an existing tool that intercepts and modifies HTTP/HTTPS traffic. The main focus is on images, which are converted to the lighter .webp format and resized based on user preferences. A configurable setting allows adjusting image quality. For particularly heavy pages, such as those packed with JavaScript, an option forces maximum compression—though this may slow down loading times.

In addition to file size reduction, the proxy blocks ads and functions as a private VPN when traffic passes through a local server. However, unlike solutions like FrogFind or MacProxy, this tool does not help older hardware access the modern web. It is primarily a data-saving measure, not a way to modernize outdated devices.

The code and technical details are available on GitHub, along with an explanatory video.
