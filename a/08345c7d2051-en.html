Pinetek Networks Launches IO-Link Module for Raspberry Pi

A HAT module for Raspberry Pi adds IO-Link support, ideal for industrial automation and prototyping.

Read the article on the TRMNL Leaderboard →

Pinetek Networks, a specialist in simplified "smartification," has introduced the IOL Core4 module, designed to work with Raspberry Pi single-board computers. This module, built as a HAT (Hardware Attached on Top), enables the connection of up to four IO-Link sensors or actuators to a system. IO-Link, standardized under IEC 61131-9, is a short-range digital communication interface used in industrial automation for bidirectional data exchange, device identification, and rich data transmission.

The IOL Core4 module can be used in two ways: standalone, via a version with an integrated microcontroller (IOL Core4 Plus), or as a communication subsystem for an existing host running the IO-Link software stack. To simplify testing, Pinetek Networks has developed a carrier board that turns the module into a HAT for Raspberry Pi 4 or 5. The evaluation kit, which includes the four-port module, carrier board, 24V power supply, and four two-meter M12 cables, is now available for purchase at €270 (excluding shipping).

The kit is officially compatible with Raspberry Pi 4 and 5 running Raspberry Pi OS "Trixie" or "Bookworm." The module can also be removed from the carrier board for integration into custom electronic designs, offering flexibility for tailored projects.
