Pinetek Networks lance un module IO-Link pour Raspberry Pi

Un module HAT pour Raspberry Pi ajoute le support IO-Link, idéal pour l'automatisation industrielle et les prototypes.

Lire l'article sur le Palmarès TRMNL →

Pinetek Networks, spécialiste de la « smartification » simplifiée, propose un module IOL Core4 compatible avec les cartes Raspberry Pi. Ce module, conçu sous forme de HAT (Hardware Attached on Top), permet de connecter jusqu’à quatre capteurs ou actionneurs IO-Link à un système. L’IO-Link, standardisé par l’IEC 61131-9, est une interface de communication numérique courte portée utilisée en automatisation industrielle pour échanger des données bidirectionnelles avec identification des appareils et transmission de données riches.

Le module IOL Core4 peut être utilisé de deux manières : autonome, via une version intégrant un microcontrôleur (IOL Core4 Plus), ou comme sous-système de communication pour un hôte existant exécutant la pile logicielle IO-Link. Pour faciliter les tests, Pinetek Networks a développé une carte porteuse transformant le module en HAT pour Raspberry Pi 4 ou 5. Ce kit d’évaluation, incluant le module quatre ports, la carte porteuse, une alimentation 24V et quatre câbles M12 de deux mètres, est disponible à l’achat pour 270 € (hors frais de port).

Le kit est officiellement compatible avec les Raspberry Pi 4 et 5 fonctionnant sous Raspberry Pi OS « Trixie » ou « Bookworm ». Le module peut également être retiré de la carte porteuse pour être intégré dans des conceptions électroniques personnalisées, offrant ainsi une flexibilité pour les projets sur mesure.
