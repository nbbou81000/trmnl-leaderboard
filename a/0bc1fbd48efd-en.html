Arduino Generates Imaginary Fish on an E-Ink Display

An Arduino project generates fictional fish with illustrations and scientific descriptions on an e-ink display.

The This Fish Does Not Exist project, created by maker Jim Bruges, uses artificial intelligence to generate entirely fictional fish species. Each creation is presented as a page inspired by 19th-century ichthyology textbooks, featuring a detailed illustration, a scientific name, classification, and textual description.

The setup is built around an Arduino UNO Q with 2 GB of RAM, paired with a Waveshare 7.5-inch monochrome e-ink display (800×480 pixels). The components are housed in a standard 7×5-inch photo frame, secured with custom 3D-printed PETG mounting plates. An optional 5,000 mAh USB power bank allows portable operation.

The project’s uniqueness lies in its dual use of a microcontroller and a Linux system on the Arduino UNO Q. A Python algorithm, fishdraw, procedurally generates each fish by determining its body shape, fins, and markings. These characteristics are then passed to a locally running Gemma 3 1B language model, which invents a plausible scientific description covering habitat, diet, depth range, and distinguishing features. The model operates offline after an initial download.

Once the illustration and description are ready, a Python library assembles them into a textbook-style page. The microcontroller updates the e-ink display using the GxEPD2 library, employing partial refreshes to animate the fish being drawn stroke by stroke and the text appearing word by word. Only modified data is transferred between processors to reduce communication overhead. A web interface lets users configure the layout, generation interval, and drawing speed, with three layout options available.
