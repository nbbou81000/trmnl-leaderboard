Patch to Remap Commodore 64 Keyboard via KERNAL ROM

A method to permanently remap the Commodore 64 keyboard by patching the KERNAL ROM has been released.

Read the article on the TRMNL Leaderboard →

Dave VW has introduced a way to permanently remap the Commodore 64 keyboard by patching the KERNAL ROM. Unlike earlier methods that relied on temporary BASIC RAM drivers, this approach targets the KERNAL ROM itself, which stores four keyboard layouts: Normal, Shift, Commodore, and Control. The 64KEY ROM PATCH project, part of the c-keymaps repository, uses a PRG file to locate these tables and apply changes via a list of DATA statements specifying the shift mask, key scan code, and corresponding PETSCII character.

After applying the patch, the modified ROM image is activated in RAM and can be saved. This image can then be transferred to a PC and burned onto an EEPROM for use on a physical Commodore 64. Users with a ROM switcher like the Easy Flash 3 or a hardware toggle switch between two ROMs can switch layouts on the fly. Emulator users can simply add the patched ROM to their collection and select it.

The included example remaps symbols such as + to -, @ to [, and shift-: to a plain colon. Technical details and source code are available at techwithdave.davevw.com and GitHub.
