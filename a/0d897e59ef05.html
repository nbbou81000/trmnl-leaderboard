Patch pour remapper le clavier du Commodore 64 via le KERNAL ROM

Une méthode permet de modifier durablement la disposition du clavier du Commodore 64 en patchant le KERNAL ROM.

Lire l'article sur le Palmarès TRMNL →

Dave VW propose une solution pour remapper le clavier du Commodore 64 sans recourir à des pilotes temporaires. Contrairement aux méthodes précédentes qui chargeaient des tables de mappage en RAM BASIC et disparaissaient au redémarrage, cette approche cible directement le KERNAL ROM, où résident les quatre tables de mappage : Normal, Shift, Commodore et Control. Le projet 64KEY ROM PATCH, intégré au dépôt c-keymaps, utilise un programme PRG pour localiser ces tables et appliquer des modifications via une liste de données définissant le masque de shift, le code de balayage des touches et le caractère PETSCII correspondant.

Une fois appliqué, le patch est activé en RAM et peut être sauvegardé sous forme d’image ROM. Cette image peut ensuite être transférée sur un PC et gravée sur une EEPROM pour une utilisation sur un Commodore 64 physique. Les utilisateurs disposant d’un ROM switcher comme l’Easy Flash 3 ou d’un commutateur matériel entre deux ROM peuvent basculer entre les mappages à la volée. Les émulateurs permettent d’ajouter directement la ROM patchée à leur collection et de la sélectionner.

Le jeu de modifications inclus dans l’exemple déplace des symboles comme le + vers le -, le @ vers le [, et le shift-: vers un deux-points simple. Les détails techniques et le code source sont disponibles sur techwithdave.davevw.com et GitHub.
