Arduino UNO Q: Embedded Linux and AI for Local Automation

Arduino UNO Q merges Linux and a microcontroller to run AI agents and automate local systems without cloud dependency.

Read the article on the TRMNL Leaderboard →

The Arduino UNO Q board features a dual-processor design: a Linux MPU for advanced software tasks and an STM32H5 microcontroller (running Zephyr RTOS) dedicated to real-time hardware control. This setup allows running standard open-source software while ensuring deterministic precision for sensor and actuator interactions.

Several software platforms can be installed directly on the UNO Q. An AI agent like OpenCode can be deployed to generate, deploy, and test Arduino sketches locally, without relying on an external computer. The agent processes requests via a language model API but executes hardware actions directly on the board, avoiding cloud-related latency.

For home automation, Home Assistant can serve as a central dashboard to manage lighting, climate control, or energy meters, while the microcontroller drives relays or fans based on captured data. n8n, a visual automation tool, enables creating local workflows connecting sensors, databases, and external services without a cloud subscription. Pi-hole can also be installed to filter DNS requests across the local network, with a physical interface (buttons, display) managed by the microcontroller. Finally, Frigate, a video object detection system, can analyze RTSP or USB streams in real time, triggering immediate hardware actions via the STM32H5.

The UNO Q can also function as a lightweight NAS via SMB, sharing local folders for storing video recordings, logs, or datasets. These applications can operate independently or be combined to create complex scenarios, such as video detection (Frigate) triggering lighting (Home Assistant), notifications (n8n), and storage on the NAS—all controlled by a single device.
