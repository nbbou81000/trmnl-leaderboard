Picothermal: An Open-Source USB-C Thermal Camera Without a Screen

An open-source USB-C thermal camera using an RP2040 and a Flir Lepton 3.5 sensor, controllable via a browser thanks to WebUSB.

Read the article on the TRMNL Leaderboard →

Cezar Chirila has developed Picothermal, a USB-C thermal camera that omits a screen and battery, instead streaming its images directly to a smartphone or PC. The project replaces the MLX90640 sensor from his earlier builds with a Flir Lepton 3.5, increasing the resolution from 32×24 pixels to 160×120 pixels. Communication is handled via WebUSB, enabling control through a web page without requiring a dedicated app. However, this solution requires Chrome, as Firefox does not support WebUSB.

The hardware is built around an RP2040 microcontroller, a USB-C connector, a buck converter for 5V to 3.3V power, and a few linear regulators (LDOs). There is no battery, charge controller, or microSD card. Chirila had the boards manufactured by two suppliers: Aisler (1.6mm thick) and JLCPCB (0.8mm thick). He chose the thicker Aisler boards as they were easier to solder. The hardware dates back to 2023, but firmware development faced delays, particularly due to debugging issues with TinyUSB.

The firmware was finally rewritten in Rust using the Embassy library in 2026, after assistance from AI Claude. Chirila notes that this version uses both cores of the RP2040 and is not maintainable, but it works as intended.
