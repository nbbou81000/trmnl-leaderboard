Disposable Windows 11 ARM64 VM on Apple Silicon Macs via tart Fork

A developer releases a tart fork enabling Windows 11 ARM64 installation on Apple Silicon Macs without Parallels or UTM, with notable limitations.

Read the article on the TRMNL Leaderboard →

Developer Mustafa Akin has released an experimental tart fork enabling the installation of a Windows 11 ARM64 virtual machine on Apple Silicon Macs. Unlike existing solutions such as Parallels or UTM, this method relies on undocumented private Apple settings, making it susceptible to being disabled by a future macOS update. As such, it is not suitable for production use.

The generated VM lacks sound, graphics acceleration, TPM module, and suspend functionality. However, it allows for instant cloning of instances to test software or automate tasks under Windows 11. Installation, tested on a Mac Studio M4 Max, took 26 minutes with a French ISO of Windows 11 ARM64. The interface remains in French, but the keyboard defaults to QWERTY.

The process requires an Apple Silicon Mac running macOS 26.6 or 27, along with Xcode to compile the fork. Users must also obtain a Windows 11 ARM64 ISO and handle licensing manually. The fork automatically injects virtio-win and WinFsp drivers, but components like the viosock driver (for communication between the VM and Mac) must be installed manually via a shared folder. The tart-guest-agent must then be configured as a startup task to enable clipboard and desktop functionality.

Once the VM is operational, it can be cloned instantly using the tart clone command to create disposable environments. The VM can be launched in headless mode with --no-graphics to run background commands.
