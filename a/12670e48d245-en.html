NesEmulatorPicoSeries: Bare-Metal NES Emulator for Pico W/2W and Pi 4

A bare-metal NES emulator written in PureMetal runs on Raspberry Pi Pico W, Pico 2 W and Pi 4 without SDK or RTOS.

Developer ajtaji has released on GitHub NesEmulatorPicoSeries, an NTSC NES emulator designed to run in bare-metal mode on three platforms: Raspberry Pi Pico W, Pico 2 W, and Raspberry Pi 4. Unlike traditional approaches, this project avoids SDKs and RTOS, compiling code directly to bare-metal machine code using PureMetalForge.

Games are not embedded in the firmware. A lightweight Python tool allows loading .nes files onto the board’s flash memory, featuring a graphical window for normal use and a command line for scripting. On the Pico 2 W with an RP2350 chip, the emulator leverages both Cortex-M33 cores at their nominal 150 MHz, paired with a 75 MHz LCD SPI clock.

Video output relies on compile-time plugins: the default is the LAFVIN ST7796, but other displays like the ILI9341, Adafruit HX8357D, or ST7789 are supported at varying stages of hardware testing. Audio output uses Bluetooth A2DP (SBC at 48 kHz stereo) via the Pico’s CYW43439 radio module, though the published firmware does not set any speaker address by default, leaving the emulator silent without manual configuration.

The project includes an on-board test suite that passes 1,926,732 checks with zero failures on a physical Pico 2 W. However, the emulator does not implement the PPU (Picture Processing Unit) with cycle accuracy and only supports documented CPU opcodes. The code is released under the MIT license.
