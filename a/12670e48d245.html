NesEmulatorPicoSeries : émulateur NES bare-metal pour Pico W/2W et Pi 4

Un émulateur NES écrit en PureMetal fonctionne en bare-metal sur Raspberry Pi Pico W, Pico 2 W et Pi 4 sans SDK ni RTOS.

Lire l'article sur le Palmarès TRMNL →

Le développeur ajtaji propose sur GitHub NesEmulatorPicoSeries, un émulateur NTSC de la NES (Nintendo Entertainment System) conçu pour fonctionner en bare-metal sur trois plateformes : Raspberry Pi Pico W, Pico 2 W et Raspberry Pi 4. Contrairement aux solutions classiques, ce projet n’utilise ni SDK ni RTOS, mais compile directement le code en machine bare-metal grâce à l’outil PureMetalForge.

Les jeux ne sont pas intégrés au firmware. Un outil Python minimaliste permet de charger des fichiers .nes sur la mémoire flash de la carte, avec une interface graphique pour une utilisation normale et une ligne de commande pour automatiser des scripts. Pour le Pico 2 W équipé d’un RP2350, l’émulateur exploite les deux cœurs Cortex-M33 à leur fréquence nominale de 150 MHz, couplée à un SPI LCD cadencé à 75 MHz.

La gestion vidéo repose sur des plugins compilés : le modèle LAFVIN ST7796 est utilisé par défaut, mais d’autres écrans comme l’ILI9341, l’Adafruit HX8357D ou le ST7789 sont supportés à différents stades de test matériel. Côté audio, la sortie Bluetooth A2DP (SBC à 48 kHz stéréo) est assurée par le module CYW43439 du Pico, mais le firmware publié ne configure aucun haut-parleur par défaut, rendant l’émulateur muet sans modification manuelle.

Le projet inclut une suite de tests embarquée qui passe 1 926 732 vérifications sans échec sur un Pico 2 W physique. Cependant, l’émulateur n’implémente pas le PPU (Picture Processing Unit) de manière exacte et se limite aux opcodes CPU documentés. Le code est distribué sous licence MIT.
