JetKVM Mini: Remote PC Control for $39 with ESP32

A compact KVM device based on ESP32 offers remote access to a computer via HDMI, even when powered off, for under $40.

The JetKVM Mini is a KVM (keyboard, video, mouse) device designed to remotely control a computer over a local network or the internet. Powered by an ESP32 microcontroller, it accepts HDMI input and connects via USB-C for power and to emulate input devices (keyboard, mouse). The base model, priced at $39, streams video at 720p60 or 1080p30. A Wi-Fi version, offered at $42, adds wireless connectivity.

Key features include Wake-on-LAN support to power on a remote computer, a two-way clipboard for text sharing between local and remote machines, and MQTT integration for smart home setups. The firmware and software are open source, enabling self-hosted deployment instead of relying on a paid cloud service.

A paid option, JetKVM Cloud, unlocks 4K60 video streaming and faster file transfers. The device is particularly useful for remote OS installations, accessing UEFI settings, or troubleshooting machines in a home lab.
