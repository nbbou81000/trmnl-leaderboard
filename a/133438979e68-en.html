Deki Engine: Open-Source 2D Game Engine with Unity-Style Editor for ESP32

An open-source C++ 2D game engine and visual editor, optimized for ESP32, offers a Unity-like workflow for game and UI development.

Read the article on the TRMNL Leaderboard →

Deki Engine is an open-source, modular C++ 2D game engine paired with a Unity-style visual editor, designed for ESP32 microcontrollers. Released under the Apache 2.0 license, the project targets boards like the LilyGO T-Deck Plus, T-Display S3 AMOLED, and soon the CrowPanel Advanced 7″ ESP32-P4.

The editor runs on Windows and Linux, featuring an integrated compiler to generate embedded code. It enables visual scene construction (sprites, text, particles, tilemaps, state machines, tweens) before flashing directly to the target board. A desktop version using SDL3 streamlines development without hardware, while a headless mode without rendering is also available.

Performance benchmarks show 60 FPS on ESP32-S3, as demonstrated in a demo video. The engine supports various hardware features through software and hardware packages: display, touch input, keyboard, trackball, GPS, LoRa, IMU, RTC, I2S audio, Wi-Fi, and BLE. A Tiled map importer is included for compatibility with external tile editors.

Developed by Jairo Baldán (Jai), a Spanish programmer, the project leverages AI assistance, evidenced by commits co-authored by an AI tool. External analysis rates the code quality as high for a solo project. The editor, documentation, and website are available in English, Simplified Chinese, Japanese, and Korean.
