Deki Engine : un moteur 2D open source pour ESP32 avec éditeur Unity-like

Un moteur C++ 2D open source et son éditeur visuel, optimisé pour ESP32, permet de créer des jeux et interfaces graphiques avec un workflow inspiré de Unity.

Deki Engine est un moteur graphique 2D modulaire en C++ accompagné d’un éditeur visuel inspiré de Unity, conçu pour les microcontrôleurs ESP32. Le projet, entièrement open source sous licence Apache 2.0, cible des cartes comme le LilyGO T-Deck Plus, le T-Display S3 AMOLED ou prochainement le CrowPanel Advanced 7″ ESP32-P4.

L’éditeur fonctionne sous Windows et Linux et intègre un compilateur pour générer le code embarqué. Il permet de construire des scènes visuellement (sprites, texte, particules, cartes de tuiles, machines à états, animations) avant de flasher directement la carte cible. Une version desktop utilisant SDL3 facilite le développement hors cible, tandis qu’un mode headless sans rendu graphique est aussi disponible.

Les performances annoncées atteignent 60 FPS sur ESP32-S3, comme démontré dans une vidéo de démo. Le moteur prend en charge des fonctionnalités matérielles variées via des packages logiciels et matériels : affichage, tactile, clavier, trackball, GPS, LoRa, IMU, RTC, audio I2S, Wi-Fi et BLE. Un importateur de cartes au format Tiled est également intégré.

Développé par Jairo Baldán (Jai), un programmeur espagnol, le projet repose en partie sur l’assistance par IA, comme en témoignent les commits co-signés par un outil d’IA. Une analyse externe qualifie la qualité du code de élevée pour un projet solo. L’éditeur, la documentation et le site web sont disponibles en anglais, chinois simplifié, japonais et coréen.
