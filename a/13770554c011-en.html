A $4 toy robot turned into an open-source AI voice assistant

A cheap toy robot is repurposed into a responsive voice assistant using lightweight AI and hardware hacking.

Read the article on the TRMNL Leaderboard →

A $4 Silverlit Maze Breaker toy robot has been repurposed into Bot Reborn, an open-source project that responds to voice commands and holds conversations. The original robot, featuring a single motor for tracks and an electromagnet for steering, was modified by cutting a PCB trace and soldering wires to the motor and steering driver inputs. These connect to an FT232H USB-to-GPIO breakout board, allowing an Android smartphone to control the robot via Chrome's WebUSB interface.

The smartphone, mounted with cardboard and rubber bands, acts as a visual interface with an animated face and provides microphone and speaker functions. A Node.js server on a computer on the same network handles speech recognition, conversational responses, and motor commands. To avoid latency from large language models, a specialized AI model, Qwen3.5-0.8B, was trained to classify movement commands (forward, backward, left, right, stop, etc.) with 86.6% accuracy on a test set of 164 examples. This lightweight model, trained in 30 minutes on a free Google Colab GPU, responds in 200 ms on a Mac mini M4.

One issue remains: the smartphone's weight causes the small robot to tip over when reversing. An alternative solution is in development, using an ESP32-S3 microcontroller, an I2S microphone (INMP441), and an audio amplifier (MAX98357A). This new hardware can already stream audio over Wi-Fi and play responses, though it hasn't been integrated with the robot's motors yet. AI processing will still run on the computer. The project's source code, training dataset, and fine-tuned model are publicly available.
