Three Home Assistant Projects to Save Your Plants

Home Assistant automations to monitor, light, and water your plants effortlessly.

With an ESP32 and a few sensors, a simple houseplant can become a fully automated system using Home Assistant. Three practical projects demonstrate this approach, ranging from basic monitoring to fully automatic watering.

A smart plant monitor with presence detection

An ESP32 paired with capacitive moisture sensors tracks soil humidity and can trigger a visual alert (RGB LEDs) when the plant needs water. Some users enhance this by adding a mmWave presence sensor to adjust LED behavior based on room occupancy. For example, animations activate only when someone is present, with a night mode disabling LEDs when the room is empty. All logic is managed by Home Assistant, which centralizes sensor data and actions. Wiring details and hardware lists are shared by creators, but 3D-printed enclosures are not yet available.

A grow light controlled entirely by automations

Instead of manually adjusting a plant grow light, an ESP32-S3 can be wired to the control pads of a generic lamp. Using ESPHome, the lamp's physical buttons are replaced by Home Assistant automations. The lamp can turn on, off, or adjust brightness and color based on the plant's needs. Some users combine this with a moisture sensor for a more integrated system, though watering remains manual.

An automatic and optimized watering system

The Plant1337 project takes automation further by watering up to four plants from a single reservoir. Four moisture sensors monitor soil humidity, while four small aquarium pumps deliver water in pulsed doses to prevent overwatering. A software filter removes noise, and a float switch detects empty reservoirs. The creator estimates refilling the reservoir once a week is sufficient. Open-source design files (KiCad) and a parts list are available on GitHub.
