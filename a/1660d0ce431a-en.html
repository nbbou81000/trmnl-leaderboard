LT6502b: A Slimmer, Orange Retro 6502 Laptop

A minimalist 6502-based portable computer featuring an orange case and hardware upgrades.

Read the article on the TRMNL Leaderboard →

TechPaula has released the LT6502b on Codeberg, a slimmer revision of the LT6502 laptop built around the 6502 processor. This new model features an orange case and retains the original’s core architecture. The project remains a work in progress.

The memory map and layout carry over from the first LT6502, with two key changes: the expansion port has been removed, and a modem alongside a SID sound chip (a component popularized by the Commodore 64) has been integrated. These additions enhance multimedia and communication capabilities.

The build process is thoroughly documented, covering 3D case renders, a partially assembled PCB, on-screen text tests, keyboard scanning code, and a fully assembled machine. Source files and documentation are hosted on Codeberg and GitHub.
