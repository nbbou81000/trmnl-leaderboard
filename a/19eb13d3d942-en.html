Esp32sim: Run ESP32 Firmware in the Browser Without Hardware

An open-source emulator lets you run ESP32 firmware directly in the browser, with no hardware or subscription required.

The esp32sim project provides an open-source emulator for simulating four Espressif ESP32 microcontroller models, covering both CPU architectures (Xtensa and RISC-V). Unlike typical solutions, it runs real firmware, including the mask ROM, second-stage bootloader, and unmodified application image, without patches or intermediate stubs. The emulation covers enough peripherals (GPIO, UART, timers, Wi-Fi, etc.) to run complete projects with behavior close to real hardware.

Four SoCs are supported: the classic ESP32 (Xtensa LX6 dual-core), ESP32-S3 (Xtensa LX7 dual-core), ESP32-C3, and ESP32-C6 (RISC-V RV32IMAC single-core). The emulator models memories, cache controllers, shared peripherals (UART, SPI, cryptography, etc.), and interrupts, while including a virtual Wi-Fi emulator with access point and NAT. Regression tests compare software outputs to hardware behavior, with adjustments for hardware exceptions and delay loops.

Several virtual boards are available for the ESP32-S3, such as the Waveshare ESP32-S3-Touch-LCD-4B (480×480 touchscreen, GT911, audio codecs) or the Waveshare ESP32-S3-CAM-OV5640 (OV5640 camera, pedestrian detection via esp-dl). A SID synthesizer and a .sid file player are also included for audio demos. The esp32sim command-line tool allows local simulations, while a web interface (via WebAssembly) provides an interactive experience without installation.

The project is released under the MIT license and requires no account, cloud, or hardware. A demo is accessible directly in the browser at https://mikroverk.github.io/esp32sim/.
