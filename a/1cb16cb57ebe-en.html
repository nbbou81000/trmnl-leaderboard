CircuitPython 11.0.0-alpha.2: Major Updates and Security Fixes

A new alpha release of CircuitPython 11.0.0 boosts performance and adds hardware features, alongside critical security updates for Python tools.

CircuitPython 11.0.0-alpha.2, released by Adafruit, represents a significant milestone for this Python distribution designed for microcontrollers. This alpha update, still in development, introduces major speed optimizations, particularly for displayio (the display system), along with firmware size reductions. It also adds support for new hardware components like the Espressif ESP32-S31 and ESP32-P4 microcontrollers.

Notable features include storage.map_file, which now allows direct reading of files from mapped flash memory, and usb_host_audio.USBIn, which supports USB microphones. The RGBMatrix system now supports ABC row addressing, and native support for USB Host Bulk IN transfers has been added. For Zephyr, several modules such as analogio, bitbangio, and pwmio are now available.

Meanwhile, security vulnerabilities have been reported in eMudhra intermediate certificates, leading to the removal of the emSign root CA certificate from trust bundles like certifi. Several Python tools must be updated immediately to prevent man-in-the-middle (MITM) attacks: certifi 2026.10.19, pip 26.2.2, uv 0.13.4, sigstore 4.5.1, conda 26.9.4, and pixi 0.82.1.
