Exodium: Open-Source Launcher to Play eXo DOS Games on Mac

A free and open-source launcher lets you play eXo collections on Mac Apple Silicon, Linux, and Windows.

Exodium is a free and open-source launcher designed to replace LaunchBox on Mac Apple Silicon, Linux, and Windows. It provides access to eXo’s retro game collections, including eXoDOS, eXoWin3x, eXoWin9x, and eXoScummVM, all from a single unified interface.

Games are downloaded on demand via official eXo torrents, eliminating the need to download entire collections upfront. Once selected, a game is fetched and launched automatically in the appropriate emulator. For DOS, Windows 3.x, and ScummVM collections, the app uses DOSBox Staging (outside Windows), while titles configured for DOSBox ECE (an optimized variant) switch to this version under Windows for maximum compatibility.

The interface includes detailed game cards with embedded video previews, box scans, manuals, and background music in MT-32 or General MIDI. Users can customize their experience with CRT shaders, adjust CPU cycles, or manually edit DOSBox configurations. For Windows 95/98 collections (eXoWin9x), Exodium downloads a full 2.5 GB system image and runs Windows 95/98 inside DOSBox-X or 86Box.

Exodium also functions as a BitTorrent client: by default, it shares data with other users while running. This feature can be disabled in the network settings. In offline mode, if the collection is already locally available, the torrent client does not launch.

Installation on macOS is limited to Apple Silicon Macs, as the app is not signed by Apple. Users must bypass Gatekeeper using the command xattr -cr /Applications/Exodium.app or via the Sentinel tool. On Linux, Exodium complements eXoDOS’s official patches, particularly for eXoWin3x, eXoWin9x, and eXoScummVM collections, which are not covered by native solutions.
