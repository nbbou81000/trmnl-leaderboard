Exodium : un lanceur open source pour jouer aux jeux DOS eXo sur Mac

Un lanceur gratuit et open source permet de jouer aux collections eXo sur Mac Apple Silicon, Linux et Windows.

Lire l'article sur le Palmarès TRMNL →

Exodium est un lanceur gratuit et open source conçu pour remplacer LaunchBox sur Mac Apple Silicon, Linux et Windows. Il permet d’accéder aux collections de jeux rétro eXo, comme eXoDOS, eXoWin3x, eXoWin9x et eXoScummVM, directement depuis une interface unifiée.

Les jeux se téléchargent à la demande via des torrents officiels d’eXo, sans nécessiter de téléchargement préalable de l’intégralité de la collection. Une fois le jeu sélectionné, il est récupéré et lancé automatiquement dans l’émulateur adapté. Pour les collections DOS, Windows 3.x et ScummVM, l’application utilise DOSBox Staging (hors Windows), tandis que les titres configurés pour DOSBox ECE (une variante optimisée) basculent automatiquement vers cette version sous Windows pour une compatibilité maximale.

L’interface propose des fiches détaillées pour chaque jeu, incluant des captures vidéo intégrées, des scans de boîtes, des manuels et des musiques de fond en MT-32 ou General MIDI. Les utilisateurs peuvent personnaliser l’expérience avec des shaders CRT, ajuster les cycles CPU ou modifier manuellement la configuration de DOSBox. Pour les collections Windows 95/98 (eXoWin9x), Exodium télécharge un système complet de 2,5 Go et un Windows 95/98 fonctionnant sous DOSBox-X ou 86Box.

Exodium agit également comme un client BitTorrent : par défaut, il partage des données avec d’autres utilisateurs tant qu’il reste ouvert. Cette fonction peut être désactivée dans les paramètres réseau. En mode hors ligne, si la collection est déjà présente localement, le client torrent ne se lance pas.

L’installation sous macOS est réservée aux Mac Apple Silicon, avec une application non signée par Apple. Les utilisateurs doivent contourner Gatekeeper en utilisant la commande xattr -cr /Applications/Exodium.app ou via l’outil Sentinel. Sous Linux, Exodium complète les patchs officiels d’eXoDOS, notamment pour les collections eXoWin3x, eXoWin9x et eXoScummVM, absentes des solutions natives.
