An AI Framework to Automatically Write and Test ESP32 Code on Real Hardware

An open-source framework automates ESP32 firmware generation and testing using AI and a Raspberry Pi, with real-time hardware validation.

Read the article on the TRMNL Leaderboard →

Andreas Spiess has developed the Embedded AI Harness, an open-source tool that merges artificial intelligence with hardware testing to automate ESP32 firmware development. The system first generates an initial firmware version using AI, then runs automated tests on an ESP32 connected to a Raspberry Pi testbench. Test results are fed back into the process to refine the firmware until it meets the required specifications.

The workflow includes four tiers of testing, with fault injection to assess how the firmware handles simulated hardware or software failures. Firmware compilation relies on ESP-IDF, Espressif’s official framework for ESP32 microcontrollers. Automation of the workflow steps is handled by GitHub Actions, which manages continuous integration for the project.

A sample project demonstrates a smart meter sensor that decodes MBus data, publishes it via MQTT, provides a captive portal for setup, and supports over-the-air updates. The project is detailed in a video and on geeky-gadgets.com.
