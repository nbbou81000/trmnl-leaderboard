Un framework IA pour écrire et tester automatiquement du code ESP32 sur matériel réel

Un framework open source automatise la génération et les tests de firmware ESP32 via IA et Raspberry Pi, avec validation matérielle en temps réel.

Lire l'article sur le Palmarès TRMNL →

Andreas Spiess propose l'Embedded AI Harness, un outil qui combine intelligence artificielle et tests matériels pour développer du firmware ESP32 sans intervention manuelle. Le système génère d’abord une première version du code via IA, puis exécute des tests automatisés sur un ESP32 connecté à un banc d’essai Raspberry Pi. Les résultats des tests sont réinjectés dans le processus pour affiner le firmware jusqu’à ce qu’il respecte les spécifications.

Le workflow s’appuie sur quatre niveaux de tests, incluant l’injection de fautes pour évaluer la robustesse du code face à des défaillances matérielles ou logicielles simulées. Le firmware est compilé avec ESP-IDF, le framework officiel d’Espressif pour les microcontrôleurs ESP32. L’automatisation des étapes est assurée par GitHub Actions, qui gère l’intégration continue du projet.

L’exemple fourni illustre un capteur de compteur intelligent capable de décoder des données MBus, de les publier via MQTT, d’offrir un portail captif pour la configuration et de supporter les mises à jour over-the-air. Le projet est documenté dans une vidéo et sur le site geeky-gadgets.com.
