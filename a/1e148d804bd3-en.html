OpenTrailPaper: DIY E-Ink Bike Computer with ESP32-S3

Open-source project turns an e-paper devkit into a standalone bike computer with offline maps and sensor support.

Read the article on the TRMNL Leaderboard →

OpenTrailPaper is an open-source project that turns the LILYGO T5 E-Paper S3 Pro development kit into a standalone e-paper bike computer. The devkit features an ESP32-S3 module, a dual-core microcontroller running up to 240 MHz with Wi-Fi 4 and Bluetooth 5.0 LE connectivity. The 4.7-inch e-paper display offers a 960×540 resolution with 16 shades of gray and capacitive touch input.

The custom firmware enables real-time ride data display, offline map navigation using GPX (GPS Exchange Format) routes, and FIT file recording (a format used by Garmin devices). A microSD card slot provides local storage for maps. Bluetooth connectivity supports pairing with external sensors like heart rate monitors, power meters, and cadence sensors. Future updates will add support for ANT/ANT+ protocols.

Companion mobile apps for Android and iOS allow users to configure settings, import maps, and manage routes. The project emphasizes autonomy, ensuring the bike computer remains functional without relying on a smartphone during rides.
