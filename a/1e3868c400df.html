Récupérer le contrôle d’un OSD dans un écran composite bon marché

Un bricoleur a détourné le circuit d’affichage intégré d’un écran de caméra pour l’utiliser comme tableau de bord personnalisé.

Un passionné d’électronique, derrière le projet Ogrinz Labs, a transformé un écran de caméra de recul automobile en solution d’affichage pour un costume robotisé inspiré de Robbie le Robot. L’écran, initialement destiné à afficher le flux vidéo de la caméra, intégrait un circuit AMT630A, un composant combinant un commutateur vidéo, un système graphique pour l’affichage à l’écran (OSD) et un microcontrôleur 8052.

Après des mois de reverse engineering, il a réussi à interagir avec ce circuit via un port I2C depuis un microcontrôleur ESP32, sans parvenir à exploiter pleinement le cœur 8052. Le résultat permet d’afficher des graphiques personnalisés, comme des données de navigation, pour assister le pilotage du costume. Une bibliothèque Arduino dédiée a été publiée sur GitHub pour faciliter la réutilisation de ce composant.

Le AMT630A est un circuit intégré spécialisé dans la superposition d’informations graphiques sur un flux vidéo, une fonctionnalité courante dans les écrans de surveillance ou les moniteurs embarqués. L’OSD (On-Screen Display) permet d’ajouter des éléments comme des menus, des icônes ou des données techniques sans modifier le signal vidéo principal. Le microcontrôleur 8052, bien que non exploité ici, est un classique des années 1980 encore utilisé dans certains systèmes embarqués.
