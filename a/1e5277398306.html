Un moniteur terminal pour SDR écrit en Rust et open source

Un outil open source en Rust pour surveiller en temps réel les signaux radio via SDR, compatible avec plusieurs matériels.

Lire l'article sur le Palmarès TRMNL →

MusiThang a publié sdrtool, un moniteur terminal dédié aux équipements de radio logicielle (SDR). Développé en Rust, ce projet affiche un spectre, un graphique de type waterfall et des instruments de mesure dans une session tmux, un terminal SSH ou un écran compact comme ceux des cyberdecks. Les indicateurs incluent une estimation du bruit selon le modèle de Friis, une mesure de bande passante centrée sur la porteuse plutôt que sur toute la plage capturée, et un niveau de bruit exprimé en densité pour éviter les variations liées au taux d'échantillonnage.

Dès qu'un récepteur SDR cesse de fonctionner, les panneaux de mesure se marquent automatiquement comme [STALE]. Le projet a été testé sur du matériel réel : HackRF One, RTL-SDR et tinySA Ultra ZS405. D'autres périphériques compatibles avec SoapySDR devraient fonctionner, mais le backend a été conçu à partir de l'API plutôt que testé sur chaque appareil. Seule une configuration avec HackRF via SoapyHackRF a été validée.

Des fonctionnalités supplémentaires sont en cours de développement, comme le décodage RDS (sous-porteuse FM à 57 kHz) et la détection de réseaux Bluetooth classiques via leur code d'accès. Le logiciel nécessite un système Linux, une installation via un script dédié, et une version de Rust 1.88 ou supérieure avec un compilateur C. Disponible sur GitHub et crates.io, le projet en est encore à ses débuts.
