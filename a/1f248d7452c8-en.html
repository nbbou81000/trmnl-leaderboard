ESP32-S31: Official Linux Support on a 320 MHz RISC-V Microcontroller

Espressif officially supports Linux on the ESP32-S31, a 320 MHz RISC-V microcontroller with MMU, Wi-Fi 6, and Bluetooth 5.4.

The ESP32-S31, a dual-core RISC-V microcontroller running up to 320 MHz, breaks new ground by including a memory management unit (MMU) and official Linux support. Unlike typical microcontrollers, this MMU enables virtualization and privilege separation between the kernel and user applications, making it possible to run a full Linux kernel instead of a stripped-down version.

Espressif provides an official Linux 6.18 development branch for the ESP32-S31, currently in developer preview. To streamline deployment, the GrieferPig project offers an unofficial port with precompiled images that can be flashed directly onto compatible development boards. This version includes partial support for symmetric multiprocessing, persistent storage, Wi-Fi, Bluetooth, GPIO, and UART. Some features like I2C, SPI, Ethernet, USB gadget mode, and audio interfaces remain experimental, while others are already stable.

The system includes BusyBox, providing a familiar command-line environment. However, hardware limitations remain significant: limited memory, no GPU, and insufficient power for graphical environments. While the ESP32-S31 won’t replace a Raspberry Pi, this milestone opens new possibilities for embedded projects requiring a full OS, such as network gateways or advanced control systems.
