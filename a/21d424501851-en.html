5 No-Code ESP32 Projects with ESPHome for Your Smart Home

Five ready-to-use projects to turn an ESP32 into a smart home tool without writing a single line of code.

Read the article on the TRMNL Leaderboard →

With ESPHome, you can configure an ESP32 for smart home tasks without writing any code. Five ready-made projects are available directly from a browser, requiring only a few clicks to get started.

Control Bluetooth devices remotely

An ESP32 can act as a relay between a Home Assistant server with Bluetooth and Bluetooth devices out of direct range. This Bluetooth proxy transmits commands between both, extending the wireless network’s reach. Configuration is done via the ESPHome interface by selecting a generic ESP32 and following on-screen instructions.

Build a local voice assistant

To avoid cloud-based voice assistants, an ESP32 can be turned into a voice interface for Home Assistant. The project supports kits like the M5Stack Atom Echo or ESP32-S3-BOX. Once connected to a computer, Home Assistant’s Assist voice assistant can be set up to run local commands or integrate with a local language model.

Turn a smart speaker into a dedicated audio player

The Home Assistant Voice: Preview Edition, an open-source smart speaker, can be repurposed as a dedicated audio player using an ESPHome project. By connecting an external speaker via the aux port and using the built-in rotary dial, you can control volume and stream music. Multiple devices can be synchronized for multi-room audio via Music Assistant.

Control IR and RF devices

Older devices using infrared (IR) or radio frequency (RF) remotes can be integrated into Home Assistant via an ESP32. For IR, a XIAO IR Mate emitter is needed, while RF control requires an M5Stack Atom Lite kit paired with a 433 MHz RF unit. These modules act as proxies to send commands from Home Assistant.

Read smart meter data

Industrial devices or some energy meters use the Modbus protocol over a RS-485 serial connection. An ESP32 with an M5Stack AtomS3 Lite and an RS485 base can create a serial proxy, making this data accessible to Home Assistant. This includes energy meters, solar inverters, or heat pumps.
