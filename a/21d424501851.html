5 projets ESP32 sans code avec ESPHome pour votre domotique

Cinq projets prêts à l'emploi pour transformer un ESP32 en outil domotique sans écrire une ligne de code.

Lire l'article sur le Palmarès TRMNL →

Avec ESPHome, il est possible de configurer un ESP32 pour des tâches domotiques sans maîtriser la programmation. Cinq projets clés en main sont disponibles directement depuis un navigateur, ne nécessitant que quelques clics pour être opérationnels.

Contrôler des appareils Bluetooth à distance

Un ESP32 peut servir de relais entre un serveur Home Assistant équipé de Bluetooth et des appareils Bluetooth situés hors de portée directe. Ce proxy Bluetooth permet de transmettre les commandes entre les deux, étendant ainsi la portée du réseau sans fil. La configuration se fait via l’interface ESPHome en sélectionnant un ESP32 générique et en suivant les instructions à l’écran.

Créer un assistant vocal local

Pour éviter les assistants vocaux cloud, un ESP32 peut être transformé en interface vocale pour Home Assistant. Le projet prend en charge des kits comme l’M5Stack Atom Echo ou l’ESP32-S3-BOX. Une fois connecté à un ordinateur, l’assistant vocal Assist de Home Assistant peut être configuré pour exécuter des commandes locales ou s’appuyer sur un modèle de langage local.

Transformer un haut-parleur en lecteur audio dédié

Le Home Assistant Voice: Preview Edition, un haut-parleur intelligent open source, peut être reconfiguré en lecteur audio dédié grâce à un projet ESPHome. En branchant un haut-parleur externe via la prise auxiliaire et en utilisant le bouton rotatif intégré, il est possible de gérer le volume et de diffuser de la musique. Plusieurs appareils peuvent être synchronisés pour une diffusion multi-pièces via Music Assistant.

Piloter des appareils IR et RF

Les appareils anciens utilisant des télécommandes infrarouges (IR) ou radiofréquences (RF) peuvent être intégrés à Home Assistant via un ESP32. Pour l’IR, un XIAO IR Mate émet des signaux, tandis que pour le RF, un kit M5Stack Atom Lite associé à une unité RF 433 MHz est requis. Ces modules agissent comme des proxys pour envoyer des commandes depuis Home Assistant.

Lire des données de compteurs intelligents

Les appareils industriels ou certains compteurs d’énergie utilisent le protocole Modbus via une connexion série RS-485. Un ESP32 équipé d’un M5Stack AtomS3 Lite et d’une base RS485 permet de créer un proxy série, rendant ces données accessibles à Home Assistant. Cela inclut les compteurs d’énergie, les onduleurs solaires ou les pompes à chaleur.
