An ESP32 Module to Display Flying Planes on an E-Ink Screen with Tesserae

A Tesserae module turns an e-ink screen into a real-time aircraft tracking dashboard.

Read the article on the TRMNL Leaderboard →

The Overhead Tesserae project displays aircraft flying over a selected area on an e-ink screen. Created by user xDaftTurtle and integrated into the Tesserae ecosystem, this module fetches public flight data to generate stylized illustrations of planes in real time.

Plane images are generated from photos sourced on planespotters.net, with their size scaled to the aircraft's wingspan. Users can select from 26 different graphic styles (vintage airline poster, engraving, woodblock print, pixel art, etc.) or add their own custom styles. An option also allows displaying the original photos directly.

This module runs on an ESP32 microcontroller and integrates with the Tesserae software, previously used for similar projects like digital frames showing birds. Flight data is pulled from public services and converted into e-ink-friendly images, providing an autonomous and visually appealing way to track local air traffic.

Source code and setup instructions are available on the Overhead Tesserae GitHub page.
