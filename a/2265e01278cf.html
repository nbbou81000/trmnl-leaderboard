Un module ESP32 pour afficher les avions sur écran e-ink avec Tesserae

Un module pour Tesserae transforme un écran e-ink en tableau de bord de suivi des avions en temps réel.

Lire l'article sur le Palmarès TRMNL →

Le projet Overhead Tesserae permet d’afficher les avions survolant une zone choisie sur un écran à encre électronique (e-ink). Développé par l’utilisateur xDaftTurtle et intégré à l’écosystème Tesserae, ce module récupère les données de vol publiques pour générer des illustrations stylisées des appareils en temps réel.

Les images des avions sont générées à partir de photos référencées sur planespotters.net, avec une taille proportionnelle à l’envergure de l’appareil. L’utilisateur peut choisir parmi 26 styles graphiques différents (affiche vintage, gravure, estampe japonaise, pixel art, etc.) ou ajouter ses propres styles personnalisés. Une option permet aussi d’afficher directement les photos originales.

Ce module s’appuie sur un microcontrôleur ESP32 et s’intègre au logiciel Tesserae, déjà utilisé pour des projets similaires comme des cadres numériques affichant des oiseaux. Les données de vol sont récupérées via des services publics et converties en images adaptées à l’écran e-ink, offrant une solution autonome et esthétique pour suivre le trafic aérien local.

Le code et les instructions détaillées sont disponibles sur la page GitHub du projet Overhead Tesserae.
