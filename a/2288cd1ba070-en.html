Romu: Ultra-Compact USB Board Based on RP2354A Launches Crowdfunding

A tiny development board that slots directly into a USB Type-A port, powered by Raspberry Pi’s RP2354A, has launched crowdfunding.

Bitmerse, an Indian startup, has launched crowdfunding for the Romu, an ultra-compact development board designed to plug directly into a USB Type-A port without cables or external programmers. According to its creators, Jaydeep Dhrangdhariya and Dhrumil Doshi, the board is "purpose-built for fast, approachable USB application development," allowing users to run MicroPython code minutes after plugging it in.

The Romu is powered by the Raspberry Pi RP2354A, a variant of the RP2350 (found on the Pico 2) with 2MB of onboard flash. The chip features two Arm Cortex-M33 cores running up to 150MHz and two open-source Hazard3 RISC-V cores, usable simultaneously. Bitmerse highlights the Arm cores with a default MicroPython firmware but also offers an alternative converting the board into a FIDO2 and Passkey authentication dongle.

While the lack of exposed GPIO pins limits expandability, the board includes a programmable LED, a capacitive button, and native USB connectivity. Potential applications include macro keyboards, security keys, MIDI controllers, or status indicators. An optional debug module ($65) provides access to UART, USB, and SWD functions via pogo pins.

The crowdfunding campaign on Crowd Supply offers the Romu for $40 (excluding shipping) before volume discounts. Shipments are expected in April 2027, though crowdfunding fulfillment is not guaranteed. Bitmerse has released design files (PCB, schematics, BOM), STL files for the enclosure, and MicroPython examples on GitHub under the CERN OHL v2 and MIT licenses.
