DIY Walkie-Talkies with ESP32-S3 and ESP-NOW for Audio

Build walkie-talkies without a smartphone using an ESP32-S3 and the ESP-NOW protocol to transmit real-time audio.

Read the article on the TRMNL Leaderboard →

This project involves building DIY walkie-talkies using a Feather ESP32-S3 Reverse TFT module, compatible with the Arduino environment. The system relies on the ESP-NOW protocol, a Wi-Fi and Bluetooth-free solution designed for data exchange between ESP32 devices. In this case, it transmits audio packets in I2S format, enabling real-time voice communication.

Each transmission can last up to 10 seconds, making it suitable for short and efficient exchanges. To extend range, a w.FL antenna is added, improving signal reception both indoors and outdoors. The detailed assembly guide explains step-by-step how to set up the components, program the ESP32-S3, and configure the ESP-NOW protocol for smooth communication.
