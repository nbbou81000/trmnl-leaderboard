FloppoScope: A Tool to Analyze Retro Floppy Disk Images

A browser-based tool to inspect floppy disk images, supporting a wide range of retro and modern formats.

Read the article on the TRMNL Leaderboard →

FloppoScope is a web-based utility for analyzing floppy disk images, supporting formats from old PCs, Apple, Amiga, Atari, BBC Micro, and even niche systems like Sharp MZ or NeXTSTEP. The tool generates a color-coded visual map of the disk’s layout, displaying file structures and filesystem details. It also allows previewing common file types directly in the browser.

The software identifies bad sectors, detects corrupted files, and generates detailed reports. It handles both standard image files and flux files (*.flux), ensuring compatibility regardless of how the disks were originally captured. All processing occurs locally, meaning the analyzed data never leaves the user’s machine.

This project is aimed at retro computing enthusiasts or anyone preserving floppy disk archives, whether personal or professional. It streamlines the exploration of diverse formats, including lesser-known standards, and simplifies converting between different image types.
