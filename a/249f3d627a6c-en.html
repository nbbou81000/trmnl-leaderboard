Monster Eyes That Track Motion Using a Webcam and Python

A CircuitPython project turns a webcam into a real-time motion-tracking system for animated monster eyes.

Read the article on the TRMNL Leaderboard →

This project, featured in an Adafruit Learning System guide, demonstrates how to create animated monster eyes that track motion detected by a USB webcam. The system relies on a Fruit Jam board, which is compatible with CircuitPython, to process captured images in real time.

The CircuitPython code leverages optimization modules like Turbo to speed up two critical tasks: rendering the monster eyes and checking for new motion in the webcam frames. The eyes' animation dynamically adjusts to the position of moving objects or people in front of the camera, delivering a striking visual effect.

The project is designed to be accessible to beginners and experienced makers alike, with clear documentation and ready-to-use code examples. No advanced computer vision skills are required, thanks to simplified libraries integrated into CircuitPython.
