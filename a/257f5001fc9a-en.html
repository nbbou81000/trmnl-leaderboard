Nokia 3310: Custom Game on Dedicated PCB and Browser

A developer replaces a Nokia 3310's motherboard with a custom PCB to run a retro game in Go, available on hardware and browser.

Read the article on the TRMNL Leaderboard →

For the Nokia 3310 Jam competition, Hoani Bryson took first place with Trick Shot II, a game designed as if it were developed for the classic phone. Instead of using official tools, he opted for a radical approach: dismantling a Nokia 3310 and installing a custom PCB to replace the original motherboard. This modification bypasses the phone’s technical limitations while preserving its look and controls.

The game adheres to the contest’s constraints: monochrome 84×48 pixel display, sound limited to a single buzzer, and control via the 12 physical buttons. Bryson also created a web-based version of the game, accessible from a browser, using an open-source game engine written in Go. This engine relies on Ebitengine for desktop and web applications, and TinyGo for embedded devices. The architecture separates game logic from hardware-specific functions, making cross-platform porting easier.

The project is fully documented on Hoani.net, and an online demo is available. The source files and instructions for reproducing the custom PCB are shared, allowing enthusiasts to draw inspiration or contribute to development.
