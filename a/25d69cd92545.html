Un Raspberry Pi transforme un dock USB en testeur automatique de disques durs

Un projet DIY transforme un Raspberry Pi et un dock USB en station de test automatique pour disques durs, avec notifications Telegram.

Lire l'article sur le Palmarès TRMNL →

Pour éviter les mauvaises surprises avec des disques durs défaillants, un maker a conçu DriveCheck, un outil automatisé fonctionnant sur Raspberry Pi. L’objectif : tester systématiquement les disques avant de les utiliser, notamment après un stockage prolongé ou un transport.

Le système repose sur un dock USB pour disques durs connecté à un Raspberry Pi, configuré en mode headless (sans écran). L’installation se fait via un fichier unique qui déploie à la fois une interface web (port 8765) et un bot Telegram pour les notifications. L’utilisateur peut aussi opter pour un webhook Discord, mais Telegram offre plus de fonctionnalités.

Dès qu’un disque est inséré dans le dock, DriveCheck lance automatiquement une série de tests : un test SMART court pour évaluer l’état général du disque, suivi d’un test de vitesse de lecture. Une option permet d’exécuter un test étendu (plusieurs heures, voire plus d’une journée), utile pour les disques suspects. Le logiciel ignore les disques déjà montés pour éviter tout risque sur le système principal.

L’interface web affiche les résultats clés des tests SMART, tandis que Telegram envoie des alertes à chaque étape (début/fin de scan, options disponibles). Le bot propose aussi des actions comme un formatage rapide, un effacement complet ou un formatage via le firmware du disque. Le disque est éjecté automatiquement après un délai configurable.

Ce projet simplifie grandement la vérification des disques, remplaçant une procédure manuelle fastidieuse par un processus automatisé et sans intervention.
