ESP_MOVIE: Play Videos on ESP32 Using Motion JPEG

An open-source library to play Motion JPEG videos and MP3 audio on ESP32, without SPI.

Read the article on the TRMNL Leaderboard →

Tomino Shun has released ESP_MOVIE, an open-source library for playing videos on ESP32 microcontrollers. It supports AVI files encoded in Motion JPEG (MJPEG) for video and MP3 for audio. Unlike typical solutions, this library does not use SPI to drive the display. Instead, it relies on an Intel 8080 8-bit parallel interface with DMA (Direct Memory Access) transfers for improved performance.

The supported color formats are RGB565 and BGR565, ensuring compatibility with a wide range of display controllers. Several display controllers have already been tested successfully, while others compatible with MIPI DCS may work without confirmation. The GitHub repository includes an examples folder with ready-to-use AVI (Motion JPEG), MP3, and JPEG files for immediate testing.
