Matrix, an Open-Source Alternative to Discord to Avoid Age Verification

Matrix, a decentralized and open-source protocol, enables the creation of self-hosted chat servers, offering an alternative to Discord amid its controversial policies.

In response to Discord’s controversial decisions, such as mandatory age verification, many are seeking alternatives. Matrix, an open-source and decentralized communication protocol, stands out as a robust solution. Unlike Discord, a closed platform subject to corporate decisions, Matrix is built on an open standard. Its main server and client software, like Synapse for the server and Element for the client, are open source, enabling customization and integration with other compatible systems.

A decentralized and flexible architecture

Matrix operates as a federated network: servers can communicate with each other, but no single server controls the entire system. This structure resembles IRC or ActivityPub (used by Mastodon or Lemmy). Users can host their own server or join public servers like matrix.org, which offers immediate access without complex setup. Federation allows users on different servers to chat in the same rooms, while the absence of a central server reduces risks of censorship or widespread outages.

Matrix also provides bridges to connect other platforms like Discord, IRC, or XMPP. This feature enables gradual migration, allowing users to communicate with contacts on other services without abrupt disruption.

Technical setup and limitations

Setting up a Matrix server requires more effort than creating a Discord server. The Synapse server can run on a standard Linux distribution or in an LXC container. For external accessibility, a Cloudflare tunnel suffices for text, but voice and video calls complicate the setup. Two additional servers are initially required: a TURN server for legacy calls and a LiveKit server for modern calls. Managing video calls may also face internet service provider restrictions (NAT), sometimes requiring a VPS with a public IP to host the TURN server. Modern video calls, which are resource-intensive, must be hosted on the main server, potentially limiting performance depending on hardware configuration.
