Create Digital Sand with LEDs and CircuitPython

A guide to simulate animated sand grains using LEDs and CircuitPython.

Read the article on the TRMNL Leaderboard →

The PixelDust project, created by PaintYourDragon, offers a software library to simulate digital sand grains. This system, detailed in an Adafruit Learning System tutorial, enables the creation of interactive animations where glowing pixels mimic falling and accumulating sand behavior.

The concept relies on addressable LEDs, such as DotStar LEDs, controlled via a CircuitPython-compatible microcontroller. Sand grains are represented by light points that react to interactions like blowing or touching, simulating natural movement. The tutorial includes specific demos for the Arcada board, designed for interactive display projects.

The approach leverages the silicon-based nature of LEDs, described as "digital sand." The animation uses simple simulated physics algorithms, where each pixel follows gravity and collision rules to produce realistic behavior. The code is open and modifiable, allowing users to experiment with different speeds, colors, or grain densities.
