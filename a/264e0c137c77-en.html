Streaming PC Games to a 2008 Nintendo DSi via Homebrew

A homebrew app turns a 2008 Nintendo DSi into a streaming screen for Linux PC games, using MJPEG video and remote control.

A homebrew app called RNDS-Stream streams Linux PC games to a 2008 Nintendo DSi by capturing the game window and sending it as an MJPEG video over the local network. The console decodes the stream and displays it, while the PC’s keyboard and mouse are controlled remotely using ydotool.

Performance-wise, the stream can reach 20 frames per second with frame skipping or 10 to 15 frames per second at maximum resolution on the DSi. The Linux server, running under X11 or Wayland, uses GStreamer for streaming and wmctrl to detect windows. The project relies on RubyNDS, a Ruby framework for DSi programming.

To run, the setup requires a flashcart to launch the tool from a microSD card. A rnds-stream.txt file must be placed at the root of the card, containing only the local IP address of the PC. The DSi’s Wi-Fi is limited to WEP or open networks, as WPA/WPA2 is not supported in DS mode. The project is experimental, with bugs and no security features—use it only on a local network.

The server automatically detects Steam libraries and Prism Launcher instances to launch games. The developer tested it only on Fedora KDE, and compatibility with other distributions is not guaranteed.
