HaloBattery: A Free Tool to Monitor Device Batteries on Windows

An open-source utility displays device battery levels directly in the Windows taskbar, without manufacturer software.

Read the article on the TRMNL Leaderboard →

HaloBattery is a free and open-source utility designed to display the battery levels of all connected devices on a Windows PC, directly in the notification area. The tool supports dongles, USB cables, controllers (such as Xbox models), and Bluetooth devices, bypassing proprietary manufacturer software.

Each device is represented by an icon in the taskbar. A colored ring around the icon indicates the battery status: white for full, orange for medium, red for critical, and green while charging. Hovering over the icon reveals the exact percentage. The tool interacts directly with devices through USB dongles, controller reports, or Bluetooth data, eliminating the need for intrusive third-party software.

Compatibility is partial: Logitech’s G502 mice are officially supported, while devices like DualSense, DualShock 4, or some Razer models already work. Corsair or the Razer BlackWidow V3 Pro have not been tested yet. For unsupported devices, a Diagnostics menu generates a report to request support via GitHub.

To use it, simply extract the archive into a folder containing the _internal subfolder, then launch the executable via right-click and the "Run with Windows" option. The tool aims to simplify battery management and prevent last-minute failures before gaming sessions or intensive use.
