HaloBattery : un outil gratuit pour surveiller les batteries de vos périphériques sous Windows

Un utilitaire open source affiche le niveau de batterie de vos périphériques directement dans la barre des tâches Windows, sans logiciel constructeur.

Lire l'article sur le Palmarès TRMNL →

HaloBattery est un utilitaire gratuit et open source conçu pour afficher le niveau de batterie de tous vos périphériques connectés à un PC sous Windows, directement dans la zone de notification. L'outil prend en charge les dongles, câbles USB, manettes (comme les Xbox) et appareils Bluetooth, en contournant les logiciels propriétaires des fabricants.

Chaque périphérique est représenté par une icône dans la barre des tâches. Un anneau coloré autour de l'icône indique l'état de la batterie : blanc pour plein, orange pour moyen, rouge pour critique, et vert lors de la charge. En survolant l'icône, un pourcentage exact s'affiche. L'outil interagit directement avec les périphériques via les dongles USB, les rapports des manettes ou les données Bluetooth, évitant ainsi l'installation de logiciels tiers souvent intrusifs.

La compatibilité reste partielle : chez Logitech, seules les souris G502 sont officiellement supportées, tandis que des périphériques comme les DualSense, DualShock 4 ou certains modèles Razer fonctionnent déjà. Corsair ou le Razer BlackWidow V3 Pro ne sont pas encore testés. Pour les appareils non reconnus, un menu Diagnostics génère un rapport utilisable pour demander un support via GitHub.

Pour l'utiliser, il suffit de décompresser l'archive dans un dossier contenant le sous-dossier _internal, puis de lancer l'exécutable via un clic droit et l'option "Lancer avec Windows". L'outil est conçu pour simplifier la gestion des batteries et éviter les pannes de dernière minute avant une session de jeu ou une utilisation intensive.
