Le code machine en emojis : une Hello World en UTF-8

Un développeur crée un programme exécutable entièrement composé d’emojis, valide sur les processeurs 8086.

Lire l'article sur le Palmarès TRMNL →

Un chercheur a découvert que certains emojis, interprétés comme des instructions machine, forment un code exécutable valide sur les processeurs Intel 8086 et 8088. Le symbole de la chèvre (🐐) correspond à la séquence F0 9F 90 90, où 90h est une instruction nop (aucune opération), tandis que F0 9F forme l’instruction lock lahf, sans effet pratique sur ces architectures. Cette observation a ouvert la voie à la création de programmes fonctionnels composés uniquement d’emojis.

Un exemple concret est une application Hello World écrite sous forme de chaîne d’emojis. Enregistrée dans un fichier avec l’extension .com et exécutée dans DOSBox avec un processeur configuré en 8086, elle affiche le message HELLO à l’écran en écrivant directement dans la mémoire vidéo. D’autres démonstrations, comme un programme graphique VGA utilisant des emojis, sont disponibles dans le billet original. Les détails techniques et des conseils pour concevoir ses propres programmes en emojis y sont également partagés.

Cette approche rappelle des techniques historiques, comme l’inclusion de code machine dans des programmes BASIC via des REM contenant des caractères ASCII, permettant des actions non prévues par le langage. Les emojis, bien que moins flexibles que les caractères ASCII, offrent une alternative ludique et visuelle pour explorer l’exécution de code bas niveau.
