Enkiplate: A Japanese Flashcard System for e-Ink Displays

An open-source project turns an e-ink screen into a Japanese flashcard system with customizable learning tools.

Read the article on the TRMNL Leaderboard →

Peter Hraska has created Enkiplate, an open-source application designed for the Inkplate 4TEMPERA e-ink display. The tool teaches Japanese using interactive flashcards: users read a card, tap the screen to reveal the answer, and then rate their performance. A scheduling algorithm determines which cards need review, while additional details appear at the top of the screen, including current temperature and the next three calendar events.

The project runs on an Inkplate 4TEMPERA featuring a 600 x 600-pixel touchscreen, an ESP32 microcontroller, 4 MB of flash memory, and PSRAM. Other Inkplate models would require firmware adjustments. A companion service runs on a host machine, generating 3-bit images (with typography and paper textures) and sending them to the device over WiFi or USB. The system has been tested on macOS, but Windows is not supported.

Enkiplate imports the JMdict English dictionary and allows users to add custom vocabulary or sentences. Weather data comes from Open-Meteo, while calendar events are fetched from a private .ics feed, excluding all-day or canceled events. Before saving new entries, the system checks their display on the screen to ensure readability. The code is MIT-licensed, while fonts and dictionary data are subject to their own terms.
