New DMA Driver for SM16380 HUB75 LED Panels on ESP32-S3

An open-source driver enables flicker-free 67 FPS animations on SM16380 HUB75 LED panels with ESP32-S3.

Read the article on the TRMNL Leaderboard →

A developer named StubbyDevs has released an open-source driver on GitHub for HUB75 LED panels using SM16380 S-PWM column drivers, optimized for the ESP32-S3. The driver leverages the chip’s LCD_CAM peripheral in i80 mode, combined with a GDMA controller.

Unlike standard shift-register-based HUB75 panels, SM16380-driven displays feature dedicated frame buffers per driver chip, generating their own PWM signals. This design makes traditional HUB75 libraries ineffective. The new driver bypasses this issue by configuring each chip via a custom protocol while offloading row scanning to hardware, eliminating CPU overhead and preventing tearing or flickering.

Tests show a 128×64 panel achieving smooth 67 FPS animations. Color depth is 4 bits per channel, with performance capped by PSRAM bandwidth rather than panel limitations. Sample projects include color bars, a plasma demo displaying the frame rate, a dual-panel 256×64 setup, and scrolling text via Adafruit_GFX. Protocol details are documented in extras/PROTOCOL.md.
