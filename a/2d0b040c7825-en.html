Raspberry Pi Prepares Pi 4 Model A and Pi Zero 3 W Models

Two new Raspberry Pi models spotted in the Linux kernel: a Pi 4 Model A and a Pi Zero 3 W, both based on the older BCM2711 SoC.

Hints about upcoming Raspberry Pi single-board computers have surfaced in the form of changes to the company's Linux kernel fork. A merged pull request, signed by Raspberry Pi's Marta Momotko, adds support for two unannounced models: the Raspberry Pi 4 Model A and the Raspberry Pi Zero 3 W.

The Pi 4 Model A revives the long-dormant "Model A" naming convention, last seen with the Pi 3 Model A+. Unlike the current Pi 4 Model B, this version will omit the Ethernet port and reduce the number of USB ports. Both models will use the Broadcom BCM2711 system-on-chip, featuring four Cortex-A72 cores clocked up to 1.8GHz and a VideoCore VI GPU. The Pi Zero 3 W, meanwhile, represents an upgrade for the Zero family, which has historically been resource-limited, though the potential for up to 8GB of LPDDR4 memory seems unlikely.

Configuration files also reveal additional details: a BCM283x-family Bluetooth and Wi-Fi module, a physical power button, and the standard 40-pin GPIO header. Both boards will feature only one HDMI output, with the second port from the Pi 4 Model B permanently disabled. Raspberry Pi has not yet provided a release date or pricing, nor has it made any formal announcement regarding these new models.
