Raspberry Pi prépare un Pi 4 Model A et un Pi Zero 3 W

Deux nouveaux modèles de cartes Raspberry Pi repérés dans le noyau Linux : un Pi 4 Model A et un Pi Zero 3 W, basés sur l'ancien SoC BCM2711.

Des indices sur les prochaines cartes monocartes Raspberry Pi ont été découverts dans des modifications du noyau Linux dédié à ses produits. Ces changements, intégrés dans un pull request signé par Marta Momotko de Raspberry Pi, ajoutent le support de deux modèles encore non annoncés : le Raspberry Pi 4 Model A et le Raspberry Pi Zero 3 W.

Le Pi 4 Model A marque un retour à la gamme « Model A », une série historique abandonnée depuis le Pi 3 Model A+. Contrairement au Pi 4 Model B actuel, cette version supprimera le port Ethernet et réduira le nombre de ports USB. Les deux modèles s’appuieront sur le Broadcom BCM2711, un système sur puce (SoC) à quatre cœurs Cortex-A72 cadencés jusqu’à 1,8 GHz, accompagné du processeur graphique VideoCore VI. Le Pi Zero 3 W, quant à lui, représente une évolution pour la gamme Zero, historiquement limitée en ressources, bien que l’utilisation de jusqu’à 8 Go de LPDDR4 semble improbable.

Les fichiers de configuration révèlent d’autres détails techniques : présence d’un module Bluetooth et Wi-Fi de la famille BCM283x, ajout d’un bouton d’alimentation physique, et maintien du connecteur GPIO 40 broches. Les deux cartes n’auront qu’un seul port HDMI, le second port du Pi 4 Model B étant désactivé en permanence. Aucune date de sortie ni tarif n’a encore été communiqué par Raspberry Pi, qui n’a pas fait d’annonce officielle à ce jour.
