An Open-Source Stereo Vision Board Based on Rockchip RV1103

Ryan Walker has designed an open-source stereo vision board around the Rockchip RV1103 SoC, capable of image processing and depth calculation.

Ryan Walker, an engineer and maker, has developed an open-source stereo vision board around the Rockchip RV1103 SoC. This single-core processor runs at 1.1 GHz, includes 64 MB of DDR2 RAM, and features a MIPI CSI-2 bus in a QFN-88 package. The board integrates two OV9281 cameras and runs Linux, enabling onboard image processing and depth calculation.

The four-layer PCB is optimized with controlled impedance traces for USB, MIPI, and Ethernet interfaces, while a solid ground plane ensures signal stability. The operating system is built using Buildroot, with out-of-tree kernel modules provided by the vendor’s BSP, as the MIPI drivers and hardware accelerators require custom adjustments.

Access to the system is available via a serial console or SSH over the USB-C port, which acts as an Ethernet adapter. Depth calculation relies on the Rockchip Video Engine, which includes a sum of absolute differences block. The software compares patches between the two camera images, shifting one horizontally until blocks match. The resulting shift corresponds to the depth value.

Walker is collecting email signups and will order ten additional boards if at least 20 people sign up. More details are available at rootkitlabs.com, and the project is documented on GitHub.
