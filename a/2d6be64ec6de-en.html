7 Essential Docker Containers for a Self-Hosted Homelab

A How-To Geek editor shares the 7 Docker services he runs permanently in his homelab, for automation, security, or entertainment.

A personal homelab can quickly turn into a clutter of unused Docker containers. Yet some services prove essential for daily use, whether to automate tasks, secure a network, or manage data. Here’s a selection of seven solutions recommended by an experienced self-hosting editor.

Smart home automation and control

Home Assistant is an open-source hub that centralizes control of smart devices, regardless of their protocols (Zigbee, Z-Wave, Matter). It enables local automations independent of cloud services and integrates AI services for a smarter home. Its main limitation in a Docker container is restricted access to built-in apps; for full functionality, it must run on dedicated hardware or a virtual machine.

Real-time monitoring and alerts

Uptime Kuma is a self-hosted monitoring tool that continuously checks the availability of services, websites, and devices. It supports multiple protocols (HTTP, TCP, DNS, etc.) and can send alerts via Discord, Telegram, or email. Its minimalist interface allows it to blend seamlessly into a dashboard, where a green status indicates normal operation.

Network-wide ad and tracker blocking

Pi-hole acts as a DNS-level filter for the entire network, blocking requests to domains known for hosting ads, trackers, or malware. It’s particularly useful for devices with limited control options (smart TVs, smartphones, IoT gadgets). Installation relies on the Docker image pihole/pihole, followed by configuring the router’s DNS to point to the Pi-hole’s IP address.

Portainer provides a web interface to manage Docker containers, view logs, start or stop services, and run Compose files. Caution: this dashboard must remain inaccessible from the internet, as it has administrative rights over the Docker host.

Vaultwarden is a self-hosted alternative to Bitwarden, compatible with official apps. It stores passwords locally and offers advanced features like time-based one-time passwords (TOTP), usually reserved for paid versions. Security depends on robust backups and the use of a reverse proxy (Nginx, Caddy) to enable HTTPS encryption.

Immich serves as an open-source alternative to Google Photos, with an intuitive interface and features like facial recognition and geolocation. However, its heavy CPU and RAM usage during large library imports can overwhelm modest hardware. Regular data backups are advised, as Immich is not a backup solution by itself.

Jellyfin is a free, open-source media server similar to Plex, but without paywalled features. For smooth playback, it’s recommended to host it on hardware with hardware transcoding support (mini PC, refurbished desktop). Raspberry Pi devices, lacking this capability, are less suitable for intensive use.
