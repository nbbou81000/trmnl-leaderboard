Home Assistant Simplifies Device and Entity Naming

Home Assistant introduces clearer naming for devices and entities in version 2026.11.

Read the article on the TRMNL Leaderboard →

Home Assistant is overhauling its device and entity naming system with the 2026.11 release, aiming for clarity and consistency while preserving existing automations and dashboards.

A more logical and less repetitive system

Previously, entity names often included redundant context to avoid confusion, such as "Smart plug 3 Power" combining device and function. Now, Home Assistant separates these elements: the device is named "Coffee machine", and its entities are "Power" or "Energy". Context is automatically added based on the display (dashboard, device page, entity picker).

Child devices (like outlets on a power strip) each receive their own name and area, eliminating generic labels like "Socket 3". Entity IDs now systematically include the area, making it easier to distinguish between two identical devices in different rooms.

Unified rules and simplified adjustments

Users no longer need to manually rename each entity to maintain consistency. Renaming a device or entity now requires a single action, as names are no longer duplicated. Custom names on cards or dashboards remain unchanged, but new displays use default names, combining area, device, and entity as needed.

Main entities (like a primary switch) can be designated as such, displaying only the device name. Zones, devices, and entities are now managed hierarchically, with uniform rules across the interface (settings, activity log, automations, etc.).
