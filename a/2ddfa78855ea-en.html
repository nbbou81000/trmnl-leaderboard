A 2009 Sony Walkman Runs ESP-NOW Using Its Original Wi-Fi Chip

A non-invasive mod enables a 2009 Sony Walkman to run ESP-NOW using its original Wi-Fi chip, without replacement.

Read the article on the TRMNL Leaderboard →

A maker successfully implemented the ESP-NOW protocol on a 2009 Sony NW-X1060 Walkman, a portable audio player featuring an original Marvell Wi-Fi chip. Unlike typical modifications that require replacing the network hardware, this method is non-invasive: the original Wi-Fi chip remains intact and functional.

The approach relies on reverse engineering the Wi-Fi chip’s RX/TX paths. The creator added software hooks to intercept and inject ESP-NOW action frames, along with a native C API on the Walkman side. This enables direct communication with ESP32 devices without additional hardware.

The demo showcases a shared aquarium between the Walkman and an ESP-Mosaico. The Mosaico supplies IMU (Inertial Measurement Unit) sensor data, while both devices render the display locally. States are synchronized in real time via ESP-NOW, creating a collaborative experience. The code and detailed instructions are available on GitHub.

This project highlights a growing trend of creative reuse of old devices, connecting them to modern ecosystems without heavy hardware modifications. It follows similar hacks, such as turning an Echo Dot 3 into a Home Assistant satellite or a rotary phone into an AI assistant.
