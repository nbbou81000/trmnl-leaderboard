DiscImageStudio etches images onto CD, DVD, and BD-R discs

A tool converts an image into burnable data for optical discs, making the drawing visible on the disc surface once written.

DiscImageStudio converts an image into burnable data for CD, DVD, or single-layer BD-R discs (25 GB, experimental). After burning, the drawing becomes visible on the disc’s surface. The tool builds on the abandoned CDImage project (2008), which required manual calibration for each disc model. DiscImageStudio reuses its interleaving code and extends support to DVDs and BD-Rs, while partially automating calibration.

How it works and compatibility

The Windows interface (Windows 10 2004 or later) lets users import an image, adjust layers and dithering, then export as a WAV file (for CD) or ISO (for DVD/BD-R). Users can add readable files to the disc’s inner or outer ring. For CDs, a CUE file is generated to assist burning with tools like cdrecord or ImgBurn.

Five pre-calibrated presets are available for three Verbatim and two Ritek models. For other discs, an assisted calibration is required: burn a test pattern, photograph it, then draw a reference line. The software adjusts parameters to correct distortion, but results may vary based on photo quality and line accuracy.

Availability and limitations

An experimental command-line version (1.3.6) exists for Mac and Linux, but it only generates disc images—burning must be done separately with third-party software. The project is hosted on GitHub.
