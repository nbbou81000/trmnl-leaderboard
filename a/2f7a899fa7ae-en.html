A Hack to Enable ReBAR on Unsupported Motherboards

An open-source tool bypasses the lack of ReBAR on older motherboards, significantly improving Intel Arc GPU performance.

Read the article on the TRMNL Leaderboard →

The arc-rebar project, released on GitHub by Rod Burlamaqui, enables the ReBAR (Resizable Base Address Register) feature on motherboards that do not natively support it. This PCIe feature allows a GPU to map a larger portion of its video memory (VRAM) into the system’s address space, beyond the standard 256 MB limit. Intel Arc GPUs, designed to leverage ReBAR, suffer performance drops on motherboards unable to handle this feature.

The script, based on an initramfs, runs before the GPU driver loads and manually reconfigures the BAR registers. Tests with an Intel Arc B580 on a 2015 Xeon motherboard showed a dramatic bandwidth improvement, from 15 GB/s to 392 GB/s. This solution specifically targets Intel Arc GPUs and addresses a limitation caused by an internal PCIe bridge with a fixed 8 MB BAR size.

Unlike generic methods that modify the BIOS using DXE modules, this approach focuses on a targeted software fix. It requires a Debian or Ubuntu installation and a compatible Intel Arc GPU. The project is open source and available on GitHub, but its use is limited to advanced users due to its technical complexity.
