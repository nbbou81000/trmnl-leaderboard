A $4 Voice Assistant with ESP32-S3 for Your Desk

An ultra-low-cost voice assistant powered by an ESP32-S3, displaying weather and social media on a 1.3-inch OLED screen.

A $4 open-source project turns an ESP32-S3 into a voice-controlled desk assistant. This microcontroller replaces an ESP32C3 in an earlier version, where WiFi issues were linked to the board’s design. The device handles timers, displays weather updates, and shows social media status on a 1.3-inch OLED screen.

Power comes from a charging module and a battery, connected to the microcontroller with short soldered wires. Firmware is flashed over USB by holding the boot button, using files from the creator’s website. Initial setup involves joining the “Deskr Buddy” network, entering home WiFi credentials at the displayed IP address, and typing a six-digit code on a web page to complete pairing. Language, voice tone, and weather settings are configured via the same interface, while weather updates require an OpenWeatherMap API key along with a city and country.

The default wake word is “Hi ESP,” but a touch button can also trigger the assistant. The two-part case was designed in Tinkercad and 3D printed.
