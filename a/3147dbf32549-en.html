An Open-Source OS for 1.54" ESP32-S3 E-Ink Display

A tiny open-source OS turns a 1.54" e-ink ESP32-S3 display into a productivity tool and digital companion.

Read the article on the TRMNL Leaderboard →

An open-source OS called unidex brings life to a 1.54" e-ink ESP32-S3 display, turning it into a compact productivity tool and digital companion. The system can be installed directly from a web browser, adding a lightweight software layer to the tiny 1.54" screen.

Features and capabilities

The unidex OS includes several built-in modules: a countdown timer to track upcoming classes or events, a voice note recorder that converts recordings into Markdown format for tools like Obsidian, and a virtual pet system. Users can customize their pet’s appearance with clothes and accessories, and pets from different devices can meet, chat, and exchange badges.

Four one-button games and a Wi-Fi-based collection game are also included. The device conserves power by entering sleep mode when no buttons are pressed, while managing battery life and local files.

The project’s code is fully open source and hosted on GitHub. Installation is browser-based, and users are encouraged to fork and modify the code for personal use, provided it is not repurposed commercially.
