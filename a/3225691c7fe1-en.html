NomadNet: Serve Web Pages and Files Over Reticulum Without Internet

A Python tool to turn a Reticulum node into a web page and file server, accessible locally over an encrypted network.

NomadNet, created by Markqvist, is a Python tool designed to work with Reticulum, an encrypted network stack that operates without TCP/IP or Internet access. It turns a Reticulum node into a server capable of hosting web pages and local files, accessible only to other nodes on the local or extended network.

Installation and setup

NomadNet is installed via pip or pipx, depending on the distribution. On Debian or Ubuntu, the recommended commands are:

  • pipx install nomadnet and pipx install rns to get NomadNet 1.5.0 and Reticulum 1.6.0.

The first launch generates two configuration files: ~/.reticulum/config for Reticulum and ~/.nomadnetwork/config for NomadNet. The built-in guide recommends a terminal of at least 135 columns by 32 lines. If characters display as squares, installing Nerd Fonts is required, or modifying the glyphs setting in the configuration to use Unicode characters instead.

By default, NomadNet activates a single network interface: the AutoInterface, which discovers Reticulum nodes locally via IPv6 and UDP. If a firewall blocks UDP ports 29716 and 42671, these must be allowed to enable communication between nodes.

Enabling the server and managing content

To activate the server function, edit the NomadNet configuration file and enable the node in the [node] section:

  • enable_node = yes activates the server.
  • node_name sets the name displayed by the node on the network.
  • disable_propagation = yes prevents the node from relaying messages from other users, limiting it to serving pages and files.

Once activated, a My Node tab appears in the interface, offering a page explorer, a micron language editor (a lightweight markup language), and a real-time preview. Pages are written in micron and stored in ~/.nomadnetwork/storage/pages, while files to share are placed in ~/.nomadnetwork/storage/files.

Links to files are written in the format :/file/file_name within a page. To improve visibility, color and underline tags can be added. However, NomadNet only refreshes the list of pages and files at startup by default. For automatic refresh, the page_refresh_interval and file_refresh_interval settings in the configuration must be adjusted.

The full address of a page combines a 32-character hexadecimal hash (identifying the node) and the page path, for example :/page/index.mu. In the Network tab, Ctrl+U allows entering a URL to connect to the node. From another device on the same network, the page displays after selecting the node in the announcement feed and clicking Connect.
