NomadNet : servez des pages et fichiers via Reticulum sans Internet

Un outil Python pour transformer un nœud Reticulum en serveur de pages et fichiers, accessible en local via un réseau chiffré.

Lire l'article sur le Palmarès TRMNL →

NomadNet, développé par Markqvist, est un programme Python conçu pour fonctionner avec Reticulum, une pile réseau chiffrée fonctionnant sans TCP/IP ni accès à Internet. Il permet de transformer un nœud Reticulum en un serveur capable de diffuser des pages web et des fichiers locaux, accessibles uniquement par les autres nœuds du réseau local ou étendu.

Installation et configuration

L’installation de NomadNet s’effectue via pip ou pipx selon la distribution. Sur Debian ou Ubuntu, il est recommandé d’utiliser :

  • pipx install nomadnet et pipx install rns pour obtenir NomadNet 1.5.0 et Reticulum 1.6.0.

Le premier lancement génère deux fichiers de configuration : ~/.reticulum/config pour Reticulum et ~/.nomadnetwork/config pour NomadNet. Le guide intégré recommande un terminal d’au moins 135 colonnes sur 32 lignes. En cas d’affichage incorrect (carrés à la place des caractères), l’installation des Nerd Fonts est nécessaire, ou la modification du paramètre glyphs dans la configuration pour utiliser des caractères Unicode.

Par défaut, NomadNet active une seule interface réseau : l’AutoInterface, qui découvre les nœuds Reticulum en local via IPv6 et UDP. Si un pare-feu bloque les ports UDP 29716 et 42671, il faut les autoriser pour permettre la communication entre nœuds.

Activation du serveur et gestion des contenus

Pour activer la fonction serveur, il faut modifier le fichier de configuration de NomadNet en activant le nœud dans la section [node] :

  • enable_node = yes active le serveur.
  • node_name définit le nom affiché par le nœud sur le réseau.
  • disable_propagation = yes empêche le nœud de relayer les messages des autres utilisateurs, le limitant à la diffusion de pages et fichiers.

Une fois activé, un onglet My Node apparaît dans l’interface, offrant un explorateur de pages, un éditeur de langage micron (un langage de balisage léger) et un aperçu en temps réel. Les pages sont écrites en micron et stockées dans ~/.nomadnetwork/storage/pages, tandis que les fichiers à partager sont placés dans ~/.nomadnetwork/storage/files.

Les liens vers les fichiers s’écrivent sous la forme :/file/nom_du_fichier dans une page. Pour améliorer leur visibilité, des balises de couleur et de soulignement peuvent être ajoutées. Cependant, NomadNet ne rafraîchit la liste des pages et fichiers qu’au démarrage par défaut. Pour un rafraîchissement automatique, il faut modifier les paramètres page_refresh_interval et file_refresh_interval dans la configuration.

L’adresse complète d’une page combine un hash de 32 caractères hexadécimaux (identifiant le nœud) et le chemin de la page, par exemple :/page/index.mu. Dans l’onglet Network, la commande Ctrl+U permet de saisir une URL pour se connecter au nœud. Depuis un autre appareil du même réseau, la page s’affiche après avoir sélectionné le nœud dans le flux d’annonces et cliqué sur Connect.
