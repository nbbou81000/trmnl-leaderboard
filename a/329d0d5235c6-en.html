Llama: A GUI for llama.cpp on Windows 11

A Windows 11 app streamlines running local AI models with llama.cpp, no command line required.

Read the article on the TRMNL Leaderboard →

The team behind llama.cpp, an inference engine for language models, now offers a dedicated graphical interface for Windows 11. Called Llama, this app installs via a .msixbundle file available in the GitHub repository’s Releases. Installation is as simple as double-clicking the file, and the tool automatically handles the installation or update of the llama.exe binary if needed.

Once launched, the app integrates into the notification area and provides a control panel to manage AI models. It displays a list of recommended GGUF models, downloadable in one click, or allows searching for any model from the Hugging Face Hub. Before each download, Llama checks available disk space and estimates the required memory using the GGUF file’s metadata, preventing saturation errors.

Downloaded models are stored in Hugging Face’s standard cache, reducing disk space waste. The app also exposes a web interface accessible via a fixed keyboard shortcut, Alt+Space, allowing interaction with the running model. This window remains quickly accessible even after closing, preserving conversation history. The shortcut cannot be changed, which may conflict with other apps using the same key combination.

Privacy-wise, Llama sends no telemetry data and runs models locally. The interface even provides example curl requests to integrate the server with other tools. However, on Windows 11, enabling Smart App Control may block the execution of llama.exe, which is unsigned, rendering the app unusable unless this feature is disabled.
