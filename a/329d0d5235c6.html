Llama : une interface graphique pour utiliser llama.cpp sous Windows 11

Une application Windows 11 simplifie l'exécution locale de modèles d'IA avec llama.cpp, sans ligne de commande.

Lire l'article sur le Palmarès TRMNL →

L’équipe derrière llama.cpp, un moteur d’inférence pour modèles de langage, propose désormais une interface graphique dédiée à Windows 11. Baptisée Llama, cette application s’installe via un fichier .msixbundle disponible dans les Releases du dépôt GitHub. L’installation se résume à un double-clic, et l’outil gère automatiquement l’installation ou la mise à jour du binaire llama.exe si nécessaire.

Une fois lancée, l’application s’intègre à la zone de notification et propose un panneau de contrôle pour gérer les modèles d’IA. Elle affiche une liste de modèles GGUF recommandés, téléchargeables en un clic, ou permet de rechercher n’importe quel modèle depuis le Hugging Face Hub. Avant chaque téléchargement, Llama vérifie l’espace disponible sur le disque et estime la mémoire requise grâce aux métadonnées du fichier GGUF, évitant ainsi les erreurs de saturation.

Les modèles téléchargés sont stockés dans le cache standard de Hugging Face, ce qui limite le gaspillage d’espace disque. L’application expose également une interface web accessible via un raccourci clavier Alt+Espace, permettant d’interagir avec le modèle en cours d’exécution. Cette fenêtre reste accessible rapidement, même après fermeture, et conserve l’historique des conversations. Le raccourci est fixe et ne peut être modifié, ce qui peut poser problème si une autre application l’utilise déjà.

Côté confidentialité, Llama ne transmet aucune donnée de télémétrie et exécute les modèles localement. L’interface propose même des exemples de requêtes curl pour intégrer le serveur à d’autres outils. Cependant, sous Windows 11, l’activation de Smart App Control peut bloquer l’exécution de llama.exe, non signé, rendant l’application inutilisable sans désactiver cette fonctionnalité.
