M5Stack Core Matrix: ESP32 with Built-in 16×16 LED Matrix for IoT Projects

A compact development kit combines an ESP32-C61HR8, a 16×16 LED matrix, and sensors for visual IoT projects.

Read the article on the TRMNL Leaderboard →

M5Stack has unveiled the Core Matrix, a development kit that integrates a 16×16 white LED matrix into a single, compact device. At its core lies an ESP32-C61HR8 microcontroller, powered by a single-core RISC-V processor running at 160 MHz, paired with 16 MB of flash storage and 8 MB of PSRAM. Wireless connectivity is provided via 2.4 GHz Wi-Fi 6 and Bluetooth LE 5.0.

The 16×16 LED matrix, featuring 256 monochrome LEDs, is driven by a TM1680 controller and can display icons, animations, or status indicators. While limited to a single color, it is well-suited for notifications or minimalist interfaces. The Core Matrix also includes a Bosch BMI270 six-axis inertial measurement unit (IMU), combining a three-axis accelerometer and gyroscope. This sensor enables gesture control or displays that react to tilting or shaking.

The kit features three programmable buttons, a dedicated power button, a passive buzzer for audio feedback, and a microSD card slot for additional storage. Power and programming are handled via a USB-C port, while a battery connector supports portable operation. For expanded functionality, the Core Matrix offers a 30-pin M5-Bus expansion interface, a four-pin Grove connector for external sensors, and an additional USB expansion port. Power management is handled by M5Stack’s M5PM1 and M5IOE1 chips, which also manage battery charging and peripheral control.

Programming is supported through the Arduino IDE and M5Stack’s UIFlow2 visual programming platform, with example code provided for the LED matrix, buttons, buzzer, IMU, and other onboard components. Measuring just 54×54×11.6 mm and weighing 28.9 grams, the Core Matrix is designed for space- and weight-constrained IoT projects. The device is priced at $29.90.
