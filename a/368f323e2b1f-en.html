CircuitPython 10.3.2 Released: Bug Fixes and Enhanced Stability

Stable release of CircuitPython featuring security fixes and stability improvements.

CircuitPython 10.3.2, released on November 11, 2026, is a bugfix update that strengthens the 10.x branch. It removes compromised root certificates from the built-in bundle, addressing security issues reported by eMudhra emSign and AAA Certificate Services. The stable release targets developers using compatible microcontrollers, with firmware files available on circuitpython.org.

Users can download the correct version for their board through a guided interface on the website, which selects the appropriate file based on model and language. Installation follows the steps in the official "Welcome to CircuitPython!" guide, while library updates are handled via a dedicated page in the same guide. For coding and interaction with the CircuitPython environment, developers can use code.circuitpython.org or the Mu editor, which simplifies access to the serial console (REPL) for debugging.

Stable ports and features

This version supports several microcontroller families considered stable, including Microchip’s SAMD21 and SAMx5x, Espressif’s ESP32 variants (C2, C3, C5, C6, C61, H2, S2, S3), Nordic’s nRF52840 and nRF52833, and Raspberry Pi’s RP2040 and RP2350. Other ports, such as those for ST’s STM32F4 family or Analog Devices’ MAX32690, remain in alpha phase with incomplete features or known bugs.

Additional fixes include minor enhancements and stability improvements, while ongoing issues are tracked on the project’s GitHub repository. Contributors to this release are acknowledged, with an invitation to join the Discord community for collaboration.
