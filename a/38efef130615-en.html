Using ESP32 Touch Pins with ESP-IDF

A step-by-step guide to using ESP32 touch pins with ESP-IDF in VS Code.

This guide explains how to use the ESP32’s touch-sensitive pins with the ESP-IDF framework in Visual Studio Code. These pins detect electrical charge variations, such as a finger touch, and can wake the microcontroller from deep sleep mode.

Prerequisites

To follow this tutorial, you need the ESP-IDF extension installed in VS Code and an ESP32 development board. The number of touch pins varies by model: the original ESP32 has 10, while the ESP32-S3 has 14. Other versions like the ESP32-C2, C3, C6, or H2 do not include touch pins. These pins can replace mechanical buttons or act as wake-up sources.

Configuring touch pins in ESP-IDF requires calibration to set an appropriate detection threshold. The process involves five steps: calibrating the channel, registering on_active/on_inactive callbacks, managing flags to avoid delays, and reading values in the main loop.

Creating an ESP-IDF Project

The ESP-IDF extension simplifies project setup by automatically generating required files. You must select the framework version (e.g., ESP-IDF v6.X), enter a project name, choose a storage directory (avoiding cloud services), specify the chip model (ESP32 or ESP32-S3), and select the correct serial port. A default project template is generated, including a main.c file to be modified for touch detection logic.

A sample code example turns on an LED when a touch pin is activated. The code handles differences between ESP32 versions (V1, V2, or V3) by adjusting detection thresholds and version-specific configurations. Calibration involves measuring a baseline value without contact, then setting an activation threshold based on this reference.
