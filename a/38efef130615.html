Utiliser les broches tactiles de l'ESP32 avec ESP-IDF

Un guide complet pour exploiter les broches tactiles de l'ESP32 avec le framework ESP-IDF sous VS Code.

Lire l'article sur le Palmarès TRMNL →

Ce tutoriel explique comment exploiter les broches tactiles de l'ESP32 avec le framework ESP-IDF, en utilisant l'environnement de développement Visual Studio Code. Les broches tactiles, présentes sur certains modèles d'ESP32, détectent les variations de charge électrique, comme un contact avec un doigt, et peuvent servir à réveiller le microcontrôleur depuis un mode veille profonde.

Configuration requise

Pour suivre ce guide, il est nécessaire d'installer l'extension ESP-IDF pour VS Code et de disposer d'une carte de développement ESP32 compatible. Le nombre de broches tactiles varie selon les modèles : l'ESP32 original en propose 10, tandis que l'ESP32-S3 en intègre 14. D'autres versions comme l'ESP32-C2, C3, C6 ou H2 n'en disposent pas. Ces broches peuvent remplacer des boutons mécaniques ou servir de source de réveil.

La configuration des broches tactiles nécessite une calibration préalable pour définir un seuil de détection adapté. Le framework ESP-IDF impose une approche en cinq étapes : calibration du canal, enregistrement des callbacks d'activation/désactivation, gestion des drapeaux pour éviter les délais, puis lecture des valeurs dans la boucle principale.

Création d'un projet ESP-IDF

L'extension ESP-IDF simplifie la création d'un projet en générant automatiquement les fichiers nécessaires. Il faut sélectionner la version du framework (par exemple ESP-IDF v6.X), préciser le nom du projet, le répertoire de stockage (hors services cloud), le modèle de puce (ESP32 ou ESP32-S3) et le port série correspondant à la carte connectée. Un modèle de projet par défaut est ensuite généré, incluant notamment le fichier main.c à modifier pour intégrer la logique de détection tactile.

Un exemple de code permet d'allumer une LED lorsque la broche tactile est touchée. Le code gère les différences entre les versions de l'ESP32 (V1, V2 ou V3) en ajustant les seuils de détection et les configurations spécifiques à chaque modèle. La calibration consiste à mesurer une valeur de référence en l'absence de contact, puis à définir un seuil d'activation basé sur cette référence.
