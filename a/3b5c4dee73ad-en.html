BIGWORDS.PAGE: Display Text on Any Screen via URL

A minimalist web tool turns any screen into a customizable display using just a URL.

Read the article on the TRMNL Leaderboard →

BIGWORDS.PAGE, created by SpeakingOfBrad, offers an ultra-simple way to broadcast text or images across multiple screens without complex setup. The tool relies on a web page accessible via a customizable URL, allowing users to display content directly in any browser, regardless of the target device (smartphone, tablet, dedicated display, etc.).

The system uses a lightweight syntax inspired by markdown, where styling parameters (font, color, size) are added directly to the URL. For instance, the command https://bigwords.page/#Hackaday renders the word "Hackaday" in large text. Additional options let users adjust appearance or add dynamic elements like images, countdown timers, or multi-page animated presentations. A visual editor is also available to generate these URLs without coding.

The project is released under the MIT license, enabling free use and even self-hosting for local network deployments. This approach removes the need for an internet connection and simplifies managing multiple screens on the same network. Commenters praise the project’s simplicity and lack of data collection, ensuring private and registration-free use.
