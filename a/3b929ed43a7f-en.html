A 30 FPS e-Paper Game Boy Display via Smart Software Tweaks

A hacker achieves 30 FPS on a 1.54" e-paper screen by pushing the limits of its built-in controller and fine-tuning calibration.

E-paper displays are notorious for slow refresh rates, low contrast, and ghosting effects—limitations that eerily echo the monochrome LCDs of 1980s Game Boys. Yet these constraints become an advantage for [Bo Made It], who managed to run Game Boy emulation on a 1.54-inch e-paper screen at 30 frames per second.

Unlike previous projects that relied on raw e-paper controllers, [Bo] used a Waveshare ESP32-S3-ePaper-1.54 development board, which includes an integrated e-paper controller. While this controller restricts direct pixel access, it enables clever software optimizations. Each pixel is assigned an "energy budget" of up to 8 electrical pulses, adjusted based on the required shade change. This approach speeds up refresh rates, as pixels aren’t driven to their full potential.

The real breakthrough lies in handling the Game Boy’s 4-bit grayscale (16 shades). [Bo] deliberately leverages ghosting to simulate intermediate gray levels. By not maintaining pixels long enough for a full transition, faster shade shifts are achieved. However, this complicates calibration: the time to shift from black to white differs from shifting to a lighter gray, requiring precise timing adjustments for each transition. Calibration involved automated testing via video analysis and remains a work in progress.

The code isn’t yet available, but [Bo] plans to open-source it once finalized. The project is part of a broader effort to integrate this display into a PDA-like device. This technique echoes a recent hack achieving 20 FPS, built on the same principles.
