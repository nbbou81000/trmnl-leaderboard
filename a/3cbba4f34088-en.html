APIO: An Open-Source Toolchain to Simplify FPGA Development

APIO streamlines FPGA development by aggregating open-source tools like Yosys and GTKWave, perfect for Verilog projects.

Read the article on the TRMNL Leaderboard →

APIO acts as an aggregator for open-source FPGA toolchains, drawing inspiration from PlatformIO. It centralizes the management of tools like Yosys (Verilog synthesis) and GTKWave (simulation), streamlining the workflow. Available as a command-line tool or a Visual Studio Code extension, APIO automates the installation and updating of required tools while bundling its own libraries.

Using APIO requires a minimal configuration file, such as apio.ini, to specify the target board (e.g., Sipeed Tang Nano 20K) and the top module. A simple LED-blinking example demonstrates its functionality. However, APIO enforces the use of its internal tool versions, which can conflict with locally installed system libraries. For instance, the libreadline.so.8 library may cause issues, requiring deletion or renaming.

Unlike proprietary tools like GOWIN’s, APIO emphasizes open-source solutions and provides advanced features for Verilog code verification and simulation. It also includes linters for formatting and correcting code. However, it does not natively support GOWIN’s proprietary IP blocks or integrated tools like the graphical pin constraint editor or embedded logic analyzer. These limitations can be bypassed using text-based constraint files or third-party tools.

A minimal LED-blinking project is available to test APIO. The associated Verilog module expects a 27 MHz clock signal and a reset input. After configuring the project, the FPGA board must be connected via a serial port to interact with its embedded microcontroller. A specific sequence (^X^C) grants access to a command shell for configuring the clock or checking its status.
