Two Arduino Libraries to Integrate Escape Room Puzzles into Home Assistant

Open source Arduino libraries turn escape room puzzles into Home Assistant devices using ESP32 or RP2040.

Read the article on the TRMNL Leaderboard →

Djair Guilherme has released two open source Arduino libraries to connect escape room puzzles to Home Assistant. The first, esp32_escaperoom, runs on ESP32 boards and handles WiFi and MQTT connectivity. The second, propmaker_escaperoom, operates on an RP2040 using the Adafruit PropMaker Feather, with no network capabilities, communicating with other puzzles via RS485.

Both libraries share a common engine: a puzzle state machine, audio management, a pin contract per board, and a hardware abstraction layer that scans the I2C bus at boot. On the Home Assistant side, integration relies on MQTT discovery through ArduinoHA, automatically adding entities without requiring YAML configuration. Device name, room, puzzle ID, and MQTT broker credentials are stored in a wifi.json file on the board, making room changes as simple as editing a file rather than recompiling.

To meet input/output needs, projects use I2C components such as PCF8574/PCF8575 port expanders, an HT16K33 display, an ADS1115 analog-to-digital converter, a PCA9685 PWM driver, or a PN532 NFC reader. A practical example, BombTimer, exposes eight sensors, a lock, four buttons, a selector, two numbers, and a switch. Both libraries are released under the MIT license.
