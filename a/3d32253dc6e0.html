Deux bibliothèques Arduino pour intégrer des énigmes d'escape game à Home Assistant

Des bibliothèques open source transforment des énigmes d'escape game en périphériques Home Assistant via ESP32 ou RP2040.

Lire l'article sur le Palmarès TRMNL →

Djair Guilherme propose deux bibliothèques Arduino open source pour connecter des énigmes d'escape game à Home Assistant. La première, esp32_escaperoom, fonctionne sur des cartes ESP32 et gère la connectivité WiFi ainsi que le protocole MQTT. La seconde, propmaker_escaperoom, s’exécute sur un RP2040 via l’Adafruit PropMaker Feather, sans réseau, en communiquant avec d’autres énigmes via RS485.

Les deux bibliothèques partagent un même moteur logiciel : une machine à états pour les énigmes, la gestion audio, un contrat de broches matérielles et une couche d’abstraction qui scanne le bus I2C au démarrage. Côté Home Assistant, l’intégration repose sur la découverte MQTT via ArduinoHA, ce qui permet d’ajouter automatiquement les entités sans écrire de fichier YAML. Les paramètres comme le nom de l’appareil, la pièce, l’identifiant de l’énigme et les identifiants du broker MQTT sont stockés dans un fichier wifi.json sur la carte, simplifiant les modifications de configuration.

Pour répondre aux besoins en entrées/sorties, les projets s’appuient sur des composants I2C comme les PCF8574/PCF8575 (expanders de ports), un écran HT16K33, un convertisseur analogique-numérique ADS1115, un pilote PWM PCA9685 ou encore un lecteur NFC PN532. Un exemple concret, BombTimer, expose huit capteurs, une serrure, quatre boutons, un sélecteur, deux entrées numériques et un interrupteur. Les deux bibliothèques sont distribuées sous licence MIT.
