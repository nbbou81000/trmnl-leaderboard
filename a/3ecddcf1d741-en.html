Seeed Studio Launches Two Bluetooth e-Paper Kits with OpenDisplay

Seeed Studio releases two Bluetooth LE e-paper kits preloaded with OpenDisplay firmware, compatible with Home Assistant and a Python SDK.

Read the article on the TRMNL Leaderboard →

Seeed Studio has launched two Bluetooth LE e-paper kits featuring the Nordic nRF52840 microcontroller, both shipping with the open-source OpenDisplay firmware. This firmware enables image transmission to the screen without relying on a cloud service.

The first kit, the OpenDisplay 4.26″ Mono, includes a 4.26-inch monochrome and grayscale e-paper display with 800×480 resolution and partial refresh. The second, the OpenDisplay 7.3″ Color, features a 7.3-inch Spectra 6 color e-paper panel at the same resolution. Each kit comes with a 2,000 mAh battery, a driver board based on the XIAO nRF52840 Plus module, and control and reset buttons.

OpenDisplay firmware allows image transmission via Bluetooth LE or Wi-Fi using the OpenDisplay Toolbox in Chrome or Edge. It is also compatible with Home Assistant, which can convert data like weather, temperature, energy usage, or calendar events into images for display. A Python SDK is available for developers not using Home Assistant.
