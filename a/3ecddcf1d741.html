Seeed Studio lance deux kits e-Paper Bluetooth avec OpenDisplay

Seeed Studio propose deux kits e-Paper Bluetooth LE préchargés avec le firmware open source OpenDisplay, compatibles avec Home Assistant et un SDK Python.

Lire l'article sur le Palmarès TRMNL →

Seeed Studio commercialise deux kits d’affichage e-Paper (encre électronique) fonctionnant en Bluetooth LE, intégrant le microcontrôleur Nordic nRF52840. Les deux modèles sont livrés avec le firmware open source OpenDisplay, conçu pour envoyer des images vers l’écran sans dépendre d’un service cloud.

Le premier kit, OpenDisplay 4.26″ Mono, utilise un écran monochrome et niveaux de gris de 4,26 pouces avec une résolution de 800×480 pixels et un rafraîchissement partiel. Le second, OpenDisplay 7.3″ Color, repose sur un écran couleur Spectra 6 de 7,3 pouces à la même résolution. Chaque kit inclut une batterie de 2 000 mAh, une carte de pilotage basée sur le module XIAO nRF52840 Plus, ainsi que des boutons de contrôle et de réinitialisation.

Le firmware OpenDisplay permet d’envoyer des images via Bluetooth LE ou Wi-Fi depuis un navigateur web, grâce à l’OpenDisplay Toolbox disponible sur Chrome ou Edge. Il est également compatible avec Home Assistant, qui peut convertir des données comme la météo, la température, la consommation énergétique ou les événements du calendrier en images pour les afficher. Un SDK Python est aussi proposé pour les développeurs ne utilisant pas Home Assistant.
