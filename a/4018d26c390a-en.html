A Home Assistant Dashboard Customized with a House Illustration

A developer turns an illustration of his house into an interactive Home Assistant dashboard.

Read the article on the TRMNL Leaderboard →

Anton Frolov hired an environment artist to create a detailed illustration of his house, which he then turned into a custom Home Assistant dashboard. The goal was to make the interface more user-friendly for his family, ensuring features like garden lighting or sprinkler timers would actually be used. The artist delivered PNG files with transparency, including day and night versions for each floor, and separate layers for each device: a static frame for the off state and an eight-frame loop for the on state.

The dashboard uses Home Assistant’s default picture-elements card. The illustration serves as the background, with devices overlaid as image elements that switch to an animated WebP when activated. An automation triggered at sunrise and sunset overlays the night version of the illustration. For irrigation controls, a custom pop-up was built using the Browser Mod extension from HACS. The dashboard is displayed on a TV via the HAOS Kiosk Display add-on, connected via HDMI.

Source files and technical details are available at antonfrolov.substack.com and on GitHub.
