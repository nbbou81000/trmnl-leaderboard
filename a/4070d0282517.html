Meeting Recorder : transcrire ses visios en local avec Omarchy

Un outil open source pour enregistrer et transcrire ses réunions en local, sans cloud ni matériel spécifique.

Lire l'article sur le Palmarès TRMNL →

Meeting Recorder est un enregistreur de visioconférences conçu pour Omarchy, une distribution Linux basée sur Arch et Hyprland. Il capture séparément le micro de l’utilisateur et le son de l’ordinateur, puis transcrit l’intégralité de la réunion en local grâce au modèle Whisper (large-v3-turbo). Aucune donnée n’est envoyée vers le cloud, garantissant une confidentialité totale.

L’outil utilise Nemotron 3 Diarization, un modèle de NVIDIA exécuté en local, pour identifier jusqu’à huit voix distinctes. Les intervenants sont automatiquement étiquetés (ex. "Remote 1", "Remote 2"), et leurs noms peuvent être personnalisés. À la fin de l’appel, une transcription structurée est générée, avec horodatage et attribution des lignes de dialogue. Un lecteur audio intégré permet de naviguer facilement dans l’enregistrement.

Le logiciel est disponible dans le dépôt de paquets d’Omarchy, uniquement sur le canal edge pour l’instant. Une commande en ligne permet aussi de l’installer sur d’autres systèmes, bien que certaines fonctionnalités (comme le chapitrage automatique) soient réservées à Omarchy. Pour les utilisateurs de Windows ou macOS, des alternatives comme Meetily ou Kassis offrent des solutions similaires, mais sans intégration native avec un agent local.

Attention : la version 1.1.1 présente un bug sur les processeurs sans AVX-512 (ex. Ryzen 5 5500), empêchant la transcription. Un correctif a été proposé par un contributeur, mais une compilation manuelle peut être nécessaire en attendant. Le modèle Whisper, d’environ 1,6 Go, est téléchargé une seule fois. Les réunions sont sauvegardées dans ~/Documents/Meetings, avec l’audio et un fichier transcript.md modifiable.

L’outil est sous licence MIT et son code est accessible sur GitHub. Son installation est simple, mais il est impératif d’informer les participants avant toute utilisation, conformément à l’article 226-1 du Code pénal.
