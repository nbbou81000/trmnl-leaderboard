Picothermal: An Open-Source Thermal Camera Without a Dedicated App

An open-source project turns a smartphone into a high-resolution thermal camera via USB-C and a web browser.

Thermal cameras are valuable for diagnosing electrical issues or detecting heat leaks in buildings, but high-resolution models can be expensive. While cheaper smartphone-connected alternatives exist, many rely on proprietary apps that may eventually become unsupported. To address these limitations, Cezar Chirila designed and built Picothermal, an open-source thermal camera that connects to a smartphone or computer via USB-C and operates directly in a web browser.

This project follows an earlier version that used an MLX90640 sensor with a resolution of just 32×24 pixels, sufficient for basic thermal imaging. The new iteration features a FLIR Lepton 3.5 sensor, delivering 160×120 pixels—25 times more than the previous model. The sensor also provides radiometric data, enabling precise temperature measurements rather than just displaying relative heat differences.

The system is built around an RP2040 microcontroller, which handles communication with the sensor and sends data over USB-C. A power supply (buck converter and regulators) powers the components, while a 3D-printed enclosure completes the device. No battery, charging circuit, or display is included, as the host smartphone or computer provides these resources. Chirila designed a custom PCB available in two thicknesses (0.8 mm and 1.6 mm), with the thicker version chosen for its sturdiness and ease of soldering, despite the USB-C connector being designed for thinner boards.

The interface uses WebUSB, eliminating the need for a dedicated app. Users simply connect the camera to an Android smartphone, open the project’s web interface in a browser, and view thermal images. This approach reduces dependency on third-party apps, though compatibility is limited by the lack of WebUSB support in some browsers. The project provides hardware design files, enclosure models, and firmware on GitHub under the MIT license. A future update may add support for USB Video Class, expanding software compatibility without relying on WebUSB.
