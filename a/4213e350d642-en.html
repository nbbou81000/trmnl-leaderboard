Doory: An Open-Source Self-Hosted Design Editor

A browser-based, account-free graphic editor to design posters, resumes or thumbnails and export them in multiple formats.

Read the article on the TRMNL Leaderboard →

Siam has released Doory, an open-source design editor that runs entirely in the browser and can be self-hosted. The tool supports creating posters, social media posts, presentations, invitations, resumes, thumbnails, business cards, and more. Users can start from a template or a blank canvas and export their work as PNG, JPG, SVG, PDF, MP4, or GIF.

The editor includes ten starter templates for gig posters, wedding invitations, resumes, YouTube thumbnails, pitch decks, and other common use cases. All templates use open-licensed fonts and are fully customizable. Additional templates can be added through the admin interface and filtered by category, size, and orientation. The frontend is built with React 19, TypeScript, Vite, Fabric.js (for interactive object manipulation), Yjs (for real-time collaboration), and Zustand (for state management).

On the backend, Doory uses Django 5, Django REST Framework, Channels (for real-time features), and PostgreSQL. Deployment is handled via Docker Compose and nginx, with optional support for Redis (for caching) and S3-compatible storage. The project is released under the Attribution Assurance License, allowing commercial use as long as the author is credited within the running application.
