PSPi 6: A Raspberry Pi Inside a PSP 1000 Shell

An open-source PCB replaces the mainboard of a PSP 1000 with a Raspberry Pi, keeping the original shell and controls intact.

Read the article on the TRMNL Leaderboard →

The PSPi 6 project, created by othermod, offers an open-source solution to repurpose a PlayStation Portable (PSP) 1000 by replacing its mainboard with a Raspberry Pi. The custom PCB fits inside the original shell, screen area, and controls, while the Raspberry Pi handles the processing tasks, effectively modernizing the device.

Hardware design files are available on GitHub under the Creative Commons BY-SA license, allowing free adaptation and sharing with proper attribution. Pre-made boards are sold on othermod.com, while PCB files can be ordered from a manufacturer for custom production. othermod warns that this project requires strong electronics and soldering skills to complete successfully.

The GitHub repository includes a wiki with a full feature list, a troubleshooting page, and build guides. othermod is actively expanding the documentation and resources. The project is designed for experienced hobbyists as well as those seeking a ready-to-use solution.
