A Sub-$500 Mini PC Turned into an Open-Source Router

A journalist tests a DIY router running OPNsense on a sub-$500 mini PC to secure a homelab.

A journalist replaced their UniFi router with a DIY router running OPNsense on a sub-$500 mini PC. The goal was to assess the performance and features of an open-source router for a homelab, comparing it to a commercial solution.

The chosen hardware is the BOSGAME Eco E6, a mini PC featuring two gigabit Ethernet ports, 12GB of RAM, and a Core 3 304 processor. This low-power system offers a flexible and scalable alternative to off-the-shelf routers. OPNsense was selected for its modern interface and ease of use, though the installation process presented some technical hurdles.

The setup required tools like balenaEtcher to write the system’s disk image and disabling Secure Boot in the BIOS. Once operational, the DIY router was configured on a dedicated subnet (10.10.10.x) to avoid conflicts with the existing UniFi network. Configuring WAN (wide area network) and LAN (local area network) ports required adjustments, particularly through OPNsense’s terminal interface.

Performance tests showed that enabling IDS/IPS (intrusion detection and prevention system) with Suricata did not impact bandwidth, unlike the UniFi solution, where this feature slightly slowed throughput. OPNsense thus secures the network without sacrificing performance, even on modest hardware.
