Arduino Library for Texas Instruments TCAN4x5x CAN-FD Controllers

Hyperion-Robotics releases an Arduino library for Texas Instruments TCAN4550/TCAN4551 CAN-FD controllers, optimized for common microcontrollers.

Hyperion-Robotics has released an open-source Arduino C++ library for Texas Instruments’ TCAN4550 and TCAN4551 CAN-FD controllers. CAN-FD (Controller Area Network Flexible Data-rate) is a high-speed variant of the CAN bus, commonly used in vehicles and robotics for data transmission.

The library wraps Texas Instruments’ low-level ANSI-C driver in an Arduino-compatible interface, eliminating the need for polling loops by using hardware interrupt service routines. This approach prevents the microcontroller from repeatedly checking the chip. The library supports AVR, SAMD, and Renesas UNO R4 (using default SPI pins), as well as ESP32, RP2040, RP2350, STM32, and Teensy (with customizable chip select, MISO, MOSI, and clock pins).

By default, the library loads Texas Instruments’ settings: 500k and 2M bit rates with standard filters, which can be overridden before initialization. High-priority CAN IDs can be routed to GPO1 or GPO2 pins, which are internally connected to MCAN_INT0 (GPO2) and MCAN_INT1 (GPO1). A software toggle directs urgent messages to the appropriate output.

Example code demonstrates sending custom C++ structs and using arbitrary SPI pins. The library is released under the BSD 3-Clause License and is available on GitHub.
