Raspberry Pi Desktop mis à jour sur Debian Trixie, abandon des 32 bits

Raspberry Pi relance son OS desktop pour PC et Mac après quatre ans, basé sur Debian Trixie et compatible AMD64 uniquement.

Lire l'article sur le Palmarès TRMNL →

Raspberry Pi a publié une version actualisée de Raspberry Pi Desktop, son système d’exploitation conçu pour les ordinateurs classiques (PC et Mac) et non pour ses cartes monocarte. Cette mouture, basée sur Debian Trixie, marque le premier renouvellement depuis plus de quatre ans, la précédente datant de juillet 2022 et reposant sur Debian 11 Bullseye, désormais hors support. Le développeur Simon Long reconnaît le long délai : « Désolé pour l’attente, mais voici enfin Debian Trixie avec Raspberry Pi Desktop pour PC et Mac. »

Ce système, initialement nommé Debian+PIXEL, adapte les optimisations de Raspberry Pi OS pour les architectures x86 et AMD64. Il conserve l’interface visuelle des versions pour Raspberry Pi, bien que certaines applications soient absentes pour des raisons de licences. Contrairement à la version précédente, il ne prend plus en charge les systèmes x86 32 bits et reste incompatible avec les Mac équipés de puces Apple Silicon. En revanche, il intègre Raspberry Pi Connect, un outil de connexion à distance permettant d’établir un terminal sécurisé ou une session de bureau complet via un navigateur web, sans configuration de ports ou installation de logiciel client.

Disponible sous forme d’image bootable pour clé USB sur le site de Raspberry Pi, cette mise à jour s’appuie sur la même base que la dernière version de Raspberry Pi OS, mais cible uniquement les machines AMD64.
