Open Source Server Revives Dead Neato Robot Vacuums

A self-hosted server replaces Neato Robotics' closed servers to revive abandoned robot vacuums since 2023.

Read the article on the TRMNL Leaderboard →

The Neato Robotics robot vacuums, which relied on the company's servers since their shutdown in 2023, can now be revived using an open-source server called Vacuula. Hosted on GitHub, this project provides a complete solution to repair and control these otherwise unusable robots. The server runs on a locally powered machine, offering an alternative to proprietary cloud services.

For Home Assistant users, an integration is available through a dedicated add-on repository. Others can deploy it using Docker Compose. An automated installer simplifies setup and tells the robot which port to connect to. Currently, testing is confirmed for ARM 64-bit and x86 64-bit architectures, with support for ARM 32-bit and possibly x86 32-bit in development to expand compatibility to older single-board computers.

The first release does not yet include support for the BotVac Connected model, though work is underway. The source code and detailed instructions are available on GitHub.
