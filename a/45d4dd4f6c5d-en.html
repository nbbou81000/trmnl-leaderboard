ESP32-S3: Whistle Speech-to-Text Without Cloud

An ESP32-S3 runs a whistle-based speech-to-text model entirely offline, with no cloud dependency.

Read the article on the TRMNL Leaderboard →

Saulo Verissimo has released whistle-esp32 on GitHub, a whistle-based speech-to-text demo running entirely on an ESP32-S3 microcontroller. Users press a button, speak a command like “make it red” or “flash the light blue”, and the onboard WS2812 LED responds. The system requires no network, cloud, or smartphone. Unlike traditional solutions that rely on predefined phrases, this model transcribes free speech and supports seven languages with automatic language detection.

The underlying model is Whistle, developed by Cactus Compute under the Apache 2.0 license. However, Cactus does not provide an ESP32 build or the engine’s source code. Verissimo implemented an independent C99 version with no external dependencies. Every tensor operation was manually verified to match the official library. Since the full model exceeds the microcontroller’s flash storage, a reduction step was applied: the cascaded decoder was limited to a depth of 4.

Matrix multiplications run in int8 on the ESP32-S3’s PIE vector unit, enabling 16 multiply-add operations per instruction. A 2-second English voice command is processed in a few seconds at 240 MHz. Performance tests show 80 % accuracy for color commands in int8 mode, and a 11.7 % word error rate on 73 LibriSpeech samples.
