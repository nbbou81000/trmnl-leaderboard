Transformer un Echo Dot 3 en satellite vocal pour Home Assistant

Un Echo Dot 3 de 2018 peut être rooté pour remplacer Alexa par un assistant vocal local, compatible Home Assistant.

Lire l'article sur le Palmarès TRMNL →

Le rooting d’un Amazon Echo Dot 3 (modèle 2018) permet de le libérer du cloud Amazon et de le transformer en satellite vocal pour Home Assistant. Cette opération, documentée par [Andy], repose sur un processus technique exigeant l’accès physique à la carte mère.

Pour les modèles dépourvus de port USB, comme l’Echo Dot 3, il est nécessaire d’ouvrir l’appareil et de souder un connecteur USB sur les plots de test présents sur la carte. Les autres appareils Echo, équipés nativement d’un port USB, simplifient cette étape. Une fois l’accès obtenu, le bootloader est déverrouillé et le système Fire OS (basé sur Android) est modifié pour remplacer l’application Alexa par hassmic, un projet open source développé par [Julian Imhof].

Ce logiciel, bien que fonctionnel, n’a pas été audité et son utilisation reste à vos risques. La prise en charge est limitée à certains modèles d’Echo Dot et Echo Show, listés sur la page du projet. Les performances vocales locales sont inférieures à celles du cloud Amazon : [Andy] a dû adapter les paramètres de reconnaissance vocale pour éviter des latences importantes, comme le passage de Whisper à Speech-to-Phrase pour des commandes simples.

Malgré ces limites, cette méthode offre une alternative pour intégrer un assistant vocal local dans un écosystème domotique, sans dépendre des serveurs Amazon.
