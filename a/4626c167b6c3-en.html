TTL-to-DVI Converter with RP2350 for Legacy Video Outputs

An open-source RP2350-based converter turns TTL RGB signals into DVI, rescuing vintage video cards without compatible monitors.

Read the article on the TRMNL Leaderboard →

TTL RGB monitors, common before the VGA era, are now scarce and incompatible with modern graphics cards. To address this, Charlysan has developed an open-source converter using an RP2350 microcontroller, which translates TTL signals into DVI output.

The project leverages the RP2350’s Programmable I/O (PIO) blocks to sample TTL inputs and store them in a framebuffer. The remaining processing power handles the DVI conversion using the PicoDVI library. A simple level-shifting circuit, such as a resistor network, is required to match logic voltage levels. The design specifically targets the Waveshare RP2350-PiZero board, which includes a built-in HDMI connector.

Management is handled via a USB serial terminal, with an optional TK GUI script for easier configuration. While not a headline-grabbing project, it fills a critical gap for retro computing enthusiasts. A similar solution previously existed for converting VGA to DVI.
