CoCoTANG: FPGA Upgrade for Color Computer 1 and 2

An open-source FPGA upgrade adds 8 MB of RAM, HDMI output, and CoCo 3 graphics to vintage Color Computer 1 and 2 machines.

Read the article on the TRMNL Leaderboard →

CoCoTANG, created by Felipe Antoniosi, offers an open-source FPGA upgrade to bring CoCo 3 features to vintage Color Computer 1 and 2 machines, first released in 1986. The project leverages a Sipeed Tang Nano 20K FPGA board to emulate the CoCo 3’s Graphics, Interrupt, Memory Enhancement (GIME) chip in programmable logic.

Unlike an emulator, this upgrade retains the original Motorola MC6809E CPU and existing hardware while adding 8 MB of RAM — far exceeding the 512 KB supported by the CoCo 3. Graphics capabilities are also expanded, enabling software that uses the CoCo 3’s display modes.

Connectivity options include an HDMI output for modern displays, along with analog alternatives (RGB, component, composite/S-Video) depending on the FPGA configuration. Both HDMI and analog outputs can run simultaneously. Additional enhancements feature a Glenside-compatible IDE interface with microSD storage, advanced audio support (stereo HDMI, Tandy Speech/Sound Cartridge emulation), and Orchestra-90 compatibility.

Installation requires several custom circuit boards: a main board for the CPU and FPGA, adapters for the motherboard’s Peripheral Interface Adapters (PIA), and a replacement for the original address decoder. Optional boards add extra video connections or an HDB-DOS ROM cartridge. Only specific CoCo 2 motherboard revisions are supported, and CoCo 1 setups need additional modifications to address electrical noise. Some software and peripherals may have compatibility issues, though most tested games work.

All source files (FPGA code, KiCad designs, PCB files, and bill of materials) are published on GitHub, but the process demands electronics expertise.
