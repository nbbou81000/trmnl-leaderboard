Build a Glowing Animated Holiday Wreath with MagTag and NeoPixel

Turn an Adafruit MagTag and NeoPixel strip into a glowing holiday wreath without soldering.

Read the article on the TRMNL Leaderboard →

The Adafruit MagTag, paired with a one-meter NeoPixel strip, can be turned into a glowing animated holiday wreath. The project uses the MagTag’s built-in e-ink display to show a static image while the NeoPixel strip provides dynamic lighting effects. No soldering is required— the MagTag features a 3-pin JST port that directly connects to standard NeoPixel strips.

The official guide walks through installing CircuitPython, a lightweight firmware for microcontrollers, along with the necessary libraries. Once the MagTag is plugged into a computer, users simply copy the required files, edit the provided code, and run the project. The code is fully customizable, allowing adjustments to animations, colors, and lighting speed.
