Une carte de vision stéréo pour bidouilleurs ARM et Linux

Une carte open source exploitant un SoC Rockchip RV1103 pour du traitement d'images stéréo en temps réel.

Lire l'article sur le Palmarès TRMNL →

Ce projet cible les passionnés d’électronique et de vision par ordinateur avec une carte dédiée à la vision stéréo, capable de traiter deux flux vidéo simultanément. Au cœur du système se trouve le Rockchip RV1103, un processeur ARM monocœur cadencé à 1,1 GHz, doté de 64 Mo de RAM DDR2 et d’un bus MIPI CSI-2 pour connecter des caméras. Il intègre nativement un support Linux, simplifiant le développement d’applications embarquées.

La carte embarque deux caméras OV9281 à obturateur global, optimisées pour capturer des images synchronisées sans distorsion temporelle. Un accéléromètre 3 axes LI2HH12 complète l’ensemble pour ajouter des données de mouvement, tandis qu’une mémoire flash de 4 Mo et un port Ethernet 10/100 Mbit assurent stockage et connectivité. Le tout est conçu pour fonctionner avec Video4Linux2, une API standard sous Linux dédiée à la gestion des flux vidéo.

L’objectif est de fournir une plateforme clé en main pour explorer la vision stéréo, notamment la détection de profondeur, sans nécessiter de matériel complexe. Les fichiers de conception (schémas, PCB, firmware) sont publiés sous licence open source sur GitHub pour permettre aux bidouilleurs d’adapter ou d’étendre le projet. Les concepteurs soulignent que des solutions similaires existaient déjà avec des Raspberry Pi, mais que cette carte se distingue par son intégration matérielle et logicielle optimisée pour les applications temps réel.
