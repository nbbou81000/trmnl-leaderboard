Simantic: Simulating Firmware to Validate AI and Electronics

A startup offers a Rust-based microcontroller simulator to test firmware via AI, without physical hardware.

Read the article on the TRMNL Leaderboard →

Simantic, founded by two former Neuralink and Tesla engineers, has launched a firmware simulation tool designed to speed up the development and validation of embedded systems. Their solution lets engineers and AI agents test and validate code without relying on physical development boards, cutting validation time from hours to seconds.

The platform offers virtual boards accessible via an API, allowing users to program and run firmware directly from a terminal. An integrated code review bot uses simulation as a verification engine to make evidence-based decisions, while a CI/CD pipeline automatically validates firmware on every commit by comparing it against a simulated version of the target microcontroller.

Simantic differentiates itself from open-source tools like Renode or QEMU by focusing on deterministic and accurate simulation, built in Rust rather than prioritizing extensibility or developer experience. Their simulation engine is tailored for critical systems (drones, electric vehicles, satellites) where timing accuracy is essential. To ensure model precision, the company uses 24/7 hardware test benches, including logic analyzers and SWD buses, paired with automated AI monitoring.

Currently, Simantic supports several microcontroller families (STM32F0/F4/H7, ESP32-S3/C3, RP2040) and regularly expands its model library. Their cloud simulator is available immediately, while a local version with no restrictions is offered via a developer subscription. Users can integrate the code review bot into their GitHub repositories for automated validation.
