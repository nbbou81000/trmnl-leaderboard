JellyDash: A Unified Dashboard to Manage Your Jellyfin Server

An open-source dashboard to monitor in real time streams, requests, and downloads on a Jellyfin server.

Read the article on the TRMNL Leaderboard →

Running a personal Jellyfin server is straightforward, but adding multiple users makes tracking usage, requests, and downloads more complex. Instead of jumping between different tools, JellyDash offers a centralized dashboard to monitor all these aspects in one place.

Real-time stream and performance tracking

JellyDash provides live insights into active streams, devices in use, and potential playback issues. A dedicated card shows connected users, playback types (direct, remuxed, or transcoded), and reasons for transcoding. This helps prevent bottlenecks, especially when handling large 4K files. The playback history, filterable by user or library, assists in server management: removing inactive accounts or keeping popular content available.

Request and download integration

JellyDash integrates with JellySeerr to display pending media requests and approve them directly from the dashboard. It also connects to download clients like qBittorrent or SABnzbd to track download statuses. While it doesn’t replace these tools, it offers a simplified overview, perfect for passive monitoring on a tablet or spare screen.

Available as a progressive web app (PWA), JellyDash installs easily and runs in the background for seamless Jellyfin server management.
