P4 Launcher: A PC-like and Retro Gaming Experience for ESP32-P4 Boards

An open-source launcher turns ESP32-P4 boards into lightweight PC-like platforms for emulators and retro games.

Read the article on the TRMNL Leaderboard →

Gil Tal has released P4 Launcher, an open-source platform that delivers a PC-like experience on ESP32-P4 boards paired with a touchscreen display. The launcher boots straight into its interface, while applications—packaged as .papp files—are stored on a microSD card and loaded into PSRAM when executed. Users can install, remove, or run apps without reflashing firmware or rebooting the device by simply copying files to the microSD card.

The project currently offers 21 PAPP (PSRAM APP) applications, primarily emulators and retro games, including Neo Geo and Atari 2600 emulators, as well as classics like Doom, Quake, Duke Nukem 3D, and OpenTyrian. Utility apps such as a clock and file manager are also included. The user interface relies on LVGL, a lightweight graphics framework, and scales to various screen resolutions. The system supports up to eight simultaneous audio streams at 4 to 192 kHz and handles up to four input devices for multiplayer sessions.

P4 Launcher is compatible with several development boards, including the Guition ESP32-P4 4.3" (800×480), Guition JC1060P470C 7" (1024×600), and M5Stack Tab5 (1280×720). It supports input devices like PlayStation 3 or Nintendo controllers. The project provides an SDK for developing new PAPP applications, along with two compatibility layers to run existing code using the odroid_* API or the v1 service table, enabling ports of games like Doom or Quake.

Firmware updates can be installed from a microSD card or GitHub, with automatic rollback if a new version fails to start. The source code, based on ESP-IDF v5.5.2, is available on GitHub. Development was assisted by Anthropic’s Claude coding assistant.
