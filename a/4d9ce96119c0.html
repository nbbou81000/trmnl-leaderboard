P4 Launcher : un lanceur PC et rétro gaming pour ESP32-P4

Un lanceur open source transforme les cartes ESP32-P4 en plateforme PC légère pour émulateurs et jeux rétro.

Lire l'article sur le Palmarès TRMNL →

Gil Tal propose P4 Launcher, une plateforme open source conçue pour offrir une expérience proche d’un PC sur les cartes ESP32-P4 équipées d’un écran tactile. Le logiciel démarre directement sur une interface dédiée, tandis que les applications, au format .papp, sont stockées sur une carte microSD et chargées dans la PSRAM lors de leur lancement. Cette approche permet d’ajouter, supprimer ou exécuter des applications sans nécessiter de reflasher le firmware ou de redémarrer l’appareil, simplement en copiant des fichiers sur la carte mémoire.

Le projet propose actuellement 21 applications PAPP (PSRAM APP), principalement des émulateurs et jeux rétro, dont des titres pour Neo Geo, Atari 2600, ainsi que des classiques comme Doom, Quake, Duke Nukem 3D et OpenTyrian. Des outils comme une horloge ou un gestionnaire de fichiers sont également disponibles. L’interface utilisateur s’appuie sur LVGL, un framework graphique léger, et s’adapte à différentes résolutions d’écran. Le système gère jusqu’à huit flux audio simultanés à des fréquences allant de 4 à 192 kHz, ainsi que jusqu’à quatre périphériques d’entrée pour des sessions multijoueurs.

P4 Launcher est compatible avec plusieurs cartes de développement, dont la Guition ESP32-P4 4.3" (800×480), la Guition JC1060P470C 7" (1024×600) et la M5Stack Tab5 (1280×720). Il prend en charge divers périphériques d’entrée, comme les manettes PlayStation 3 ou Nintendo. Le projet inclut un SDK pour développer de nouvelles applications PAPP, ainsi que deux couches de compatibilité permettant d’exécuter du code existant via les API odroid_* ou le service table v1, facilitant notamment le portage de titres comme Doom ou Quake.

Les mises à jour du firmware peuvent être effectuées depuis une carte microSD ou GitHub, avec une fonction de retour automatique en cas d’échec. Le code source, basé sur ESP-IDF v5.5.2, est disponible sur GitHub. Le développement du projet a été assisté par l’assistant de codage Claude d’Anthropic.
