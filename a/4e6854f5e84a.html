RV565 : un format vidéo optimisé pour les microcontrôleurs et écrans SPI

Un nouveau format vidéo léger et indépendant des frames pour les écrans SPI, compatible ESP32-S3 et RP2350.

elixpo propose RV565, un format vidéo et un lecteur conçus pour les écrans SPI comme le ST7789, optimisés pour les microcontrôleurs à faible puissance. Contrairement aux formats classiques, chaque frame est stockée sous forme de flux zlib indépendant, déjà converti en RGB565 — le format natif des écrans ciblés. Ainsi, le microcontrôleur n’a pas besoin de traiter les pixels avant affichage, réduisant la charge de calcul.

La conversion s’effectue via un outil en ligne ou un package Python (rv565 sur PyPI), utilisant FFmpeg pour extraire les frames. L’outil prédit le temps de décodage de chaque frame grâce à un modèle de coût mesuré sur le microcontrôleur, avec une précision remarquable : sur un Pico 2, il a estimé un temps de 49,00 ms pour une frame mesurée à 49,03 ms.

Des exemples pour Arduino, un composant ESP-IDF, ainsi que des adaptateurs pour les bibliothèques TFT_eSPI et LovyanGFX sont disponibles. Ces adaptateurs permettent d’envoyer les données par DMA, optimisant encore les performances. Sur un ESP32-S3 avec des frames de 180×135 affichées sur un écran 320×240, l’utilisation mémoire est de 79,9 KiB en mode monocœur et 152,4 KiB en dual-core.

Ce projet a été développé pour l’application Gallery de l’Oreo Badge, un badge ESP32-S3 certifié OSHWA. Le code source et la documentation sont accessibles sur GitHub.
