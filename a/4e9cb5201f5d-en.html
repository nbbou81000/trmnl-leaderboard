Turning an NES into a Desktop PC with an FPGA Adapter

A project turns the original NES console into a functional desktop PC using an FPGA adapter and a custom Linux distro.

The creator Throaty Mumbo has shown that the original Nintendo Entertainment System (NES) can be repurposed into a desktop computer. Unlike modern consoles, the NES loads games directly from a cartridge, which acts as a hardware extension of the system. This feature made it possible to use a modified cartridge to embed an x86 processor via an FPGA (Field-Programmable Gate Array), a reconfigurable chip that simulates specific hardware behavior.

The adapter used, the Everdrive N8 Pro, replaces the default cartridge and transmits video and input signals to the NES processor while receiving keyboard and mouse commands through a dedicated USB adapter. The operating system, a custom Linux distribution, runs on the FPGA and manages peripherals without the NES processing complex data directly. A Wi-Fi adapter was also added to enable network connectivity.

Limitations remain: resolution and color depth are constrained by the NES’s graphical capabilities, but the setup allows for web browsing and running basic applications. The project demonstrates how an old hardware architecture can be reused for unexpected purposes with modern components.
