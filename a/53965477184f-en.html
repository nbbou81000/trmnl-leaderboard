REA: An MCP Server to Automate Reverse Engineering with AI

An MCP server connects AI agents to tools like Ghidra to automate binary analysis and code generation.

Read the article on the TRMNL Leaderboard →

REA (Reverse Engineer Anything) is an MCP server designed to streamline reverse engineering tasks using AI agents like Claude Code. It connects to analysis tools such as Ghidra, Hopper, or IDA, as well as analyzers for Electron apps, .NET applications, or websites. The goal is to allow an AI agent to dissect a function in a binary or application and generate a functional version of the code without access to the source code.

A test bench was set up using Claude Code Opus 5.5 and Ghidra 12.1.4 to evaluate REA. Four exercises were conducted: creating a keygen for a dummy application, applying a patch to modify a line and word counter utility, cloning a system wake function from a macOS app, and extracting cheat codes from a compressed DOS game (Wolfenstein 3D).

In each case, REA enabled the AI agent to analyze the binary, understand its behavior, and generate functional code. For example, the keygen exercise resulted in a Python script generated in 2 minutes, validating 479 random usernames. For the patch, the agent modified the executable by redirecting instructions to an unused memory area and re-signing the binary. For Amphetamine, REA extracted the system wake logic and generated an equivalent tool in Swift. Finally, for Wolfenstein 3D, it recreated a decompressor and identified hidden keyboard shortcuts, confirming their presence in the original source code.

However, comparative tests with an AI agent using Ghidra directly showed that REA was not consistently more efficient. It was faster in three exercises (keygen, Amphetamine, Wolfenstein 3D) but slower for the patch. REA is released under the MIT license and operates locally, though results are sent to the AI model provider. Tools like Hopper or IDA remain paid and require separate licenses.

The creator of REA specifies that the tool should not be used to bypass licenses or modify games, hence the use of dummy crackmes and already public cheat codes in the tests. Another limitation involves security: researchers have demonstrated that a malicious binary can manipulate AI agent results by injecting misleading text strings into the decompiled code.

To install REA, run the following command: npx rea-agents setup.
