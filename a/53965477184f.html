REA : un serveur MCP pour automatiser le reverse engineering avec IA

Un serveur MCP permet de connecter des agents IA à des outils comme Ghidra pour automatiser l'analyse de binaires et générer du code.

Lire l'article sur le Palmarès TRMNL →

REA (Reverse Engineer Anything) est un serveur MCP conçu pour faciliter le reverse engineering via des agents IA comme Claude Code. Il s’intègre à des outils d’analyse comme Ghidra, Hopper ou IDA, ainsi qu’à des analyseurs dédiés aux applications Electron, .NET ou aux sites web. L’objectif est de permettre à un agent IA de décortiquer une fonction dans un binaire ou une application, puis de générer une version fonctionnelle du code sans accès au code source.

Pour tester REA, un banc d’essai a été mis en place avec Claude Code Opus 5.5 et Ghidra 12.1.4. Quatre exercices ont été réalisés : la création d’un keygen pour une fausse application, un patch pour modifier un utilitaire de comptage de lignes et de mots, le clonage d’une fonction de veille système d’une application macOS, et l’extraction de codes de triche d’un jeu DOS compressé (Wolfenstein 3D).

Dans chaque cas, REA a permis à l’agent IA d’analyser le binaire, de comprendre son fonctionnement et de générer du code fonctionnel. Par exemple, pour le keygen, REA a produit un script Python en 2 minutes pour valider 479 noms d’utilisateurs aléatoires. Pour le patch, l’agent a modifié l’exécutable en détournant des instructions vers une zone inutilisée et en re-signant le binaire. Pour Amphetamine, REA a extrait la logique de veille système et généré un outil équivalent en Swift. Enfin, pour Wolfenstein 3D, il a recréé un décompresseur et identifié des raccourcis clavier cachés, confirmant leur présence dans le code source original.

Cependant, des tests comparatifs avec un agent IA utilisant directement Ghidra ont montré que REA n’était pas systématiquement plus performant. Il a été plus rapide pour trois exercices (keygen, Amphetamine, Wolfenstein 3D), mais plus lent pour le patch. REA est distribué sous licence MIT et fonctionne en local, bien que les résultats soient envoyés au fournisseur du modèle IA utilisé. Les outils comme Hopper ou IDA restent payants et nécessitent des licences séparées.

Le créateur de REA précise que l’outil ne doit pas être utilisé pour contourner des licences ou modifier des jeux, d’où l’utilisation de crackmes et de codes de triche déjà publics dans les tests. Une autre limite concerne la sécurité : des chercheurs ont démontré qu’un binaire malveillant peut manipuler les résultats d’un agent IA en y injectant des chaînes de texte trompeuses dans le code décompilé.

Pour installer REA, la commande suivante est requise : npx rea-agents setup.
