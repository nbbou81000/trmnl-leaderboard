A ZX Spectrum Demoscene Intro Written in Z80 Assembly

A developer recreates a retro demo for the 128K ZX Spectrum with graphical effects and AY music.

Read the article on the TRMNL Leaderboard →

Mark Dastmalchi-Round created a demoscene intro for a stock 128K ZX Spectrum, published on his blog. The demo features smooth scrolling text with custom fonts, a three-channel AY soundtrack, animated VU meters, and a parallax starfield. The final code is 10,287 bytes, while the complete tape image reaches 19,552 bytes. Development began on December 13 of the previous year.

The write-up explains the Z80 assembly implementation. The scrolling text uses rl (rotate left) instructions: pixels falling off one character cell drop into the carry flag and reappear in the next. The starfield avoids random number generators or X/Y coordinates: each star is stored as a screen byte plus a bit mask, with a separate occupancy table to skip cells containing text. The music, adapted from the 1989 Amiga demo Sounds Of Gnome, was squeezed from four to three channels using Vortex Tracker ornaments for arpeggio chords.

The toolchain includes the Pasmo assembler, the FUSE emulator, a basic text editor, and walks with his dogs. A demo video and source code are available on markround.com and GitHub.
