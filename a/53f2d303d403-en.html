Renesas Unveils RZ/T2N Quad-Core Chip for Robotics and Industrial Equipment

Renesas launches RZ/T2N quad-core microprocessor tailored for industrial and robotics applications with integrated motor control.

Renesas has expanded its RZ family with the RZ/T2N, a microprocessor tailored for industrial equipment and robotics. The chip integrates motor control interfaces, encoders, and industrial Ethernet connectivity into a single package, streamlining embedded system design.

The RZ/T2N features two processor clusters: a dual-core Arm Cortex-A55 cluster running up to 1.2 GHz for application processing, and a dual-core Cortex-R52 cluster optimized for real-time tasks, operating at up to 800 MHz. Each Cortex-R52 core includes 576 KB of tightly-coupled memory (TCM) and 2 MB of on-chip static RAM (SRAM), both protected by error correction code (ECC). An LPDDR4 interface supports external memory expansion.

The chip integrates a motor controller capable of handling up to four axes, along with three 12-bit analog-to-digital converters (ADCs) and a 15-channel delta-sigma intermediate-frequency (IF) interface. It also features an eight-channel motor encoder interface supporting multiple industrial protocols, including Tamagawa T-Format, HIPERFACE DSL, EnDat, and BiSS. For connectivity, three gigabit Ethernet MACs with TSN (Time-Sensitive Networking) support are included, alongside an integrated Ethernet switch and an EtherCAT Sub-Device Controller. The chip also supports PROFINET RT/IRT and EtherNet/IP protocols.

Additional interfaces include four SPI ports, three I2C buses, fourteen SCI (Serial Communication Interface) channels, two CAN-FD buses, a security block with a hardware-based true random number generator (TRNG), and a hardware accelerator for trigonometric functions. Renesas highlights that the RZ/T2N helps designers balance performance, footprint, and cost while offering scalability for next-generation industrial automation systems.

An evaluation board is available for order at $549, though the chips themselves are not yet available through sales channels at the time of announcement.
