3D-Printed Case for Adafruit QT PY ESP32-C3 with Reset Button Access

A 3D-printed enclosure designed to house an Adafruit QT PY ESP32-C3 board while providing access to the reset button and USB-C connector.

Read the article on the TRMNL Leaderboard →

A user named JeremyLaurens_210732 has designed a 3D-printed enclosure specifically for the Adafruit QT PY ESP32-C3 board. This compact case features a snap-shut top for secure protection while allowing easy access to the board's components. Two cutouts are included—one for the reset button or PIN9 pin—and a small slit at the back enables cable routing, useful for connecting external sensors like a BME280 (a combined temperature, humidity, and pressure sensor).

The enclosure is also compatible with the STEMMA version of the board, which can plug directly into a STEMMA expansion board. This design is particularly well-suited for CircuitPython users, a simplified programming framework for microcontrollers, ideal for sensor node projects.

The STL files for 3D printing are available for free download on Printables. This project aligns with the DIY electronics and 3D printing community's tradition, often highlighted every Thursday by Adafruit under the #3DThursday hashtag.
