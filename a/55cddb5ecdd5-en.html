3 Raspberry Pi Projects to Try This Weekend

System dashboards, a weather station, and a self-hosted blog to set up in just a few hours.

Read the article on the TRMNL Leaderboard →

A Raspberry Pi 4 or newer can power three quick weekend projects. The first is a system dashboard built in PHP, displaying real-time stats like CPU temperature, RAM usage, storage space, and offering remote shutdown or reboot options. Setup takes five minutes with a web server (Apache, Nginx, or Lighttpd) and PHP installed via a single command.

The second project turns an old Pi and a monitor into an astronomy and weather clock. The aw-clock software shows time, date, weather conditions, and can integrate external sensors (GPS, temperature, humidity) for added data. Compilation requires Chromium and minor tweaks, but the interface is accessible from any device on the network—perfect for multi-Pi setups.

Lastly, Haven provides a self-hosted alternative to Facebook for private blogging. This lightweight CMS supports Markdown, image uploads, and user authentication, running in Docker. Access is restricted to authorized users, making it ideal for sharing content with a trusted circle.
