Turning a Smartphone Motherboard into an RC Plane Controller

An old Xiaomi Mi 8 repurposed as an RC plane controller using LTE connectivity showcases smartphone upcycling potential.

A repurposed Xiaomi Mi 8 smartphone motherboard, eight years old, has been transformed into a controller for an RC plane using LTE connectivity. Purchased second-hand for just $23, the device was flashed with LineageOS, a lightweight and updated version of Android, to enhance its performance.

The main technical hurdle was bypassing the OS requirement for a display during boot. The operating system checks for the screen’s presence and may fail if it is missing. The solution involved editing the boot.img file to disable display detection in the device tree. Once resolved, a 3D-printed bracket was designed to securely fit the motherboard inside the plane’s fuselage.

To enable communication with the plane’s avionics, a custom USB-to-UART adapter PCB was built around a CH340 IC. This adapter facilitated initial testing by sending commands via an LTE link, replacing traditional 2.4 GHz radio control. The phone’s front camera was repurposed as an FPV (First Person View) camera for a custom Android application. Early tests confirmed compatibility with the plane’s flight controller.

Real-world testing was limited to ground trials due to local drone flight restrictions. The maiden flight is planned at a dedicated airstrip and will be documented in an upcoming video. This project aligns with a broader trend of using recycled smartphones for remote control applications, inspired by documented military uses during the conflict in Ukraine.

The primary advantage of this method is the extended range of the LTE link, far surpassing that of a traditional radio link. However, the cellular network’s latency, which can reach a few milliseconds, should be considered for applications requiring immediate responsiveness.
