FltCast: Real-Time Flight Tracker with RTL-SDR and LED Matrix

A self-contained flight tracker using RTL-SDR and a 64×32 LED matrix, without relying on external APIs.

Read the article on the TRMNL Leaderboard →

FltCast is an open-source project designed to track aircraft in real time using an RTL-SDR (a low-cost software-defined radio receiver) and a 64×32 RGB LED HUB75 matrix. Unlike most solutions that rely on APIs like OpenSky, this system captures ADS-B signals directly from passing aircraft. These signals, received via a dedicated antenna, contain position and identification data of the planes.

Once the raw data is collected on port 30003, FltCast processes it in C++ to extract relevant information. The software selects the aircraft closest to the antenna’s location and enriches the data with a local database. The results are then displayed in real time on the LED matrix, providing a visual and immediate representation of detected flights.

The project is hosted on GitHub and includes a detailed build guide for assembling the hardware, including a custom 3D-printed case. The source code and instructions are available at bytecadia.com.
