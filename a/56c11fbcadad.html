FltCast : un traqueur de vols aériens en temps réel avec RTL-SDR

Un traqueur de vols aériens autonome utilisant un RTL-SDR et une matrice LED 64×32, sans dépendre d'API.

Lire l'article sur le Palmarès TRMNL →

FltCast est un projet open source conçu pour suivre les vols aériens en temps réel à l’aide d’un RTL-SDR (un récepteur radio logiciel à bas coût) et d’une matrice LED RGB HUB75 de 64×32 pixels. Contrairement à la plupart des solutions qui s’appuient sur des API comme OpenSky, ce système capte directement les signaux ADS-B émis par les avions en vol. Ces signaux, reçus via une antenne dédiée, contiennent des données de position et d’identification des appareils.

Une fois les données brutes collectées sur le port 30003, FltCast les traite en C++ pour extraire les informations pertinentes. Le logiciel sélectionne les avions les plus proches de la position de l’antenne, puis enrichit ces données avec une base de données locale. Les résultats sont ensuite affichés en temps réel sur la matrice LED, offrant une visualisation visuelle et immédiate des vols détectés.

Le projet est hébergé sur GitHub et propose un guide de construction détaillé pour assembler le matériel, incluant l’impression 3D d’un boîtier personnalisé. Le code source et les instructions sont disponibles à l’adresse bytecadia.com.
