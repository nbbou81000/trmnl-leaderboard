DIY Cybersecurity Tool with ESP32 and OLED Display

An open-source project turns an ESP32 and OLED display into a portable cybersecurity tool for legal experimentation.

A maker using the pseudonym Yellow Purple has built a DIY cybersecurity tool inspired by the Flipper Zero, using an ESP32 microcontroller and an OLED display. This compact handheld device allows users to explore cybersecurity concepts, particularly radio-based interactions, while displaying menus and output on the integrated screen. The project focuses on learning and experimentation rather than offering a finished product.

The ESP32 handles radio functions, while the OLED screen displays interfaces and data. Wi-Fi tests are restricted to the creator’s personal network, with a clear warning that unauthorized access to other networks is illegal. No full technical specifications or assembly steps are provided, but a demonstration video is available to showcase the project in action.
