A daily newspaper printed automatically each morning

A developer automates the printing of a custom newspaper every morning using a cloud routine and a Pico 2 W.

Read the article on the TRMNL Leaderboard →

Erol Sen has built a system that generates and prints a two-page newspaper every morning without any human intervention. The process involves three separate components: a cloud routine run by Claude at 5:15 AM, GitHub Actions for layout and validation, and a Raspberry Pi Pico 2 W connected to the Wi-Fi network. The Pico retrieves the generated file and sends it to the printer at 8:45 AM on weekdays, or 10:00 AM on weekends.

The three parts communicate indirectly through a private Git repository. Each step leaves a file-based trace, and the Pico only makes outgoing HTTPS requests to GitHub every five minutes, minimizing security risks. The Pico's access token is restricted to reading the repository and triggering workflows, with no additional permissions.

The newspaper content is structured in JSON, then formatted into a fixed three-column layout on A4 paper. GitHub Actions uses Headless Chrome to generate the pages, with fonts stored in the repository, and automatically rejects versions that fail validation checks. The printer used, an HP LaserJet M111w, only supports PWG raster format without anti-aliasing, requiring a specific page generation process.

The project is released under the MIT license and requires a Raspberry Pi Pico 2 W (or Pico W), a network printer compatible with IPP, and a Claude subscription. Technical details and code are available at erolsen.dev and on GitHub.
