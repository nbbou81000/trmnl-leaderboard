Un journal imprimé chaque matin par une routine automatisée

Un développeur automatise l'impression d'un journal personnalisé chaque matin via une routine cloud et un Pico 2 W.

Lire l'article sur le Palmarès TRMNL →

Erol Sen a conçu un système qui génère et imprime un journal de deux pages chaque matin, sans intervention humaine. Le processus repose sur trois composants distincts : une routine Cloud exécutée par Claude à 5h15, GitHub Actions pour la mise en page et la validation, et un Raspberry Pi Pico 2 W connecté au réseau Wi-Fi. Le Pico récupère le fichier généré et l'envoie à l'imprimante à 8h45 en semaine, ou à 10h le week-end.

Les trois éléments communiquent indirectement via un dépôt Git privé. Chaque étape laisse une trace sous forme de fichier, et le Pico n'effectue que des requêtes HTTPS sortantes vers GitHub toutes les cinq minutes, limitant ainsi les risques de sécurité. Le jeton d'accès du Pico n'autorise que la lecture du dépôt et le déclenchement des workflows, sans accès supplémentaire.

Le contenu du journal est structuré en JSON, puis mis en page selon un modèle fixe en trois colonnes sur format A4. GitHub Actions utilise Headless Chrome pour générer les pages, avec des polices stockées dans le dépôt, et rejette automatiquement les versions non conformes aux vérifications. L'imprimante utilisée, un HP LaserJet M111w, ne prend en charge que le format raster PWG sans anti-crénelage, ce qui impose une génération spécifique des pages.

Le projet est publié sous licence MIT et nécessite un Raspberry Pi Pico 2 W (ou Pico W), une imprimante réseau compatible IPP, ainsi qu'un abonnement à Claude. Les détails techniques et le code sont disponibles sur erolsen.dev et sur GitHub.
