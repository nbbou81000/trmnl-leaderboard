PCB Autorouter Switches to Hexagonal Grid for Denser Routing

A developer proposes a hexagonal grid approach for PCB autorouters, offering denser routing and simpler algorithms than square grids.

Read the article on the TRMNL Leaderboard →

Automated PCB autorouters still lag behind human expertise, but their simpler algorithms make them approachable for determined developers. James Bowman built his own autorouter in the CuFlow PCB design tool, opting for a hexagonal grid instead of a square one to improve routing density.

Unlike square grids (with 4 or 8 neighbors depending on diagonal rules), a hexagonal grid provides six equidistant neighbors, enabling tighter trace placement. The hexagonal shape, closer to a circle, also reduces minimum-distance constraints, allowing smaller cells and more efficient space usage. The underlying algorithm, Lee’s algorithm, remains unchanged but benefits from this structure for better performance.

This approach differs from traditional external tools, which often struggle with high-speed routing requirements. Comments highlight the limits of automated autorouters: proper initial component placement can drastically reduce or eliminate the need for complex routing. Some users also warn about compatibility issues with standard file formats (like ODB) when traces are too tightly packed.

Others suggest integrating component placement optimization or advanced analysis for high-speed memory (DDR), where routing constraints are most demanding.
