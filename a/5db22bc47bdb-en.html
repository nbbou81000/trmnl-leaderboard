Pixel Art Aquarium for Interstate 75 LED Controller

An animated pixel art aquarium runs on two HUB75 LED panels controlled by a Pimoroni Interstate 75 W (RP2350).

An open-source project by NickyMoo on GitHub turns two 64 x 64 pixel HUB75 LED panels into an animated pixel art aquarium. The setup, driven by a Pimoroni Interstate 75 W (RP2350) microcontroller, displays a 128 x 64 pixel scene without requiring internet access, user accounts, or network code.

Inside the aquarium

The virtual tank features resident and visiting fish, jellyfish, a night anglerfish, a ghost, submarines, bubbles, animated foliage and coral, a snail, a hermit crab, an oyster with a pearl, and a treasure chest. Feeding animations trigger automatically at :15 and :45 past the hour, lasting 28 seconds each.

Features and limitations

The system automatically switches between day and night color palettes, with night mode active from 20:00 to 06:59. The frame rate is set to 15 FPS. Pressing button B toggles a 24-hour clock in the top-left corner, drawn over the aquarium. The RTC (Real-Time Clock) module tracks local time only, without timezone or daylight saving adjustments, and requires manual reset after power loss. A Tkinter and Pillow-based emulator, emulator.py, lets users preview the scene on a computer without hardware. The code is released under the MIT license.
