nRF54L15: Native Arduino Core Without Zephyr Dependency

An Arduino core for nRF54L15 microcontrollers removes Zephyr and nRF Connect SDK dependencies, with Bluefruit52Lib compatibility.

Read the article on the TRMNL Leaderboard →

Lolren has released nrf54-arduino-core, an Arduino core for Nordic Semiconductor’s nRF54 family of microcontrollers. Unlike existing solutions, this project interacts directly with hardware at the register level, eliminating the need for Zephyr runtime or the nRF Connect SDK. Supported boards include the Seeed XIAO nRF54L15, XIAO nRF54LM20A, HOLYIOT modules, generic modules, and Nordic’s nRF54L15 DK.

Standard Arduino functions are available: pinMode, digitalWrite, analogRead, along with Wire, SPI, and Serial interfaces. Native Bluetooth LE connectivity is supported, with a Bluefruit52Lib compatibility layer to ease porting of Adafruit-style sketches. Note that ArduinoBLE is not used as the native BLE library here.

The core also exposes the VPR RISC-V coprocessor and optimizes power management, including support for the nPM1300 PMIC and deep power-down for QSPI flash on the LM20A board. Installation is possible via the Arduino IDE’s Boards Manager or PlatformIO, which has supported GDB debugging and Unity tests since release 1.0.21. Experimental protocols like Thread, Matter, Zigbee, and Channel Sounding are included but not part of the stable feature set.
