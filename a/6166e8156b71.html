MeshCore : un protocole léger de routage maillé pour radios LoRa embarquées

Seeed Studio propose MeshCore, une bibliothèque C++ légère pour le routage multi-sauts dans des réseaux radio embarqués, compatible LoRa et autres radios par paquets.

Seeed Studio a publié MeshCore sur GitHub, une bibliothèque C++ légère conçue pour gérer le routage multi-sauts dans des projets embarqués utilisant des radios par paquets comme LoRa. Contrairement à des solutions existantes comme Meshtastic ou Reticulum, MeshCore se positionne comme une alternative adaptée aux besoins des développeurs souhaitant intégrer des fonctionnalités de routage maillé dans des systèmes embarqués, avec un accent sur les usages hors ligne et d'urgence.

Le protocole permet aux nœuds du réseau de relayer automatiquement les messages entre eux, étendant ainsi la portée bien au-delà de la limite d'un seul lien radio, sans nécessiter de connexion internet. Des binaires précompilés sont disponibles pour plusieurs appareils compatibles, éliminant la nécessité de compiler manuellement le firmware. Le flashage s'effectue via des outils comme Adafruit ESPTool, et le réseau peut être configuré ou surveillé via une console série. Selon la version flashée, les nœuds peuvent se connecter via BLE, USB ou Wi-Fi.

La configuration des répéteurs et des serveurs de salle s'effectue soit via un outil web accessible via USB, soit à distance via LoRa depuis une application mobile dédiée. Un exemple d'application, Simple Secure Chat, permet d'échanger des messages chiffrés directement depuis le moniteur série de Visual Studio Code ou une application terminal série sur Android.
