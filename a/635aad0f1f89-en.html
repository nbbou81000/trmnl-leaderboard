PS2 in Browser: Static Recompilation to WebAssembly

An open-source project runs PS2 games in a browser without an emulator.

Read the article on the TRMNL Leaderboard →

Samir (@snuri00) has released ps2-web-recomp on GitHub, a tool that runs PlayStation 2 games directly in a browser without an emulator. Instead of emulation, this approach uses static recompilation: the machine code of the PS2’s Emotion Engine processor is translated ahead of time into C++, then compiled to WebAssembly. The project also includes a partial reimplementation of the PS2’s operating system and hardware, with graphics rendering handled by WebGPU.

The first game tested, Gran Turismo 4, was chosen for its complexity: it leverages both of the PS2’s vector units, precise floating-point calculations, and advanced graphics techniques, such as reading rendered images back to generate palettes. The game boots, displays menus, allows racing with sound, and even saves progress to a virtual memory card stored in the browser. On a laptop with an integrated GPU, the project achieves 50 frames per second in Chrome at twice the PS2’s native resolution.

Another game, God of War II, was adapted using the same scripts with no game-specific changes. This test uncovered two bugs: one in the recompiler and another in the timing of the vector units. Converting an ISO disc image of a game you own into a web page takes about three and a half minutes on an 8-core laptop. No game data is included with the project.
