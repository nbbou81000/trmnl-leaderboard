ESP32 Flight Tracker Running on an Apple II CRT Monitor

A geeky project combines an ESP32 with an Apple II monochrome CRT to display real-time ADS-B flight data.

Read the article on the TRMNL Leaderboard →

This aerial project uses an ESP32-WROOM-32 microcontroller to fetch ADS-B flight data and display it on a green monochrome CRT screen from an old Apple II. The ESP32, equipped with an 8-bit digital-to-analog converter, generates a composite video signal compatible with the vintage monitor’s input. No external power supply is needed, as the dev board connects directly to the screen.

The application, developed without sharing the code, also includes weather data and local sensor readings accessible via Wi-Fi. The creator admits to using large language models to quickly generate the interface, describing the project as "vibe-coded"—built purely for fun without aiming to share the code. The CRT screen, with its retro green display, adds a distinctive aesthetic touch to the project.
