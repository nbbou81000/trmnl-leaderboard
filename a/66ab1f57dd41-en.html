Semtech's LR2021 LoRa chip repurposed as an open-source SDR receiver

An open-source project leverages an undocumented command in Semtech’s LR2021 to turn it into an SDR receiver spanning 100 MHz to 2.74 GHz.

The LR2021-SDR project by Samuel Reynolds repurposes Semtech’s LR2021 LoRa transceiver into a software-defined radio (SDR) receiver, leveraging an undocumented ROM command to access raw 16-bit I/Q samples. This enables decoding of P25 Phase 1 digital voice, POCSAG pager messages, and analog FM signals without an external SDR dongle.

Features and technical constraints

The LR2021-SDR supports reception from 100 MHz to 2.74 GHz, far exceeding the chip’s official 150–960 MHz and 1.5–2.5 GHz bands. Continuous capture at 125,000 complex samples per second runs for up to 391 seconds without data loss, while short bursts reach 250,000 samples/s. Higher rates (500,000 or 1,000,000 samples/s) cause FIFO overflows due to the 16 MHz SPI interface limitation. Experimental transmission is also supported for short bursts, such as P25 voice frames or sensor data, but continuous transmission and real-time voice remain under development.

The GPL-3.0-licensed firmware includes a C library, standalone ESP32-P4 firmware, Python tools, and build instructions. It can be used with the LakeShark project for handheld SDR scanning or in USB capture mode for offline analysis on a computer. Tests confirmed reception at 100 MHz, 1.3 GHz, 2.6 GHz, and 2.74 GHz, though performance varies by hardware and does not guarantee calibrated sensitivity across all devices.
