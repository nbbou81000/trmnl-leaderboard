A pen plotter converts Markdown into handwriting

A tool converts Markdown into handwritten text drawn by a pen plotter, for customized lists or notes.

Read the article on the TRMNL Leaderboard →

Daniel Catt has built a tool that converts Markdown text into handwritten-style drawings using a pen plotter. His setup uses a Bantam Tools NextDraw 8511, controlled via Kitty, his AI assistant. The system generates morning to-do lists, envelope addresses, or packing lists on A6 index cards or A5 notes.

Unlike a laser printer, this plotter is slower, but it allows users to start the process and collect the pages later. The tool supports headings, underlining, strikethrough, and bold text—with bold achieved by writing over the same word multiple times. Italics are not supported. The text is not rendered using fonts but converted into a single-stroke cursive SVG, designed to be drawn by hand with a pen.

Catt also wrote node-based code to chain a random seed through his "70s Pop" generator, followed by a kaleidoscope step, then scaling and placement. He then plotted the node graph itself as an SVG. He notes that he has spent more time this month fine-tuning his plotting tools than actually plotting.
