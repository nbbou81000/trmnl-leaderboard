A Coffee Machine Turned into a Doom Console by a Hardware Hacker

A tinkerer hacked a Linux-based coffee machine to run Doom, leveraging debug interfaces and security flaws.

Hardware hacker Robin M. transformed a Spengler PSL50 coffee machine into a Doom-running console by exploiting its embedded Linux system. His journey began with the discovery of an unused microphone mentioned in the device’s service documentation, prompting him to purchase a spare display/controller module on eBay for further investigation.

The coffee machine’s main board features an NXP i.MX 6 processor (Arm Cortex-A9) running a Yocto-based embedded Linux system. It includes Ethernet, USB, microSD storage, and interfaces for payment hardware, cup dispensers, and energy-saving modules. After powering the board with 24 volts, Robin identified a 3.3 V UART connector (115,200 baud) providing access to the unprotected U-Boot bootloader.

By altering the kernel command line, he launched a root shell and changed the system password. The USB update mechanism was also found to be flawed: updates rely on an autorun.sh script and a hash, but the verification key is stored in plaintext on the device. Robin bypassed this security to inject custom code.

After confirming the microphone wasn’t actively recording, he focused on running Doom. Despite an outdated Linux environment (kernel 3.10.17) and glibc 2.18, he used fbDOOM, a lightweight port that renders directly to the framebuffer. The game was executed from a prepared USB drive, first in testing and then on the actual machine.
