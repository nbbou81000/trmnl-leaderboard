Super Mario 64 Runs on a Zune HD Thanks to a Software Hack

A developer successfully runs Super Mario 64 on a 2009 Zune HD, a technical feat achieved through complex software porting.

The Zune HD, Microsoft’s media player released in 2009, proves to be more than just an MP3 player. Powered by an NVIDIA Tegra APX 2600 processor, a dedicated GPU, and 128 MB of RAM, it ran Windows CE 6.0, a system closely related to Windows Phone 7. This hardware, already advanced for its time, enabled developer rsheldiii to port Super Mario 64 to the device.

The project leverages sm64ex, a modified version of sm64-port, itself derived from a full decompilation of the original game. While this adaptation initially targets Linux and Windows, rsheldiii had to add a hardware-specific layer for the Zune HD. The process includes pre-compiling shaders using NVIDIA Tegra tools, as the Zune HD’s graphics driver cannot compile them on the fly. An XNA interface, required to run programs on the device, serves as a launcher before the game itself starts.

The results are impressive: the game runs smoothly, without noticeable lag. On-screen touch controls, adjustable in transparency, provide a viable gaming experience. Sound and save functionality work as expected. The Zune HD even features video output, potentially allowing gameplay on an external screen with an appropriate controller.
