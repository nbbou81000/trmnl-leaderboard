DIY Internet Radio with ESP32-S3 and OLED Display

A minimalist internet radio kit using an ESP32-S3, an OLED screen, and an I2S audio amplifier.

Read the article on the TRMNL Leaderboard →

This project offers a DIY solution to listen to internet radio stations without relying on AM/FM waves. The system’s core is an ESP32-S3 development board, featuring built-in Wi-Fi to connect directly to the network and stream audio.

The user interface consists of a 1.3-inch OLED screen connected via I2C and a rotary encoder for navigation. Audio output is handled by an I2S MAX98357 amplifier paired with a 3 W speaker. After flashing the firmware, the device only needs the Wi-Fi credentials and the station’s URL to start playing.

This build demonstrates a streamlined way to turn a microcontroller into a multimedia tool, using accessible components and standard protocols. Electronics tinkerers can adapt this design for other purposes, such as voice commands or local playlist management.
