WLED Wi-Fi RGB Matrix Panel Clock Powered by ESP32-C3

An open-source project turns an 8×32 LED matrix into a Wi-Fi clock with light effects and scrolling text.

Read the article on the TRMNL Leaderboard →

A maker going by DrejkCZ has shared an open-source project to turn an 8×32 WS2812 RGB LED matrix into a Wi-Fi-enabled clock. The setup uses an ESP32-C3 Super Mini microcontroller, which supports both Wi-Fi and Bluetooth, to drive four 8×8 LED modules (256 LEDs total) via GPIO 8. The wiring follows the GRB color order and limits power draw to 1000 mA.

The project runs WLED firmware, installed directly from install.wled.me. This allows automatic NTP time synchronization and timezone configuration. Features include clock display, scrolling text input, and built-in light effects. All settings can be adjusted remotely via a web browser or mobile app without requiring programming skills.

The necessary files, including the code and 3D-printable enclosure design, are available for download on MakerWorld. The project aligns with the Adafruit ecosystem, simplifying access to compatible components and documentation.
