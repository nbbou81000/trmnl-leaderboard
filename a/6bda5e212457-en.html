SolidCraft: Open-Source Parametric CAD for Desktop and Browser

A new open-source 3D modeling tool, written in Rust, offers parametric and automation-friendly design.

Read the article on the TRMNL Leaderboard →

SolidCraft is a new open-source 3D modeling tool designed to stand out with its parametric and automation-friendly approach. Built entirely in Rust, it organizes 3D models as a sequence of operations in a timeline. Changing a parameter—such as wall thickness—automatically triggers the rebuilding of dependent features, eliminating manual recalculations.

The software runs both as a desktop application and a web-based tool accessible through a browser. All user actions are exposed as JSON-based commands, enabling easy scripting and automation. SolidCraft also includes a headless command-line interface and an MCP (Model Context Protocol) server, allowing AI agents to interact with the software programmatically.

Still in early development, SolidCraft already supports core features like sketching, solid modeling, and constraint management. A live online demo is available for hands-on testing, while a development roadmap outlines upcoming features. The project emphasizes modularity, separating rendering from command execution to enable innovative use cases.
