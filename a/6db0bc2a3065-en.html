Konnect: A KiCad 10 Plugin for AI-Assisted PCB Design

A Rust plugin for KiCad 10 enables AI-assisted PCB design through the Model Context Protocol.

Read the article on the TRMNL Leaderboard →

Konnect, created by GitHub user mixelpixx, is a native plugin for KiCad 10 that enables AI-assisted electronic schematic and PCB design through the Model Context Protocol (MCP). Written in Rust, this standalone binary weighs 20 to 25 MB after installation and is distributed as a roughly 9 MB download, requiring no additional dependencies or version matching.

The plugin provides 228 tools across 21 on-demand toolsets, covering the entire workflow: schematic capture, PCB layout and routing, ERC and DRC checks, design-review audits, JLCPCB part search, and manufacturing exports. To optimize token costs, the router does not load all tools at once (about 23,000 tokens) but uses a starter kit of 2,000 tokens and loads required toolsets as needed.

Konnect succeeds the older KiCAD-MCP-Server, a Python and TypeScript project. The rewrite removes SWIG bindings, now deprecated by KiCad, and communicates with KiCad 10 via the official IPC API, using protobuf over NNG. Edits integrate seamlessly with KiCad’s undo and redo functions. Schematic files are edited using an S-expression engine with atomic writes and UUID preservation. A standalone schematic viewer is also included, re-rendering files in real time as they change.
