Moonfin: The Jellyfin Client Built for Homelabbers

Moonfin, a Jellyfin and Emby client, includes built-in admin tools and advanced features for self-hosted server users.

Read the article on the TRMNL Leaderboard →

Moonfin stands out from other Jellyfin and Emby clients by embedding server administration tools directly into its interface. Unlike traditional solutions that require leaving the app to manage the server via a web dashboard, Moonfin lets you edit user settings, modify libraries, view logs, or adjust server configurations without ever leaving the application.

The client supports connecting to multiple Jellyfin and Emby servers at once, merging their contents into a single unified library. Features like global search or the "Continue Watching" list then apply across all connected servers, making it easier to manage a scattered server setup (mini PC, NAS, etc.).

Moonfin also includes native integration with Seerr, a self-hosted app for discovering media and managing content requests. Users can browse upcoming releases, submit requests for missing movies or shows, and track their progress directly within Moonfin. The optional Moonbase extension syncs settings across devices, stores API keys server-side, and delivers push notifications.

For retro gaming enthusiasts, Moonfin lets you play ROMs directly from the app. The client supports multiple emulators (NES, SNES, GBA, DS, PS1, N64, etc.), with save states synced between devices. Gamepad navigation is optimized, eliminating the need for touchscreens or remote controls.

Finally, Moonfin adapts its playback engine based on the platform to minimize transcoding, a resource-intensive process. Depending on the device (Apple, Windows, Android, Roku), it uses dedicated engines like AetherEngine, libmpv, or ExoPlayer, reducing unnecessary conversions and improving compatibility with native formats.
