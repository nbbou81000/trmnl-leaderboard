LILYGO T-Display K230: RISC-V AI Dev Kit with AMOLED Screen and LoRa

A portable development kit powered by a dual-core RISC-V SoC with AI accelerator, AMOLED touchscreen, and LoRa or cellular connectivity.

The LILYGO T-Display K230 is a portable development kit built around the dual-core Kendryte K230 RISC-V processor running at 1.6 GHz for the main core and 800 MHz for the secondary, with support for vector extensions and 64-bit floating-point units. It features a dedicated AI accelerator (KPU), compatible with TensorFlow, PyTorch, and ONNX, delivering typical performance of 85 frames per second for ResNet-50 in INT8.

The kit includes a 4.1-inch AMOLED touchscreen (568×123 pixels) driven by an RM69A10 controller, along with a rotatable 2MP camera module (GC2093) capable of 1080p recording. It also offers an HDMI output up to 1080p30, a 10/100 Mbps Ethernet port, and WiFi 4 connectivity. Two wireless options are available: a LoRa transceiver (SX1262 or LR2021) and, via an optional keyboard, an nRF9151 module for LTE-M/NB-IoT cellular and GNSS positioning.

The kit provides 1GB of LPDDR4 RAM, a microSD card slot for storage, built-in microphone and speaker, and an I2S audio amplifier. Three USB Type-C ports handle power, debugging, and OTG connectivity. A bare board version is available, while a cased version adds a 40-pin GPIO header and a Qwiic I2C port. The optional detachable keyboard includes a keyboard controller, backlighting, and battery management for two 21700 cells.

Software support includes Kendryte’s Linux SDK, CanMV and RT-Smart firmware, and an LVGL-based launcher. Example applications for camera, video, audio, LoRa, and battery monitoring are provided. Experimental support for Meshtastic and LoRaWAN is also included.

The kit starts at $98.79 for the bare board, $150 for the cased version, and $180 for the LoRa transceiver variant. The optional keyboard ranges from $70.94 to $133 depending on configuration.
