Encrypted IoT Networking via RF24Gateway with nRF24, nRF52x and nRF54x

An open-source project adds encryption to radio communications between nRF24, nRF52 and nRF54 microcontrollers using RF24Gateway.

A developer has announced the addition of encryption to wireless communications between nRF24, nRF52, and nRF54 microcontrollers via an update to RF24Gateway. This project, based on the nrf_to_nrf library, enables direct radio exchanges without relying on Bluetooth or Zigbee. It leverages the Enhanced ShockBurst (ESB) protocol, an optimized radio communication method for Nordic Semiconductor microcontrollers.

The nrf_to_nrf library already included AES/CCM encryption for nRF52840 and nRF54L15 models. This feature is now extended to other nRF52 and nRF54 components. The goal is to integrate this encryption into RF24Gateway, a tool that turns microcontrollers into wireless Ethernet adapters. This allows protocols like MQTT or HTTP to run over a secure radio network.

RF24Gateway requires a Linux device with GPIO and SPI ports, such as a Raspberry Pi. The code is already written, and pull requests are under review. The developer expects an official release within the next 48 hours. Technical details are available on the Seeed Studio forum and the associated GitHub repository.
