SylphideOS: A Graphical OS for Microcontrollers

A graphical operating system for microcontrollers, inspired by 1990s Macintosh, running on FreeRTOS.

By 2026, microcontrollers have become powerful enough to rival computers from the 1990s. SylphideOS, created by Thomas, introduces a graphical operating system (GUI) with a user interface reminiscent of early Macintosh machines, but designed to run on microcontrollers. Unlike most projects that emulate old hardware, SylphideOS leverages the raw power of microcontrollers to deliver a functional OS.

The system is built on FreeRTOS, a well-established open-source real-time operating system that handles task scheduling and resource management. SylphideOS supports standard hardware interfaces, including display via a framebuffer, keyboard input, and storage. Currently, it is compatible with the RP2350 platform and selected ESP32 variants, as well as an emulator for development and testing. This project stands out by offering a persistent OS that operates independently of the running applications, unlike many existing solutions that function primarily as bootloaders.

The multi-platform support expands potential use cases, though its viability as a desktop system remains unproven. While the project has sparked curiosity, its long-term success hinges on delivering a stable user experience and performance that meets the tight constraints of microcontrollers.
