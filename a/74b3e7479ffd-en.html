BeagleConnect QuadESC: Open-Source 4-Channel BLDC Motor Controller

BeagleBoard.org unveils an open-source 4-channel BLDC motor controller based on TI’s AM13E23019 SoM, targeting robotics and drone applications.

BeagleBoard.org has launched the BeagleConnect QuadESC, an open-source carrier board designed to control four three-phase BLDC (brushless DC) motors. It relies on the BeagleConnect Torque SoM, featuring a TI AM13E23019 microcontroller (Cortex-M33 at 200 MHz) with a trigonometric math unit (TMU) and a TinyEngine neural-network accelerator for edge AI.

The QuadESC board includes four DRV8323SRTAR (TI) gate drivers per motor, with synchronized current and voltage sensing, as well as four temperature sensors. It offers an 8-pin flight controller interface (DShot, telemetry, current reporting) and a CAN FD connector. The Torque SoM, measuring 25.4 × 38.1 mm, provides 128KB SRAM, 512KB flash, and UART, SPI, I²C, and CAN interfaces. Power input requires a regulated 5V supply, while analog measurements need an external reference (VAA).

Targeting multi-motor applications like drones or robotics, the QuadESC supports continuous currents up to 40A and bursts up to 70A per motor (subject to thermal validation). It accepts 3S to 6S batteries (9–25.2V) and includes TI regulators for power management. Software support includes TI’s AM13E2X SDK, with Zephyr RTOS and OpenOCD compatibility in development. The board ships without pre-loaded firmware; users must implement motor control, current sensing, and fault handling. KiCad hardware designs, firmware sources, and documentation are available on GitHub.

Pricing and availability have not been announced. Further details are available on the product page and Embed Consult’s website.
