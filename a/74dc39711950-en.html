The oldest native GUI application still running on Windows 11

A user identifies a 1992 graphical program running natively on Windows 11 without modification or emulation.

Read the article on the TRMNL Leaderboard →

A survey published on blog.enlyth.com identified CDPLAYER.EXE, a Windows built-in audio player, as the oldest graphical user interface (GUI) application still running natively on Windows 11. Dated November 16, 1992, and originating from Windows NT build 347, this program relies on compatibility mechanisms still present in current Windows versions.

The research ruled out 16-bit applications, incompatible with 64-bit Windows, as well as pre-1992 versions. Windows NT 3.1 builds from 1991 used an unsupported Portable Executable (PE) format, while mid-1992 versions employed a Windows API call convention incompatible with modern standards, causing crashes. CDPLAYER.EXE avoids these issues by using the system library crtdll.dll, still included in Windows 11’s SysWOW64 folder. To function, it requires a cdemu.dll file that emulates a CD-ROM drive, enabling audio playback.

The survey also highlights FREECELL.EXE (February 22, 1993), playable via Win32s, and REVERSI.EXE (November 15, 1985, Windows 1.01), which runs only with an emulator like otvdm. Technical details and source links are available on blog.enlyth.com and a related GitHub repository.
