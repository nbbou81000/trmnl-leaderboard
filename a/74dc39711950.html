Le plus vieux logiciel GUI natif encore compatible avec Windows 11

Un utilisateur identifie un programme graphique de 1992 fonctionnant sans modification ni émulation sur Windows 11.

Lire l'article sur le Palmarès TRMNL →

Une enquête publiée sur blog.enlyth.com a déterminé que CDPLAYER.EXE, un lecteur audio intégré à Windows, est le plus ancien logiciel graphique (GUI) encore exécutable nativement sur Windows 11. Daté du 16 novembre 1992 et issu de la build 347 de Windows NT, ce programme exploite des mécanismes de compatibilité encore présents dans les versions actuelles de Windows.

Les recherches ont écarté les applications 16 bits, incompatibles avec les versions 64 bits de Windows, ainsi que les versions antérieures à 1992. Les builds de Windows NT 3.1 de 1991 utilisaient un format de fichier exécutable (PE) non supporté par Windows 11, tandis que les versions de mi-1992 employaient un appel de fonctions Windows (API) incompatible avec les conventions modernes, provoquant des plantages. CDPLAYER.EXE évite ces écueils en s’appuyant sur la bibliothèque système crtdll.dll, toujours présente dans le dossier SysWOW64 de Windows 11. Pour fonctionner, il nécessite un fichier cdemu.dll simulant un lecteur CD-ROM, permettant la lecture de fichiers audio.

L’enquête mentionne également FREECELL.EXE (22 février 1993), jouable via Win32s, et REVERSI.EXE (15 novembre 1985, Windows 1.01), exécutable uniquement avec un émulateur comme otvdm. Les détails techniques et les liens vers les sources sont disponibles sur blog.enlyth.com et un dépôt GitHub associé.
