Open Firmware Revives Dead Onkyo AV Receivers

An open-source firmware bypasses hardware limitations in dead Onkyo receivers, enabling critical component replacements without losing functionality.

Read the article on the TRMNL Leaderboard →

Some Onkyo audio-video receivers, such as the TX-NR717 model, can suffer from a specific failure: the device powers on but produces no sound. According to developer Jokūbas, this issue is often linked to two components: the D830 (or DA830) processor from Texas Instruments, or the 64 MB NAND flash memory chip storing the firmware. If either of these components fails, replacing them with standard parts proves difficult.

For instance, the D830 processor can be swapped with a compatible model like the OMAP-L137, but the stock firmware fails to boot with the new chip. Similarly, modern NAND flash memories use 2 KB or 4 KB pages, compared to the 512-byte pages of original models, making their replacement impossible without software adaptation.

The OSIRIS project, an open-source firmware, addresses these issues by supporting both compatible D830 processors and modern flash memories. Once the hardware is replaced and the new firmware is installed, the Onkyo receiver regains its functionality. However, the project is still in development: the list of implemented features remains limited, and some elements are either untested or non-functional.

The firmware does not resolve all hardware issues: some passive components may still require replacement to restore proper operation.
