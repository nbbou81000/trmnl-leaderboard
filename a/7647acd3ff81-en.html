Thoreau BASIC: A Modern Take on GW-BASIC for x86 PCs

A project revives GW-BASIC, compatible with old code, but optimized for modern PCs and 21st-century features.

Read the article on the TRMNL Leaderboard →

Thoreau BASIC is a modern reinterpretation of GW-BASIC, the historic language bundled with early IBM-compatible PCs. Unlike the original, this project retains the old syntax (line numbers, GOTO statements) while adapting it to contemporary standards.

The software can boot directly from a modern x86 PC’s UEFI or run under Windows. It leverages 64-bit architectures, including memory management and multithreading. Graphics are rendered in 24-bit color at any resolution supported by the display. Additional commands handle file management, keyboard/mouse input, sound (32 channels), and even sprite rendering.

Thoreau BASIC is not open source, but the author offers a "pay what you want" model on Itch.io, where sample programs are also available. The project stands out from other BASIC revival attempts, such as MoonBASIC or BASIC-256, by staying closer to the original while integrating modern features.
