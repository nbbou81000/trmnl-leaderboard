Adafruit teste de nouveaux codes pour un écran DIY HomeView en CircuitPython

Pedro d'Adafruit présente les avancées du projet DIY HomeView avec des prototypes et du code CircuitPython pour écrans Metro ESP32-P4.

Lire l'article sur le Palmarès TRMNL →

Lors d’un live récent, l’équipe Adafruit a détaillé les développements autour du projet DIY HomeView, une initiative open source visant à créer des écrans d’affichage personnalisés à l’aide de microcontrôleurs et de CircuitPython. Pedro, ingénieur chez Adafruit, a présenté les dernières versions du code et des prototypes fonctionnels pour le Metro ESP32-P4, une carte compatible avec des écrans tactiles comme le 7in Pi Touch Display 2 ou le 5in Pi Touch Display 2.

Le projet s’appuie sur CircuitPython, un langage de programmation simplifié pour l’électronique, permettant aux développeurs de créer rapidement des interfaces graphiques pour des écrans e-ink ou LCD. Les prototypes testés intègrent des fonctionnalités de base comme l’affichage de données en temps réel, avec une attention particulière portée à la stabilité et à la compatibilité des bibliothèques logicielles.

En parallèle, l’équipe a mis en avant un modèle 3D original, le Christmas Creeper, une création festive inspirée des créatures de Minecraft, conçue pour être imprimée en 3D. Ce projet illustre l’intégration croissante entre électronique et impression 3D, un thème récurrent dans la communauté maker. Le modèle est disponible en téléchargement sur MakerWorld, avec une vidéo de démonstration associée.

Les développeurs intéressés par le projet DIY HomeView peuvent suivre les mises à jour sur les canaux officiels d’Adafruit, où les fichiers et le code sont partagés en open source.
