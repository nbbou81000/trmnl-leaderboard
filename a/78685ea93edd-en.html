Lxa: Native AmigaOS Emulation Layer for Linux

A new tool runs AmigaOS programs natively on Linux without dedicated hardware.

Read the article on the TRMNL Leaderboard →

Guenter Bartsch has released lxa, a Linux Amiga emulation layer published on GitHub under the MIT license. This tool runs AmigaOS 3.1 applications natively on Linux, similar to how WINE runs Windows programs. It combines a 68000 CPU emulator with AmigaOS library implementations, while bridging system calls to Linux file and I/O operations.

On first execution, lxa creates a ~/.lxa/ directory containing the required system files. Unlike other solutions, it focuses solely on OS-compliant applications, omitting emulation of ECS or AGA chip registers. Display output uses RTG (Retargetable Graphics) systems like Picasso96, enabling true-color output at arbitrary resolutions. The stated goal is to provide a development platform for Amiga software on Linux, allowing productivity apps, IDEs, and GUI toolkits to run on a Linux PC or Raspberry Pi without Amiga hardware.

Development of lxa is validated by comparing results against a reference AmigaOS 3.1 machine. A companion tool, twin runner, executes the same scenarios on both lxa and the reference, then compares Intuition trees, pixel snapshots, and text output. All 9,932 executables from the Fred Fish collection have been successfully run under lxa. Version 0.11.28 closes milestone M2, adding support for GELs, copper lists, PaletteExtra, and library versions matching AmigaOS 3.1.
