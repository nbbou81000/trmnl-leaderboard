eeink: ESP32-Powered Text Adventures on E-Ink Readers

An open-source project turns Xteink e-ink readers into text adventure platforms, featuring a dedicated IDE.

Read the article on the TRMNL Leaderboard →

The eeink project, created by [t0mg], repurposes Xteink e-ink readers into platforms for interactive text adventures. These devices, powered by an ESP32 microcontroller, are popular for their compact size and affordability while remaining highly customizable. The X4 Pro model features an ESP32-S3 with additional RAM, while the X3/X4 versions use an ESP32-C3, which has stricter memory limitations.

The project focuses on adventures written in the ink scripting language, designed for interactive storytelling. To streamline development, [t0mg] created eenkY, an open-source integrated development environment (IDE) under the MIT license, available on GitHub. This tool enables users to design choose-your-own-adventure books or text-based games and run them directly on Xteink readers. A demo video demonstrates the project in action.

Originally intended for reading, Xteink devices prove versatile for gaming or educational purposes. Their support for custom firmware makes them adaptable, though some versions sold by third-party retailers are locked, requiring unlocking to install alternative software.
