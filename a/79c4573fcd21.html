eeink : des aventures textuelles sur liseuse e-ink ESP32

Un projet open source transforme les liseuses Xteink en plateformes pour jeux d'aventure textuels, avec un IDE dédié.

Lire l'article sur le Palmarès TRMNL →

Le projet eeink, développé par [t0mg], permet de transformer les liseuses Xteink en supports pour des aventures textuelles interactives. Ces appareils, basés sur un microcontrôleur ESP32, sont appréciés pour leur taille compacte et leur prix abordable, tout en restant hautement personnalisables. Le modèle X4 Pro intègre un ESP32-S3 offrant plus de mémoire vive, tandis que les versions X3/X4 utilisent un ESP32-C3, limitant leur capacité de stockage.

Le projet cible spécifiquement les aventures écrites avec le langage ink, un outil de script dédié aux récits interactifs. Pour faciliter la création, [t0mg] a développé eenkY, un environnement de développement intégré (IDE) open source sous licence MIT, disponible sur GitHub. Ce logiciel permet de concevoir des livres dont vous êtes le héros ou des jeux d'aventure textuels, puis de les exécuter directement sur les liseuses Xteink. Une vidéo de démonstration illustre le fonctionnement du projet.

Les liseuses Xteink, souvent utilisées pour la lecture, se révèlent ainsi adaptées à des usages ludiques ou éducatifs. Leur compatibilité avec des firmwares personnalisés en fait des outils polyvalents, bien que certaines versions distribuées par des revendeurs tiers soient verrouillées, nécessitant un déverrouillage pour installer des logiciels tiers.
