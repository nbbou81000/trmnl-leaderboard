Visualize Regular Expressions with a Virtual Marble Run

An interactive tool turns regular expressions into a marble run to visualize how they process strings.

Read the article on the TRMNL Leaderboard →

For those who grasp concepts better through physical visualization than abstract symbols, Regex Marble Run offers a playful way to break down regular expressions. The tool generates a virtual marble machine that illustrates, step by step, how a regular expression processes a string.

Users input a regular expression and a test string. Each character in the string is represented by a marble that travels through the expression’s components. Marbles that match the criteria land in a success box, while mismatches end up in a failure box. For example, the expression ^[hH]ack.[dD][^0-9]*$ is split into segments: the caret (^) enforces a string start, [hH] accepts either h or H, and the dot (.) matches any single character. The brackets [dD] target a d or D, while [^0-9] excludes digits, and the asterisk (*) allows zero or more occurrences.

The site enables real-time visualization of matches, with step-by-step navigation through the process. While not intended to replace existing regular expression editors like regex101.com or regexr.com, it provides a visual alternative for understanding basic mechanisms or debugging complex patterns. Available online, it requires no installation.
