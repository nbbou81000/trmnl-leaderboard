Visualisez les expressions régulières avec un jeu de billes virtuel

Un outil interactif transforme les expressions régulières en parcours de billes pour mieux comprendre leur fonctionnement.

Lire l'article sur le Palmarès TRMNL →

Pour ceux qui saisissent mieux les concepts concrets que les abstractions, Regex Marble Run propose une approche ludique pour décortiquer les expressions régulières. L’outil génère une machine à billes virtuelle qui illustre, étape par étape, comment une expression régulière analyse une chaîne de caractères.

L’utilisateur saisit une expression régulière et une chaîne de test. Chaque caractère de la chaîne est représenté par une bille qui traverse les différents éléments de l’expression. Les billes qui correspondent aux critères de l’expression atterrissent dans une boîte de succès, tandis que les autres finissent dans une boîte d’échec. Par exemple, l’expression ^[hH]ack.[dD][^0-9]*$ est décomposée en segments : le caret (^) impose un début de chaîne, [hH] accepte un h ou H, et le point (.) correspond à n’importe quel caractère. Les crochets [dD] ciblent un d ou D, tandis que [^0-9] exclut les chiffres, et l’astérisque (*) autorise zéro ou plusieurs occurrences.

Le site permet de visualiser les correspondances en temps réel, avec la possibilité de naviguer pas à pas dans le processus. Bien que l’outil ne soit pas conçu pour remplacer les éditeurs d’expressions régulières existants comme regex101.com ou regexr.com, il offre une alternative visuelle pour comprendre les mécanismes de base ou déboguer des motifs complexes. Disponible en ligne, il ne nécessite aucune installation.
