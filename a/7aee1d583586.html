Une caméra thermique pilotable via navigateur avec WebUSB

Un projet open source associe un capteur FLIR Lepton à un RP2040 pour afficher des images thermiques directement dans un navigateur, sans application dédiée.

Lire l'article sur le Palmarès TRMNL →

Ce projet transforme un capteur thermique FLIR Lepton en périphérique autonome pilotable via un navigateur web grâce à la technologie WebUSB. Le cœur du système repose sur un microcontrôleur RP2040, qui communique avec le capteur sans circuit de support complexe, la gestion de l’alimentation et des protocoles étant assurée par l’hôte USB (ici, un ordinateur).

L’utilisation est simplifiée : il suffit de se rendre sur une page web hébergée localement, compatible WebUSB, pour visualiser les images thermiques en temps réel. L’interface, hébergée sur GitHub, est conçue pour éviter la dépendance à une application mobile ou desktop, souvent abandonnée à moyen terme. Cette approche garantit une meilleure pérennité du projet, le navigateur servant de plateforme stable pour l’interaction.

Les commentaires soulignent les avantages de WebUSB, comme son intégration native dans les navigateurs modernes et sa résistance aux évolutions logicielles, contrairement aux applications dédiées. Certains suggèrent d’aller plus loin en intégrant une page web directement sur le périphérique, mais les contraintes techniques (nécessité d’un HTTPS local) et les limitations des navigateurs rendent cette solution moins accessible. D’autres évoquent des alternatives comme l’émulation d’un périphérique UVC (pour la vidéo standard), mais les paramètres spécifiques aux caméras thermiques rendent cette option peu adaptée.
