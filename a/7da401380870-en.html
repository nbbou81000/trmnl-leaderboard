LoraReach: Open-Source Carrier Board to Build Your Own LoRaWAN Gateway

An open-source carrier board to design a custom LoRaWAN gateway based on a Raspberry Pi Compute Module 4.

LoRaWAN is an IoT technology designed to send small data packets over long distances with minimal power consumption. It is widely used in environmental monitoring, agriculture, and industrial automation, where sensors are spread across large areas. However, these sensors require gateways to connect their data to the internet, and commercial solutions often lack flexibility for customization.

Brightix introduces LoraReach, an open-source carrier board designed to build a custom LoRaWAN gateway. Unlike proprietary solutions, this board provides a customizable hardware foundation while allowing users to run their own software. It is built around a Raspberry Pi Compute Module 4 (CM4), which is also compatible with other pin-compatible compute modules, offering the power of an embedded Linux computer.

The board features two mini-PCIe slots: one for an SPI-based LoRaWAN concentrator module to communicate with LoRaWAN devices, and another for an optional 4G/LTE cellular modem for wireless internet access. A SIM card slot is included. Additional components include a Gigabit Ethernet port, a microSD card reader, Wi-Fi (depending on the installed module), an integrated GPS receiver with a patch antenna for location reporting and precise timing, and an integrated power supply accepting 120-240 VAC. Typical power consumption is under 10 W, and the device measures 146×118×50 mm.

LoraReach runs standard Linux and uses Semtech’s official packet forwarder, enabling compatibility with popular LoRaWAN network servers such as The Things Network, Loriot, or ChirpStack. Users can also run their own software for local data logging, diagnostics, or other processing tasks. Brightix provides the hardware schematics and bill of materials as open-source resources, allowing developers to inspect and modify the design. Components like the CM4, LoRaWAN concentrator, 4G modem, and microSD card must be purchased separately. No release date or pricing has been announced yet, but Brightix is accepting sign-ups for notifications about the upcoming crowdfunding campaign.
