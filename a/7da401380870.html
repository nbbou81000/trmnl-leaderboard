LoraReach : une carte open source pour construire son propre gateway LoRaWAN

Une carte open source pour créer un gateway LoRaWAN personnalisé autour d'un Raspberry Pi Compute Module 4.

LoRaWAN est une technologie IoT optimisée pour transmettre de petites quantités de données sur de longues distances avec une consommation énergétique réduite. Elle convient particulièrement aux applications comme la surveillance environnementale, l’agriculture ou l’automatisation industrielle, où les capteurs sont dispersés sur de vastes zones. Cependant, ces capteurs nécessitent des gateways (passerelles) pour relier leurs données à internet, et les solutions commerciales existantes manquent souvent de flexibilité.

Brightix propose LoraReach, une carte porteuse open source conçue pour construire soi-même un gateway LoRaWAN. Contrairement aux solutions propriétaires, cette carte offre une base matérielle modifiable tout en permettant d’exécuter des logiciels personnalisés. Elle s’articule autour d’un Raspberry Pi Compute Module 4 (CM4), compatible avec d’autres modules de calcul pin-to-pin, offrant ainsi la puissance d’un ordinateur Linux embarqué.

La carte intègre deux slots mini-PCIe : l’un pour un module concentrateur LoRaWAN basé sur SPI, chargé de communiquer avec les dispositifs LoRaWAN, et l’autre pour un modem cellulaire 4G/LTE optionnel, permettant une connexion internet sans fil. Un emplacement pour carte SIM est également présent. D’autres composants incluent un port Ethernet Gigabit, un lecteur de microSD, le Wi-Fi (selon le module installé), un récepteur GPS avec antenne patch pour le géopositionnement et la synchronisation temporelle, ainsi qu’une alimentation intégrée acceptant le 120-240 VAC. La consommation typique est inférieure à 10 W, et l’ensemble mesure 146×118×50 mm.

LoraReach fonctionne sous Linux standard et utilise le packet forwarder officiel de Semtech, ce qui lui permet de s’interfacer avec des serveurs LoRaWAN populaires comme The Things Network, Loriot ou ChirpStack. Les utilisateurs peuvent aussi exécuter leurs propres logiciels pour le traitement local des données ou le diagnostic. Brightix met à disposition les schémas électroniques et la liste des composants en open source, permettant une inspection et une modification du design. Les composants comme le CM4, le concentrateur LoRaWAN, le modem 4G et la carte microSD doivent être fournis séparément. Aucune date de sortie ni prix n’ont encore été annoncés, mais Brightix propose de s’inscrire pour être notifié lors de la prochaine campagne de financement participatif.
