MicroPython: New Tools and End of a Beloved Feature

The Python on Microcontrollers newsletter unveils two new development environments, the removal of a long-standing feature, and key updates for Python 3.15.

Read the article on the TRMNL Leaderboard →

The latest issue of the Python on Microcontrollers newsletter highlights several key developments. This week, two new MicroPython development environments were introduced.

Microbe, created by Mikayel Grigoryan, is a lightweight IDE that interacts directly with a microcontroller board. It features a Python language server that understands the hardware and network setup, and handles firmware flashing. Built on Tauri instead of Electron, it leverages the system’s native webview and includes a Rust-based core. The source code is available on GitHub.

Thingstudio offers a visual, low-code approach to programming microcontrollers. Users design a flow of connected nodes in a browser-based editor, similar to Node-RED, which is then compiled into MicroPython and sent directly to the board. The code runs independently, with no external dependencies. Sources and a user guide are available on GitHub.

Another significant change is the removal of CircuitPython’s « Pirate » language pack, a playful feature from early firmware versions. As the number of supported boards grew, this option became a burden on the build process. Developers have now decided to drop it for the upcoming CircuitPython 11 releases.

In the Python ecosystem, version 3.15 brings an enhanced profiler, an experimental JIT compiler, optimized dictionary structures, and a lazy import feature to defer module loading until needed. A standout addition is default UTF-8 support across all platforms, including Windows, where this was previously unavailable.

Additionally, the Casio-MicroPython project enables writing and running MicroPython programs on Casio fx-CG100 graphing calculators. Programs are limited to a single 300-line file and use dedicated modules like casioplot for graphics. The project, released under the MIT License, is available on GitHub.
