MicroPython : nouveaux outils et fin d'une fonctionnalité emblématique

La newsletter Python sur microcontrôleurs annonce deux environnements de développement, la suppression d'une fonctionnalité historique et des avancées majeures pour Python 3.15.

La dernière édition de la newsletter Python on Microcontrollers met en lumière plusieurs évolutions notables. Deux nouveaux environnements de développement dédiés à MicroPython font leur apparition cette semaine.

Microbe, développé par Mikayel Grigoryan, se présente comme un IDE léger fonctionnant directement avec une carte microcontrôleur. Il intègre un serveur de langage Python capable de reconnaître l'environnement matériel et réseau, tout en prenant en charge la programmation et le flashage du firmware. Construit sur Tauri plutôt que sur Electron, il utilise le moteur de rendu natif du système d'exploitation et repose sur un noyau en Rust. Son code est disponible sur GitHub.

Thingstudio propose une approche visuelle et low-code pour programmer des microcontrôleurs. L'utilisateur construit un flux de nœuds connectés via une interface graphique, similaire à Node-RED, qui est ensuite compilé en MicroPython avant d'être envoyé directement sur la carte. Aucune dépendance externe n'est requise : le code s'exécute en autonomie. Les sources et un guide utilisateur sont accessibles sur GitHub.

Autre annonce marquante : la suppression de la version « Pirate » de CircuitPython, une fonctionnalité humoristique des premières versions du firmware. Avec l'augmentation du nombre de cartes supportées, cette option alourdissait inutilement le processus de compilation. Les développeurs ont finalement décidé de l'abandonner pour les prochaines versions de CircuitPython 11.

Côté Python, la version 3.15 introduit un profilage amélioré, un compilateur expérimental JIT, une optimisation des structures de dictionnaires et une option d'importation paresseuse. Une particularité notable est le support UTF-8 activé par défaut sur toutes les plateformes, y compris Windows, où cette fonctionnalité était auparavant absente.

Enfin, le projet Casio-MicroPython permet d'écrire et d'exécuter des programmes MicroPython sur les calculatrices graphiques Casio fx-CG100. Les programmes sont limités à un seul fichier de 300 lignes maximum et utilisent des modules dédiés comme casioplot pour les graphiques. Le projet, sous licence MIT, est disponible sur GitHub.
