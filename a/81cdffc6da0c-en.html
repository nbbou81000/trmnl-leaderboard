Duke Nukem 3D Runs on an RP2350 with pico-duke3D

The iconic 1990s FPS now runs on an RP2350 board via pico-duke3D.

Duke Nukem 3D, the 1996 first-person shooter from 3D Realms, now runs on an RP2350 microcontroller board thanks to the pico-duke3D project. Developed by [PicoPlus-devel], this adaptation executes the game on a Pico clone with a DVI output, turning the microcontroller into a single-game console.

Unlike DOOM (1993), which ran on modest setups like a 386 PC with 4 MB of RAM, Duke Nukem 3D required more power: a 486DX2 processor and 8 MB of memory, often paired with VESA or PCI graphics cards. The pico-duke3D project proves that the RP2350, despite its small size, can handle this demanding 1996 title. The game supports SNES or USB controllers depending on the hardware used. The shareware version is playable, as is the full version if the user owns a valid license.
