A $10 Gamepad Built with RP2040 and Open-Source Firmware

A minimalist gamepad under $10, built with an RP2040-Zero, a protoboard, and GP2040-CE firmware.

Read the article on the TRMNL Leaderboard →

Frustrated by the cost and complexity of commercial gamepads, Lazy_Duck built a barebones controller using basic components and a DIY approach. The project centers around an RP2040-Zero, an affordable and versatile microcontroller, soldered onto a protoboard instead of a dedicated PCB.

The build combines a joystick, a few buttons, and a microswitch, all housed in a 3D-printed case. To ensure durability, heat-set threaded inserts are added during printing, creating a sturdy frame. On the software side, the GP2040-CE firmware handles controller emulation and configuration via a web interface, fully utilizing the RP2040’s dual-core capabilities.

This project isn’t just a simple gamepad—it’s a modular foundation for custom controllers. The firmware supports adding features like an OLED display, RGB LEDs, or other peripherals. For the 3D-printed parts, a resin printer can produce high-quality, precise button caps.
