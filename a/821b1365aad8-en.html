New open source UEXT module adds 100 Mbit Ethernet to diverse boards

Olimex releases an open source module to add wired 100 Mbit Ethernet to UEXT or pUEXT-compatible boards, including certain ESP32 and Raspberry Pi PICO variants.

Olimex has unveiled the UEXT-CH390, an open source module measuring 50 x 21 mm that adds 100 Mbit wired Ethernet connectivity to boards equipped with a UEXT or pUEXT connector. The module leverages the WCH CH390 SPI-to-Ethernet controller, a dedicated chip for converting SPI signals to Ethernet frames.

Targeting boards lacking native Ethernet, such as the Raspberry Pi PICO, PICO2, or ESP32 variants without an integrated Ethernet MAC—including the ESP32-S3, C3, C5, and C6—the UEXT-CH390 fills a gap in wired connectivity options. While ESPHome already supported the CH390 on ESP32, Olimex developed a new driver for RP2040 boards (used in the PICO series), expanding compatibility.

The module ships with ready-to-use project examples: an ESPHome firmware compatible with version 2026.9.0, a Pico SDK example using lwIP (a lightweight TCP/IP stack) with a minimal web server, and a UF2 firmware that can be flashed directly into Home Assistant. All sources—KiCad files, schematics, and firmware—are published under open licenses.

Priced at 4.95 EUR, the module is available for pre-order now, with shipping starting on November 9, 2026. Further details can be found on Olimex’s blog and their GitHub repository.
