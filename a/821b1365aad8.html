Nouveau module UEXT open source pour ajouter l'Ethernet 100 Mbit à des cartes variées

Olimex lance un module open source pour ajouter une connexion Ethernet filaire à des cartes compatibles UEXT ou pUEXT, dont certains ESP32 et Raspberry Pi PICO.

Olimex présente le UEXT-CH390, un module open source de petite taille (50 x 21 mm) conçu pour ajouter une connectivité Ethernet filaire à 100 Mbit/s sur des cartes équipées d’un connecteur UEXT ou pUEXT. Ce module utilise le contrôleur WCH CH390, un circuit dédié à la conversion SPI vers Ethernet, compatible avec plusieurs environnements de développement.

Le UEXT-CH390 s’adresse notamment aux cartes sans interface Ethernet native, comme les Raspberry Pi PICO, PICO2 ou les modèles d’ESP32 dépourvus de MAC Ethernet intégré, tels que les ESP32-S3, C3, C5 et C6. Pour les ESP32, le support existait déjà dans ESPHome, mais Olimex a développé un pilote spécifique pour les RP2040 (utilisés dans les PICO), élargissant ainsi les possibilités d’intégration.

Le module est fourni avec des exemples de projets prêts à l’emploi : un firmware ESPHome compatible avec la version 2026.9.0, un exemple pour le Pico SDK utilisant lwIP (une pile TCP/IP légère) et un serveur web minimaliste, ainsi qu’un firmware UF2 directement flashable dans Home Assistant. Les fichiers sources (KiCad, schémas et firmware) sont publiés en open source.

Disponible en précommande au prix de 4,95 €, le module sera expédié à partir du 9 novembre 2026. Plus d’informations sont disponibles sur le blog d’Olimex et sur leur dépôt GitHub.
