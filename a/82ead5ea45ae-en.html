ESP32-S31: First RISC-V Microcontroller Running Full Linux

A dual-core RISC-V ESP32-S31 microcontroller now runs full Linux, thanks to its memory management unit (MMU).

The ESP32-S31, the latest addition to the ESP32 family, represents a significant milestone by combining a dual-core RISC-V processor with WiFi 6 connectivity. Unlike most microcontrollers, it includes a Memory Management Unit (MMU), enabling it to run a full version of Linux—rather than a stripped-down no-MMU variant. This brings it closer to traditional system-on-chip (SoC) designs, though its limited resources still restrict performance for demanding tasks.

The project is still in its early stages, but Espressif’s GitHub repository already hosts a port of the Linux 6.x kernel. Development boards are available on AliExpress at various price points, making experimentation affordable. However, hardware constraints—such as 16 to 32 MB of RAM—severely limit performance, placing it on par with a NetBSD system from the 1980s running on workstations of the era.

Technical uncertainties remain, particularly regarding the TLB (Translation Lookaside Buffer) architecture or the external PSRAM interface, whose specifications in Espressif’s documentation appear unclear. Despite these challenges, the ESP32-S31 signals a convergence between microcontrollers and SoCs, with more powerful chips expected to follow.
