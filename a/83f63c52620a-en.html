A Camera That Doesn’t Capture Photos—It Finds Existing Ones

An experimental camera uses a Raspberry Pi to identify images by their mathematical code instead of saving them.

Read the article on the TRMNL Leaderboard →

Instead of capturing a photo, the Image Locator Camera locates it within a theoretical library containing every possible pixel combination. This works because a digital image is a finite sequence of pixels, limited in configurations. For instance, a 3×3 monochrome image has only 512 possible combinations, each matching a page in a book. The device analyzes the scene, converts the pixels into a nine-bit binary number, and displays the corresponding page number.

The prototype, built by Strange Inventions, uses a Raspberry Pi Zero W paired with an OV5647 camera module. A Adafruit 1.3" Color TFT Bonnet (240×240 pixels) with a joystick handles navigation. Power is supplied by a Waveshare UPS HAT, all assembled in a 3D-printed case. Python code and design files are available, but the project is limited to very low-resolution images.

Increasing resolution to 4×4 pixels multiplies the required pages by 128, making a physical library unmanageable. Color or high-resolution versions are impossible to materialize. The project includes monochrome and RGB modes to demonstrate the concept without physical books. Complete files are sold for about $21, while electronic and mechanical components cost around $80. An optional 512-page library is available for an additional $72.
