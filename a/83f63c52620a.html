Un appareil photo qui ne prend pas de photo mais trouve l'image existante

Un projet expérimental transforme un Raspberry Pi en caméra qui identifie une image par son code mathématique plutôt que de la sauvegarder.

Plutôt que de capturer une photo, l'Image Locator Camera la localise dans une bibliothèque théorique contenant toutes les combinaisons possibles de pixels. Ce principe repose sur l’idée que chaque image numérique est une suite finie de pixels, donc limitée en nombre de configurations. Par exemple, une image monochrome de 3×3 pixels ne peut générer que 512 combinaisons distinctes, chacune correspondant à une page d’un livre. Le dispositif analyse la scène, convertit les pixels en un nombre binaire de neuf bits, puis affiche le numéro de page où cette configuration apparaît.

Le prototype, conçu par Strange Inventions, utilise un Raspberry Pi Zero W couplé à un module caméra OV5647. Un écran Adafruit 1.3" Color TFT Bonnet (240×240 pixels) et un joystick permettent de naviguer dans l’interface. Une batterie est fournie par un Waveshare UPS HAT, le tout assemblé dans un boîtier imprimé en 3D. Le code Python et les fichiers de conception sont disponibles, mais le projet reste limité à des images de très basse résolution.

En effet, passer à une résolution de 4×4 pixels multiplie par 128 le nombre de pages nécessaires, rendant la bibliothèque physique ingérable. Les versions en couleur ou haute résolution sont donc impossibles à matérialiser. Le projet inclut des modes monochromes et RVB pour démontrer le concept sans nécessiter de livres physiques. Les fichiers complets sont vendus environ 21 $, tandis que les composants électroniques et mécaniques coûtent autour de 80 $. Une version incluant la bibliothèque de 512 pages est proposée pour 72 $ supplémentaires.
