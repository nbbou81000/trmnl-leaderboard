OFFgrid-SDR: Browser-Based SDR Receiver Without Installation

A fully functional SDR receiver running in a web browser, with no software to install or internet connection required.

Read the article on the TRMNL Leaderboard →

The OFFgrid-SDR project, published by diddy-boy on GitHub, turns a single HTML file into a standalone software-defined radio (SDR) receiver. Users simply copy the index.html file to a USB drive, plug in an RTL-SDR dongle and an antenna, and gain access to a receiver covering shortwave, FM, airband, and VHF/UHF bands.

The tool requires no installation, administrator rights, or internet connection. It supports multiple demodulation modes, including AM, synchronous AM (USB/LSB), CW, narrowband/wideband FM, and weather fax. A demo mode is available by visiting index.html?demo, which simulates radio stations to test features like FM stereo with RDS, fading shortwave signals, SSB transmissions, Morse code, and weather fax charts.

A noted limitation is that the RTL-SDR dongle can only be used by one application at a time. Users must close software like SDR#, SDR++, gqrx, or rtl_tcp before running OFFgrid-SDR. The GitHub repository includes only documentation and licenses, with no additional code or dependencies.
