OFFgrid-SDR : un récepteur radio SDR en HTML sans installation

Un récepteur SDR entièrement fonctionnel dans un navigateur, sans logiciel à installer ni connexion internet.

Lire l'article sur le Palmarès TRMNL →

Le projet OFFgrid-SDR, publié par diddy-boy sur GitHub, transforme un simple fichier HTML en récepteur radio logiciel (SDR) autonome. Il suffit de copier le fichier index.html sur une clé USB, de brancher un dongle RTL-SDR et une antenne pour accéder à un récepteur couvrant les bandes shortwave, FM, airband et VHF/UHF.

L’outil ne nécessite aucune installation, ni droits administrateur, ni connexion internet. Il prend en charge plusieurs modes de démodulation : AM, AM synchrone (USB/LSB), CW, FM étroite/large, et fax météo. Les utilisateurs peuvent aussi activer un mode démo via l’URL index.html?demo, qui simule des stations radio pour tester les fonctionnalités, incluant la stéréo FM avec RDS, des signaux HF variables, des transmissions en Morse ou encore des cartes fax météo.

Une limitation est signalée : le dongle RTL-SDR ne peut être utilisé que par une seule application à la fois. Ainsi, les logiciels comme SDR#, SDR++, gqrx ou rtl_tcp doivent être fermés avant de lancer OFFgrid-SDR. Le dépôt GitHub contient uniquement de la documentation et les licences associées, sans autre code ou dépendance.
