Smart TV et Pi-hole : comment les publicités passent encore

Les téléviseurs intelligents et autres appareils contournent souvent Pi-hole. Voici pourquoi et comment bloquer ces fuites.

Un Pi-hole bloque des milliers de requêtes DNS chaque semaine, mais certains appareils, comme les téléviseurs intelligents, continuent d’afficher des publicités. La raison ? Ces appareils ignorent délibérément le serveur DNS local pour se connecter directement aux serveurs du fabricant.

Pourquoi Pi-hole échoue parfois

Un Pi-hole fonctionne en interceptant les requêtes DNS avant qu’elles n’atteignent un serveur externe. Cependant, certains appareils utilisent des DNS codés en dur (par exemple, 8.8.8.8) ou des protocoles chiffrés comme DNS over HTTPS (DoH) ou DNS over TLS (DoT). Ces méthodes contournent le Pi-hole, car elles chiffrent les requêtes ou utilisent des ports non standard (853 pour DoT, 443 pour DoH), empêchant toute interception.

Les téléviseurs intelligents, les enceintes connectées ou même certains réfrigérateurs intelligents sont souvent configurés pour utiliser ces alternatives, rendant le Pi-hole inefficace contre leurs publicités intégrées.

Solutions pour forcer le passage par Pi-hole

Plusieurs méthodes permettent de limiter ces contournements :

  • Configurer le routeur pour qu’il ne distribue que l’adresse du Pi-hole en DNS, pour les protocoles IPv4 et IPv6.
  • Rediriger le trafic DNS via une règle NAT sur le routeur, forçant les requêtes non chiffrées (port 53) à passer par le Pi-hole.
  • Bloquer le port 853 pour empêcher l’utilisation de DoT, sauf si le Pi-hole est configuré pour gérer DoT en aval.
  • Bloquer les adresses IP des serveurs DoH via une liste noire sur le routeur, forçant les appareils à utiliser le DNS local ou à être bloqués.

Ces réglages nécessitent un routeur compatible, comme ceux équipés de firmwares tiers (OpenWrt) ou des solutions logicielles avancées (OPNsense, pfSense). Une alternative consiste à assembler un routeur DIY avec deux ports Ethernet et l’un de ces logiciels.

En l’absence de ces options, certains appareils devront être déconnectés du réseau ou configurés manuellement pour utiliser le Pi-hole.
