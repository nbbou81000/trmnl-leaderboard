Analyseur logique intégré sur FPGA GOWIN avec Tang Nano 20K

Découvrez comment configurer un analyseur logique intégré directement dans un FPGA GOWIN via les outils open-source ou propriétaires, avec des astuces pour basculer entre configurations.

Les outils GOWIN permettent d’intégrer un analyseur logique directement dans un FPGA comme le Tang Nano 20K, sans matériel supplémentaire. Cette fonctionnalité repose sur un fichier de configuration GAO, qui définit les conditions de déclenchement et les signaux à surveiller. Contrairement aux outils open-source, cette solution native évite les étapes de simulation externes avant la compilation.

Pour activer ou désactiver un fichier GAO, il suffit de cliquer droit sur le fichier dans l’IDE GOWIN et de choisir l’option correspondante. Cette méthode permet de basculer rapidement entre plusieurs configurations (par exemple, une pour les tests et une autre pour la production) sans modifier le code Verilog. Le mode Standard est recommandé par défaut, car le mode Lite limite les fonctionnalités de l’analyseur.

L’analyseur logique s’intègre au design Verilog en décrivant le comportement matériel souhaité. Contrairement à un langage de programmation classique, Verilog ne contrôle pas l’exécution séquentielle, mais définit des relations entre signaux synchronisés par une horloge. Par exemple, un système simple comme un clignotement de LEDs nécessite un compteur incrémenté à chaque cycle d’horloge (27 MHz dans l’exemple cité). Les signaux ne changent pas instantanément : des retards liés à la longueur des pistes, à la température ou à la conception des composants peuvent perturber le fonctionnement. Une horloge permet de stabiliser les signaux avant de les utiliser, évitant ainsi des comportements imprévisibles.

Le fichier Verilog fourni inclut un module de gestion des LEDs et un bloc IP pour implémenter une interface UART. En appuyant sur un bouton utilisateur, l’appareil alterne entre un mode d’écho simple et un mode où chaque caractère entrant est incrémenté avant d’être renvoyé. L’analyseur logique capture ces échanges, permettant de visualiser les impulsions et les données série en temps réel. Les captures montrent notamment les fronts d’impulsion des LEDs et les trames UART, avec des horloges adaptées à chaque cas d’usage.
