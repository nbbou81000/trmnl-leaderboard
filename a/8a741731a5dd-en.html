Focuspocus: A Lightweight Arduino GUI Library

A minimalist Arduino library to build graphical interfaces on TFT or OLED screens.

Read the article on the TRMNL Leaderboard →

Developer glutio has released Focuspocus, an open-source Arduino library designed to simplify GUI creation on displays. It supports interactive elements such as buttons, labels, checkboxes, radio buttons, sliders, progress bars, and pop-ups, with automatic layout, touch input, and focus-driven navigation.

The library adds just 12 to 16 KB of flash usage. Basic examples like HelloButton run on an Arduino Uno, which reaches 93 % flash usage with this single project alone. More powerful boards like Mega, Nano Every, SAMD, ESP32, or RP2040 provide ample room for additional sketch code.

The system uses a window stack managed by a focus manager. The main sketch loop must call fm.loop(millis()) to handle timers, layouts, and redraws. Rendering is handled through AdafruitGraphics, a wrapper compatible with Adafruit_GFX and extendable to other libraries via the BGraphicsApi interface. Three themes are included: a dark TFT mode, a light gray mode, and a monochrome mode for 128×64 OLED screens.

Each example comes with a diagram.json file for the Wokwi simulator, a Win32 graphics backend, and doctest unit tests that simulate touch and key inputs. The library is licensed under MIT and available on GitHub.
