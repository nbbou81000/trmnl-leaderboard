A 16-bit relay computer runs Pi and Dijkstra

A 16-bit relay computer built by Peter computes Pi and runs Dijkstra’s shortest path algorithm using self-holding relays at 24 V.

Read the article on the TRMNL Leaderboard →

Peter built a fully functional 16-bit relay computer based on an accumulator architecture. All calculations and load/store operations pass through an accumulator (ACC), a central register temporarily holding manipulated data. The instruction set includes 19 commands and three addressing modes, including indirect addressing, enabling the use of pointers and tables in memory.

Performance is modest: computing Pi to two decimal places took over 8 minutes and 1,377 instructions, while the integer square root of 60,000 was calculated as 244. Despite these limitations, the machine also runs Dijkstra’s shortest path algorithm.

The system features non-relay memory: an Arduino handles data storage, while a second Arduino generates the clock. This clock consists of four separate pulses, as each self-holding relay register must be cleared before writing. The architecture lacks a stack, but a single SR register stores the return address, limiting subroutine calls to one level deep (CALL and RET).

Peter validated his design using multiple tools: simulation in the game Logic World, Excel macros stepping through code, and a VHDL FPGA emulator replicating the relay logic.
