Banana Pi lance un module BPI-CM7 basé sur l'Allwinner H618

Banana Pi prépare un module BPI-CM7 avec SoC Allwinner H618, LPDDR4, Wi-Fi 5 et Bluetooth 5.0, pour concurrencer les Compute Modules Raspberry Pi.

Lire l'article sur le Palmarès TRMNL →

Banana Pi annonce un nouveau module BPI-CM7, centré sur le système sur puce (SoC) Allwinner H618. Ce module embarque jusqu’à 2 Go de mémoire LPDDR4 et 32 Go de stockage eMMC, avec une mémoire EEPROM de 256 octets. Il intègre un processeur graphique Arm Mali-G31 et un module de connectivité K019 de Kertong Polytron Technologies, basé sur le chipset Cypress CYW43455, offrant du Wi-Fi 5 (dual-band) et du Bluetooth 5.0.

Le module propose une sortie vidéo et audio HDMI, un port USB 2.0 OTG, trois ports USB 2.0 Host, un lecteur microSD pour l’extension de stockage, ainsi qu’un port Ethernet Fast (10/100). Côté entrées/sorties, il prend en charge l’UART, le TWI/I2C, le SPI, l’I2S/PCM, le DMIC, le SPDIF, l’IR et la modulation de largeur d’impulsion (PWM). En revanche, il ne dispose pas de convertisseur analogique-numérique (ADC) intégré.

Pour exploiter pleinement ses fonctionnalités, Banana Pi propose une carte porteuse dédiée, la BPI-CM7IO. Celle-ci ajoute un slot d’extension de type mini-PCIe avec interface USB 2.0, un emplacement pour modem cellulaire, une sortie vidéo composite, une sortie audio analogique et un port UART de débogage. Aucune information sur le prix ou la disponibilité n’a encore été communiquée, mais Banana Pi indique que le module devrait être proposé à un tarif inférieur à celui d’un Raspberry Pi Compute Module 5 d’entrée de gamme.
