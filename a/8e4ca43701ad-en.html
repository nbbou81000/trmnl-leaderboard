A Wi-Fi 7 Router Turned into a 320 MSps Software-Defined Radio Receiver

A Gemtek W1700K Wi-Fi 7 router is repurposed as a wideband SDR receiver via open-source firmware, capturing up to 320 MSps across 2.4 GHz, 5 GHz, and 6 GHz bands.

The open-source project w1700k-sdr repurposes a Gemtek W1700K (or W1700K2) Wi-Fi 7 router into a wideband SDR receiver, capturing raw 14-bit I/Q samples at up to 320 MSps. Unlike solutions like ESP-SDR, which streams data over UART with bandwidth limitations, this project uses a 10 GbE connection to transfer data without loss.

How it works and specifications

The router leverages its MediaTek MT7996 Wi-Fi 7 chipset to capture signals across the 2.4 GHz, 5 GHz, and 6 GHz bands. Data is transmitted via the Airoha AN7581 (quad-core Cortex-A53 SoC) to a Linux computer, where real-time spectrum and waterfall displays are rendered in a browser. The custom firmware replaces the stock system, enabling raw sample capture instead of processing standard Wi-Fi traffic. A 1 GiB DMA buffer in the router’s memory handles continuous streams, while a lossless compression system reduces the throughput to about 9.75 Gbit/s over the 10 GbE link.

The project supports variable sample rates (40, 80, 160, or 320 MSps) with 14-bit resolution. It also allows manual gain adjustment, analog bandwidth control (20–320 MHz), and band switching during streaming. A frequency-response correction feature (« flatten ») compensates for distortions introduced by the radio’s decimation filters.

To install the firmware, you need a compatible router (W1700K or W1700K2), a 3.3V USB-to-serial adapter, an Ethernet connection for flashing, and a Linux PC with a 10 GbE NIC. The spectrum is accessible via a browser at http://router:8073. The code is mostly MIT-licensed, with some components under GPL and BSD.
