KeyBridge 2.0: Turn a USB Keyboard into a Home Assistant Control Panel

An open-source project lets you repurpose a USB keyboard as a Home Assistant control panel, without needing an intermediate computer.

Read the article on the TRMNL Leaderboard →

The KeyBridge project repurposes a standard USB keyboard as a smart home controller for Home Assistant, turning each key into a programmable button. Unlike a typical setup where the keyboard sends inputs to a computer, KeyBridge intercepts keypresses directly using an ESP32-S2 microcontroller with USB host capabilities. This eliminates the need for an intermediate PC, as inputs are sent straight to Home Assistant via ESPHome.

KeyBridge 2.0 improves upon the original 2025 release with a smaller circuit board and native ESPHome integration, streamlining configuration and device setup in Home Assistant. Users can either build the device themselves or preorder a ready-to-use board for $35. The first production run includes 150 units, but shipping is not expected until the end of the year.

The project works with full-size keyboards as well as smaller devices like macropads or numeric keypads. Each key can be assigned to trigger automations, control devices, or run smart home routines. For instance, a numeric keypad could serve as a media controller (play/pause, rewind, subtitles) or a bedside panel for lighting, heating, and bedtime routines.
