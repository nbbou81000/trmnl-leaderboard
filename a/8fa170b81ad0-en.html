Floppy Drive Emulator for Commodore 1551 Using Original 6510 and Pi Pico

A Commodore 1551 floppy drive emulator, scarce in 2026, recreates original hardware using a Pi Pico and a vintage 6510 CPU.

The Commodore 1551 floppy drive, designed for the Commodore 16 and Plus/4 computers, has become a rare item by 2026. Instead of relying on traditional software emulation, [Maciej Witkowiak] developed a hybrid solution: the original 6510 CPU and ROM are preserved, while the drive hardware is emulated using a Pi Pico and a CPLD for glue logic.

The Pi Pico even generates the clock and IRQ timing signals required by the vintage 8-bit CPU. The 64 KB ROM accommodates both the original firmware and community-enhanced versions. An OLED display is included to select disk images for emulation. Originally designed as a daughterboard plugged into an original drive mainboard, the project is now available as a GitHub repository for enthusiasts to build themselves.
