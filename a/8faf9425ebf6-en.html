Meatloaf: An ESP32 Bridge to Connect Commodore Computers to the Modern Era

An ESP32-based device lets Commodore computers access remote files via their IEC serial port without complex setup.

Read the article on the TRMNL Leaderboard →

Commodore computers like the C64 or VIC-20 rely on an IEC serial port to interact with storage peripherals such as 1541 disk drives. However, their architecture restricts direct access to modern files stored on servers or accessible via URLs. Meatloaf, created by user jaime, offers a hardware and software solution to bridge this gap.

The device is built around an ESP32 microcontroller (or an ESP32-S3, according to some feedback), which connects to a Commodore’s IEC port. Unlike other solutions, Meatloaf requires no prior configuration on the retro machine: the user simply enters the desired file’s URL from the Commodore, and the device fetches the content in real time. The system handles nested files, such as compressed archives, and transmits them to the Commodore as if they were being read from a classic floppy drive.

While Meatloaf can store files locally, its key feature is its ability to retrieve data from virtually any online source. A dedicated GitHub page provides technical details and invites contributions. Some users note that the device does not emulate a 1551 drive, limiting its use to standard IEC-compatible models.
