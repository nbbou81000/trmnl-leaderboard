Un système téléphonique analogique personnalisable avec ESP32

Un projet open source transforme des téléphones anciens en système téléphonique complet avec ESP32, MQTT et Bluetooth optionnel.

Lire l'article sur le Palmarès TRMNL →

Le projet Analog Redial d’Hackaday.io permet de recycler un ou deux téléphones analogiques (rotatifs ou à touches) en un système téléphonique fonctionnel. Une carte électronique dédiée fournit la tonalité de numérotation, la sonnerie et permet aux appareils de communiquer entre eux. Elle intègre également une fonction répondeur automatique.

La configuration s’effectue via une interface web : il est possible de définir des codes de numérotation personnalisés et d’importer des fichiers audio pour les messages. Contrairement à une version précédente basée sur un Raspberry Pi, cette nouvelle mouture repose sur un ESP32, réduisant les coûts de fabrication tout en offrant davantage de fonctionnalités.

L’ESP32 détecte les chiffres composés et gère un plan de numérotation sous forme de tableau modifiable. Une option permet d’intégrer le système à Home Assistant via MQTT, transmettant l’état des lignes, un bouton pour déclencher la sonnerie, le nombre de messages et un événement à chaque décrochage. Une alternative sans MQTT est disponible via des webhooks. Pour les utilisateurs de téléphones rotatifs, un module Bluetooth optionnel (BM64) permet d’utiliser l’appareil comme combiné pour un smartphone.

Le matériel est conçu avec KiCad, tandis que le firmware, écrit en C sous licence MIT, repose sur ESP-IDF. Les plans détaillés et le code source sont accessibles sur GitHub et la page du projet sur Hackaday.io.
