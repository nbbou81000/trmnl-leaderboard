F3D 4.0 Now Supports FreeCAD FCStd Files

The open-source 3D viewer F3D now supports FreeCAD FCStd files in version 4.0.

Read the article on the TRMNL Leaderboard →

The open-source 3D viewer and renderer F3D now supports FreeCAD FCStd files starting with version 4.0. The software offers advanced features such as adjustable lighting, dynamic positioning, animation playback, and even video creation.

A public web viewer is available for quick testing, allowing users to load sample files or local files directly in their browser. Installable packages are also provided for multiple operating systems.

FreeCAD itself uses F3D to generate thumbnails for STEP files. Other projects leverage F3D as well, including Manyfold, an open-source, self-hostable 3D file hosting system. The latest release of Manyfold now displays default image previews of FreeCAD FCStd files stored on a Manyfold instance.
