Strata: Running a 125-Billion-Parameter LLM on a Standard Gaming PC

An open-source project enables running massive language models on consumer hardware, no supercomputer required.

The Strata project, created by Niko1221, offers a way to run large language models (LLMs) locally on consumer-grade hardware. Unlike traditional methods that require GPU clusters or cloud services, Strata enables running a 125-billion-parameter LLM on a standard gaming PC, such as one equipped with an RTX 5070 GPU featuring 12 GB of VRAM.

Strata leverages variants of the Qwen3.8 model, available in multiple quantized and specialized versions (general-purpose, coding, etc.). The model uses a mixture-of-experts architecture, where only a fraction of the experts (10 out of 24,576) is loaded into VRAM at any given time, while the rest remains in system RAM or on the SSD. A 29 GB file stored on the disk serves as a lookup table for less frequently used experts. This smart memory management reduces VRAM usage while maintaining acceptable performance.

The project also employs speculative decoding, a technique where multiple candidate tokens are evaluated in a single pass, speeding up text generation. Tests show that an RTX 5070 can generate between 50 and 90 tokens per second, depending on the model’s quantization level. Strata is installed via a setup.sh script that guides the user and automatically configures startup options. Once running, it can be accessed through a web browser or exposes APIs compatible with OpenAI and Anthropic standards, allowing easy integration with existing tools like coding assistants.

Hardware requirements remain significant: at least 32 GB of RAM, 12 GB of VRAM, and 80 GB of storage are needed to run the model. Strata demonstrates how advanced memory management and model architecture techniques can make massive LLMs accessible on consumer hardware, though performance still lags behind cloud-based or high-end solutions.
