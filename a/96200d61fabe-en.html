Raspberry Pi Desktop Now Available for PC and Mac in 2026

Raspberry Pi Desktop, based on Debian Trixie, is now available for PC and Mac after years of waiting.

After a decade of development and several years without updates, Raspberry Pi has finally released a modern version of its desktop environment, originally designed for its single-board computers, adapted for PCs and Macs. Based on Debian Trixie (64-bit), this system replaces older 32-bit versions and drops the historic PIXEL name (Pi XWindows Environment Lightweight), which became unavailable due to a trademark conflict. The image is downloadable as a bootable .iso file from a USB drive.

The interface includes the latest Raspberry Pi desktop features, such as a redesigned Control Centre and a new dock. The Raspberry Pi Connect client is also included, enabling remote control of a PC or Mac via the web interface, with the same functionality as on a Raspberry Pi. The only difference is device identification: a customizable name is required on PCs/Macs, unlike Raspberry Pi devices, which use a unique hardware ID.

At boot, users can choose between running the system in persistence mode (changes are saved to the USB drive) or resetting this persistence. Once the desktop is launched, the system can be installed directly onto the computer’s hard drive or SSD using the Calamares installer, accessible via a shortcut or the main menu.

This release targets primarily Intel-based PCs and Macs, as Debian’s support for Apple Silicon remains experimental. Compatibility is ensured for most machines built in the last 15 years, provided they support 64-bit architecture. The project, born from a personal experiment in 2016, gained unexpected popularity, pushing the team to maintain this version despite its lack of direct revenue model for Raspberry Pi.

The download is available now from the official Raspberry Pi website.
