Raspberry Pi Desktop disponible pour PC et Mac en version 2026

Le système Raspberry Pi Desktop, basé sur Debian Trixie, est enfin disponible pour PC et Mac après une longue attente.

Lire l'article sur le Palmarès TRMNL →

Après une décennie de développement et plusieurs années sans mise à jour, Raspberry Pi propose enfin une version moderne de son environnement de bureau, initialement conçu pour ses nano-ordinateurs, adaptée aux PC et Mac. Basé sur Debian Trixie (64 bits), ce système remplace les anciennes versions 32 bits et abandonne le nom historique PIXEL (Pi XWindows Environment Lightweight), devenu indisponible à cause d’un conflit de marque. L’image est téléchargeable sous forme de fichier .iso bootable depuis une clé USB.

L’interface intègre les dernières évolutions du bureau Raspberry Pi, dont un centre de contrôle repensé et un nouveau dock. Le client Raspberry Pi Connect est également inclus, permettant de contrôler à distance un PC ou Mac via l’interface web dédiée, avec les mêmes fonctionnalités que sur un Raspberry Pi. La seule différence réside dans l’identification du périphérique : un nom personnalisable est requis sur PC/Mac, contrairement aux Raspberry Pi qui utilisent un identifiant matériel unique.

Deux options sont proposées au démarrage : exécuter le système en mode persistant (les modifications sont sauvegardées sur la clé USB) ou réinitialiser cette persistance. Une fois le bureau lancé, l’utilisateur peut installer le système directement sur le disque dur ou SSD de l’ordinateur via l’installeur Calamares, accessible depuis un raccourci ou le menu principal.

Cette version cible principalement les PC et Mac Intel, car le support d’Apple Silicon reste expérimental chez Debian. La compatibilité est assurée pour la plupart des machines fabriquées depuis 15 ans, sous réserve d’architecture 64 bits. Le projet, initialement né d’une expérience personnelle en 2016, a connu un succès inattendu, poussant l’équipe à maintenir cette version malgré son absence de modèle économique direct pour Raspberry Pi.

Le téléchargement est disponible dès maintenant sur le site officiel de Raspberry Pi.
