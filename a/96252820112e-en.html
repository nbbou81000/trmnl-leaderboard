LILYGO T-Halow P4: M.2 2280 Board with ESP32-P4 and Long-Range WiFi HaLow

A compact M.2 2280 development board integrates an ESP32-P4, an ESP32-C6, and a WiFi HaLow module for long-range IoT applications.

The LILYGO T-Halow P4 is a compact M.2 2280 (80 x 22 mm) development board designed for long-range IoT applications. It integrates Espressif Systems’ ESP32-P4 MCU, an ESP32-C6 wireless co-processor, and TaiXin Semiconductor’s WiFi HaLow module (TX-AH).

The ESP32-P4 features a dual-core RISC-V processor running at 400 MHz, a 2D graphics accelerator, H.264 video encoding up to 1080p30, and JPEG decoding. It includes 32 MB of PSRAM (per GitHub documentation, though the product page lists 8 MB) and supports MIPI CSI for cameras and MIPI DSI for displays. The WiFi HaLow module (802.11ah) delivers up to 32.5 Mbps throughput and a theoretical 1.2 km range in line-of-sight conditions, with selectable frequency bands (859–894 MHz or 902–928 MHz).

The ESP32-C6 adds WiFi 6 (2.4 GHz), Bluetooth 5, and 802.15.4 (Zigbee/Thread/Matter) connectivity via an external IPEX connector. Powered via USB-C, the board exposes its pins through an M.2 B-key connector for easy integration into custom projects. Example code for HaLow communication, camera, and display operations is provided on GitHub, compatible with ESP-IDF 5.4.1 or later.
