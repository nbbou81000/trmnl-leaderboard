Python 3.15 and MicroPython 1.30: Updates and Tools for Embedded Electronics

Python 3.15 has been released with an optimized experimental JIT, while MicroPython 1.30 is nearing release with new features for embedded electronics.

Python 3.15 was officially released on October 9, 2026, after a delay to fix lazy import bugs. This major update includes an optimized experimental JIT compiler to speed up code execution, according to Python Insider and Phoronix. Originally scheduled for October 1st, the release required a third release candidate before finalization.

MicroPython 1.30 nearing release

On the MicroPython side, version 1.30 is in development with 75% completion on GitHub. Seventeen pull requests remain open, while 53 have been merged. No official release date has been announced yet, but a launch is expected in December 2026. Meanwhile, CircuitPython 11 is progressing and promises significant new capabilities.

Tools and projects around MicroPython

Several recent tools and projects leverage MicroPython for embedded electronics. Picotronix, a modular oscilloscope and logic analyzer, uses two Raspberry Pi Pico 2 boards (including a Pico 2 W) to provide interchangeable modules: analog inputs, a 12-bit signal generator, a 12-channel logic analyzer at 150 MSPS, and an ADC-100 with dual 100 MSPS converters. The entire system is programmable directly in MicroPython, with access to the RP2350’s PIO state machines.

A new IDE called micro-repl, released under the MIT license, enables MicroPython development on Android, Windows, macOS, Linux, and web browsers. It provides an interactive REPL, a file explorer, and a code editor with a unified interface.

The Python community continues to grow with projects like pico-bay, an application and MCP server to manage Raspberry Pi Pico and ESP32 boards running MicroPython or CircuitPython via USB, as well as comprehensive guides for enabling Wi-Fi on Pico W and Pico 2 W boards with MicroPython.
