Python 3.15 et MicroPython 1.30 : nouveautés et outils pour l'électronique embarquée

Python 3.15 est sorti avec un JIT expérimental optimisé, tandis que MicroPython 1.30 approche avec de nouvelles fonctionnalités pour l'électronique embarquée.

La version Python 3.15 a été officiellement publiée le 9 octobre 2026, après un retard dû à la correction de bugs liés aux imports paresseux. Cette mise à jour majeure intègre un compilateur JIT expérimental optimisé pour accélérer l'exécution du code, selon Python Insider et Phoronix. Précédemment prévue pour le 1er octobre, la sortie a nécessité une troisième version candidate avant d'être finalisée.

MicroPython 1.30 en approche

Côté MicroPython, la version 1.30 est en développement avec un avancement à 75 % sur GitHub. Dix-sept pull requests restent ouvertes, tandis que 53 ont été fusionnées. Aucune date officielle n'est encore annoncée, mais une sortie est attendue pour décembre 2026. Parallèlement, CircuitPython 11 progresse et promet d'apporter de nouvelles capacités significatives.

Outils et projets autour de MicroPython

Plusieurs outils et projets récents exploitent MicroPython pour l'électronique embarquée. Picotronix, un oscilloscope et analyseur logique modulaire, utilise deux Raspberry Pi Pico 2 (dont un Pico 2 W) pour offrir des modules interchangeables : entrées analogiques, générateur de signaux 12 bits, analyseur logique 12 canaux à 150 MSPS, et ADC-100 avec deux convertisseurs 100 MSPS. L'ensemble est programmable directement en MicroPython, avec accès aux machines d'état PIO du RP2350.

Un nouvel IDE nommé micro-repl, publié sous licence MIT, permet de développer en MicroPython sur Android, Windows, macOS, Linux et navigateur web. Il offre un REPL interactif, un explorateur de fichiers et un éditeur de code avec une interface unifiée.

La communauté Python continue de s'enrichir avec des projets comme pico-bay, une application et un serveur MCP pour gérer les cartes Raspberry Pi Pico et ESP32 sous MicroPython ou CircuitPython via USB, ainsi que des guides complets pour activer le Wi-Fi sur les Pico W et Pico 2 W avec MicroPython.
