CrossPoint 1.6.5: Dark Mode and Library Sorting for E-Ink Readers

CrossPoint 1.6.5 enhances e-ink readers with full dark mode and improved library sorting.

Read the article on the TRMNL Leaderboard →

CrossPoint 1.6.5 introduces two major features for compatible e-ink readers. First, a full dark mode displays white text on a black background across menus, libraries, dictionaries, and the user interface. Unlike some manufacturer solutions, this option avoids white flashes during full screen refreshes.

Another addition allows users to set transparent images as sleep screens. Simply place transparent PNG or BMP files in the .sleep-overlay folder to overlay them when the device is turned off.

Library enhancements

Version 1.6.5 improves book organization with sorting by date, title, or author. A search bar speeds up navigation in large collections, and the list view now displays authors’ names—unlike the folder view, which only shows titles. Cover view remains unavailable, but these changes make the interface more user-friendly.

Full release notes are available on GitHub. To install CrossPoint 1.6.5 on a compatible e-ink reader (such as Xteink X3, X4 Classic, X4 Pro, or M5Stack PaperMono), visit the official website and follow the flashing instructions. Open-source developers maintain a faster update pace compared to some paid solutions.
