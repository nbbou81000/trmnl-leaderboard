Arduino Nano Matter Now Supports Zigbee

Arduino’s Nano Matter board now supports Zigbee through a Silicon Labs core update, streamlining smart home integration.

Read the article on the TRMNL Leaderboard →

Arduino’s Nano Matter board, designed for low-power smart home applications, now supports Zigbee 3.0 through a Silicon Labs core update (version 5.0), adding a third wireless connectivity option alongside Matter over Thread and Bluetooth LE. Integration is streamlined directly in the Arduino IDE by selecting Zigbee in the Tools › Protocol stack menu before compiling and uploading sketches. The code is compiled with the Zigbee 3.0 stack without hardware changes.

A dedicated library, wrapping Silicon Labs’ EmberZNet stack, simplifies device creation with Arduino-style classes for sensors, switches, and bulbs. For instance, a temperature sensor can be set up in a few lines of code, with a custom name and automatic measurement of the MGM240S module’s temperature.

The Zigbee Smart Clock project, developed to test the library, demonstrates this integration. Comprising a Nano Matter, a Modulino Thermo (temperature/humidity sensor), a Modulino Light (light sensor), and a 32×8 LED matrix, it connects to a Zigbee network and sends data to Home Assistant. The module also retrieves the time from the network and automatically adjusts its brightness. The code, wiring diagram, and 3D-printable enclosure files are available on the Arduino Project Hub.

The library includes 14 ready-to-use examples covering 11 device types: bulbs (on/off, dimmable, RGB), switches, sensors (temperature, humidity, light), contact sensors, and even a time client. Devices can be configured as routers (default, relaying mesh traffic) or end devices. A direct binding feature allows linking a switch to a bulb without relying on the hub for instant control. The library also handles identification commands (LED blinking) and stores network settings in the module’s non-volatile memory, preserving the connection after a reset.

To operate, the Nano Matter requires a Zigbee coordinator, which can be a commercial hub (Amazon Echo, SmartThings, Hubitat Elevation, IKEA DIRIGERA) or another Nano Matter converted into a coordinator using a Python script included in the Arduino core. This script, run from a terminal, turns a Nano Matter into a Zigbee radio for Home Assistant ZHA. Once configured, the coordinator can be repurposed as a standard device by resetting its firmware via the Burn Bootloader tool.
