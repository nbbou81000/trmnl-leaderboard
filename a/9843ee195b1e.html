Arduino Nano Matter : Zigbee désormais supporté

Le Nano Matter d'Arduino intègre Zigbee via une mise à jour du cœur Silicon Labs, simplifiant l'intégration dans les réseaux domotiques.

Lire l'article sur le Palmarès TRMNL →

La carte Arduino Nano Matter, conçue pour des applications domotiques à faible consommation, ajoute une troisième option de connectivité sans fil avec le protocole Zigbee. Jusqu’ici limitée à Matter over Thread et Bluetooth LE via son module Silicon Labs MGM240S, elle prend désormais en charge Zigbee 3.0 grâce à une mise à jour du cœur Arduino pour Silicon Labs (version 5.0).

L’intégration se fait directement depuis l’IDE Arduino : il suffit de sélectionner Zigbee dans le menu Tools › Protocol stack avant de compiler et téléverser le sketch. Le code est alors compilé avec la pile Zigbee 3.0, sans modification matérielle. Une bibliothèque dédiée, basée sur le stack EmberZNet de Silicon Labs, simplifie la création de périphériques Zigbee en proposant des classes Arduino pour les capteurs, interrupteurs ou ampoules. Par exemple, un capteur de température peut être configuré en quelques lignes de code, avec un nom personnalisé et une mesure automatique de la température du module MGM240S.

Le projet Zigbee Smart Clock, développé pour tester la bibliothèque, illustre cette intégration. Composé d’une Nano Matter, d’un Modulino Thermo (capteur de température/humidité), d’un Modulino Light (capteur de luminosité) et d’une matrice LED 32×8, il se connecte à un réseau Zigbee et transmet ses données à Home Assistant. Le module récupère également l’heure du réseau et ajuste automatiquement sa luminosité. Le code, le schéma de câblage et les fichiers 3D pour l’enceinte sont disponibles sur l’Arduino Project Hub.

La bibliothèque propose 14 exemples prêts à l’emploi couvrant 11 types de périphériques : ampoules (on/off, dimmables, RGB), interrupteurs, capteurs (température, humidité, lumière), capteurs de contact, et même un client de synchronisation horaire. Les périphériques peuvent être configurés comme routeurs (par défaut, relayant le trafic du réseau maillé) ou comme dispositifs terminaux. Une fonctionnalité de binding direct permet de lier un interrupteur à une ampoule sans passer par le hub, pour un contrôle instantané. La bibliothèque gère également les commandes d’identification (clignotement d’une LED) et stocke les paramètres du réseau dans la mémoire non volatile du module, préservant la connexion après un redémarrage.

Pour fonctionner, le Nano Matter nécessite un coordinateur Zigbee, qui peut être un hub commercial (Amazon Echo, SmartThings, Hubitat Elevation, IKEA DIRIGERA) ou un autre Nano Matter transformé en coordinateur via un script Python inclus dans le cœur Arduino. Ce script, exécuté depuis un terminal, convertit un Nano Matter en radio Zigbee pour Home Assistant ZHA. Une fois configuré, le coordinateur peut être réutilisé comme périphérique classique en réinitialisant son firmware via l’outil Burn Bootloader.
