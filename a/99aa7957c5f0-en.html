Sensea: DIY Underwater Camera Built with Raspberry Pi 3

An open-source project turns a Raspberry Pi 3 into a low-cost underwater camera to explore ponds and rivers.

Sensea is an open-source project designed to provide an affordable DIY solution for underwater exploration. Originally conceived as an alternative to a GoPro, the system is built around a Raspberry Pi 3 Model B+, offering a cost-effective way to capture underwater footage. The setup leverages the board’s low power consumption, allowing it to run on a standard 5V USB power bank for extended periods.

The creators aim to inspire hobbyist makers by making underwater exploration accessible. The project emphasizes simplicity and component availability, though no further technical details or build instructions are provided in the source.
