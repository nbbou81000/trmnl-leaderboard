Boar BBS: A Go-Based Telnet/SSH Bulletin Board with Games and Mail

An open-source Go-based bulletin board accessible via SSH or telnet, compatible with classic door games.

Read the article on the TRMNL Leaderboard →

Developer rh1tech has released Boar BBS, an open-source bulletin board system (BBS) accessible via telnet or SSH. Written in Go, the project simplifies deployment by compiling into a single binary and storing all data in a SQLite file using a pure-Go driver, eliminating the need for a C compiler.

The system includes classic BBS features such as hotkey menus, private mail, public message boards, live chat, and a oneliner wall. Sysop tools allow moderation of accounts. To register, users type NEW at the handle prompt; the first account becomes the system operator (sysop), while subsequent accounts remain read-only until approved. Up to five SSH public keys can be linked to an account for passwordless login.

Boar BBS supports door games through a JSON configuration file. Before launching a game, the system generates the required files DOOR.SYS and DORINFO1.DEF. Classic DOS games like LORD or TradeWars 2002 can run under DOSBox-X via an emulated serial port, though the author notes no real DOS testing has been done yet. Additional features include a FidoNet layer and an optional web-based sysop interface.

The code is licensed under GPL v3 and available on GitHub.
