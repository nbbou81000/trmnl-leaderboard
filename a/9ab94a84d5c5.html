Boar BBS : un serveur de babillard électronique en Go avec SSH et jeux

Un nouveau système de babillard électronique open source accessible en SSH ou telnet, écrit en Go et compatible avec les jeux classiques.

Le développeur rh1tech a publié Boar BBS, un serveur de babillard électronique (BBS) accessible via telnet ou SSH. Ce projet open source, écrit en Go, se distingue par sa simplicité : il génère un binaire unique et stocke toutes les données dans un fichier SQLite via un pilote Go pur, évitant ainsi l’usage d’un compilateur C.

Le système propose des fonctionnalités classiques des BBS : menus à raccourcis, courrier privé, forums publics, chat en temps réel et un mur de messages. Les outils de gestion (sysop) permettent de modérer les comptes. Pour s’inscrire, il suffit de taper NEW au prompt du nom d’utilisateur : le premier compte devient administrateur, tandis que les suivants restent en lecture seule jusqu’à validation par le sysop. Jusqu’à cinq clés SSH peuvent être associées à un compte pour une connexion sans mot de passe.

Boar BBS supporte également les door games (jeux externes) via un fichier de configuration JSON. Avant de lancer un jeu, le système génère les fichiers DOOR.SYS et DORINFO1.DEF nécessaires. Les jeux DOS comme LORD ou TradeWars 2002 peuvent fonctionner sous DOSBox-X via un port série émulé, bien que l’auteur précise qu’aucun essai avec un vrai DOS n’ait encore été réalisé. Une couche FidoNet et une interface web optionnelle pour les administrateurs sont également incluses.
