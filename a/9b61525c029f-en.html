WireSkein automates electronic signal testing

An open-source tool converts logic analyzer captures into automated tests to verify signal behavior.

Read the article on the TRMNL Leaderboard →

WireSkein, part of the Open Embedded Probe project on GitHub, automates the verification of electronic signals by turning logic analyzer captures into test cases. Instead of manually inspecting waveforms, the tool generates tests that automatically check if signals behave as expected.

The software, released under the MIT license, requires Python 3.11 or later and numpy as its only dependency. A test consists of two steps: recording a signal capture and then verifying it against predefined criteria. Checks include square waves, logic levels, rising or falling edges, pulse counts, and communication protocols like I2C, SPI, and UART.

If a required signal for a test is missing from the capture, it is marked as unchecked and causes the test to fail by default. A pytest plugin records each run and performs verification afterward. Captures are saved in the .wireskein format, a compressed file that preserves each channel at its original sample rate. Analog channels are also supported, with their own rates and raw ADC values.

A browser-based viewer is included in the package, and conversion tools to and from sigrok’s .sr format are available. Conversion works block by block, allowing large data streams to be processed without overwhelming memory. The project is currently in beta.
