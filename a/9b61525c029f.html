WireSkein automatise les tests de signaux électroniques

Un outil open source transforme les captures d'analyseurs logiques en tests automatisés pour vérifier le comportement des signaux.

WireSkein, développé dans le cadre du projet Open Embedded Probe et hébergé sur GitHub, propose une solution pour automatiser la vérification des signaux électroniques. Plutôt que d’analyser manuellement des formes d’onde, l’outil génère des tests qui valident automatiquement si les signaux respectent les attentes définies.

Le logiciel, distribué sous licence MIT, nécessite Python 3.11 ou une version ultérieure, ainsi que la bibliothèque numpy comme seule dépendance. Un test se compose de deux étapes : l’enregistrement d’une capture de signal, puis sa vérification selon des critères prédéfinis. Les vérifications couvrent notamment les ondes carrées, les niveaux logiques, les fronts montants ou descendants, les comptages d’impulsions, ainsi que les protocoles de communication I2C, SPI et UART.

Si un signal requis pour un test n’est pas présent dans la capture, il est marqué comme non vérifiable et le test échoue par défaut. Un plugin pour pytest permet d’enregistrer chaque exécution et de lancer la vérification après coup. Les captures sont sauvegardées au format .wireskein, un fichier compressé qui conserve les canaux à leur fréquence d’échantillonnage d’origine. Les canaux analogiques sont également supportés, avec leurs propres taux et valeurs brutes d’ADC.

Un visualiseur web est inclus dans le package, et des outils de conversion vers et depuis le format .sr de sigrok sont disponibles. La conversion s’effectue par blocs, ce qui permet de traiter des flux de données volumineux sans saturer la mémoire. Le projet est actuellement en phase de bêta.
