VitaOS: An Open-Source Replacement for the PS Vita Dashboard

An open-source project replaces the aging PS Vita interface with a modern dashboard inspired by the PS5.

Read the article on the TRMNL Leaderboard →

Since its launch in 2012, the PS Vita displayed a frozen dashboard with animated blue bubbles and an impractical organization for managing games, movies, and music. The user, accustomed to software modifications on their console, sought a solution to modernize this interface without altering existing functionalities.

VitaOS, an open-source project, offers a complete replacement of the LiveArea with a tab-based menu directly inspired by the PS5 interface. The dashboard now displays information like the last played game, quick resume snapshots, time, battery level, and local weather. Games are sorted by system (RetroArch, native PS Vita, PSP) with box art and gameplay previews, while movies appear in a cover flow view with automatic resume. Homebrew apps are grouped in a dedicated tab, customizable via drag-and-drop, and an integrated store allows downloading new homebrews without leaving the interface.

The installation relies on a VPK file and VitaShell, required for consoles modified via HENkaku or Enso. VitaOS can be launched from the LiveArea or, with an optional plugin, become the default interface at startup. A fallback option temporarily disables the plugin in case of issues. The interface includes its own virtual keyboard, interface sounds, and a wallpaper reacting to console movements. The project, maintained primarily by a single developer, supports eight languages and is actively evolving, though some imperfections remain due to its open-source status.
