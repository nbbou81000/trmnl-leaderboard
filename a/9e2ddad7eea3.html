Transformer un vieux smartphone en tableau de bord domotique avec Android Auto

Un développeur utilise Headunit Revived pour créer un tableau de bord domotique personnalisé à partir d’un ancien smartphone, sans surcoût ni interface complexe.

Plutôt que d’investir dans un écran dédié comme le Google Nest Hub ou une tablette classique, un passionné de domotique a choisi une solution originale : transformer un ancien smartphone en tableau de bord tactile pour contrôler son installation. L’objectif était de centraliser les commandes sans multiplier les applications ou les interfaces encombrantes.

Pour y parvenir, il a utilisé Headunit Revived, une application gratuite (avec option payante dans le Play Store) qui transforme un smartphone ou une tablette Android en récepteur Android Auto. Une fois installée, l’application active le mode « Self Mode », permettant d’afficher des applications compatibles sur l’écran principal avec une interface optimisée pour les interactions rapides. Contrairement aux widgets classiques, cette solution propose une navigation fluide et ciblée, sans nécessiter de configuration manuelle complexe.

L’intégration avec Home Assistant est particulièrement efficace : l’application affiche des boutons de contrôle directs pour les appareils et zones domotiques, ainsi que des automatisations basiques. Les commandes de médias (lecture, pause, playlists) et les notifications (calendrier, messages) s’affichent également de manière épurée, sans distraire l’utilisateur. L’auteur souligne que cette approche reproduit en partie le fonctionnement d’Apple HomeView, mais avec un matériel existant et sans coût supplémentaire.

Le résultat est un tableau de bord personnalisé, toujours accessible à portée de main, qui évite les allers-retours entre applications. L’auteur précise que même un ancien smartphone ou une tablette d’entrée de gamme suffit pour cette utilisation, rendant la solution accessible à moindre frais.
