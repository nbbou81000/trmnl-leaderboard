Arduino App Lab 0.11: Deployment, AI, and Mobile Sensors

App Lab 0.11 for UNO Q adds scalable deployment, pose recognition, and mobile sensor streaming.

Read the article on the TRMNL Leaderboard →

Arduino App Lab 0.11 enhances the development tool for the UNO Q board with features aimed at scaling or simplifying electronic projects.

Scalable Deployment

The update introduces App Releases, frozen and precompiled packages designed to be installed on compatible boards via the Works with Arduino program. Unlike classic exports, these packages lock dependencies to ensure consistent behavior across devices. External AI models or libraries are downloaded at installation, streamlining setup.

Built-in AI Assistance

An Agent Panel integrates directly into the editor to assist development in real time. It analyzes open code and files, allows project modifications via natural language instructions, and maintains a chat history per project. Unlike the Agent Mode (introduced in 0.10), this panel remains accessible alongside code editing.

Pose Recognition and AI

A new Pose Estimation Brick enables real-time body pose detection on the VENTUNO Q board. It offers two modes: standard skeletal tracking (17 points, 10 FPS) with predefined pose recognition (standing, sitting, arms raised), and a custom mode where users provide photos to train the system to recognize a specific pose, such as a tennis swing. No external modeling tools are required.

Users can also import language models from Hugging Face for the LLM Brick, with automatic compatibility checks and quantization adjustments.

Mobile Sensors and Positioning

The mobile companion app now streams microphone and IMU data to App Lab via a remote sensor peripheral, in real time and secured by WebSocket. Data is sent as JSON, enabling custom integration. An example using the Qualcomm Terrestrial Positioning Service (TPS) demonstrates indoor positioning by leveraging Wi-Fi, cellular, and Bluetooth LE signals, with minimal power impact.

Editor improvements include reference search for Python and C++, YAML syntax checking, and a dedicated console per Brick container.
