TNY-360 v2: Open-Source DIY Robot Dog for Everyone

An open-hardware, modular quadruped robot designed to make robotics more accessible.

Read the article on the TRMNL Leaderboard →

Paul Loisil, a developer and computer science student, has released the TNY-360 v2, an open-hardware quadrupedal robot dog designed to simplify robotics. After nearly three years of solo development, Loisil aimed to bridge the gap between overly simplistic robots and overly complex, expensive systems. The project features a modular PCB ecosystem to minimize wiring errors and ease assembly.

The robot is powered by an Espressif ESP32-S3 microcontroller, split across two cores: the "Reflex" core handles kinematics calculations and a 200Hz closed-loop control system for modified TowerPro MG996R servos with analog feedback via a custom op-amp PCB, while the "Brain" core manages orchestration, network connectivity, and the user interface. The hardware is modular, with dedicated PCBs for control, sensors, power, and the "brain," connected via JST cables and low-profile headers to reduce clutter and miswiring risks. A dorsal port provides I2C and power for optional expansion boards.

The base configuration includes 12 modified MG996R servos for the legs, 2 MG90D micro-servos for the ears, an Omnivision OV2640 camera module, an STMicroelectronics VL53L0X time-of-flight lidar, an LSM6DS3 six-axis IMU, an SSD1306-based 128×64 OLED display, an I2S MEMS microphone, and an onboard speaker. Pre-orders are open on the TNY Robotics website: $332 for a barebones kit, $458 for a more complete maker kit. A fully-assembled "Ready2Run" kit is planned at $688 but is not yet available. Documentation, hardware files, and source code for V1 are available on GitHub under the Creative Commons Attribution-NonCommercial-ShareAlike 4.0 license, with V2 files to be uploaded soon.
