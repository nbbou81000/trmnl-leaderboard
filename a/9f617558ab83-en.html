RF Watchkeeper: A Versatile System to Monitor Radio Waves

An open-source project automatically monitors air traffic, maritime, satellite, and wireless sensor communications.

Thomas Vikström has created RF Watchkeeper, an embedded computing platform designed to continuously monitor multiple types of radio transmissions without human intervention. The system is built around a Qualcomm Dragonwing IQ-9075 evaluation kit, paired with affordable software-defined radio (SDR) receivers such as the RTL-SDR Blog V4 or an RTL2832U-based USB tuner. Unlike traditional radio receivers, SDRs handle most signal processing in software, enabling frequency changes and decoding of different transmission types as needed.

Features and applications

RF Watchkeeper supports four monitoring categories:

  • Aviation communications: captures exchanges between control towers and aircraft, as well as ATIS (Automatic Terminal Information Service) broadcasts, which provide weather and airport operational data. The system locally transcribes these messages, though recognition errors may occur with poor reception.
  • Maritime traffic: decodes AIS (Automatic Identification System) signals around 162 MHz using AIS-Catcher, enabling vessel tracking on a map. Marine weather reports have been received from stations over 100 kilometers away.
  • Wireless sensors: decodes transmissions from compatible sensors (weather stations, temperature sensors, tire pressure monitoring systems) operating at 433 MHz.
  • METEOR weather satellites: predicts satellite passes, records transmissions around 137 MHz, and converts data into Earth images using SatDump. Reception is limited by the use of an indoor antenna.

The Dragonwing IQ-9075 accelerates data processing through dedicated hardware accelerators for local AI workloads. In a test, an accelerated ATIS processing pipeline completed in seconds, compared to over two minutes with a CPU-only Whisper Small run, though the pipelines differed.

All collected data is stored locally and accessible via a web-based dashboard that also displays the system's status.

The project, still in development, faces reliability issues and could improve reception with better antennas. The source code and documentation are available on GitHub for enthusiasts looking to replicate the setup.
