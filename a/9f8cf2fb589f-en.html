NESCD: A DIY CD Player for the NES Using RP2350B

A tinkerer adds a functional CD drive to a NES with eject button and volume knob, using an RP2350B microcontroller and an Everdrive N8 Pro.

Read the article on the TRMNL Leaderboard →

The NESCD project, created by tinkerer Throaty Mumbo, turns a NES into a console capable of playing CDs through a DIY electronic setup. The system uses an RP2350B microcontroller, an IDE CD drive, and an Everdrive N8 Pro, a universal cartridge that loads ROMs from an SD card.

Once assembled, users insert a burned CD into the drive, then launch the cdplayer.nes ROM from the Everdrive menu. The microcontroller extracts the ROM from the disc, sends it to the cartridge via USB, and the game starts automatically. The setup includes a 3D-printed case with an eject button and a volume knob for a seamless integration.

The project is fully documented on a GitHub repository under the MIT license, offering all the files needed to replicate the build: electronic schematics, PCB designs, STL files for 3D printing the case, firmware, and scripts to burn custom ROMs onto CDs. Among the examples provided is a CD version of Super Mario Bros., featuring an opening cinematic and music played directly from the disc.

The creator highlights that the cdplayer.nes ROM has an unexpected use: it turns the NES into a simple CD audio player. Users just need to load this ROM from the Everdrive, insert a standard audio CD, and the console plays the music through its speakers.

The project is designed for electronics and retro gaming enthusiasts, with comprehensive documentation and open-source tools. All files and instructions are available online for those eager to try it out.
