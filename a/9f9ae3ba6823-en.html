A Magnetic E-Ink Kitchen Timer with Adafruit MagTag

A rechargeable, magnetic, and programmable kitchen timer featuring an e-ink display, visual and sound alerts.

This project introduces a practical kitchen timer built around the Adafruit MagTag, a device featuring an e-ink display, built-in buttons, NeoPixels, and a speaker. The e-ink screen shows the remaining time, while visual (NeoPixels flashing) and sound alerts (via the speaker) signal the end of the countdown.

The timer is rechargeable, magnetic, and programmable, offering flexible use in a kitchen. The e-ink display ensures low power consumption and optimal readability, even in bright daylight. The built-in buttons simplify time setup, while the NeoPixels add a visual cue to alerts.

Once the time elapses, the timer displays an end message and triggers alerts to grab attention. A detailed guide is available to build this project.
