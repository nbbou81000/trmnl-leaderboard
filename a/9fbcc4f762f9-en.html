Hackaday’s 2026 retrocomputing challenge highlighted a diverse range of projects, awarding three top entries and honoring several standout creations. Winners received a $150 DigiKey gift card.

Top Three Projects

The first-place prize went to Mike for his vacuum tube computer, a massive machine featuring 460 Russian 6N3P triodes and 1,840 1N33 diodes. This 8-bit system uses a NOR gate architecture with just 16 instructions. It includes a 7-segment display salvaged from British railway clocks and runs a simple airship simulator. The judges praised its complexity and dedication.

The Microtronic Phoenix, developed by a team of hackers, recreates the 1970s Busch Microtronic educational computer, which used a 4-bit TMS1600 processor. The project uses an Atmel microcontroller-based emulator to run the original firmware. Retrieving the mask-programmed firmware required a logic analyzer.

A Tiny Sieve is a Lehmer sieve, a mechanical device for rapid factorization of large numbers. This project replaces historical components like bicycle chains or delay lines with 30 ATtiny412 microcontrollers, controlled by an RP2040. While slower than later electronic versions, it showcases a niche in computing history.

Notable Mentions

In the "old hardware for modern tasks" category, NES Radar uses an NES console to display air traffic data via an external server. Meatloaf enables a Commodore 64 to load programs from a network, while USBSID-Pico uses two real SID chips to emulate the Commodore 64’s sound.

The "modern hardware emulating the past" category includes Pico-mac-nano, an emulator of the Macintosh 128k housed in a miniature case replicating the original design. Win95 Retro Weather Display presents weather data in a tiny CRT-style display with a Windows 95 aesthetic. Finally, Microbox 2K2 recreates an 80s computer using an Xmos XU216 SoC, leveraging its multicore architecture to emulate each system component individually.
