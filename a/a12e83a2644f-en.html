A lightweight language model for chatting and coding in Python

A researcher releases Kadmos-1, a compact language model that can chat and write Python code.

Read the article on the TRMNL Leaderboard →

Kristijonas Adomaitis has released Kadmos-1, a decoder-only transformer language model with 45.8 million parameters. Designed for short conversations and generating small Python programs, it starts from random initialization without relying on a pre-trained model. Its architecture, tokenizer, and weights are entirely built within the dedicated GitHub repository.

The model file, consisting of around 110 lines of PyTorch code, is optimized for cross-platform use: it leverages Metal (MPS) acceleration on Apple Silicon chips and falls back to the CPU on other systems. To use it, download the kadmos-1.pt file from the latest release and start a chat session. The model retains the last 512 tokens (words or word fragments) exchanged to contextualize its responses.

Adomaitis highlights the limitations of this compact model: it often misinterprets questions, invents facts, or generates non-functional Python code. In a shared example, out of three generated functions, two run correctly, while the third returns an incorrect sum with wrong comments.

The model was trained on public datasets including stories, Python source code, everyday conversations, and Python-related Q&A pairs. Dataset licenses are listed in the DATA.md file, with some restricted to non-commercial use. The Kadmos-1 code is MIT-licensed, but several datasets impose usage constraints.
