A DIY ADS-B Receiver for Under $50

An open-source project turns an ESP32-S3 into an ADS-B aircraft receiver for under $50.

Read the article on the TRMNL Leaderboard →

A maker has built an affordable ADS-B (Automatic Dependent Surveillance-Broadcast) receiver using an ESP32-S3 microcontroller paired with a Meshnology W12 board. This board features a LoRa LR2021 module tuned to 1090 MHz, the frequency used by aircraft to broadcast their position and flight data.

The setup decodes ADS-B transmissions, which employ OOK and Manchester encoding, and validates the data’s CRC before displaying aircraft tracks on a basic web interface. An optional GNSS receiver can be added to pinpoint both the receiver’s location and the detected aircraft.

The creator reports decent performance, with the system picking up signals from up to 150 nautical miles (about 278 km) away using a 915 MHz antenna. However, minor tweaks are required: adjusting the board’s filter configuration to prevent attenuation of the 1090 MHz signals.

This project joins the ranks of other ADS-B monitoring solutions, such as software-defined radio (SDR) setups. Electronics and radio enthusiasts are encouraged to share their own projects.
