ESP32 Turns into a Software-Defined Radio Receiver via Hidden Feature

An undocumented feature in some ESP32 chips enables them to function as SDR receivers without extra hardware.

Read the article on the TRMNL Leaderboard →

An independent discovery by two enthusiasts reveals that some ESP32 microcontrollers (starting from versions with the Tensilica core) include an undocumented radio feature. This function allows extracting the I/Q stream (quadrature radio signal) before the Wi-Fi modem, enabling its use via software-defined radio (SDR) software on an external computer.

Only ESP32 models with 2.4 GHz or 5 GHz radio support are affected, excluding Bluetooth-only versions or ESP32-P4 chips without radio. The feature is limited to reception but covers both 2.4 GHz and 5 GHz bands depending on the model. While this solution doesn’t replace dedicated SDR receivers like RTL-SDR, it opens possibilities for projects requiring passive radio spectrum monitoring.

Users suggest that transmission might also be possible, though undocumented. The main technical limitation lies in data transfer to a computer: the maximum throughput of ESP32’s SDIO (4-bit) or PARLIO (8-bit) interfaces cannot fully handle high-speed I/Q streams, restricting applications to narrow bands or reduced data rates.
