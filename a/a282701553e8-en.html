BBC Micro Emulator on RP2350: A Retro Microcomputer in the Palm of Your Hand

A cycle-accurate BBC Micro emulator, designed for a $1.20 microcontroller, now runs on a Raspberry Pi RP2350 with an integrated touchscreen.

Dominic Pajak has successfully ported a cycle-accurate emulator of the BBC Micro, a popular 1980s UK home computer, to a Raspberry Pi RP2350 microcontroller costing just $1.20. The project leverages the Pimoroni Presto development board, featuring an RP2350, a 480×480 touchscreen, Wi-Fi, and an SD card slot. The emulator boots directly into Elite, the classic space trading and combat game, without requiring an external computer.

,

Technical optimizations and challenges

,

The emulator is based on beebjit, an open-source project that accurately reproduces the BBC Micro’s 6502 processor and associated hardware on a cycle-by-cycle basis. However, beebjit was originally designed for much more powerful machines. To adapt it to the RP2350, Pajak ported the emulator to its dual Cortex-M33 cores and developed a just-in-time (JIT) compiler for the Thumb-2 instruction set. This compiler translates 6502 instructions into native ARM code, significantly speeding up execution compared to traditional interpretation.

,

The limited memory (520 KB of SRAM and 8 MB of PSRAM) posed major challenges. Pajak allocated 4 MB of PSRAM for compiled code and implemented software mechanisms to handle memory accesses and code invalidation without a memory management unit (MMU).

,

The workload is split between the two cores: one handles CPU and hardware emulation, while the other manages graphics. The RP2350’s programmable I/O hardware synchronizes display timing. The initial JIT implementation ran Elite at 1.45 times its original speed, later increasing to 7.6 times after further optimizations. At normal speed, the emulator uses only 13% of one core and 11% of the other.

,

The project’s GitHub repository includes the source code, precompiled firmware, flashing instructions for the Pimoroni Presto, build scripts, testing tools, performance monitoring utilities, and detailed documentation explaining how the emulator works. The project is open source under the GNU GPL v3 license.
