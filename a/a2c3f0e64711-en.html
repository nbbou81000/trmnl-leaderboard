pico_hdmi: Native HDMI Output Library for RP2350 Without Overclocking

An open-source library enabling native 480p and 720p60 HDMI output on RP2350 without bit-banging or overclocking.

Read the article on the TRMNL Leaderboard →

Weeb Labs has released pico_hdmi, an open-source library (Unlicense) enabling native HDMI video and audio output on the RP2350 or Raspberry Pi Pico 2. Unlike software-based bit-banging methods, this library leverages the RP2350’s built-in HSTX peripheral and hardware TMDS encoding, eliminating the need for overclocking to achieve 480p resolution.

Audio support is included with a default sample rate of 48 kHz, but the library also supports 32 kHz, 44.1 kHz, 88.2 kHz, 96 kHz, 176.4 kHz, and 192 kHz. Default output pins are set with the clock on GPIO12/13 and the three data pairs on GPIO14 through GPIO19. Boards with swapped lanes or polarity can override the default pinout. Pads are configured for fast slew and 12 mA drive strength to ensure edge margin stability at 720p60.

A 2.0 beta branch introduces an optional scanout path for applications requiring heavy per-line processing, overlays, 320-to-640 scaling, or live capture. A specific mode allows the callback to return a 320-pixel RGB565 line, which is doubled via DMA to produce a 640-pixel output. For 720p60 output, the RP2350 must run at 372 MHz with a 1.3V core voltage.
