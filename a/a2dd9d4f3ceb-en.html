Sudopi Zer0: Open-Source Linux Handheld Built on Raspberry Pi Zero 2 W

An open-source project turns a Raspberry Pi Zero 2 W into a self-contained Linux handheld terminal with ortholinear keyboard and built-in battery.

The Sudopi Zer0, created by Signals Circuits, is a self-contained Linux handheld terminal built around a Raspberry Pi Zero 2 W. This microcomputer features a quad-core Arm Cortex-A53 processor running up to 1 GHz, paired with 512 MB of RAM. Unlike the standard Pi Zero 2 W, which only includes a camera connector and a 40-pin header, this project integrates a carrier board that restores missing ports, including two USB ports via a USB hub and a STEMMA QT/Qwiic connector for adding sensors without soldering.

The compact case houses an ortholinear keyboard — with keys arranged in a regular grid — and a thumbstick serving as a mouse replacement. For audio, a dedicated board manages an amplifier, a speaker, and a headphone jack. A custom power board powers the entire system and allows charging the internal battery via a USB-C port. The project, still in its early stages with only three commits on its repository, already provides electronic schematics online and is preparing assembly kits.
