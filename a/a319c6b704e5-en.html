The Oldest Windows Software Still Running on Windows 11

A researcher identifies the earliest Windows 11-compatible GUI application, despite the lack of 16-bit support.

Read the article on the TRMNL Leaderboard →

In the open-source world, software is often compiled from source for a specific distribution, allowing old versions to run on modern systems. Under Windows, this flexibility is rare: binary applications depend on the APIs present in the operating system. Since Windows 11 dropped support for 16-bit applications, a time limit is imposed to determine the oldest GUI application still executable.

The investigation by [Enlyth] revealed that the 1993 version of Freecell for Win32s (a 32-bit extension for Windows 3.1) still runs. However, the search extended to early pre-release versions of Windows NT 3.1, whose APIs were initially incompatible with later releases. After multiple failed attempts, a November 1992 version of the CD player from Windows NT 3.1 finally ran, thanks to a DLL still present in Windows 11. This DLL emulates a CD drive, highlighting an era when such devices were ubiquitous before being replaced by modern storage solutions.

The official record, however, belongs to an even older application: Reversi, bundled with Windows 1.01 in November 1985. Using a DOS virtual machine emulator (VDM) based on WINE, this graphical application was executed on Windows 11, despite the lack of native 16-bit support. This feat underscores the exceptional binary backward compatibility of the Win32 API, a legacy spanning over 30 years of development.
