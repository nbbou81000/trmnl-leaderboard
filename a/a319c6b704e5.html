Le plus vieux logiciel Windows encore compatible avec Windows 11

Un chercheur identifie la première application graphique Windows 11 fonctionnelle, malgré l'absence de support 16 bits.

Lire l'article sur le Palmarès TRMNL →

Dans l’univers du logiciel libre, les programmes sont souvent compilés pour une distribution spécifique, ce qui permet à des versions anciennes de fonctionner sur les systèmes récents. Sous Windows, cette flexibilité est rare : les applications binaires dépendent des APIs (interfaces de programmation) présentes dans le système. Depuis que Windows 11 a abandonné le support des applications 16 bits, une limite temporelle s’impose pour déterminer la plus ancienne application graphique encore exécutable.

L’enquête menée par [Enlyth] a révélé que la version 1993 de Freecell pour Win32s (une extension 32 bits pour Windows 3.1) fonctionne toujours. Cependant, la recherche s’est poursuivie vers les versions préliminaires de Windows NT 3.1, dont les APIs étaient initialement incompatibles avec les versions ultérieures. Après plusieurs essais infructueux, une version de novembre 1992 du lecteur CD de Windows NT 3.1 a finalement pu s’exécuter, grâce à une DLL encore présente dans Windows 11. Cette DLL émule un lecteur CD, rappelant l’époque où ces périphériques étaient omniprésents, avant d’être remplacés par des solutions de stockage modernes.

Le record officiel revient cependant à une application encore plus ancienne : Reversi, livrée avec Windows 1.01 en novembre 1985. Grâce à un émulateur de machines virtuelles DOS (VDM) basé sur WINE, cette application graphique a pu être exécutée sous Windows 11, malgré l’absence native de support 16 bits. Cette prouesse souligne la rétrocompatibilité binaire exceptionnelle de l’API Win32, un héritage de plus de 30 ans de développement.
