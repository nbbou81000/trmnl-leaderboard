Synergy Logic SLM-RP4: Modular Industrial PLC Based on Raspberry Pi 4

A modular industrial PLC compatible with Raspberry Pi 4 for automation and industrial IoT applications.

Read the article on the TRMNL Leaderboard →

Synergy Logic has launched the SLM-RP4, a modular industrial PLC built around a Raspberry Pi 4 single-board computer, targeting industrial automation, machine control, data acquisition, and Industrial IoT (IIoT) applications. This DIN-rail mountable controller supports 24V DC power input and features an SPI-based backplane that can connect up to eight Synergy Logic I/O modules, providing up to 128 I/O points.

The SLM-RP4 includes a passive aluminum enclosure, two micro-HDMI ports, a 3.5mm audio jack, USB ports (2x USB 3.0, 2x USB 2.0, 1x USB-C for auxiliary power), Gigabit Ethernet, Wi-Fi 5, and Bluetooth 5.0. It runs Raspberry Pi OS with OpenPLC Runtime preinstalled, supporting IEC 61131-3 programming languages such as Ladder Diagram and Structured Text.

The SPI backplane supports 18 compatible I/O modules (not hot-swappable), including digital I/O, relays, analog voltage/current I/O (0–10V, 4–20mA), and thermocouple inputs (types J, K, etc.). Modules stack to the right of the controller, with their position determining their SPI slot address. The system offers adjustable I/O scan intervals from 1 ms to 1000 ms, error detection, and a hardware watchdog for fault recovery.

Synergy Logic provides Python and C++ libraries for direct backplane control and documentation for integrating FUXA, an open-source HMI/SCADA platform compatible with OpenPLC via Modbus TCP. The SLM-RP4 is certified to UL 61010, UL 61010-2-201, and CE standards, operating between 0°C and 50°C. It is available for $249, with expansion modules sold separately. A previous model, the SL-RP4, is priced at $149.
