Building Retro GUIs for Windows 3.11 and OS/2 on Original Hardware

A developer recreates graphical interfaces for Windows 3.11 and OS/2 Warp 3 on original hardware using historical development tools.

Read the article on the TRMNL Leaderboard →

A developer created graphical interfaces to control microcontroller projects on retro operating systems, Windows 3.11 and OS/2 Warp 3, using 1990s development tools. His first attempt with Borland Delphi 1 (1995), the last environment to generate 16-bit Windows programs, worked out of the box. He then switched to Microsoft Visual C++ 1.52 (1993), where interfaces are coded manually instead of using drag-and-drop.

To compile these applications, he relied on scarce resources: Charles Petzold’s Programming Windows 3.1 book, a Borland reference, and the built-in help of the Windows 3.1 SDK. The final app communicates with an FPGA audio player over a serial port. To port the same software to OS/2 Warp 3, he used the Windows Libraries for OS/2 and patched one byte in the NE executable header to force 16-bit mode. However, the Delphi build failed due to the absence of TOOLHELP.DLL in the 1991 WLO libraries, despite an attempt to replace it with ReactOS’s toolhelp.c.

The Visual C++ build ran as-is, adopting OS/2’s native window style. Technical details and source code are available on chrisdevblog.com and GitHub.
