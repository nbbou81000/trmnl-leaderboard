Créer des interfaces rétro pour Windows 3.11 et OS/2 sur matériel d'époque

Un développeur recrée des interfaces graphiques pour Windows 3.11 et OS/2 Warp 3 sur matériel d'origine, en utilisant des outils de développement historiques.

Lire l'article sur le Palmarès TRMNL →

Un passionné a conçu des applications graphiques pour contrôler ses projets de microcontrôleurs sur des systèmes d’exploitation rétro, Windows 3.11 et OS/2 Warp 3, en exploitant des outils de développement des années 1990. Son premier essai avec Borland Delphi 1 (1995), le dernier environnement à générer des programmes 16 bits pour Windows, a fonctionné immédiatement. Il a ensuite migré vers Microsoft Visual C++ 1.52 (1993), où les interfaces s’écrivent directement en code, sans glisser-déposer.

Pour compiler ces applications, il a dû s’appuyer sur des ressources rares : le livre Programming Windows 3.1 de Charles Petzold, une référence Borland, et l’aide en ligne du Windows 3.1 SDK intégré au compilateur. L’application finale communique avec un lecteur audio FPGA via un port série. Pour porter le même logiciel sur OS/2 Warp 3, il a utilisé les Windows Libraries for OS/2 et modifié un octet dans l’en-tête du fichier exécutable (NE) pour forcer le mode 16 bits. En revanche, la version Delphi a échoué en raison de l’absence de TOOLHELP.DLL dans les bibliothèques WLO de 1991, malgré une tentative de remplacement inspirée du projet ReactOS.

La version Visual C++ a fonctionné sans ajustement supplémentaire, adoptant le style natif des fenêtres d’OS/2. Les détails techniques et le code source sont disponibles sur chrisdevblog.com et GitHub.
