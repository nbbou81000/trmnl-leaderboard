Home Assistant 2026.10: Vector Maps and Trigger IDs

Home Assistant 2026.10 brings vector maps, simplified trigger IDs, and a renamed cloud service.

Home Assistant 2026.10, released on October 7, 2026, introduces significant updates including a map overhaul and simplified automations. The Home Assistant Cloud service is renamed Home Assistant Link, with no changes to its functionality. The transition is scheduled for December 2026.

Vector maps and OpenStreetMap integration

The built-in maps now use vector tiles provided by OpenStreetMap instead of pre-rendered images. This change ensures sharp rendering at any zoom level, dark mode compatibility, and smooth navigation. Devices unable to render vectors fall back to the classic map. Markers are redesigned: people appear with their profile pictures, zones with colored icons, and overlapping markers merge into bubbles. A new overview displays recent user activity and zone details, accessible from the dashboard or a smartphone.

Automations: trigger IDs made accessible

The trigger IDs, a long-standing feature allowing multiple triggers in a single automation, now feature a dedicated UI. Manual YAML configuration remains optional for users who prefer it.

Other additions include a redesigned profile page, a dedicated panel for Modbus connections, and 15 new integrations. Contributors, including those who improved the release notes, are acknowledged for their work.
