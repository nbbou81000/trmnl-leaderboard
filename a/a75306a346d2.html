Les CPU x86 démarrent toujours en mode 16 bits, héritage de 1978

Tous les processeurs x86 modernes démarrent en mode réel 16 bits, comme l’Intel 8086 de 1978, avant de basculer en mode protégé.

Depuis 1978, année de sortie de l’Intel 8086, les processeurs x86 démarrent systématiquement en mode réel, un environnement 16 bits sans mémoire protégée ni pagination. Intel et AMD confirment que leurs architectures 64 bits, malgré leur modernité, conservent ce comportement à la mise sous tension. Le firmware UEFI exécute seulement quelques instructions en mode réel avant de basculer en mode protégé, mais les cœurs supplémentaires du CPU repassent brièvement par ce stade à chaque redémarrage.

Ce mécanisme historique persiste dans les noyaux Linux et Windows. Le code de démarrage de Linux, présent dans le fichier trampoline_64.S, et le noyau de Windows 11, via un stub nommé HalpRMStub, reproduisent encore les calculs de segments hérités de l’Intel 8086. Intel avait envisagé en 2023 de supprimer définitivement le mode réel avec son projet X86S, mais a abandonné cette initiative en décembre 2024.

Une alternative émergente pourrait provenir d’un processeur expérimental évoqué en septembre 2026 par l’expert Christian Ludloff sur les listes de diffusion du noyau Linux. Ce processeur, qualifié de PM64-only et PML5-only, démarrerait directement en mode 64 bits, sans passer par le mode réel.
