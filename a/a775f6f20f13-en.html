A Fully 3D-Printed Apollo DSKY Powered by Raspberry Pi

An aerospace engineer recreates the Apollo command interface using a Raspberry Pi and 3D printing, all open source.

Read the article on the TRMNL Leaderboard →

Michael Newton, an aerospace avionics engineer based in Calgary, has recreated the DSKY (Display and Keyboard Unit), the command interface of the Apollo Guidance Computer (AGC) used during the Apollo missions. This 1:1 scale 3D-printed enclosure integrates a Raspberry Pi running the Virtual AGC emulator, faithfully replicating the original system’s functions.

The AGC, developed by MIT in 1966, had less than 100 KB of memory and a 1.024 MHz clock speed, yet it enabled astronauts to handle navigation, maneuvers, and re-entries. The DSKY emulated by the Raspberry Pi even reproduces the 1201 and 1202 alarm codes (as seen during Apollo 11) and the 15-bit data structure with parity bit.

The project relies on open-source CAD files derived from MIT’s original blueprints. Michael adapted the 3D models for printing, designed a case 90% faithful to the original, and used Kailh Box Navy mechanical keys for the keyboard. The Raspberry Pi communicates with components via USB microcontrollers, offering a low-power, easy-to-duplicate solution. The yaAGC emulator, developed by VirtualAGC, accurately replicates the AGC’s behavior, including its logic architecture based solely on 3-input NOR gates.

Michael is considering a premium version with an aluminum case, improved annunciators, and an electroluminescent display. Meanwhile, his assembly guide and 3D files are available open source on GitHub for anyone to replicate the project.
