PaperMono: An E-Ink Shopping List Synced Between Fridge and Phone

A wall-mounted e-ink screen displays and syncs a shopping list with a mobile web interface. Technical details and setup guide.

The PaperMono project turns the M5Stack PaperMono e-ink display (ESP32-S3 with a 3.97" 480×800 touchscreen) into a synchronized shopping list that appears on your fridge and updates in real time on a mobile web app. This open-source project, licensed under GPL-3.0, includes a complete C++ firmware (around 2,400 lines) and a FastAPI server to manage the data.

Key features

The e-ink screen displays the list grouped by aisles, ordered as you walk through the store. Items can be checked off with a tap, or added using an optimized on-screen keyboard that only redraws changed areas to avoid flickering. Suggestions are based on a shared history between the device and the phone. The server stores data locally (SQLite) and syncs changes over Wi-Fi, which is activated only during updates (every hour, or immediately after an edit or screen tap). The system works offline: additions or deletions are stored in flash memory until the next sync.

The firmware handles e-ink display refreshes intelligently: partial updates prevent panel wear, while a full refresh every 10 updates minimizes visual artifacts. Power consumption is optimized with deep sleep mode and automatic shutdown at low battery levels. The frontlight is disabled by default.

Setup and customization

The project is divided into three parts: the firmware (flashed via PlatformIO), the server (Python/FastAPI), and detailed documentation. To get started, you need to configure Wi-Fi credentials and the server URL in the firmware, then run the server locally or via Docker. An optional feature uses Claude Code to automatically sort new items into aisles, though this is not required. Advanced users can adapt the code for other purposes, such as a smart home dashboard or calendar.

This is a personal project by Seamus Cawley, built on reused drivers and components from MonoMesh, another open-source firmware for the same hardware. The server lacks built-in authentication, so it’s recommended to deploy it on a secure local network or behind a reverse proxy.
