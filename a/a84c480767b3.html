PaperMono : une liste de courses e-ink synchronisée entre frigo et smartphone

Un écran e-ink mural affiche et synchronise une liste de courses avec une interface web mobile. Détails techniques et installation.

Lire l'article sur le Palmarès TRMNL →

Le PaperMono transforme l’écran e-ink M5Stack PaperMono (ESP32-S3 avec écran tactile 3,97" 480×800) en liste de courses interactive, affichée sur le frigo et synchronisée avec une application web mobile. Le projet, open source sous licence GPL-3.0, propose un firmware complet en C++ (environ 2 400 lignes) et un serveur FastAPI pour gérer les données.

Fonctionnalités clés

L’écran affiche la liste groupée par rayons, dans l’ordre de passage en magasin. Les éléments peuvent être cochés d’un simple tap, ou ajoutés via un clavier tactile optimisé : seules les zones modifiées sont rafraîchies pour éviter les clignotements. Les suggestions d’articles s’appuient sur un historique partagé entre l’écran et le smartphone. Le serveur stocke les données localement (SQLite) et synchronise les modifications via Wi-Fi, activé uniquement lors des mises à jour (toutes les heures, ou immédiatement après une édition ou un tap sur l’écran). Le système fonctionne hors ligne : les ajouts ou suppressions sont conservés en mémoire flash jusqu’à la prochaine synchronisation.

Le firmware gère intelligemment l’affichage e-ink : les rafraîchissements partiels évitent l’usure du panneau, tandis qu’un rafraîchissement complet toutes les 10 mises à jour limite les artefacts visuels. La consommation énergétique est maîtrisée grâce à un mode veille profond et une extinction automatique en cas de batterie faible. Le rétroéclairage est désactivé par défaut.

Installation et personnalisation

Le projet est structuré en trois parties : le firmware (à flasher via PlatformIO), le serveur (Python/FastAPI) et une documentation détaillée. Pour démarrer, il faut configurer les identifiants Wi-Fi et l’URL du serveur dans le firmware, puis lancer le serveur localement ou via Docker. Une option permet de classer automatiquement les nouveaux articles dans les rayons via une intégration avec Claude Code, bien que cette fonctionnalité soit facultative. Les utilisateurs avancés peuvent adapter le code pour d’autres usages, comme un tableau de bord domotique ou un agenda.

Le projet est un travail personnel de Seamus Cawley, qui s’appuie sur des drivers et composants réutilisés depuis MonoMesh, un autre firmware open source pour le même matériel. Aucune authentification n’est intégrée au serveur : il est recommandé de le déployer sur un réseau local sécurisé ou derrière un proxy inverse.
