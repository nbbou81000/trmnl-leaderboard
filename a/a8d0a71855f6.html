Baochip-1x : un SoC RISC-V ouvert pour applications critiques

Un processeur RISC-V 22 nm conçu pour les applications exigeant une vérification totale, avec documentation et matériel disponibles.

Lire l'article sur le Palmarès TRMNL →

Le Baochip-1x est un système sur puce (SoC) conçu pour les applications où la transparence et la sécurité des transistors sont critiques. Développé avec l’aide de Andrew « Bunnie » Huang, connu pour ses projets open source comme le Precursor, ce SoC s’appuie sur une architecture FPGA déjà éprouvée. Il prend en charge le jeu d’instructions RV32IMAC de RISC-V, permettant d’exécuter des logiciels compatibles, dont un guide de programmation est fourni.

Le Baochip-1x intègre un cœur VexRISC-V monocœur cadencé à 350 MHz, accompagné de 4 Mo de mémoire résistive (RRAM) et de 2 Mo de SRAM. Sa conception met l’accent sur la sécurité, avec des fonctionnalités dédiées intégrées directement dans le silicium. Le projet propose également une version matérielle physique, la carte d’évaluation « Dabao », dont le format rappelle celui d’un Raspberry Pi Pico, facilitant son intégration dans des projets DIY.

Les sources du SoC, rédigées en SystemVerilog et Verilog, sont accessibles pour une vérification complète. Le Baochip-1x cible les développeurs et les passionnés de matériel critique, où chaque composant doit être traçable et auditable. Aucune date de disponibilité ou de prix n’est communiquée dans l’annonce.
