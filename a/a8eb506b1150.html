Installer NetBSD 11 sur un Raspberry Pi 4 : guide pas à pas

Un guide détaillé pour installer NetBSD 11 sur un Raspberry Pi 4, système léger sans IA intégrée.

Lire l'article sur le Palmarès TRMNL →

NetBSD, système d’exploitation open source en développement, se distingue par l’absence de composants liés à l’intelligence artificielle, une particularité rare dans le paysage actuel. Un utilisateur a documenté son expérience pour installer NetBSD 11 sur un Raspberry Pi 4, un projet accessible même aux non-experts.

Préparation de la carte SD

L’image NetBSD 11 pour architecture ARM64 (arm64.img.gz) est téléchargeable depuis le dépôt officiel. Après extraction, elle doit être écrite sur une carte microSD avec l’outil dd sous Linux ou via une interface graphique comme Balena Etcher. La commande suivante copie l’image sur le périphérique /dev/sda (à adapter selon le système) :

sudo dd if=arm64.img of=/dev/sda bs=4M status=progress conv=fsync

Configuration du firmware UEFI

Le firmware UEFI spécifique au Raspberry Pi 4 (version 1.53) doit être copié dans la partition de boot de la carte SD. Après avoir monté cette partition (/dev/sda1), les fichiers du firmware sont transférés pour permettre le démarrage du système. Le Raspberry Pi est ensuite démarré avec la touche ESC pour accéder au menu UEFI, où l’ordre de boot est modifié afin de privilégier la carte SD.

Une fois NetBSD démarré, le système redimensionne automatiquement le système de fichiers racine. La connexion initiale s’effectue avec l’utilisateur root. Il est recommandé de créer un utilisateur standard via useradd et de définir un mot de passe.

La gestion du Wi-Fi nécessite une manipulation supplémentaire : un lien symbolique doit être créé dans /libdata/firmware/if_bwfm pour associer le firmware adapté au modèle du Raspberry Pi 4. Une configuration réseau via wpa_supplicant permet ensuite de se connecter à un point d’accès.

NetBSD propose deux gestionnaires de paquets : pkg_src pour une installation depuis les sources, et pkgin pour des paquets précompilés. L’activation de pkgin passe par la modification du fichier ~/.profile. Des outils comme nano, fastfetch ou doas (alternative à sudo) peuvent être installés pour améliorer l’expérience utilisateur.

Pour une interface graphique, l’environnement NsCDE, inspiré de l’ancien CDE, est compatible avec NetBSD. Son installation nécessite plusieurs dépendances et une configuration manuelle du PATH et des variables d’environnement. Une fois configuré, l’environnement graphique est lancé via xdm.
