Xibalba 64: A New Physical N64 Game in 2026 with Homebrew Engine

A developer releases a brand-new Nintendo 64 game, built from scratch using a custom engine, featuring local co-op and multiplayer modes.

Dominic Szablewski has created Xibalba 64, a first-person shooter (FPS) game rendered in 3D, released as a physical cartridge complete with manual and box art. This is a rare feat: a brand-new game for the Nintendo 64, launched in 1996, rather than a re-release or classic homebrew.

To achieve this, Szablewski used high_impact, his open-source game engine licensed under MIT. Originally designed for 2D games, it was adapted to handle 3D environments by enforcing a strict rule: levels must be completely flat, with no elevation changes. This workaround allows the engine to bypass its architectural limitations, including an extremely limited texture memory (4 KB). Despite these constraints, the game maintains a stable 60 frames-per-second refresh rate, with minor drops only in four-player split-screen mode.

Xibalba 64 includes local co-op for two players and a four-player deathmatch mode. The project showcases how dedicated enthusiasts push retro hardware to its limits, using clever techniques to overcome the N64’s technical constraints. Szablewski details the challenges faced, from level design to music integration and performance optimization.
