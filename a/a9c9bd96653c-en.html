Arduino Library to Calculate Sunrise/Sunset Without Hardware

An open-source Arduino library computes sunrise and sunset times using pure math, no hardware needed.

Read the article on the TRMNL Leaderboard →

Cliff (@clifarr) has released SunLocator, an open-source Arduino library that calculates sunrise, sunset, and twilight times using only geographic and temporal inputs. Unlike typical solutions, it requires no additional hardware, Wi-Fi, or RTC module. The code relies solely on standard Arduino APIs and the math.h library, ensuring compatibility with any microcontroller following the Arduino API.

The user inputs a date, location (latitude/longitude), UTC offset, and solar elevation angle. The library then returns the local time when the sun reaches that angle. For example, official sunrise/sunset times use an angle of -0.833°, accounting for the sun’s apparent diameter and atmospheric refraction. Civil, nautical, and astronomical twilight correspond to different angles. Results are provided as minutes after local midnight or as a structured time format.

Within the polar circles, the library indicates when no crossing occurs. The dayLength() function returns 1440 minutes for midnight sun and 0 for polar night. The UTC offset must be manually adjusted for daylight saving time, as the library does not handle this rule automatically. The algorithm is based on the USNO Almanac for Computers (1990) and has been validated against published data at 15 locations over 5 dates.
