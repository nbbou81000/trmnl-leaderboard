FxTwitter: A Free API to Read X Without an Account or API Key

A free public API lets you fetch public X posts in JSON without an account or paid API key, including videos, translations, and RSS feeds.

FxTwitter, through its public API api.fxtwitter.com, lets users access public X posts in JSON without requiring an account or paid API key. Unlike browsing x.com directly, this tool offers features not available natively: downloading videos in MP4, automatic post translation, and RSS feeds for accounts (up to 100 posts). The API is rate-limited to 1,000 requests per minute per IP address.

To fetch a post, use its ID (e.g., 20 for @jack’s first tweet) in the URL: api.fxtwitter.com/2/status/20. The response is a JSON file containing the post text, author, metrics (likes, reposts, replies), and date. To extract only the text, use a curl command combined with jq (a JSON processing tool): curl -s "https://api.fxtwitter.com/2/status/20" | jq -r '.status.text'.

Automatic translation is available by adding the ?lang=fr parameter to the URL. The API uses X’s translation services (like Grok) or a third-party service if needed. For a full profile, the /2/profile/ endpoint (e.g., api.fxtwitter.com/2/profile/jack) returns the bio, follower count, and registration date.

Downloading videos and creating RSS feeds

Videos can be downloaded directly as MP4 by prefixing the URL with d.fxtwitter.com (e.g., curl -L -o video.mp4 "https://d.fxtwitter.com/NASA/status/2102748685792596449"). The post’s JSON includes different resolutions to select the desired quality.

Each public account has an RSS feed accessible via fxtwitter.com/[username]/feed.xml. The feed displays up to 100 posts by default, with options to filter media (media.xml) or include replies (?with_replies=1).

Limitations and caution

The API relies on real X accounts to distribute requests, a method similar to Nitter’s, which could attract legal action. The source code is available under the MIT license, allowing self-hosting if the service is blocked. Official domains to use are fxtwitter.com, twittpr.com, fixupx.com, xfixup.com, and fxbsky.app for Bluesky. Fraudulent domains (e.g., fxtwiter.com) have already been reported.
