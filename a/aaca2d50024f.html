FxTwitter : une API gratuite pour lire X sans compte ni clé API

Une API publique et gratuite permet d’accéder aux posts publics de X en JSON, sans compte ni clé payante, avec vidéos, traductions et flux RSS.

L’outil FxTwitter, via son API publique api.fxtwitter.com, permet d’accéder aux posts publics de X sans nécessiter de compte ou de clé API payante. Contrairement à la navigation classique sur x.com, cette solution offre des fonctionnalités absentes : récupération des vidéos en MP4, traduction automatique des posts, et génération de flux RSS pour les comptes (jusqu’à 100 posts). L’API est limitée à 1 000 requêtes par minute et par adresse IP.

Pour récupérer un post, il suffit d’utiliser l’identifiant du message (ex. 20 pour le premier tweet de @jack) dans l’URL : api.fxtwitter.com/2/status/20. La réponse est un fichier JSON contenant le texte du post, l’auteur, les métriques (likes, reposts, réponses) et la date. Pour extraire uniquement le texte, une commande curl combinée à jq (un outil de traitement de JSON) permet de filtrer les données : curl -s "https://api.fxtwitter.com/2/status/20" | jq -r '.status.text'.

La traduction automatique est disponible en ajoutant le paramètre ?lang=fr à l’URL. L’API utilise alors les services de traduction de X (comme Grok) ou un service tiers si nécessaire. Pour un profil complet, la route /2/profile/ (ex. api.fxtwitter.com/2/profile/jack) renvoie la bio, le nombre d’abonnés et la date d’inscription.

Récupérer les vidéos et créer des flux RSS

Les vidéos peuvent être téléchargées directement en MP4 en préfixant l’URL avec d.fxtwitter.com (ex. curl -L -o video.mp4 "https://d.fxtwitter.com/NASA/status/2102748685792596449"). Le JSON du post contient les différentes résolutions disponibles pour choisir la qualité souhaitée.

Chaque compte public dispose d’un flux RSS accessible via fxtwitter.com/[nom_utilisateur]/feed.xml. Ce flux affiche jusqu’à 100 posts par défaut, avec des options pour filtrer les médias (media.xml) ou inclure les réponses (?with_replies=1).

Limites et vigilance

L’API repose sur des comptes X réels pour répartir les requêtes, une méthode similaire à celle de Nitter, ce qui pourrait attirer des poursuites similaires. Le code source est disponible sous licence MIT, permettant une auto-hébergement en cas de blocage. Les domaines officiels à utiliser sont fxtwitter.com, twittpr.com, fixupx.com, xfixup.com et fxbsky.app pour Bluesky. Des domaines frauduleux (ex. fxtwiter.com) ont déjà été signalés.
