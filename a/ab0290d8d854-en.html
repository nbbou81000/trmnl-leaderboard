An Open-Source Game Engine for Microcontrollers

An open-source game editor inspired by Godot enables 2D and 3D game development for Arduino Nano ESP32 and STM32F746.

Read the article on the TRMNL Leaderboard →

Creating a game for microcontrollers is no small feat, but Jet Studio, an open-source editor, makes it accessible. Built as a Godot application with a C++ GDExtension, it lets developers design games for boards like the Arduino Nano ESP32 or STM32F746, using common ILI9341 SPI LCD displays.

The tool supports both 2D and 3D games, delivering solid performance: a 2D shooter demo runs at 62 FPS on the Nano ESP32 and 83 FPS on the STM32F746. Demo projects include a partially 3D Outrun-style racer and a 3D physics simulation, showcasing the engine’s versatility for creative projects.

The creator, Fedyfausto, clarifies that Jet Studio’s code is hand-written, with the only LLM assistance used to debug an out-of-memory issue on the STM32 port. The project is available on GitHub, where feedback, bug reports, and pull requests are encouraged.
