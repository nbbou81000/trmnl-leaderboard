Un moteur de jeu open source pour microcontrôleurs

Un éditeur de jeux open source inspiré de Godot permet de créer des jeux 2D et 3D pour Arduino Nano ESP32 et STM32F746.

Lire l'article sur le Palmarès TRMNL →

Développer un jeu pour microcontrôleur n’est pas une tâche triviale, mais Jet Studio, un éditeur open source, simplifie le processus. Conçu comme une application Godot dotée d’une extension C++ (GDExtension), il permet de concevoir des jeux fonctionnant sur des cartes comme l’Arduino Nano ESP32 ou l’STM32F746, en s’appuyant sur des écrans LCD SPI ILI9341, très répandus.

L’outil supporte à la fois les jeux en 2D et en 3D, avec des performances remarquables : un jeu de type shooter 2D atteint 62 FPS sur l’Arduino Nano ESP32 et 83 FPS sur l’STM32F746. Parmi les démonstrations disponibles, on trouve un jeu partiellement 3D dans le style d’Outrun ainsi qu’une simulation physique en 3D. Ces exemples illustrent les capacités du moteur, laissant libre cours à l’imagination des développeurs pour créer leurs propres projets.

L’auteur, Fedyfausto, précise que le code de Jet Studio est entièrement écrit à la main, à l’exception d’un recours ponctuel à un modèle de langage pour déboguer une erreur de mémoire sur la version STM32. Le projet est hébergé sur GitHub, où les retours, les rapports d’anomalies et les contributions sont les bienvenus.
