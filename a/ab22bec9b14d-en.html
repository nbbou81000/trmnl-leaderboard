Why Keep Old USB Drives in a Homelab?

Old USB drives still serve a purpose in a homelab for OS installation, boot drives, or 3D printing file storage.

USB drives, once essential for file transfers, have seen their use decline. Yet, in a homelab, they remain useful for specific tasks. The author explains why they keep old USB drives instead of discarding them.

Ventoy: a practical but limited solution

Ventoy is a tool that turns a USB drive into a multiboot installer for multiple operating systems. Users simply copy ISO files of installers onto the drive and select the desired system at startup. The author used this method for Windows, Ubuntu, and other Linux distributions. However, Ventoy doesn’t work with all installers, such as OPNsense, which required a dedicated USB drive.

Dedicated USB drives for specific uses

Instead of rewriting a USB drive for each installation, the author now prefers dedicated drives for single purposes. For example, an old 16GB USB drive from a trade show was repurposed to install OPNsense. This approach avoids conflicts and simplifies installer management.

Some systems, like Unraid, even require installation on a USB drive. Until version 7.3, Unraid couldn’t be installed on a hard drive or SSD, making USB drives essential for this use case.

A storage solution for 3D printers

In a digital fabrication homelab, USB drives also serve as storage for 3D printing files and timelapses. Modern 3D printers, such as those from Bambu Lab or Elegoo, use USB drives to store print files and timelapse videos, replacing older microSD cards. The author keeps USB drives on hand to equip new printers without buying new ones each time.

While USB drives are no longer ideal for large file transfers, they remain useful for targeted tasks in a technical environment.
