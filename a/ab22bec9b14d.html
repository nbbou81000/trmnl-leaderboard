Pourquoi garder ses anciennes clés USB dans un homelab ?

Les clés USB obsolètes trouvent encore leur utilité dans un homelab pour installer des OS, servir de support de boot ou stocker des fichiers 3D.

Les clés USB, autrefois indispensables pour transférer des fichiers, ont vu leur usage décliner. Pourtant, dans un homelab, elles restent utiles pour des tâches spécifiques. L’auteur explique pourquoi il conserve ses anciennes clés USB plutôt que de les jeter.

Ventoy : une solution pratique, mais limitée

Le logiciel Ventoy permet de transformer une clé USB en multiboot pour installer plusieurs systèmes d’exploitation. Il suffit de copier les fichiers ISO des installateurs sur la clé, puis de sélectionner le système souhaité au démarrage. L’auteur utilisait cette méthode pour ses installateurs Windows, Ubuntu et autres distributions Linux. Cependant, Ventoy ne fonctionne pas avec tous les installateurs, comme OPNsense, qui a nécessité l’utilisation d’une clé dédiée.

Des clés USB dédiées pour des usages précis

Plutôt que de réécrire une clé à chaque installation, l’auteur préfère désormais des clés USB dédiées à un seul système. Par exemple, une ancienne clé de 16 Go, récupérée d’un salon professionnel, a été réutilisée pour installer OPNsense. Cette approche évite les conflits et simplifie la gestion des installateurs.

Certains systèmes, comme Unraid, nécessitent même d’être installés sur une clé USB. Jusqu’à la version 7.3, Unraid ne pouvait pas être installé sur un disque dur ou un SSD, ce qui rend les clés USB indispensables pour ce type d’usage.

Un support pour les imprimantes 3D

Dans un homelab dédié à la fabrication numérique, les clés USB servent aussi de stockage pour les fichiers 3D et les timelapses. Les imprimantes 3D modernes, comme celles de Bambu Lab ou Elegoo, utilisent des clés USB pour stocker les fichiers d’impression et les vidéos de timelapse, remplaçant les anciennes cartes microSD. L’auteur conserve donc des clés USB pour équiper ses nouveaux appareils sans avoir à en acheter de nouvelles à chaque fois.

Si les clés USB ne sont plus adaptées au transfert de fichiers volumineux, elles restent utiles pour des tâches ciblées dans un environnement technique.
