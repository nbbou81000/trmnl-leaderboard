Selectric-256: Encrypted Messaging for Retro and Modern Computers

An ESP32-based device enables end-to-end encrypted messaging between two computers without internet access, even on vintage machines like a PDP-11.

Selectric-256, a project inspired by the fictional Fringe universe, offers a practical way to exchange end-to-end encrypted messages between two computers, whether modern or vintage. Developed by Legionlabs, this device is built around an ESP32 microcontroller and costs around $8 per unit.

The peripheral connects to a host computer via USB or an optional serial interface (using a MAX232 chip for older machines). It handles network communication independently by linking to a public or private MQTT broker, without exposing the host computer to the internet. Messages are encrypted end-to-end using a combination of post-quantum cryptography (ML-KEM) and symmetric encryption (AES-256-GCM).

Each device features two permanent 32-byte identifiers for mutual authentication. After establishing a connection, an ephemeral secret is generated to encrypt messages, while a session counter prevents replay attacks. The protocol does not rely on trusting the MQTT broker, though the current implementation lacks TLS, which slightly limits security.

The firmware, compatible with ESP32S3 SuperMini and ESP32S chips, is programmed via the Arduino IDE. Two Python drivers are provided as examples, and the documentation allows for custom interface development. The project is open source and fully detailed in a comprehensive tutorial.
