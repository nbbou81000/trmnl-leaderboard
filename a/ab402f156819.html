Selectric-256 : messagerie chiffrée pour ordinateurs rétro et modernes

Un périphérique ESP32 permet d'échanger des messages chiffrés entre deux machines sans connexion Internet, même sur des ordinateurs anciens comme un PDP-11.

Inspiré par l’univers fictif de la série Fringe, le projet Selectric-256 propose une solution concrète pour communiquer de manière sécurisée entre deux ordinateurs, qu’ils soient modernes ou vintage. Développé par Legionlabs, ce périphérique repose sur un microcontrôleur ESP32 et coûte environ 8 dollars par unité.

Le dispositif se connecte à un ordinateur hôte via USB ou une interface série (optionnelle, avec un circuit MAX232 pour les machines anciennes). Il gère indépendamment la communication réseau en se connectant à un broker MQTT public ou privé, sans exposer l’ordinateur hôte à Internet. Les échanges sont chiffrés de bout en bout grâce à une combinaison de cryptographie post-quantum (ML-KEM) et de chiffrement symétrique (AES-256-GCM).

Chaque appareil possède deux identifiants permanents de 32 octets pour s’authentifier mutuellement. Une fois la connexion établie, un secret éphémère est généré pour chiffrer les messages, tandis qu’un compteur de session empêche les attaques par rejeu. Le protocole ne dépend pas de la confiance envers le broker MQTT, bien que l’absence de TLS dans l’implémentation actuelle limite partiellement la sécurité.

Le firmware, compatible avec les ESP32S3 SuperMini et ESP32S, est programmé via l’Arduino IDE. Deux exemples de pilotes Python sont fournis pour faciliter l’intégration, et la documentation permet de créer des interfaces personnalisées. Le projet est open source et détaillé dans un tutoriel complet.
