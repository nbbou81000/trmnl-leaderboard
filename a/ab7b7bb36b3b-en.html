Windows 95 Emulated on ESP32-P4 in 155 Seconds

An ESP32-P4 board with a 1280×800 display runs Windows 95 OSR2 from a microSD card, featuring 16 MB RAM and USB peripherals.

A developer named winitboonkliang has ported Chunhui He’s x86 emulator tiny386 to the Guition JC8012P4A1C board, powered by an ESP32-P4 microcontroller. This board features a 1280×800 MIPI-DSI 10.1-inch display, making it suitable for running a retro operating system. The project boots Windows 95 OSR2 from a microSD card while supporting USB keyboard and mouse input.

Performance matches a 386SX at approximately 1.5 MIPS, with a boot time of around 155 seconds to reach the desktop. The emulated system is allocated 16 MB of RAM, preventing paging to the microSD card. Performance analysis shows Windows 95 spends 97% of its time waiting for disk access. Raw sector reads take 0.36 ms, but overall transfer rates are capped at 55 KB/s due to newlib’s unbuffered refill path, which reads data one byte at a time.

Several optimizations were implemented to improve performance. A 2 MB block cache with 4 KB lines reduces disk wait time to 36%. The ESP32-P4’s Pixel Processing Accelerator handles hardware rotation of the display, while a dirty flag skips rendering unchanged frames. Jump tables for opcode decoding were also re-enabled.

The GitHub repository does not include a preinstalled operating system. Detailed measurements and source code are provided for contributors interested in reproducing or enhancing the emulation.
