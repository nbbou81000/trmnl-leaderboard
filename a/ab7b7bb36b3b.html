Windows 95 émulé sur un ESP32-P4 en 155 secondes

Un ESP32-P4 avec écran 1280×800 exécute Windows 95 OSR2 depuis une carte microSD, avec 16 Mo de RAM et des périphériques USB.

Un développeur nommé winitboonkliang a adapté l’émulateur x86 tiny386 de Chunhui He pour fonctionner sur la carte Guition JC8012P4A1C, basée sur un microcontrôleur ESP32-P4. Ce modèle intègre un écran MIPI-DSI 1280×800 de 10,1 pouces, idéal pour afficher un système d’exploitation rétro. Le projet permet de démarrer Windows 95 OSR2 depuis une carte microSD, avec prise en charge d’un clavier et d’une souris USB.

Les performances atteignent celles d’un 386SX, soit environ 1,5 MIPS, avec un temps de chargement d’environ 155 secondes jusqu’au bureau. La mémoire allouée à l’émulation est de 16 Mo, évitant ainsi le recours au paging sur la carte microSD. L’analyse des temps d’exécution révèle que Windows 95 passe 97 % de son temps en attente des accès disque. Les lectures de secteurs brutes prennent 0,36 ms, mais les transferts globaux plafonnent à 55 Ko/s, en raison du chemin de rafraîchissement non bufferisé de newlib, qui lit les données octet par octet.

Plusieurs optimisations ont été apportées pour améliorer les performances. Une mémoire cache de 2 Mo avec des lignes de 4 Ko réduit le temps d’accès disque à 36 %. Le Pixel Processing Accelerator du ESP32-P4 gère la rotation matérielle de l’affichage, tandis qu’un drapeau de saleté évite le rendu des images inchangées. Les tables de saut pour le décodage des opcodes ont également été réactivées.

Le dépôt GitHub ne fournit pas de système d’exploitation préinstallé. Les mesures détaillées et le code source sont disponibles pour les contributeurs souhaitant reproduire ou améliorer l’émulation.
