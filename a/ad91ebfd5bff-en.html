Clotty: DIY Menstrual Cycle Tracker with No Cloud, and DOOM

An open-source menstrual cycle tracker without data collection, designed to be visible and customizable, featuring a color screen and an RP2040 microcontroller.

Read the article on the TRMNL Leaderboard →

Clotty is an open-source device designed to track menstrual cycles while ensuring personal data protection. Unlike most dedicated apps and services, it does not transmit any information to remote servers, sell data, or expose it to leaks or commercial exploitation. Its intentionally ostentatious design—shaped like a uterus with integrated sensors and a color LCD screen—makes it an object that openly embraces its purpose without discretion.

The project is built around an RP2040 microcontroller, a color screen, and various sensors housed on a palm-sized PCB. The "ovaries" feature touch-sensitive areas, and the entire device is designed to be autonomous and portable. While the hardware is functional, the software is still under active development. Advanced features, such as predictive analysis or the user interface, are being implemented. Updates are published on the project’s GitHub repository.

To validate the hardware’s capabilities, Clotty can run DOOM, a software proof of concept that demonstrates its ability to handle resource-intensive applications. The source code for this adapted version is available in a dedicated fork of the RP2040-DOOM project. The creator, [kati], emphasizes a playful and engaging design, drawing inspiration from Tamagotchi-style interaction to make the tool more accessible. Other projects, like a slightly sentient 20-sided die, showcase this creative approach.

The project is still in the prototyping phase, but its radical approach to privacy and its bold aesthetics make it a notable alternative to proprietary solutions.
