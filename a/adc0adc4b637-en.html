ESP32 4-Channel PWM Fan Controller for Servers and NAS Systems

An open-source ESP32-based controller compatible with Home Assistant manages up to four PWM fans with temperature monitoring and mmWave presence detection.

The ESP32 4-channel PWM fan controller, developed by CoolMaker Lab in China, is an open-source board compatible with Home Assistant designed for thermal management in servers, NAS units, network cabinets, and DIY enclosures. It independently controls up to four 4-pin PWM fans, allowing speed adjustment, RPM monitoring via tachometer, and individual power switching.

The board supports up to four external DS18B20 temperature sensors for automatic fan speed adjustment, along with a web interface, HTTP REST API, and Bluetooth proxy functionality. The v2.0 hardware and firmware add support for the LD2402G 24GHz mmWave radar for presence-based automation.

Key specifications include:

  • MCU: ESP32-WROOM-32-N4 module with 4MB flash, 2.4GHz Wi-Fi, and Bluetooth LE
  • Fan control: 4x independent 4-pin PWM connectors with 1–100% speed adjustment, 4x tachometer inputs for RPM monitoring
  • Power switching: TPS22810DBVR load switches for complete shutdown (zero-RPM operation)
  • Temperature sensing: 3-pin connector for up to 4x external DS18B20 1-wire sensors
  • Expansion: 4-pin header (5V, GND, GPIO4, GPIO5), UART support for LD2402G radar
  • Power: 12V DC input via barrel jack, TPS5430DDAR buck converter (12V→5V), AMS1117-3.3 regulator (5V→3.3V)

The controller runs ESPHome for seamless Home Assistant integration, enabling centralized fan control, automations, and OTA updates. A built-in web interface and REST API are also available for direct management. The v2.0 firmware allows assigning a temperature sensor to each fan, with adjustable thresholds (default: off at 30°C, max speed at 50°C). The project is fully open source, with PCB files, precompiled firmware, documentation, and enclosure STEP files available on GitHub (Chinese and English).

Available on Tindie for $28 (excluding shipping), the board ships from China with shipping starting at $5. A commercial alternative (ARCTIC Fan Controller) exists but is limited to PCs/servers, lacking wireless connectivity and Home Assistant compatibility.
