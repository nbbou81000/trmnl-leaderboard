Contrôleur de ventilateurs PWM 4 canaux ESP32 pour serveurs et NAS

Un contrôleur open source compatible Home Assistant gère jusqu’à quatre ventilateurs PWM avec surveillance de température et détection de présence mmWave.

Le ESP32 4-channel PWM fan controller, conçu par CoolMaker Lab en Chine, est une carte open source compatible Home Assistant dédiée à la gestion thermique des serveurs, NAS, baies réseau ou autres boîtiers DIY. Elle permet de contrôler indépendamment jusqu’à quatre ventilateurs 4 broches PWM, avec ajustement de vitesse, surveillance du régime via tachymètre et coupure individuelle de l’alimentation.

La carte prend en charge jusqu’à quatre capteurs de température externes DS18B20 pour ajuster automatiquement la vitesse des ventilateurs, ainsi qu’une interface web, une API REST HTTP et une fonction de proxy Bluetooth. La version 2.0 du matériel et du firmware ajoute la compatibilité avec un capteur mmWave LD2402G (24 GHz) pour des automatisations basées sur la présence.

Spécifications techniques :

  • Microcontrôleur : ESP32-WROOM-32-N4 (4 Mo de flash, Wi-Fi 2,4 GHz, Bluetooth LE)
  • Contrôle des ventilateurs : 4 connecteurs PWM 4 broches avec ajustement de 1 à 100 %, 4 entrées tachymètre pour le suivi du régime
  • Alimentation des ventilateurs : interrupteurs TPS22810DBVR pour une coupure complète (mode silencieux)
  • Température : connecteur 3 broches pour jusqu’à 4 capteurs DS18B20 (1-wire)
  • Extensions : en-tête 4 broches (5V, GND, GPIO4, GPIO5), support UART pour le capteur LD2402G
  • Alimentation : entrée 12V DC (barrel jack), convertisseur buck TPS5430DDAR (12V→5V), régulateur AMS1117-3.3 (5V→3.3V)

Le contrôleur fonctionne avec ESPHome pour une intégration native à Home Assistant, offrant une gestion centralisée des ventilateurs, des automatisations et des mises à jour OTA. Une interface web et une API REST sont également disponibles pour un contrôle direct. La version 2.0 permet d’assigner un capteur de température par ventilateur, avec des seuils ajustables (par défaut : arrêt à 30°C, vitesse maximale à 50°C). Le projet est entièrement open source, avec fichiers PCB, firmware précompilé, documentation et fichiers d’enclosure disponibles sur GitHub (bilingue chinois/anglais).

Disponible sur Tindie au prix de 28 $ (hors frais de port), la carte est expédiée depuis la Chine avec des frais de livraison à partir de 5 $. Une alternative commerciale existe (ARCTIC Fan Controller), mais elle se limite aux PC/serveurs, sans connectivité sans fil ni compatibilité Home Assistant.
