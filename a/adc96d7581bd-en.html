Two ESP32s Communicate Using a Single LED

A developer leverages LED/photodiode duality to enable two ESP32s to communicate using a single visible LED.

A developer has created an unconventional method for two ESP32 microcontrollers to communicate using a single visible LED. The project, named SecurePair, relies on an Arduino library that handles both cryptographic key exchange and encrypted data transmission. The technique exploits a lesser-known property of LEDs: their ability to function as photodiodes.

The system establishes a secure link between devices, with the LED alternately serving as a transmitter and receiver. While the examples use two ESP32s, the library supports multiple devices simultaneously. In practice, the visible LED is primarily used for initial pairing, while encrypted data transmission can proceed via wireless protocols like ESPNow or LoRa. This hybrid approach combines hardware simplicity with enhanced security.

Comments highlight earlier projects using bidirectional LEDs, such as a rudimentary touchscreen made from an 8x8 LED grid rapidly switching between emission and reception modes. An academic reference from 2003 also details this technique, underscoring its enduring potential. A demonstration video showcases the system in action.
