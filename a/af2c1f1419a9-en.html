Control an ESP32 Light with Matter and Voice Assistants

Turn an ESP32 into a Matter-compatible smart switch compatible with Alexa, Google Home, and Apple Home via Arduino IDE.

This tutorial shows how to build a Matter-compatible on/off light device using an ESP32 programmed with the Arduino IDE. The project allows controlling a GPIO pin via a physical switch or voice assistant, while maintaining the light state after a reboot and supporting full factory reset.

The Matter protocol, developed by the Connectivity Standards Alliance (CSA) with major players like Apple, Google, and Amazon, aims to standardize interactions between smart home devices. It ensures interoperability across ecosystems (Apple Home, Google Home, Amazon Alexa, Home Assistant, etc.), secure local communication, and easy setup using a QR code or manual pairing code.

Before starting, you need the ESP32 Arduino Core version 3.1.0 or later, which includes the Matter library by default. The guide explains key concepts: node (a single Matter device), endpoint (a function like a switch), cluster (a group of attributes and commands, e.g., the On/Off cluster), and fabric (the logical network created when pairing with a controller).

The provided Arduino sketch turns the ESP32 into a Matter On/Off Light node, controlling a GPIO pin. The switch state is saved in non-volatile memory to persist after a reboot. The code also handles a physical button (default BOOT button) to manually toggle the light. Compatible ESP32 chips include those supporting CHIPoBLE (Bluetooth Low Energy for Wi-Fi credential transfer), while others require manual entry of credentials in the sketch.
