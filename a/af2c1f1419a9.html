Contrôler une lumière ESP32 avec Matter et les assistants vocaux

Transformez un ESP32 en interrupteur connecté Matter compatible avec Alexa, Google Home et Apple Home via Arduino IDE.

Lire l'article sur le Palmarès TRMNL →

Ce tutoriel explique comment concevoir un dispositif d’éclairage compatible Matter à partir d’un ESP32 programmé avec l’Arduino IDE. Le projet permet de contrôler une broche GPIO via un interrupteur physique ou un assistant vocal, tout en assurant la persistance de l’état de la lumière après un redémarrage et la possibilité de réinitialisation complète.

Le protocole Matter, développé par la Connectivity Standards Alliance (CSA) avec des acteurs majeurs comme Apple, Google et Amazon, vise à uniformiser les interactions entre appareils connectés. Il garantit l’interopérabilité entre différents écosystèmes (Apple Home, Google Home, Amazon Alexa, Home Assistant, etc.), une communication locale sécurisée et chiffrée, ainsi qu’une configuration simplifiée via un code QR ou un code manuel.

Avant de commencer, il faut disposer de l’ESP32 Arduino Core version 3.1.0 ou ultérieure, qui intègre nativement la bibliothèque Matter. Le guide détaille les concepts clés : nœud (un appareil Matter unique), point de terminaison (fonctionnalité comme un interrupteur), cluster (groupe d’attributs et commandes, par exemple le cluster On/Off) et fabric (réseau logique créé lors de l’appairage avec un contrôleur).

Le sketch Arduino fourni transforme l’ESP32 en un nœud Matter On/Off Light, contrôlant une broche GPIO. L’état de l’interrupteur est sauvegardé dans la mémoire non volatile pour persister après un redémarrage. Le code gère aussi un bouton physique (par défaut le bouton BOOT) pour basculer manuellement l’état de la lumière. Les puces ESP32 compatibles Matter incluent les modèles supportant le CHIPoBLE (Bluetooth Low Energy pour la transmission des identifiants Wi-Fi), tandis que les autres nécessitent une saisie manuelle des identifiants dans le sketch.
