The Motorola T900 Pager Gets a Modern Revival with Wireless Tech

A maker revives the Motorola T900 pager by replacing its internals with an ESP32-S3, adding Meshtastic, Bluetooth, and Wi-Fi for modern messaging.

The Motorola T900, a QWERTY keyboard pager released in 2000, is being revived with modern internals. The project aims to preserve the original enclosure, keyboard, and LCD while replacing the outdated electronics. Reverse engineering was required to control the keyboard and display, as documentation for the T900’s internals was scarce.

The current prototype uses a Heltec V4 development board with an ESP32-S3 microcontroller, providing processing power and wireless connectivity. The project already integrates Meshtastic, an open-source platform for long-range, decentralized messaging over LoRa networks, operated via the original keyboard and display. Additional features in development include Bluetooth connectivity to an Android smartphone for SMS messaging, and a Wi-Fi-based messaging system between compatible devices. A dedicated messaging service with unique identification numbers, direct messages, channels, and acknowledgements is also planned, switching between Wi-Fi and LoRa based on availability.

Future additions include classic games like Snake, a Tamagotchi-style virtual pet, wireless configuration and updates, and the restoration of the original electroluminescent backlighting. Vibration alerts, classic pager tones, and a rechargeable lithium battery are also on the roadmap. The developer intends to eventually produce a custom replacement PCB that fits inside the original T900 enclosure, allowing other enthusiasts to perform the same conversion.
