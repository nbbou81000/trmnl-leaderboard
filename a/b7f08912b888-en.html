DIY CO2 Monitor with E-Ink Display and ESP32 for Home Assistant

An open-source ESP32-based CO2, temperature and humidity sensor with an e-ink display, Home Assistant-compatible and designed for multi-year battery life.

Read the article on the TRMNL Leaderboard →

Shared on Reddit by MrNiceThings, this open-source project turns an ESP32 microcontroller (ESP-WROOM-32 model), a 4.2-inch e-paper display, and sensors into a CO2, temperature, and humidity monitor. The device wakes up at intervals, takes measurements, updates the screen, and returns to deep sleep, ensuring multi-year battery life.

It integrates with Home Assistant or any MQTT-compatible system, but can also operate offline as a standalone display. The project’s code and documentation are available on GitHub, enabling quick replication. While a 3D-printed enclosure is in the works, users can already build their own casing using the provided guidelines.
