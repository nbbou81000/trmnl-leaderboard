Arduino Unveils Kit to Build Custom Physical Interfaces with UNO Q

Arduino's new kit lets you build physical interfaces (buttons, knobs) to control a Linux system running on the UNO Q board.

Read the article on the TRMNL Leaderboard →

Arduino has launched the UNO Q SBC Controller Bundle, a kit designed to build custom physical interfaces for its UNO Q 4GB board, a dual-processor device capable of running Linux. The kit targets makers and developers looking to replace traditional input devices (keyboard, mouse) with tactile controls such as buttons, a knob, a joystick, or pixels for dynamic visual feedback.

The bundle includes Modulino nodes (buttons, joystick, knob, pixels) compatible with the Arduino App Lab development environment. A 3D-printable enclosure is provided to give the project a polished, product-like appearance. Detailed tutorials are available on Arduino Project Hub to guide assembly and configuration.

The UNO Q can serve as a Linux workstation for various applications, including managing Home Assistant dashboards, running retro games, or controlling embedded AI routines. The Modulino ecosystem’s modular design allows users to add or replace components as projects evolve. Optional accessories like an 8-in-1 USB-C hub (HDMI, Ethernet, additional USB ports), a 45W USB-C power supply, and a 24-pin USB-C cable are also available to enhance the setup.
