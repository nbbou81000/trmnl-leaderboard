A WiFi 7 Router Turned into a Wideband Software-Defined Receiver

A developer repurposed a Gemtek Wi-Fi 7 router into a wideband SDR receiver capturing signals up to 320 Msps.

Read the article on the TRMNL Leaderboard →

The w1700k-sdr project, published on GitHub by developer h0m3us3r, repurposes a Gemtek W1700K Wi-Fi 7 router (HW 1.x or W1700K2 HW 2.1) into a wideband software-defined receiver (SDR). The system leverages the MediaTek MT7996 radio chip, which captures raw 14-bit IQ data at up to 320 Msps.

Signal processing is handled by the Airoha AN7581 SoC, which streams data over a 10 GbE link to a Linux host. The host runs a web interface displaying a live spectrum and waterfall (spectral density graph), along with receiver controls. The MT7996 firmware is entirely built from the GitHub repository, without proprietary MediaTek code: it includes a ROM patch, WM and WA modules, and initialization decoded from a trace of MediaTek’s original firmware.

Upon power-up, the router boots directly and accepts host commands to adjust the local oscillator (LO), sample rate, capture settings, streaming, gain, and filters. Tests show full capture of the 2.4 GHz band at 320 Msps, with a 262,144-point FFT analyzed at 100 spectra per second. The streaming throughput reaches 9.75 Gbit/s. Required hardware includes a 3.3 V USB serial adapter for installation and a 10 GbE NIC on the host.
