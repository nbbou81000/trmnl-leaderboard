Control a Raspberry Pi Pico Over SSH with an Embedded Server

An embedded SSH server on an RP2040 enables controlling a Pico over Ethernet, even for basic tasks.

The SSH (Secure Shell) protocol, introduced in 1995, remains a reliable solution for remote machine administration. Ricardo Marques took this concept further by adapting it to an RP2040 microcontroller, the core of the Raspberry Pi Pico. This affordable and powerful component is found in many development boards. To add network connectivity, the author used a WIZnet W5500-EVB-Pico board, which includes a TCP/IP controller and an RJ45 Ethernet port. An alternative is to pair a Pico (or any RP2040 board) with a separate W5500 module.

The project relies on a custom firmware developed with PlatformIO, combining Arduino-Pico Ethernet drivers and modules for TCP/IP and SSH. Installation begins by cloning a GitHub repository, then configuring a static IP address or using default settings. A critical step involves generating security keys. After compiling and uploading the firmware to the RP2040, simply connect the board via Ethernet and SSH into it from a computer on the same network using the default account « sshrp ». Once connected, the user can turn the onboard LED on or off, make it blink, or check its status.

While this demonstration is limited to basic commands, it proves the feasibility of remote control via Ethernet on a microcontroller. This method can be extended to other connected peripherals, offering an alternative to serial, Bluetooth, or Wi-Fi solutions depending on the use case.
