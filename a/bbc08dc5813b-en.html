ESP32 and SHT41 Sensor: Measuring Temperature and Humidity

Learn how to connect an SHT41 sensor to an ESP32 via I2C to measure temperature and humidity accurately.

The SHT41 is a 4th-generation temperature and humidity sensor from Sensirion, offering high accuracy (±0.2°C for temperature and ±1.8% RH for humidity) and low power consumption (0.4 µA on average). It is well-suited for projects requiring reliable measurements while minimizing energy use. The sensor communicates via I2C, making it easy to interface with microcontrollers like the ESP32.

Three versions of the sensor are available: SHT40, SHT41, and SHT45. The main difference lies in accuracy, with the SHT45 providing the highest precision. All three share the same pinout and I2C interface, allowing for easy interchangeability. The sensor can be used on a development board or a breakout module, often featuring STEMMA QT/Qwiic connectors for simplified connections to other I2C modules.

To interface it with an ESP32, simply connect the power pins (VIN and 3Vo) and the I2C pins (SCL and SDA) to the corresponding ESP32 pins. The I2C pin configuration may vary depending on the ESP32 model. Once wired, libraries like Adafruit SHT4x can be used to easily retrieve temperature and humidity data. This library supports all three sensor versions and offers precision options (high, medium, or low) as well as control over the built-in heater to prevent condensation in humid environments.

The sensor also includes an adjustable internal heater with three levels, useful for maintaining performance in extreme conditions. Its use with the ESP32 is documented through simple code examples available in the Adafruit or Sensirion libraries.
