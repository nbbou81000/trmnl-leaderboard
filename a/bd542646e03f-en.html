Running Linux on an RTX Spark Laptop Without a Microsoft Account

A developer successfully runs Arch Linux on an ASUS ProArt P16 with 6,144 CUDA cores, bypassing official Windows-only support.

Read the article on the TRMNL Leaderboard →

Josephine Pfeiffer, an Arch Linux package maintainer, documented on her blog josie.lol how she installed Arch Linux ARM on an ASUS ProArt P16 H7607BA-SE033W (128 GB model). Designed for Windows, this laptop lacks official Linux support. The project involved multiple technical fixes: correcting ACPI (Advanced Configuration and Power Interface) allocations for the framebuffer, deriving ACPI overrides from the laptop’s own tables, patching the hid-asus driver for the keyboard, and writing a machine driver for audio.

The outcome includes a bootable USB and an extended version of Archinstall 4.5 to automate the installation. In ARM64 mode, 7-Zip (20 threads) outperforms published Windows results by 5 % in compression. Memory management stands out: Linux reports 116.0 GiB as both system RAM and total CUDA memory from a single pool, with no reservation slider or reboot between workloads. A test with vLLM and NVIDIA’s Qwen3.8-Flash-Next-FP4 model allocated nearly 90 GiB to the model and its KV cache, handling 150 requests over ten minutes without errors.
