Linux sur un PC portable RTX Spark sans compte Microsoft

Une développeuse porte Arch Linux sur un ASUS ProArt P16 équipé de 6 144 cœurs CUDA, sans support officiel.

Lire l'article sur le Palmarès TRMNL →

Josephine Pfeiffer, mainteneuse de paquets pour Arch Linux, a partagé sur son blog josie.lol son expérience d’installation d’Arch Linux ARM sur un ASUS ProArt P16 H7607BA-SE033W (configuration 128 Go). Ce portable, conçu pour Windows, n’offre aucun support officiel pour Linux. La tâche a nécessité plusieurs ajustements techniques : correction des allocations ACPI (Advanced Configuration and Power Interface) pour le framebuffer, dérivation des overrides ACPI depuis les tables du matériel, patch du pilote hid-asus pour le clavier, et création d’un pilote machine dédié au son.

Le résultat inclut un USB bootable et une version étendue de l’outil Archinstall 4.5 pour automatiser l’installation. Les performances en ARM64 avec 7-Zip (20 threads) dépassent de 5 % celles publiées sous Windows pour la compression. La gestion mémoire est particulièrement notable : Linux détecte 116,0 GiB comme RAM système et mémoire CUDA combinées, sans réservation ni redémarrage entre les charges de travail. Un test avec vLLM et le modèle NVIDIA Qwen3.8-Flash-Next-FP4 a alloué près de 90 GiB au modèle et à son cache KV, tout en traitant 150 requêtes en dix minutes sans erreur.

Les détails techniques et les liens vers les dépôts GitHub sont disponibles sur josie.lol.
