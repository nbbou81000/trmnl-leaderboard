Retro OS Rebuilt in HTML/CSS/JS for Ultra-Fast Browser Use

Eight historical operating systems rebuilt in web code, executable in under two seconds in a browser.

Read the article on the TRMNL Leaderboard →

Developer Wiesław Šoltés has released on GitHub eight reconstructions of old operating systems, entirely rewritten in HTML, CSS, and JavaScript. These versions load in under two seconds and include Windows 3.1, 95, 98, Me, 2000, XP, Vista, and Mac OS 9, complete with functional applications and interfaces faithful to the originals.

Each system offers a varying number of built-in apps: 28 for Windows 3.1, 56 for XP, and 60 for Me, covering tools like Notepad, File Explorer, or games like Minesweeper. The interfaces adhere to the original menus and groups, and apps share a common virtual disk, enabling consistent file management across tools. For example, a document created in Notepad appears in File Explorer and the MS-DOS command prompt, with support for commands like DIR or TYPE.

Performance-wise, these reconstructions are lightweight: Windows 95 weighs 183 KB, Mac OS 9 180 KB, while XP and Vista reach 4.5 MB and 2.5 MB respectively. Graphics rendering relies on the GPU via WebGPU, WebGL2, or Canvas 2D depending on compatibility, while idle desktops avoid unnecessary recalculations. No emulation is used: each window and menu is a standard HTML element, explaining the fast loading times.

The project also includes VB6 Studio Web, a functional Visual Basic 6 IDE running in the browser. This tool allows designing forms, debugging step-by-step, and compiling projects into standalone HTML pages or native Windows executables (PE32 format). Existing projects (.vbp, .vbg) can be imported, and an AI-assisted coding agent (OpenAI, Anthropic, Gemini) is integrated to automate tasks. A sample calculator compiled into HTML weighs 1.9 MB, while a PE32 executable generated directly from the browser reaches 34 KB.

These reconstructions are not emulators: they replicate the look and behavior of original OSes but do not run old binary code. They are ideal for discovering these systems, drawing inspiration from their design, or developing custom web interfaces. To run original software from the era, users would need solutions like v86, Infinite Mac, or RetroTick.
