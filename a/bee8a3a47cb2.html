Des OS rétro recodés en HTML/CSS/JS pour navigateur ultra-rapide

Huit systèmes d’exploitation historiques recréés en code web, exécutables en moins de deux secondes dans un navigateur.

Lire l'article sur le Palmarès TRMNL →

Le développeur Wiesław Šoltés a publié sur GitHub huit reconstitutions d’anciens systèmes d’exploitation, entièrement réécrites en HTML, CSS et JavaScript. Ces versions, chargées en moins de deux secondes, incluent Windows 3.1, 95, 98, Me, 2000, XP, Vista et Mac OS 9, avec des applications fonctionnelles et des interfaces fidèles aux originaux.

Chaque système propose un nombre variable d’applications intégrées : 28 pour Windows 3.1, 56 pour XP et 60 pour Me, couvrant des outils comme le Bloc-notes, l’Explorateur de fichiers ou des jeux comme le Démineur. Les interfaces respectent les menus et groupes d’origine, et les applications partagent un disque virtuel commun, permettant une gestion cohérente des fichiers entre les outils. Par exemple, un document créé dans le Bloc-notes apparaît dans l’Explorateur et l’invite de commandes MS-DOS, avec prise en charge des commandes comme DIR ou TYPE.

Côté performances, ces reconstitutions sont légères : Windows 95 pèse 183 Ko, Mac OS 9 180 Ko, et XP ou Vista atteignent respectivement 4,5 Mo et 2,5 Mo. Les rendus graphiques s’appuient sur le GPU via WebGPU, WebGL2 ou Canvas 2D selon la compatibilité, tandis que les bureaux au repos ne déclenchent aucun recalcul inutile. Aucune émulation n’est utilisée : chaque fenêtre et menu est un élément HTML standard, ce qui explique la rapidité de chargement.

Le projet inclut également VB6 Studio Web, un IDE Visual Basic 6 fonctionnel dans le navigateur. Cet outil permet de concevoir des formulaires, déboguer du code pas à pas et compiler des projets en pages HTML autonomes ou en exécutables Windows natifs (format PE32). Les projets existants (.vbp, .vbg) peuvent être importés, et un agent de code assisté par IA (OpenAI, Anthropic, Gemini) est intégré pour automatiser certaines tâches. Un exemple, une calculatrice compilée en HTML, pèse 1,9 Mo, tandis qu’un exécutable PE32 généré directement depuis le navigateur atteint 34 Ko.

Ces reconstitutions ne sont pas des émulateurs : elles reproduisent l’apparence et le comportement des OS d’origine, mais sans exécuter de code binaire ancien. Elles sont idéales pour découvrir ces systèmes, s’inspirer de leur design ou développer des interfaces web personnalisées. Pour faire tourner des logiciels d’époque, il faudra se tourner vers des solutions comme v86, Infinite Mac ou RetroTick.
