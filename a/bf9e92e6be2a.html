Un talkie-walkie vocal pour dialoguer avec Claude Code en déplacement

Un projet DIY transforme un smartphone en interface vocale pour interagir avec Claude Code sans utiliser les mains, idéal pour les déplacements.

Lire l'article sur le Palmarès TRMNL →

Un développeur, Bookmari, a conçu Walkie Claudie pour répondre à un besoin pratique : utiliser Claude Code lors de déplacements professionnels, notamment en tant que chauffeur-livreur. L’interface permet d’échanger vocalement avec l’assistant IA, évitant ainsi de manipuler un clavier ou un écran en conduisant.

Le système repose sur un smartphone connecté directement au PC exécutant Claude Code, avec la possibilité d’utiliser un VPN pour les connexions à distance. Une fonction push-to-talk est intégrée via un bouton sur des écouteurs Bluetooth, simplifiant l’activation de la reconnaissance vocale. Un mode spécial maintient le canal actif pendant les pauses prolongées, facilitant la formulation des requêtes. L’interface arbore un style rétro inspiré des talkies-walkies, avec des effets sonores comme un bruit de squelch (silencieux) ou des bruits de changement de canal pour renforcer l’immersion.

Le projet est open source et conçu pour ceux qui souhaitent rester connectés à leur assistant IA en permanence, même en déplacement. Cependant, le commentaire d’un lecteur rappelle les risques liés à l’utilisation d’un tel système en conduisant.
