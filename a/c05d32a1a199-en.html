DIY System to Automatically Measure Parcels Before Shipping

An electronic setup measures a parcel’s weight, length, width and height, then sends the data to a web interface for shipping quotes.

Shipping a package often means hunting for a misplaced tape measure, converting fractions to decimals, and weighing the object. To automate these steps, a DIY project introduces a system that instantly calculates a parcel’s dimensions and weight as soon as it is placed on the platform.

The setup combines four key components: a UNIHIKER K10 as the central unit, a DFRobot 8×8 Matrix ToF (Time-of-Flight) sensor to measure distances, a DFRobot Gravity HX711-based weight sensor kit, and a DFRobot Gravity I2C Hub to aggregate data. The weight sensor acts as a scale, while the ToF module scans the box’s contours in 3D.

The height is calculated by subtracting the distance to the top of the box from the distance to the platform. For width and length, the system uses trigonometry: it combines the distance to the top of the box with the angle of detected edges to derive linear dimensions. The UNIHIKER K10 then displays a grid on its screen, visualizing the boundaries of the scanned parcel.

In the demo, the K10 sends measurements over a serial connection to a computer, which displays them on a custom web page. This interface can also fetch real-time shipping quotes if the carrier provides an API. Otherwise, values can be entered manually or linked via a script to the carrier’s interface for automated data transfer.
