LEGO Technic Drawing Machine: No Code, No Electronics, Just Bricks

A motorized LEGO Technic drawing machine creates spirograph-like patterns using pure mechanics, no code or electronics required.

A new LEGO Technic project demonstrates how to build a drawing machine using only mechanical parts, no electronics or code required. Shared by Brick Trials on YouTube, the device relies on a single motor, a worm gear, and a crank to drive a pen arm and a rotating turntable.

The key mechanism involves two slightly out-of-sync movements: the turntable spins the paper while the crank swings the pen arm. This gradual phase shift causes each stroke to land a few degrees further around the paper, slowly forming a dense spirograph-like flower pattern in about three minutes. The result mimics classic spirograph drawings but is powered entirely by LEGO mechanics.

The build uses standard LEGO Technic bricks, with no added electronics or microcontrollers. The 4K video on YouTube walks through the assembly process with authentic LEGO brick sounds, followed by the machine in action, drawing intricate geometric patterns.
