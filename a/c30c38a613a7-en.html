A Tiny World Model Running Games on a Raspberry Pi Pico 2 W

A tiny world model based on transformers generates and plays games in real time on a microcontroller.

An open-source project, Tiny World Model, uses two small neural networks to generate and play games in real time on a Raspberry Pi Pico 2 W. The first network predicts the next game state from the current frame and an action, while the second selects actions based on the generated frame. Both networks run in parallel on the same microcontroller, never accessing the real game: the world model only sees the agent’s actions, and the agent only perceives frames produced by the model.

The games, such as Pac-Man, Breakout, or Doom-lite, are implemented in a few hundred lines of Python code using NumPy. Each frame is represented as a grid of tokens, where hidden game states (like a ball’s direction or a minimap) are embedded directly into the token structure. The model employs a single transformer block (attention + ReLU MLP) with weights reused in a loop, reducing memory usage. The number of iterations in the loop affects accuracy and execution speed: two iterations are used on the Pico 2 W to maintain a decent frame rate.

The project includes a reinforcement learning (RL) agent capable of learning directly on the board by generating its own training data from the model’s output frames. The pre-trained agent can be swapped for a fresh version that learns from scratch, and a button allows manual control of the generated game. The model’s weights, quantized to int8, are embedded directly into the Rust firmware for optimized execution on the microcontroller.
