DIY Game Boy with ESP32 and a Spare LCD Screen

An open-source project turns an unused LCD screen into a portable retro console using an ESP32 microcontroller.

Read the article on the TRMNL Leaderboard →

A spare LCD screen can become much more than just a leftover component. That’s what Engineeroids, an electronics enthusiast, proved by repurposing a 160×128 pixel ST7735 LCD into a retro gaming console powered by an ESP32 DevKit V1 microcontroller. Originally planned as a music controller, the project evolved into a functional Game Boy emulator capable of running titles like Pokémon, The Legend of Zelda, Tetris, and Contra.

The setup relies on simple and accessible components: an analog joystick and two push buttons provide controls, while everything is assembled on a 7×9 cm perfboard. The lack of an enclosure exposes the circuits but simplifies construction. Power is supplied via USB, with no built-in battery, which limits portability but avoids complex power management.

On the software side, the Peanut-GB emulator, written in C99, runs Game Boy games. The firmware, developed in C using the Arduino framework, loads a single game directly into the ESP32’s flash memory. This approach avoids compatibility issues with SD cards, where larger games fail to load. A save function is currently being experimented with, along with a custom splash screen to enhance the user experience.

The project remains a work in progress, but already offers a low-cost and quick-to-build alternative for retro gaming enthusiasts.
