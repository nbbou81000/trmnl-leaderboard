Old Chumby One Revived as Static Internet Radio

A 2009 Chumby One, with its slow ARM9 processor and limited memory, is repurposed as a Static Radio internet radio using a custom C client.

Read the article on the TRMNL Leaderboard →

Static Radio, an online radio station broadcasting podcasts, inspired [Brendan Fitzpatrick] to repurpose a 2009 Chumby One into a dedicated internet radio. This device, powered by a 454 MHz ARM9 processor and just 64 MB of RAM, runs Linux 2.6.28—a long-obsolete system. Despite these hardware limitations, he managed to install a native C client to stream Static Radio without altering the original firmware.

To bypass the Chumby’s outdated software constraints, [Brendan] integrated mbedTLS to replace the ancient OpenSSL 0.9.7 (from 2004), deemed inadequate for modern connections. The client also leverages a fixed-point Helix MP3 decoder, along with tools to handle HE-AAC audio streams and a polyphase resampler. The audio output is routed to the Chumby’s ALSA PCM device for smooth playback. A standout feature preloads the two neighboring stations, ensuring seamless crossfading when switching channels.

This project highlights how an old device, originally tied to defunct online services, can be revived through software optimizations. The client boots from a USB stick without modifying the original installation, making it a non-invasive solution for unused Chumby One units.
