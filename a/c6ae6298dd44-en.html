Paperboy: Game Boy Emulation at 60 FPS on ESP32 e-Ink Screens

An ESP-IDF firmware enables Game Boy emulation on M5Stack e-ink screens, delivering 60 FPS and sound support.

Developer hpsaturn has ported Paperboy, an e-ink driver originally created by Wenting Zhang, to older hardware. This ESP-IDF firmware directly drives e-ink panels at the row and column level, achieving up to 60 frames per second without requiring a full screen refresh. Paperboy was initially designed to run original Game Boy games on M5Stack devices equipped with e-ink screens.

The emulation relies on the CrankBoy core (based on peanut_gb), which executes game logic at the full DMG Game Boy speed. Each frame is rendered directly onto the e-paper panel, while the screen refresh follows the physical constraints of e-ink technology. The project also includes sound support, touch controls, an on-device ROM picker, and persistent save states. Originally, Paperboy ran on an M5Paper ESP32-S3. The migrated version now operates on an M5Paper v1.1, which uses a standard ESP32 chip.

The source code is available on GitLab, and the project is also shared via an X (formerly Twitter) post.
