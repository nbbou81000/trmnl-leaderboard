DIY Retro Console That Reads CDs Like the Good Old Days

An enthusiast built a retro console that reads CDs, featuring custom wireless controllers and meticulous aesthetics.

A maker named Emmet has built a retro gaming console that runs exclusively on CDs, the optical discs from the 1990s. Unlike modern consoles that rely on downloads, this machine embraces nostalgia and the accessibility of physical media. It uses an Intel N150 single-board computer, a modest choice that limits raw power but allows it to run emulators through Batocera, a Linux distribution designed for retro gaming.

For controls, Emmet designed custom wireless controllers using ESP32-S3 modules, which offer more processing power than some of the retro systems they emulate. Unlike other projects that simply load games from a USB drive, this console reads ROM files directly from CDs, paired with a script to automatically add them to the emulator libraries. The system even handles autorun for titles, though the creator opted for a manual approach for better control.

The most polished aspect of the project is the creation of custom CD labels and jewel case art, along with a 3D-printed enclosure, giving the setup a look closer to a commercial console. This attention to detail enhances immersion, turning a basic PC hooked to a screen into an authentic retro gaming machine. The project highlights a renewed interest in optical media, driven by nostalgia, cost-effective storage, or even the urge to repurpose old consoles like the NES.
