Arduino UNO Q: Linux and Microcontroller for Embedded Projects

The new Arduino UNO Q merges Debian Linux and STM32 for real-time and embedded AI applications.

A hybrid architecture for advanced prototyping

The Arduino UNO Q combines a Qualcomm Dragonwing QRB2210 processor running Debian Linux with an STM32U585 microcontroller in bare-metal mode. This setup leverages Debian’s ecosystem for complex software tasks like AI or networking, while ensuring real-time control of actuators and sensors via the STM32. The system targets sub-millisecond operations for demanding applications such as robotics or industrial automation.

Concrete projects from the community

Several creations showcase the platform’s potential. Curie is an open-source desk companion using UNO Q to aid focus through audio and visual interactions, designed for people with attention disorders. An autonomous pantry assistant identifies and reads product labels aloud for visually impaired users, while a robotic arm recognizes configured users to hand them selected objects. Finally, a depth measurement tool uses a standard camera and a depth model running on the VENTUNO Q’s NPU, offering four visualization modes to estimate distances.

These projects rely on open-source libraries and tools, bolstered by Arduino’s community contributions. In 2026, the community added 1,218 new libraries, bringing the total to 8,754, and 420 new open-source projects were shared.
