A Claude Client for Nokia 6300 via Go Server and Docker

A developer built an unofficial client to interact with the Claude AI from an old Nokia 6300, using a self-hosted Go server.

Read the article on the TRMNL Leaderboard →

Emir Karşıyakalı has developed Claude S40, an unofficial client for Nokia Series 40 phones running Java, enabling interaction with the Claude AI assistant. The project allows users to ask questions, receive responses on the Nokia’s screen, and even create calendar entries directly on the device.

The system relies on a Go-based server, distributed as a Docker image for self-hosting. This server manages the Anthropic API key, splits responses into 8 KB chunks (the Nokia’s limit), and stores conversations for up to 30 days. The Nokia 6300, which only supports TLS 1.0 and lacks SNI support, requires a self-signed certificate installed on the phone to establish a secure connection between the server and the device.

The code is released under the MIT license, but the project’s viability depends on 2G network availability. Orange plans to fully shut down its 2G network in metropolitan France by October 20, 2026, making the Nokia 6300 unusable for this project after that date. The client has only been tested on the Nokia 6300 (RM-217) and requires a SIM card with mobile data enabled. The developer is now working on a custom firmware to bypass Java restrictions and expand the phone’s capabilities.
