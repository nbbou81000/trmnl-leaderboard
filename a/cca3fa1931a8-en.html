Virtual Mac: Run macOS on a Jailbroken iPad, up to Tahoe

An open-source project lets you run macOS on an M1/M2 iPad Pro or Air M1 by jailbreaking and using iPadOS versions before 16.4.

The Virtual Mac project enables users to virtualize macOS versions from Monterey to Tahoe on a jailbroken iPad. This allows running apps like Xcode, Terminal, Final Cut Pro, Logic Pro, or Pixelmator Pro directly on the Apple tablet.

Compatible devices include iPad Pro M1/M2, iPad Air M1, or iPhone 14 Pro/Pro Max. Models with 1 TB or 2 TB storage and 16 GB RAM are recommended for performance comparable to VirtualBuddy or UTM on M1/M2 Macs.

Installation requires jailbreaking the device (using Dopamine, for example) and adding the project’s repository in Sileo. The process is outlined in the project’s readme, supporting iPadOS 15 to 16.3.1 or iPadOS 14 to 14.8.1. The Dopamine-roothide variant is not supported.

Operation relies on the touchscreen: a single tap for clicks, a two-finger tap for secondary clicks, and scrolling via swipes. A virtual keyboard is accessible via a dedicated icon. However, iCloud or Apple account connections are not supported—users must select "Set Up Later" during macOS installation.

The project requires iPadOS 16.3.1 or earlier, as Apple removed its hypervisor starting with iPadOS 16.4, making porting to newer versions highly difficult. Downgrading is not straightforward, so this solution is limited to users with compatible devices.
