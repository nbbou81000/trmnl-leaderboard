Droidputer: Turn an Android Phone into a Display for ESP32-S3

An open-source project turns an Android phone into a screen and keyboard for an ESP32-S3 microcontroller via USB-OTG.

Read the article on the TRMNL Leaderboard →

Felipe Cavalcanti has shared on Hackster.io a project called Droidputer, which turns an Android phone into a display and keyboard for an ESP32-S3 microcontroller. The phone connects to the microcontroller via USB-OTG, while the firmware runs directly on the ESP32-S3. The smartphone handles display, user input, GPS, and even flashing the microcontroller.

Originally designed to add a larger screen to an M5Stack Cardputer, the project evolved into a standalone solution. Now, a basic ESP32-S3 development kit and an OTG-capable Android phone are all that’s needed. Several Cardputer-compatible apps have been adapted for Droidputer, including stellar-map (star map), miniacid (ISS tracker), ESP32Marauder (Wi-Fi security tool), Ultimate-Remote (universal remote), and Tiny-Journal (note-taking). A full list of tested applications is available in the project’s GitHub repository.

The project is accessible on Hackster.io and its source code is hosted on GitHub.
