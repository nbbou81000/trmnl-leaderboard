Droidputer : transformer un smartphone Android en écran pour ESP32-S3

Un projet open source utilise un smartphone Android comme écran et clavier pour un microcontrôleur ESP32-S3 via USB-OTG.

Lire l'article sur le Palmarès TRMNL →

Felipe Cavalcanti a partagé sur Hackster.io un projet nommé Droidputer, qui permet d'utiliser un smartphone Android comme écran et clavier pour un microcontrôleur ESP32-S3. Le téléphone se connecte au microcontrôleur via USB-OTG, tandis que le firmware s'exécute directement sur l'ESP32-S3. Le smartphone prend en charge l'affichage, les entrées utilisateur, le GPS et même la programmation du microcontrôleur.

Initialement conçu pour ajouter un écran plus grand à un M5Stack Cardputer, le projet a évolué vers une solution autonome. Désormais, un simple kit de développement ESP32-S3 et un téléphone Android compatible OTG suffisent. Plusieurs applications compatibles avec Cardputer ont été adaptées pour fonctionner avec Droidputer, comme stellar-map (carte stellaire), miniacid (suivi de l'ISS), ESP32Marauder (outil de sécurité Wi-Fi), Ultimate-Remote (télécommande universelle), ou encore Tiny-Journal (prise de notes). Une liste complète des applications testées est disponible dans le dépôt GitHub du projet.

Le projet est accessible sur Hackster.io et son code source est hébergé sur GitHub.
