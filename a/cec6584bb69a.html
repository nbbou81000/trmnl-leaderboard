Moments : un firmware open source pour dashboard e-ink adaptatif

Un firmware open source transforme un écran e-ink en dashboard intelligent qui s'adapte à son environnement et à l'heure.

Lire l'article sur le Palmarès TRMNL →

Makestreme propose Moments, un firmware open source conçu pour l’écran e-ink Seeed Studio reTerminal Sticky. Contrairement à des solutions comme TRMNL, il ne nécessite ni abonnement ni compte cloud. Le système affiche dynamiquement des contenus différents selon l’orientation du dispositif, l’heure ou d’autres paramètres, via des Moments : interfaces statiques, applications interactives ou automatisations.

Parmi les exemples fournis, on trouve un briefing matinal pour un affichage sur une table de chevet, une application de recettes activée près d’un réfrigérateur, un dashboard de bureau avec agenda et données boursières, ou encore une alerte de porte utilisant le haut-parleur intégré et envoyant une notification sur smartphone. Le firmware se flashe directement depuis une page web, sans modification matérielle.

Après installation, l’écran crée un point d’accès WiFi temporaire pour configurer le système via une interface locale accessible à l’adresse http://moments.local. Cette console permet de gérer les Moments, les widgets et les connexions aux services. Un appui sur le bouton de volume bas force une vérification immédiate du contexte, l’écran passant en veille pour économiser l’énergie.

Le projet est documenté sur Hackster.io et le code source est disponible sur GitHub.
