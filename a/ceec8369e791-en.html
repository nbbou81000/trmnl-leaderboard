ZecTrix Note 4: ESP32-S3 E-Ink Display with Voice Recognition

A 4.2-inch ESP32-S3 e-ink display with voice recognition, Wi-Fi, Bluetooth, and NFC for smart notes.

The ZecTrix Note 4, developed by Chinese lab ZecTrix Lab, is a smart e-ink display powered by an ESP32-S3 microcontroller. It stands out for its built-in voice recognition, enabled by an integrated microphone and speaker. The device features a 4.2-inch e-ink screen that can display reminders, notes, clocks, weather data, images, or custom templates. An alternative version, the Note 4C, replaces the monochrome display with a four-color (BWRY) e-paper panel.

The core of the system is an ESP32-S3 chip from Espressif Systems, featuring dual-core Tensilica LX7 processors running up to 240 MHz with AI/ML acceleration. It includes 512KB of SRAM, 8MB of PSRAM, and 16MB of flash storage. Connectivity options include 2.4GHz Wi-Fi 4, Bluetooth 5.0, and NFC for contactless interactions. Power is supplied by a 2,000mAh rechargeable battery, with a USB Type-C port for charging or data transfer. Physical buttons and a GPIO expansion header allow for custom hardware integrations.

The Note 4’s e-ink display offers a 400 × 300 resolution with partial refresh support, while the Note 4C uses a four-color (black, white, red, yellow) e-paper display for enhanced visual distinction. Both models target applications such as voice note-taking, reminder management, or real-time information display.
