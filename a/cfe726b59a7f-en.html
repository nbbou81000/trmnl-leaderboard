Home Assistant 2026.10: Advanced Matter Leak Sensor and Lock Management

Home Assistant 2026.10 enhances Matter leak sensor and lock management with configurable alarms and access control.

Home Assistant 2026.10 improves integration of Matter leak sensors by allowing users to configure audible and visual alarms directly from the interface. Previously, these settings were restricted to manufacturer apps, limiting user autonomy. Now, two dedicated switches (Audible alarm enabled and Visual alarm enabled) appear on the configuration page of compatible sensors, based on Matter’s Boolean State Configuration standard. These options let users enable or disable sirens and lights separately, without triggering the alarm immediately. Users can prioritize visual alerts for rarely visited areas or sound alerts for accessible spaces.

However, this feature is only available if the sensor implements the Boolean State Configuration cluster and declares its capabilities (siren, light, or both). Devices not supporting this standard won’t display these switches. To test the new options, the author simulated a leak sensor using an ESP32-C6, leveraging Arduino-ESP32’s Matter Water Leak Detector example. Though functional, their prototype didn’t show the alarm switches because the required cluster wasn’t included in the code.

Matter lock control: access management and instant locking

For locks, Home Assistant now extends access management via Matter. Users can add, modify, or delete PIN codes, as well as generate temporary access codes, directly from the interface. A new option also allows controlling instant locking (EnableOneTouchLocking), available if the lock supports the corresponding attribute in the Door Lock cluster. This feature depends on manufacturer implementation, with some models like the Aqara Smart Lock U200 supporting it, while others, such as the Secuyou Smart Lock, do not.

Home Assistant strictly adheres to the Matter specification, but feature support varies across devices. Users are advised to check technical specifications before purchasing, as some manufacturers have not yet enabled all options via the Matter ecosystem.
