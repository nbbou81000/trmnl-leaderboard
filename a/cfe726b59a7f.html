Home Assistant 2026.10 : gestion avancée des capteurs de fuite et serrures Matter

La mise à jour 2026.10 de Home Assistant améliore la gestion des capteurs de fuite et des serrures Matter, avec des alarmes configurables et un contrôle des accès.

Lire l'article sur le Palmarès TRMNL →

La version 2026.10 de Home Assistant introduit une meilleure intégration des capteurs de fuite Matter, permettant désormais de configurer les alarmes sonores et visuelles directement depuis l’interface. Jusqu’ici, ces réglages étaient réservés aux applications des fabricants, limitant l’autonomie des utilisateurs. Désormais, deux interrupteurs dédiés (Audible alarm enabled et Visual alarm enabled) apparaissent sur la page de configuration des capteurs compatibles, s’appuyant sur la norme Boolean State Configuration de Matter. Ces options permettent d’activer ou désactiver séparément les sirènes et les voyants, sans déclencher immédiatement l’alarme. L’utilisateur peut ainsi privilégier une notification visuelle pour les zones peu fréquentées ou une alerte sonore pour les espaces accessibles.

Cependant, cette fonctionnalité n’est disponible que si le capteur implémente spécifiquement le cluster Boolean State Configuration et déclare ses capacités (sirène, lumière, ou les deux). Les dispositifs ne supportant pas cette norme ne bénéficient pas de ces interrupteurs. Pour tester ces nouvelles options, l’auteur a simulé un capteur de fuite avec un ESP32-C6, utilisant l’exemple Arduino-ESP32 dédié aux détecteurs de fuite Matter. Bien que fonctionnel, son prototype n’a pas affiché les interrupteurs d’alarme, faute d’avoir intégré le cluster requis dans le code.

Contrôle des serrures Matter : gestion des accès et verrouillage instantané

Côté serrures, Home Assistant étend désormais la gestion des accès via Matter. Les utilisateurs peuvent ajouter, modifier ou supprimer des codes PIN, ainsi que générer des codes d’accès temporaires, directement depuis l’interface. Une nouvelle option permet aussi de contrôler le verrouillage instantané (EnableOneTouchLocking), activable si la serrure supporte l’attribut correspondant dans le cluster Door Lock. Cette fonctionnalité reste dépendante de l’implémentation par le fabricant, certains modèles comme l’Aqara Smart Lock U200 la supportant, tandis que d’autres, comme le Secuyou Smart Lock, ne l’intègrent pas.

Home Assistant se conforme strictement à la spécification Matter, mais la prise en charge des fonctionnalités varie selon les appareils. Les utilisateurs sont invités à vérifier les fiches techniques des dispositifs avant achat, certains fabricants ne supportant pas encore toutes les options via l’écosystème Matter.
