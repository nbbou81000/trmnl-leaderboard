Rotary Phones Get a Modern Revival with ESP32-C6

A maker revives old rotary phones by turning them into functional phone systems with modern features.

Read the article on the TRMNL Leaderboard →

Maker Scott Dylewski has created Analog Redial, an open-source telephone system built around an ESP32-C6 microcontroller. The project revives old rotary or touch-tone phones by adding modern features like dial tones, ringing, an answering machine, and intercom calls between connected devices.

The hardware combines an ESP32-C6 development board, an ES8388 audio codec, and one or two Silvertel AG1171 Subscriber Line Interface Circuits (SLICs). The SLICs provide the electrical signals traditional phones require, such as loop current and ringing voltage. The codec handles audio conversion, while the ESP32-C6 manages dialing, generates phone tones, handles calls, and hosts a web-based configuration interface.

The system works entirely offline, allowing two connected phones to call each other without Wi-Fi or external phone service. Multiple Analog Redial boards can also communicate over a local network using VoIP, with SIP support for integration with servers like Asterisk or FreePBX. Custom dialing codes trigger specific actions, such as recording a message, reciting pi digits, or activating connected hardware.

An experimental integration with Home Assistant via MQTT or webhooks enables the phone to trigger smart home automations, like ringing when a smart doorbell is pressed. An optional BM64 Bluetooth module adds smartphone connectivity, allowing users to make and receive cellular calls through their vintage phones, with the original mechanical bell ringing for incoming calls.

KiCad design files, firmware, documentation, and 3D-printable enclosure files are available under permissive open-source licenses in the project’s GitHub repository. A basic single-line board costs about $37 when ordering five units, with an additional $10 for a second line and roughly $15 for Bluetooth.
