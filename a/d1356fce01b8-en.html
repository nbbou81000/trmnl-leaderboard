Trilium: A Note-Taking App to Organize Your Homelab

A tech journalist uses Trilium, an open-source self-hosted tool, to centralize and structure scattered homelab notes.

A growing homelab with over 20 Docker containers spread across six machines, VPS, and networking gear makes tracking technical details a challenge. The author, struggling with scattered notes (Word files, Notes app snippets, network configs in LLM chats), sought a centralized solution for critical information: IP addresses, ports, configurations, and troubleshooting steps.

After dismissing self-hosted wikis and standard note apps, he chose Trilium, an open-source self-hosted note-taking tool based on a hierarchical note tree. Key features include sync, progressive web app (PWA), revision history, password protection, and a web clipper. Deployment via Docker on a personal server took minutes, but importing existing data—spread across various formats—required prior organization.

Gradual migration and immediate benefits

The author used a local language model (Gemma 4 via llama.cpp) to sort and structure old notes before importing them into Trilium. Despite import imperfections, the tree structure quickly took shape, providing a clear overview of his infrastructure. Benefits appeared rapidly: precise search (exact match first, then fuzzy logic), instant access to configurations, and reduced stress during technical interventions.

However, the author identified a major risk: hosting notes on the same server as the documented services. In case of failure, accessing reconstruction data becomes impossible. To address this, he plans to use Trilium’s sync and backup options, redirecting them to separate VPS or NAS storage.

Trilium proves to be a suitable solution for complex homelabs, but its effectiveness depends on initial data organization and setting up external backups.
