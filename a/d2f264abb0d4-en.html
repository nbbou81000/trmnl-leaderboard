An ESP32 Board to Monitor Your UPS Over the Network

An ESP32-based device lets you remotely monitor a USB UPS over Wi-Fi.

Read the article on the TRMNL Leaderboard →

Uninterruptible power supplies (UPS) protect electronics during outages, but battery health and runtime are often hard to track without a connected computer. Developer Aron Reid created My UPS Pal, an ESP32-S3-based board that connects a standard USB UPS to your local network for remote monitoring.

The compact 36×58 mm board features an ESP32-S3-WROOM-1-N16R8 module (16 MB flash, 8 MB PSRAM), a USB-A port for UPS communication, a USB-C port for power and programming, status LEDs, and a header for an optional 0.96-inch OLED display. Additional GPIO pins allow for further expansion. The device runs a Network UPS Tools (NUT) server, compatible with software like Home Assistant, Synology, TrueNAS, Unraid, and Proxmox. Depending on the UPS data, users can monitor battery charge, estimated runtime, voltage, power consumption, and operational status. A built-in web interface provides live readings, historical data, and an outage log, with options to run battery self-tests, control alarms, or issue shutdown commands when supported.

For secure remote access, My UPS Pal includes Tailscale support, eliminating the need to expose the device directly to the internet. Development challenges included memory limitations for Tailscale, USB-C power issues, and a reversed OLED connector that damaged a display, all resolved in the final design. The device consumes about 0.4 watts in normal operation.

My UPS Pal is available as a preassembled board starting at $33, or $41 with an integrated OLED display. The firmware, documentation, and hardware design are open source on GitHub, and the software can also run on compatible ESP32-S3 development boards.
