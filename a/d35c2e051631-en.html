Olimex Adds Wired Ethernet to RP2040 and ESP32 via UEXT Module

A €5 compact module adds 100 Mbit Ethernet to RP2040, RP2350, and ESP32 boards via UEXT or pUEXT.

Read the article on the TRMNL Leaderboard →

Bulgarian open-hardware company Olimex has released the UEXT-CH390, a compact 100 Mbit Ethernet add-on module designed to work with Raspberry Pi RP2040, RP2350, and Espressif ESP32 microcontroller boards. The module leverages WCH’s CH390 SPI-to-Ethernet controller and connects without soldering via either the standard UEXT or the smaller pUEXT connector. Measuring just 50×21 mm, it is primarily intended for Olimex’s own development boards but remains compatible with any board featuring these connectors.

The company highlights the benefits of wired Ethernet over Wi-Fi, such as avoiding wireless network attacks or enabling reliable connections in challenging environments like basements or behind metal walls. For Home Assistant users, the module is fully supported in ESPHome on ESP32, with a newly developed RP2040 driver. A GitHub project provides an ESPHome 2026.9.0-compatible example for RP2040 and a Pico SDK example using lwIP with a minimal web server.

Technical implementation required workarounds, including software reset and polling due to the lack of interrupt and reset pins on the UEXT connector. Olimex also addressed SPI access conflicts and disabled ESPHome’s API watchdog for standalone use. The module is available for pre-order at €4.95 (around $5.55) from the Olimex store, with open-source hardware and firmware released under the CERN OHL-S v2 and MIT licenses respectively.
