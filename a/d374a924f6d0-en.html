Commodore 64 Keyboard Font Recreated as Vector Typeface

The iconic Commodore 64 keyboard font is now available as a vector typeface, ready for integration into your projects.

Read the article on the TRMNL Leaderboard →

The Commodore 64, the iconic 1980s computer, is instantly recognizable by its distinctive keyboard font. This typography, featuring slightly narrow letters with strong contrast between thick and thin strokes, had never been digitized as a vector font until now. Levente Szabadkai has recreated the font by tracing glyphs from photographs of the original keyboard, including PETSCII symbols, function keys, and even the Commodore logo.

Available for free on GitHub, the font is provided in multiple vector formats, making it suitable for design software or personal projects. The typeface is uppercase-only, as the C64 keyboard keys only displayed uppercase letters, though the machine itself supported lowercase characters via key combinations. Some users note minor differences between the vector font and the printed keycaps, particularly for letters like G, R, or M, where curves or angles vary slightly. These discrepancies stem from a geometric normalization process applied during digitization.

The project also includes full solid cursor arrows, unlike some modern reproductions that use outlined versions. The files are ready to use for adding a retro touch to interfaces, documents, or digital creations.
