Humidity Alert System with Arduino and Windows GUI

An Arduino-based humidity monitor alerts via LEDs, buzzer and Windows software when air humidity goes out of safe ranges.

Read the article on the TRMNL Leaderboard →

A project posted on Hackster.io turns a basic humidity sensor into a visual and audible alert system. The Arduino Nano reads data from a DHT11 sensor every two seconds via a digital pin. When humidity drops below 65% or rises above 80%, a red LED lights up and an active buzzer sounds, while the green LED turns off. Within the ideal range (between 65% and 80%), only the green LED remains lit and the system stays silent.

The Windows GUI, built in C# using Windows Forms, connects to the board via a serial port at 9600 baud. It displays real-time readings in a dark theme, with a color code to indicate status: green for normal humidity, red for critical levels. The interface update is secured using the Invoke method, preventing conflicts between the serial reading thread and the graphical display.

The author notes that the original plan aimed for full automation using a 5V relay to power a cool mist humidifier, but this approach failed. The humidifier’s built-in control system, featuring touch buttons and auto mode, did not respond to power cycling, making direct Arduino control impossible. The project was thus refocused on alerts, providing a reliable way to monitor ambient humidity.
