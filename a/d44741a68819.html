Système d'alerte d'humidité avec Arduino et interface Windows

Un moniteur d'humidité Arduino alerte via LED, buzzer et logiciel Windows quand l'air sort des seuils de confort.

Lire l'article sur le Palmarès TRMNL →

Un projet publié sur Hackster.io transforme un simple capteur d’humidité en système d’alerte visuel et sonore. L’Arduino Nano lit les données d’un capteur DHT11 toutes les deux secondes via une broche numérique. Lorsque l’humidité descend sous 65 % ou dépasse 80 %, une LED rouge s’allume et un buzzer actif retentit, tandis que la LED verte s’éteint. Dans la plage idéale (entre 65 % et 80 %), seule la LED verte reste allumée et le système reste silencieux.

L’interface graphique sous Windows, développée en C# avec Windows Forms, se connecte à la carte via un port série à 9600 bauds. Elle affiche les relevés en temps réel dans un thème sombre, avec un code couleur pour indiquer l’état : vert pour une humidité normale, rouge pour un niveau critique. La mise à jour de l’interface est sécurisée grâce à la méthode Invoke, qui évite les conflits entre le thread de lecture série et l’affichage graphique.

L’auteur précise que le projet initial prévoyait une automatisation complète via un relais 5V pour activer un humidificateur, mais cette approche a échoué. Le système de contrôle intégré de l’humidificateur n’a pas réagi aux coupures de courant, rendant impossible une gestion directe par l’Arduino. Le projet s’est donc recentré sur l’alerte, offrant une solution fiable pour surveiller l’humidité ambiante.
