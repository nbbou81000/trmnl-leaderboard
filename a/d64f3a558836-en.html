Home Assistant 2026.11 Integrates Official Marketplace

Home Assistant 2026.11 replaces HACS with an integrated Marketplace, streamlining the installation of community components.

The Open Home Foundation has released Home Assistant 2026.11, a major update that officially integrates the Marketplace, replacing the former Home Assistant Community Store (HACS). The latter, previously optional, allowed users to install community-created integrations, themes, dashboard cards, and templates, but was not part of the core software.

The new Marketplace replicates all HACS functionalities without requiring additional installation. It is now directly accessible from the Home Assistant interface, under Settings Marketplace. Unlike HACS, which required different installation methods depending on the setup (containerized or not), the Marketplace works uniformly across all Home Assistant installations.

Key improvements include a streamlined installation process: adding a component from the Marketplace immediately triggers its setup workflow, eliminating intermediate restarts. Updates for community integrations now appear in the global Home Assistant update list. The system also offers better source filtering, simplified repository management, and a redesigned interface with enhanced branding visibility.

However, the Marketplace retains a critical distinction: community integrations remain untested by default, unlike official components. Users must accept a warning about potential risks before installation. Additionally, HACS will continue to function on older Home Assistant versions but will no longer receive updates.

This release also introduces other features, such as the ability to exclude specific items (rooms or labels) from automations, a Triggered by filter to analyze device actions, and support for Matter 1.5 cameras along with two-way audio for compatible Reolink cameras. Other improvements include dashboard section copying, automatic section population, new cards and badges, a YAML-free alert card, and simplified color management for light tiles.
