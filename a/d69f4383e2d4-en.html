Interactive VHS Video Game Powered by FPGA and Microcontroller

A hacker turns a VHS cassette into an interactive game console using a DE1-SoC board and an RP2350 MCU.

Read the article on the TRMNL Leaderboard →

Early VHS-based games, like the ActionMax, offered minimal experiences with fixed targets and light gun mechanics. To push beyond these limits, a developer built a system using a DE1-SoC FPGA board and an RP2350 microcontroller, enabling real interaction.

The VHS cassette contains both game binary data and video streams. The DE1-SoC, via its composite input, decodes this data, while the RP2350 handles player inputs and executes the game’s bytecode. This approach allows advanced effects, such as background videos for Super Mario Bros or interactive segments for Night Trap and a Doom variant using prerecorded footage.

Unlike commercial systems from the 1980s, this solution provides far greater development flexibility, even for an audience from that era. The project is documented in an ongoing GitHub repository, inviting enthusiasts to contribute.
