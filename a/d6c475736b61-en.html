Controlling an iPhone with AI via an ESP32-S3

An ESP32-S3 emulates a USB mouse and keyboard to control an iPhone from an AI, without jailbreaking or Apple hardware.

To automate actions on an iPhone without jailbreaking, Henry Yuan outlines a method using an ESP32-S3 microcontroller. The approach bypasses Apple’s development tools, such as a developer account or a Mac.

The first step involves capturing the iPhone’s screen in real time. The screen is mirrored via AirPlay using UxPlay, then streamed as a JPEG feed to the chosen AI agent through a Gstreamer pipeline. The agent analyzes the images to determine the next actions.

Control of the iPhone is handled by the ESP32-S3, configured as a USB-HID device. It emulates both a mouse and a keyboard, enabling interaction with the interface via AssistiveTouch, an iOS accessibility feature. The AI agent can then click, scroll, or type without manual input.

While technically intricate, this method provides an alternative to traditional software hacking. It allows automating repetitive tasks or testing interfaces without altering the iPhone’s operating system.
