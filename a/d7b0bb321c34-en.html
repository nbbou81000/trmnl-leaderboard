beebgame: A Scrolling-Platformer Engine for BBC Micro in Assembly

A scrolling-platformer game engine for BBC Micro, compatible with BBC Model B and BBC Master 128, released under MIT license.

Developer Eben Upton has released beebgame, an assembly-language scrolling-platformer game engine for BBC Micro computers with 64KB of sideways RAM, including the BBC Model B and BBC Master 128. The engine enables the creation of side-scrolling platform games using the original hardware’s graphical capabilities.

The source code is written in ca65, an assembler compatible with the cc65 toolchain, and is compiled differently depending on the target: a BHW flag generates a version for the BBC Model B (BHW=1) or the BBC Master 128 (BHW=0). A single bootable disc can thus run on both machines. The engine handles display via MODE 1 (320×256 pixels, 4 colors), masked sprites, tiles, and a rupture display chain for smooth scrolling.

The project includes build tools, automated tests (requiring Node.js and the jsbeeb emulator), and full documentation. The code is released under the MIT license and was extracted from the Cleo game, which serves as a reference and includes this engine as a submodule. To compile a game, Python 3 and the cc65 tools are required.
