beebgame : un moteur de jeu pour BBC Micro en assembleur

Un moteur de jeu en assembleur pour BBC Micro, compatible BBC Model B et BBC Master 128, publié sous licence MIT.

Lire l'article sur le Palmarès TRMNL →

Le développeur Eben Upton a partagé beebgame, un moteur de jeu en assembleur conçu pour les micro-ordinateurs BBC Micro équipés de 64 Ko de RAM latérale, notamment le BBC Model B et le BBC Master 128. Ce moteur permet de créer des jeux de plateforme à défilement horizontal en exploitant les capacités graphiques du matériel d'origine.

Le code source est écrit en ca65, un assembleur compatible avec la suite cc65, et est compilé différemment selon la cible : un flag BHW permet de générer une version adaptée au BBC Model B (BHW=1) ou au BBC Master 128 (BHW=0). Un même jeu peut ainsi être distribué sur un seul disque bootable, compatible avec les deux machines. Le moteur gère l'affichage via un MODE 1 (résolution de 320×256 pixels en 4 couleurs), des sprites masqués, des tuiles et une chaîne de rupture pour le défilement fluide.

Le projet inclut des outils de compilation, des tests automatisés (nécessitant Node.js et l'émulateur jsbeeb), ainsi qu'une documentation complète. Le code est publié sous licence MIT et est extrait du jeu Cleo, qui sert de référence et intègre ce moteur comme sous-module. Pour compiler un jeu, il faut disposer de Python 3 et des outils de la suite cc65.
