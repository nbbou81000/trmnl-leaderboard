CutScape 0.6.0: Inkscape Extension for 2D Plotters and CNC Machines

Updated Inkscape extension to control 2D machines, featuring presets for Secabo cutters.

Read the article on the TRMNL Leaderboard →

Developer jetpax has released version 0.6.0 of CutScape, an Inkscape extension designed to send designs to 2D machines like plotters, vinyl cutters, engravers, or CNC mills. This update adds presets for Secabo’s C IV, S, and T series cutters.

Improvements include the removal of Inkscape’s warning dialogs triggered by CutScape messages. The interface is now available in French. However, the author warns that the Secabo presets haven’t been tested on real hardware—they were derived from driver data bundled with DrawCut and only validated against a simulator. A test cut is strongly recommended before full use, and users are encouraged to report issues via GitHub issues.

CutScape requires Inkscape 1.4 or newer. Installation is done via Extensions → CutScape → Add Cutter, with setup details available in the project’s README on GitHub.
