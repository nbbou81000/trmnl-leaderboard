Olimex UEXT-CH390: Open-Source SPI Ethernet Module for Microcontrollers

A compact open-source module adds 10/100 Mbps Ethernet connectivity via SPI to boards like Raspberry Pi Pico or ESP32.

Olimex has unveiled the UEXT-CH390, an open-source hardware module designed to add wired 10/100 Mbps Ethernet connectivity to microcontroller boards lacking built-in Ethernet ports. Built around the WCH CH390 controller, it connects via SPI and supports 10/100 Mbps speeds. The module includes an RJ45 connector, a standard UEXT connector, and a smaller 1.0mm-pitch pUEXT connector, measuring 50 x 21 mm.

The CH390 integrates both MAC (Media Access Control) and PHY (Physical Layer) Ethernet interfaces, streamlining integration. It supports auto-negotiation, Auto-MDIX, a 16KB packet buffer, and a factory-programmed MAC address. It handles IPv4/IPv6, TCP, UDP, and IEEE 802.3x flow control. The host interface uses SPI in modes 0 or 3, with clock speeds up to 72 MHz.

The module is compatible with several boards, including Raspberry Pi Pico and Pico 2, as well as ESP32-S3, C3, C5, and C6. Olimex provides drivers for ESPHome on ESP32 and a dedicated RP2040 driver. The ESPHome 2026.9.0 firmware enables DHCP configuration, automatic discovery in Home Assistant, OTA updates over Ethernet, and a local web interface that works offline. It also allows monitoring the BOOT1 button state, counting button presses, and blinking an LED if the Ethernet connection is lost.

Olimex offers a ready-to-flash UF2 firmware for the RP2040-PICO30U-16 board, along with source code and configuration files on GitHub. A sample application using lwIP and a simple web server is also available for developers preferring not to use ESPHome. All hardware (KiCad schematics) and software files are provided as open source.

The module is available for pre-order at €4.95, with shipping expected to begin on November 9, 2026.
