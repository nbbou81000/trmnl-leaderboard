Olimex UEXT-CH390 : un module Ethernet SPI open source pour microcontrôleurs

Un module compact et open source ajoute une connectivité Ethernet 10/100 Mbps via SPI à des cartes comme Raspberry Pi Pico ou ESP32.

Lire l'article sur le Palmarès TRMNL →

Olimex présente l'UEXT-CH390, un module matériel ouvert conçu pour ajouter une connectivité Ethernet filaire à des cartes microcontrôleurs dépourvues de port Ethernet intégré. Basé sur le contrôleur WCH CH390, il se connecte en SPI et supporte les débits 10/100 Mbps. Le module intègre un connecteur RJ45, un connecteur UEXT standard et un second connecteur pUEXT plus compact (1,0 mm de pas). Ses dimensions sont de 50 x 21 mm.

Le CH390 combine une interface MAC (Media Access Control) et PHY (Physical Layer) Ethernet, simplifiant l'intégration. Il gère l'auto-négociation, le MDIX automatique, un buffer de 16 Ko pour les paquets et un adressage MAC préprogrammé en usine. Il prend en charge les protocoles IPv4/IPv6, TCP et UDP, ainsi que le contrôle de flux IEEE 802.3x. L'interface hôte utilise le protocole SPI en modes 0 ou 3, avec une fréquence d'horloge pouvant atteindre 72 MHz.

Ce module est compatible avec plusieurs cartes, dont les Raspberry Pi Pico et Pico 2, ainsi que les ESP32-S3, C3, C5 et C6. Olimex fournit des pilotes pour ESPHome sur ESP32 et un pilote dédié aux cartes RP2040. Le firmware ESPHome 2026.9.0 permet une configuration via DHCP, une détection automatique dans Home Assistant, des mises à jour OTA par Ethernet, et une interface web locale fonctionnant hors ligne. Il permet également de surveiller l'état du bouton BOOT1, de compter ses appuis et de clignoter une LED en cas de perte de connexion.

Olimex propose un firmware UF2 prêt à l'emploi pour la carte RP2040-PICO30U-16, ainsi que le code source et les fichiers de configuration sur GitHub. Un exemple d'application utilisant lwIP et un serveur web simple est également disponible pour les développeurs souhaitant éviter ESPHome. Tous les fichiers matériels (schémas KiCad) et logiciels sont accessibles en open source.

Le module est disponible en précommande à 4,95 €, avec une expédition prévue à partir du 9 novembre 2026.
