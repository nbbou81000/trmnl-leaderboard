7 overlooked Home Assistant features you should start using

Home Assistant hides many powerful features that even long-time users overlook.

Home Assistant offers more than just basic virtual switches like Input Booleans, which store simple on/off states (e.g., "I took my tablets today"). The platform includes a variety of helper configurations: thresholds, counters, timers, text inputs, templates, and even a mold risk indicator. These tools enable more nuanced automations without starting from scratch.

Leveraging pre-built automations

Blueprints provide ready-to-use automation templates shared by the community, covering needs like battery-powered device monitoring or occupancy-based heating. Before building a custom solution, checking for existing Blueprints can save significant time.

Trigger IDs streamline multi-event automations. For instance, a single automation can handle both presence detection and its clearance, using a Choose action to adapt responses based on the trigger’s ID. Since version 2026.10, the automation editor makes this feature easier to implement.

ESPHome and flexible scheduling

ESPHome, an open-source framework, lets users create firmware for microcontrollers like ESP32 boards without soldering. The resulting sensors integrate directly with Home Assistant. Despite its perceived complexity, ESPHome is accessible for basic projects.

For irregular schedules, calendars replace rigid time-based triggers. For example, an automation set for weekdays can automatically skip execution if a holiday is added to the calendar, avoiding unnecessary actions.

Labels group unrelated entities by shared attributes. They enable precise control, such as powering down only "critical" labeled devices at night or monitoring all battery-powered gadgets.

Scene snapshots capture the current state of selected devices to restore it later. This is useful for temporary actions (e.g., flashing lights when a package arrives), eliminating the need to manually record and restore each entity’s state.
