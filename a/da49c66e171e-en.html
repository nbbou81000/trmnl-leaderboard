Connecting a Withings Scale to Home Assistant via ESP32

A user bypasses Withings cloud to send scale data directly to Home Assistant using an ESP32.

Read the article on the TRMNL Leaderboard →

A Home Assistant enthusiast connected their Withings Body+ scale to Home Assistant without relying on Withings’ cloud service. The setup uses a classic Bluetooth ESP32 microcontroller to receive weight and body composition data directly from the scale after each weigh-in, then forwards it to Home Assistant over Wi-Fi via ESPHome.

The user disabled the scale’s Wi-Fi network to prevent it from uploading data to Withings’ servers. The system automatically identifies users through an embedded ID in the measurements, allowing separate tracking for multiple profiles. The author emphasized that only the original ESP32 (not ESP32-C3 or ESP32-S3 models) supports the required Bluetooth Classic protocol.

Reverse-engineering the scale’s Bluetooth protocol proved challenging, as it is undocumented. The author leveraged OpenCode to analyze Android app code snippets and reconstruct an ESPHome component. Early attempts failed, but after multiple firmware builds and tests, the connection was successfully established. In Home Assistant, the data appears as standard sensors, with template sensors added to retain the last measurement even after a restart.

The solution is specific to the Withings Body+ and the original ESP32. The code is not yet published, but the author plans to share it later.
