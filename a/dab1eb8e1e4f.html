Un moteur Arduino pour faire tourner plusieurs jeux rétro

Un moteur de jeu open source pour Arduino Uno permet d'exécuter des titres classiques comme Manic Miner ou Space Invaders.

Lire l'article sur le Palmarès TRMNL →

Un moteur de jeu conçu pour l'Arduino Uno permet désormais d’exécuter plusieurs jeux rétro sur cette plateforme 8 bits limitée en ressources. Initialement porté depuis un jeu ZX Spectrum, Manic Miner, le projet a évolué vers un moteur 2D capable d’afficher une carte de 256×256 pixels avec défilement, ainsi que jusqu’à neuf sprites simultanément.

Le système génère un signal vidéo à 50 images par seconde sans utiliser de framebuffer, une technique qui économise la mémoire mais impose des contraintes sur la précision de l’horloge. Seuls les Arduino Uno équipés d’un oscillateur à quartz garantissent cette stabilité, les clones moins précis pouvant perturber l’affichage. Deux canaux audio PWM complètent l’expérience, pilotables via quelques résistances pour connecter un haut-parleur.

Quatre jeux sont déjà compatibles : Manic Miner, Scramble, Space Invaders et Pac-Man. Le projet est entièrement open source et disponible sur GitHub, avec une version WebAssembly pour tester le moteur sans matériel dédié.
