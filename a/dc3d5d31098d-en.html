Micro REPL: A Multiplatform Open-Source MicroPython IDE

A new open-source MicroPython IDE supporting Android, Windows, macOS, Linux and browsers, streamlines embedded development.

Read the article on the TRMNL Leaderboard →

Mahmoud Aly introduces Micro REPL, an open-source MicroPython IDE designed to run across multiple platforms. The tool is available for Android, Windows, macOS, Linux, or as a browser-based application. Once a board is connected via USB, users access an interactive REPL (Read-Eval-Print Loop), a file explorer, and a code editor with a consistent layout across all operating systems.

The terminal executes code in real time, maintains command history, performs soft resets of the board, and stops scripts stuck in infinite loops. The file explorer lets users manage files on the device—creating, renaming, deleting, running, or importing them. The editor includes syntax highlighting, undo/redo functions, and keyboard shortcuts on desktop versions (F5 to run a script, Ctrl/Cmd + S to save). Recently opened files are restored after a restart, and over 20 themes are available for customization.

The browser version relies on Web Serial, requiring a compatible browser (Chrome, Edge, or Opera) and a connection over HTTPS or localhost. On Linux, the desktop app prompts to install a udev rule if it fails to open a serial port. For Android, two builds are offered: one without analytics and another with Firebase integration. The project is released under the MIT license.
