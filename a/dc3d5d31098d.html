Micro REPL : un IDE MicroPython multiplateforme et open source

Un nouvel IDE MicroPython open source, compatible Android, Windows, macOS, Linux et navigateur, simplifie le développement embarqué.

Lire l'article sur le Palmarès TRMNL →

Mahmoud Aly propose Micro REPL, un environnement de développement intégré (IDE) dédié à MicroPython, conçu pour fonctionner sur plusieurs plateformes. L’outil s’installe sur Android, Windows, macOS, Linux ou s’exécute directement dans un navigateur. Une fois connecté à une carte via USB, l’utilisateur accède à un REPL interactif (Read-Eval-Print Loop), un explorateur de fichiers et un éditeur de code dont l’interface reste identique quel que soit le système d’exploitation.

Le terminal permet d’exécuter du code en temps réel, conserve l’historique des commandes, réinitialise la carte à distance et interrompt les scripts en boucle infinie. L’explorateur de fichiers permet de gérer les fichiers stockés sur la carte : création, renommage, suppression, exécution ou importation. L’éditeur intègre la coloration syntaxique, des fonctions d’annulation et de rétablissement, ainsi que des raccourcis clavier sur les versions desktop (F5 pour exécuter un script, Ctrl/Cmd + S pour sauvegarder). Les fichiers récemment ouverts sont restaurés après un redémarrage, et plus de 20 thèmes sont disponibles pour personnaliser l’apparence de l’application.

La version navigateur repose sur Web Serial, nécessitant un navigateur compatible (Chrome, Edge ou Opera) et une connexion en HTTPS ou sur localhost. Sous Linux, l’application desktop propose d’installer une règle udev lors de la première tentative d’accès à un port série. Pour Android, deux versions sont disponibles : l’une sans suivi analytique, l’autre intégrant Firebase. Le projet est distribué sous licence MIT.
