Issued: A Self-Hosted Server to Read Your Comics Without Reorganizing Them

A lightweight self-hosted server to browse your comics and BDs archives from a browser, without altering their structure.

Read the article on the TRMNL Leaderboard →

Issued is a lightweight tool designed for comic and BD enthusiasts who want to browse their archives from a browser without reorganizing files. The software scans a folder containing files in CBZ, CBR, CB7 or PDF formats and generates a browsable library accessible via a web interface or OPDS-compatible apps like Panels, Chunky Reader or Moon+ Reader.

Unlike other solutions, Issued preserves the original file structure: a folder containing comics is treated as a series, and subfolders are not mixed. The server displays recent additions, ongoing reads, and allows marking ongoing series with an Ongoing button. Cover thumbnails are generated once to reduce server load, and new file scanning can run automatically or manually based on preferences.

For security reasons, the OPDS catalog remains accessible without authentication, meaning the port 8181 should not be exposed directly to the internet. The developer recommends using a local network, a reverse proxy or a VPN like Tailscale for secure access. Installation is possible via Docker or standalone executables for macOS, Linux and Windows. The interface features a purple theme as a tribute to the developer’s daughter.

The software is released under the MIT license and, according to the developer, supports up to 20,000 files, as they use it daily with around 4,500 comics.
