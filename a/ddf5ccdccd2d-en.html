ESP32-P4: Run apps from an SD card without rebooting

A new firmware lets you load and run applications from an SD card on the ESP32-P4 without rebooting or reflashing.

Read the article on the TRMNL Leaderboard →

Gil Tal has released ESP32_P4_Launcher, an open-source firmware for the ESP32-P4 that enables running programs stored on an SD card, similar to how a PC loads software from a disk. Unlike traditional methods, this approach avoids reflashing or rebooting. Applications are distributed as .papp files, dynamically loaded into PSRAM (external RAM), relocated, and linked to the main firmware’s services before execution. Once an app exits, its resources are automatically reclaimed.

The system is based on the PAPP (PSRAM App) concept, leveraging the ESP32-P4’s ability to execute code from PSRAM instead of flash. Each .papp file works like a dynamic library (DLL) with a main() function. For instance, Quake loads in about 70 ms. Twenty-one example applications are already available, including console emulators (NES, Neo Geo), games like Doom, Duke Nukem 3D, and OpenTyrian, as well as utilities such as a clock and a file manager. No ROMs or game data are included with the project.

Three boards are officially supported: the Guition ESP32-P4 4.3″, the Guition 7″, and the M5Stack Tab5. Applications compiled for one board work without modification on the others, thanks to versioned interfaces ensuring backward compatibility. However, the ABI (Application Binary Interface) remains in preview and may change. The project is hosted on GitHub.
