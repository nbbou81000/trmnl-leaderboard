Construire une caméra time-lapse avec un Raspberry Pi 4

Un projet open source transforme un Raspberry Pi 4 en caméra time-lapse autonome pour suivre une rénovation de jardin.

Lire l'article sur le Palmarès TRMNL →

Un maker a conçu une caméra time-lapse autonome pour documenter les étapes d’une rénovation de jardin. Le système repose sur un Raspberry Pi 4 équipé d’un module caméra 3 Wide (12 MP), alimenté via un seul câble PoE (Power over Ethernet).

Le logiciel open source, disponible sur GitHub, prend une photo toutes les minutes uniquement en journée, en ajustant automatiquement les intervalles selon la position géographique (latitude et longitude) pour suivre les variations saisonnières. Une fois la carte SD remplie à plus de 85 %, les anciennes images sont supprimées automatiquement pour libérer de l’espace. Un Mac peut récupérer les clichés dès qu’un disque externe est branché, et une commande simple permet de générer une vidéo à partir d’une plage de dates choisie. Le projet inclut aussi un mode film et une interface de contrôle accessible depuis un smartphone.

Les fichiers sources et les détails techniques sont partagés sur GitHub, YouTube et Reddit. Une version détaillée du tutoriel est en préparation.
