Un Game Boy Advance non modifié transformé en synthétiseur musical

Un Game Boy Advance d'origine, sans modification, devient un synthétiseur grâce à une astuce logicielle exploitant son mode multiboot.

Le Game Boy Advance (GBA) est souvent utilisé pour recréer des sons rétro, mais généralement en démontant l’appareil ou en récupérant des composants. Pourtant, un projet récent démontre qu’il est possible de transformer un GBA d’origine en synthétiseur musical, sans aucune modification matérielle.

La clé de cette astuce réside dans le mode multiboot du GBA, une fonctionnalité originale permettant d’envoyer du code exécutable via un câble de liaison vers d’autres consoles dépourvues de cartouche. À l’époque, cela permettait de jouer à des jeux multijoueurs sans posséder chaque cartouche. Aujourd’hui, cette fonction est détournée pour charger directement un logiciel de synthèse dans la mémoire vive du GBA. Il suffit de connecter la console à un ordinateur, de lancer le programme, puis de l’allumer : le synthétiseur s’exécute automatiquement dans la RAM. Le son est diffusé via la prise casque, tandis que les commandes peuvent être gérées depuis l’ordinateur ou les boutons du GBA.

Dans une démonstration vidéo, l’auteur du projet, [Andy], utilise le GBA avec d’autres équipements musicaux. Les sons générés par la console non modifiée sont jugés convaincants, offrant une alternative accessible pour s’initier à la musique chiptune ou éviter de démonter du matériel vintage comme un Sega Genesis pour en extraire les circuits audio.
