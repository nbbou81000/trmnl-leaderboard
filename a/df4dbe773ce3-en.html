LakeShark: An Open-Source Pocket Radio Scanner Based on ESP32-P4

An open-source project turns ESP32-P4 boards into portable radio scanners without needing a PC.

Read the article on the TRMNL Leaderboard →

The LakeShark open-source project, created by SAMS0N1TE, turns ESP32-P4 development boards into compact radio scanners without requiring a separate computer. Unlike traditional setups that rely on a PC and specialized software, LakeShark leverages the ESP32-P4’s built-in capabilities to receive and decode a wide range of radio signals.

Multiple compatible boards are supported, including the LILYGO T-Display P4, which features a 4.1-inch AMOLED touchscreen (568×1232 pixels), GPS, and motion sensors. Depending on the model, it includes either an SX1262 LoRa transceiver or the more versatile LR2021 radio module. The latter can capture digital P25 signals, analog FM broadcasts, ADS-B aircraft transmissions, and pager messages without an external SDR receiver. Recent firmware updates even allow specialized programs to run on the LR2021’s internal processor, offloading tasks like FFT processing and frequency sweeps from the ESP32-P4.

For setups without these modules, an RTL-SDR receiver can be connected via USB to access signals such as P25 trunked radio systems, FM broadcasts, or POCSAG pager messages. Experimental support for the HackRF One is also in development. LakeShark goes beyond radio scanning, offering applications for MeshCore communication, sub-GHz signal capture and replay, FT8 decoding, GPS utilities, offline maps, and even an audio player. An optional detachable MIX-RF keyboard adds physical controls alongside CC1101, nRF24, and NFC hardware.

The project is available on GitHub under the GPL-3.0 license, complete with source code, firmware, and installation instructions. Waveshare ESP32-P4 boards can operate in headless mode via a serial terminal or a connected Flipper Zero, while the LakeShark Desktop environment allows applications to run in windows on a PC while the ESP32-P4 handles the radio processing.
