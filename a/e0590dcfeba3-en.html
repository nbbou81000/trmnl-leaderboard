M5Stack Core Matrix: IoT Controller with 16×16 LED Matrix and WiFi 6

A compact IoT controller based on ESP32-C61, featuring a 16×16 LED matrix and a 6-axis motion sensor.

Read the article on the TRMNL Leaderboard →

M5Stack has launched the Core Matrix, an IoT controller built around Espressif’s ESP32-C61 microcontroller. The module features a 16×16 white LED matrix (256 LEDs) for displaying icons, animations, notifications, or device status. It targets IoT applications, sensor monitoring, and interactive interfaces.

The Core Matrix includes a BMI270 sensor from Bosch, combining a 3-axis accelerometer and gyroscope to detect motion. Wireless connectivity includes WiFi 6 (2.4 GHz) and Bluetooth LE 5.0, along with a microSD card slot for data storage. Power management is handled via a USB-C port or an external 3.7V battery, with a dedicated circuit to optimize consumption (down to 8.21 µA in sleep mode).

I/O options include three user buttons, a passive buzzer, a power button, and expansion interfaces: M5-Bus (30-pin) and Grove I2C (5V). The onboard memory consists of 320KB SRAM, 8MB PSRAM, and 16MB QSPI flash. The ESP32-C61 SoC, based on a 160 MHz RISC-V core, is complemented by 256KB ROM.

Development is supported via the Arduino IDE, the visual UIFlow2 platform, or the M5Unified and M5GFX libraries. M5Stack provides code examples, schematics, and comprehensive technical documentation. The kit is available for $29.99 on AliExpress and the official store, without a battery included.
