Turn a USB Printer into a WiFi Printer with an ESP32-S3

An open-source project adds WiFi to a Brother HL-1110 printer using an ESP32-S3, without altering the existing driver.

Read the article on the TRMNL Leaderboard →

A developer named MAXXTANG shared on Hackster.io a project that connects a Brother HL-1110 laser printer, which only supports USB, to a WiFi network using an ESP32-S3 microcontroller. The setup acts as a network bridge: the computer sends the print job via the standard Brother driver to TCP port 9100, and the ESP32-S3 forwards the data over its USB Host port to the printer. The circuit uses the ESP32-S3’s USB Host port to link the printer, while a separate OTG adapter and UART port handle power and firmware flashing.

The project targets a specific ESP32-S3 board, the N16R8, which features 16 MB of flash memory and 8 MB of PSRAM. On first boot, the module creates a WiFi access point named PrintServer-Setup (192.168.4.1) to configure 2.4 GHz network credentials. Once connected, a dashboard accessible at http://hl1110.local displays the printer’s status, WiFi settings, and allows system restarts. The firmware, developed using Arduino with the Espressif package, includes features like mDNS, a watchdog, OTA updates, and a 512 KB PSRAM print buffer.

This solution functions as a raw port-9100 bridge with no native support for AirPrint, IPP, or LPD, and no authentication mechanism. It is intended for use on a trusted local network. The code is released under the MIT license and available on GitHub.
