A 2013 Kindle Paperwhite Turned into an E-Ink Desk Assistant

A 2013 6th-gen Kindle Paperwhite repurposed as an e-ink desk assistant with task list, calendar, and Pomodoro timer.

A user repurposed a 6th-generation Kindle Paperwhite (2013) into an e-ink desk assistant by leveraging its aging hardware after Amazon discontinued support. The device runs custom software via a jailbreak method.

The interface includes a task manager where items can be checked off, pinned, and followed by an automatic Pomodoro timer that takes over the screen upon activation. The calendar feature provides meeting alerts five minutes in advance and allows joining calls with a single tap.

Beyond organization, the assistant doubles as a Stream Deck by tapping icons to control host computer applications, switching between screens smoothly. The source code, still being cleaned up, will be released soon to let others replicate the setup.
