Arduino App Lab 0.11: Project Export and Mobile Sensor Streaming

New Arduino App Lab IDE version with project export and smartphone sensor streaming for UNO Q and VENTUNO Q boards.

Read the article on the TRMNL Leaderboard →

Arduino has released version 0.11 of its Arduino App Lab integrated development environment (IDE), tailored for the Arduino UNO Q and VENTUNO Q single-board computers. These boards feature a "dual-brain" architecture: a Qualcomm Dragonwing application-class processor for general tasks and an STMicroelectronics STM32 microcontroller for real-time operations. The IDE supports programming both units simultaneously, using Python for the Dragonwing and Wiring-style C/C++ for the STM32.

The update introduces "Apps Releases", production-ready distribution bundles generated directly within the IDE. These packages are compatible with Arduino UNO Q and VENTUNO Q boards, as well as third-party hardware certified under the "Works with Arduino" program.

New features include a 17-point pose estimation model (referred to as a "Brick") capable of processing up to 10 frames per second, though limited to the VENTUNO Q due to performance requirements. The Large Language Model (LLM) Brick now supports importing compatible models from Hugging Face, while an integrated chatbot interface provides conversational interaction. The companion mobile app expands its capabilities by enabling WebSocket-based streaming of microphone and inertial measurement unit (IMU) data from smartphones. Additionally, a Terrestrial Positioning Service (TPS) Brick uses Wi-Fi, Bluetooth Low Energy, and cellular network signals to determine the board's location.

Version 0.11 is available as a free download on Arduino's website, with the source code published on GitHub under the GNU General Public License 3.
