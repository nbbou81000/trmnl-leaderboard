PicoLab: All-in-One Electronics Toolbox with RP2350

A compact box combines oscilloscope, logic analyzer, and adjustable power supply around an RP2350.

Read the article on the TRMNL Leaderboard →

For electronics tinkerers, PicoLab offers an all-in-one solution in a single box. Developed by Max.K, the project combines a 4-channel oscilloscope, an 8-channel logic analyzer, GPIO interfaces, a data logger, and serial, SPI, and I²C ports. An adjustable power supply rounds out the package, making it self-sufficient for many testing tasks.

The system’s core is a RP2350 microcontroller in its extended-pin version, paired with custom interface and protection circuitry. Its standout feature is the interface: the device connects via USB and exposes a web page accessible from any browser through an integrated network server. No dedicated software is required—just a browser and USB networking support. The source code is available on GitHub for those interested in building or modifying it.

However, users point out some limitations. The lack of USB 2.0 high-speed support restricts real-time captures to speeds below the RP2350’s maximum capabilities. Discussions also highlight hardware constraints, such as the need for additional modules to exceed 8 logic analyzer channels or RAM limits for long or high-frequency captures. The firmware, while functional, is criticized for its organization, deemed complex and difficult to maintain.

The project highlights the trade-offs between simplicity, cost, and performance, while paving the way for open-source adaptations for electronics enthusiasts.
