A DNS ad-blocker on ESP32-C3 without PSRAM for $2

A lightweight DNS ad-blocker for ESP32-C3 stores domains in flash using 40-bit hashes, avoiding the need for PSRAM.

Read the article on the TRMNL Leaderboard →

A GitHub project by Zed (@M-Abozaid) introduces a DNS ad-blocker running on a $2 ESP32-C3 without requiring PSRAM. Unlike traditional solutions that load domain lists into RAM, this system stores each domain as a sorted 40-bit FNV-1a hash directly in flash memory. This method accommodates over 140,000 domains in about 0.7 MB of flash, with lookup times under 10 ms and RAM usage around 50 KB.

The 40-bit hash size is carefully chosen: it nearly eliminates collisions at 141k domains and produces just one at 537k. A 32-bit hash would save 20% of flash space but result in about seven collisions at 250k domains. The project includes a UDP DNS sinkhole, a web dashboard accessible at c3adblock.local, a WiFi captive portal for initial setup, and OTA updates for both firmware and blocklist.

On a 4 MB ESP32-C3 board, OTA firmware updates require two application slots, leaving roughly 1.3 MB for the domain list—about 250k entries. To use the 537k “ultimate” list, the partition table must be configured in single-app mode. A printable STL case for the C3 SuperMini board is also provided.
