CO₂ Monitors That Visibly Signal Their Failures

A maker modifies CO₂ sensors to visibly signal failures, preventing misleading readings from silent malfunctions.

Read the article on the TRMNL Leaderboard →

CO₂ sensors are crucial for monitoring indoor air quality, but their failure can go unnoticed if the system keeps displaying the last valid reading. William Collis addressed this by adding a visible failure indicator to his monitors.

Each monitor uses a Sensirion SCD30 CO₂ sensor paired with a Seeed XIAO ESP32-C3 board running ESPHome, which communicates with Home Assistant, an open-source home automation platform. Instead of rewriting the ESPHome firmware, William modified the sensor behavior through a configuration file. Now, if a fault is detected, a dedicated LED flashes to alert users visually, making any malfunction immediately obvious.

This ensures users never rely on outdated or incorrect data, even if the sensor fails. The project demonstrates how software tweaks can significantly improve the reliability of environmental monitoring systems.
