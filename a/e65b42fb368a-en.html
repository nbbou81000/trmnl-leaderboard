First Pi Pico Project: Under-Bed Light and Home Assistant Obsession

A $6 microcontroller triggers an under-bed light via Home Assistant, despite false positives.

Read the article on the TRMNL Leaderboard →

The Pi Pico W, priced around $6, is a Wi-Fi microcontroller based on the RP2040, designed for simple, low-power electronic projects. Unlike standard Raspberry Pi boards, it lacks the memory to run a full operating system but excels as the brain of basic sensors or actuators. The newer Pi Pico 2 W uses the RP2350 and offers slightly improved performance.

The author tested an under-bed motion-activated light project, combining a Pi Pico W, a PIR motion sensor, and a Wi-Fi LED strip. The Pico detects movement and sends the data to Home Assistant, which triggers the LED strip. While the idea was promising, the PIR sensor proved too sensitive: warm blankets or pets caused false triggers, disrupting sleep.

Despite this practical failure, the project highlighted the ease of use of Pi Pico boards and the value of Home Assistant for automating household tasks. Tools like ESPHome now simplify programming a Pico—YAML configuration files replace complex coding in languages like C or Python. The author then expanded into multiple projects (door sensors, washer/dryer monitors, plant moisture probes) thanks to this accessible approach.
