Home Assistant 2026.10: Redesigned OpenStreetMap Map and User Profiles

Home Assistant's October 2026 beta brings a local OpenStreetMap map and enhanced user profiles.

Home Assistant’s October 2026 beta, version 2026.10, introduces major upgrades to its mapping system and user profiles. The built-in map, previously reliant on a third-party provider requiring an API key, now uses OpenStreetMap (OSM), an open-source alternative. Maps are cached locally, ensuring smooth navigation even during network outages, and offer a sharper, more responsive experience.

Visual improvements include redesigned markers, using photos and specific colors for better clarity. Users can now define and track geographic zones, making it easier to monitor the movements of family members or friends via location-enabled apps. A new dedicated tab for people displays recent activity and frequented zones, while an overview panel is accessible from the main dashboard.

Enhanced user profiles

User profiles, once limited to basic user management, now function as customizable dashboards. Clicking a username in the sidebar opens a dedicated space where users can adjust the default dashboard’s appearance, menu item order, and localization settings (date format, time zone). Notifications, display, and shortcuts automatically adapt to the device in use (smartphone, desktop).

Users can now change their profile photos without admin intervention, a long-awaited feature. Automation triggers have also been revamped: adding a "triggered by" condition displays an organized list of available events, simplifying configuration.

The beta is available for testing until October 7, 2026, when the stable release is scheduled. It supports Windows, macOS, Linux, iOS, and Android.
