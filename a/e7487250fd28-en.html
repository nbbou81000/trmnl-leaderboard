Real-Time UK Train Departure Display for Pimoroni Presto

An open-source project displays live UK train departures on an e-ink screen without Raspberry Pi or cloud services.

Read the article on the TRMNL Leaderboard →

Robin Cole has released an open-source project that displays live UK train departures on the Pimoroni Presto, an e-ink screen. The software pulls real-time data directly from the Rail Data Marketplace (RDM) REST/JSON API provided by National Rail Darwin, bypassing legacy SOAP services and avoiding the need for a Raspberry Pi, server, or cloud function.

Configuration is handled through two local files: secrets.py stores API credentials, while config.py lets users define the station list, destination filters (e.g., Waterloo), RDM API URL, refresh interval, screen brightness, and an inactivity timeout. Setting the timeout to zero keeps the display permanently on. Both configuration files are excluded from version control via .gitignore.

Installation is straightforward—simply upload the code over USB. Users can either replace main.py to start the train display immediately or keep the default launcher and upload train_display.py, which appears in the menu with a dedicated travel icon. The repository also includes a dependency-free test suite and a renderer preview tool to simulate the display on a connected Presto without installing files.

Cole notes the app was developed iteratively with OpenAI Codex and tested on physical hardware throughout the process.
