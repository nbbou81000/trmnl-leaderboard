Turn a Wii Remote into a Home Assistant Controller

Three ways to repurpose a Wii Remote as a Home Assistant smart home controller.

The Wii Remote, despite being 20 years old, remains a versatile device thanks to its Bluetooth connectivity, motion sensors, infrared camera, and physical buttons. Three methods allow repurposing it as a controller for Home Assistant, the open-source home automation platform.

Replace the motherboard with an ESP32

The OpenMote project replaces the Wii Remote’s original circuit board with a custom board built around an ESP32-S3 microcontroller. This solution, compatible with the controller’s physical buttons, turns the Wii Remote into a standalone device that connects via Wi-Fi to Home Assistant using the ESPHome firmware. Each button press or motion can trigger actions or automations in the smart home. The built-in infrared emitter can also learn codes from existing remotes to control TVs or air conditioners. The modified Wii Remote can also function as a standard Bluetooth controller for a PC or Steam Deck. Two versions are available for pre-order on Crowd Supply until the end of October 2026: a fully assembled remote or a DIY modification kit. Shipments are expected in February 2027.

Connect the Wii Remote to a Raspberry Pi

With the open-source tool CWiid, a standard Wii Remote can communicate with a Raspberry Pi via Bluetooth without hardware modifications. CWiid provides Linux libraries to interpret the controller’s inputs and forward them to Home Assistant. A tutorial video by The Raspberry Pi Guy and a GitHub repository with Python scripts demonstrate the process. Data can be relayed via Home Assistant’s REST API or the MQTT protocol to trigger automations. The wminput tool also turns the Wii Remote into a mouse, ideal for navigating a Home Assistant interface displayed on a screen connected to the Raspberry Pi.

For Windows users, the Touchmote software, updated in October 2026, allows using the Wii Remote as a pointing device without additional hardware. The controller’s infrared camera detects the position of one or two sensor bars placed in front of the screen, turning the Wii Remote into a touchpad for direct interaction with a Home Assistant dashboard in a browser.
