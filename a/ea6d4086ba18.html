Transformer une Wiimote en contrôleur Home Assistant

Trois méthodes pour recycler une Wiimote en interface de domotique avec Home Assistant.

Lire l'article sur le Palmarès TRMNL →

La Wiimote, malgré ses 20 ans, reste un périphérique polyvalent grâce à sa connectivité Bluetooth, ses capteurs de mouvement, sa caméra infrarouge et ses boutons physiques. Trois approches permettent de l’exploiter comme contrôleur pour Home Assistant, la plateforme open source de domotique.

Remplacer la carte mère par un ESP32

Le projet OpenMote propose de remplacer la carte électronique d’origine de la Wiimote par une carte personnalisée basée sur un microcontrôleur ESP32-S3. Cette solution, compatible avec les boutons physiques de la manette, transforme la Wiimote en un périphérique autonome se connectant en Wi-Fi à Home Assistant via le firmware ESPHome. Chaque appui ou mouvement peut déclencher des actions ou des automatisations dans la domotique. L’émetteur infrarouge intégré permet aussi d’apprendre les codes des télécommandes existantes pour contrôler téléviseurs ou climatiseurs. La Wiimote modifiée peut également fonctionner en tant que manette Bluetooth classique pour un PC ou un Steam Deck. Deux versions sont disponibles en précommande sur Crowd Supply jusqu’à fin octobre 2026 : une Wiimote entièrement assemblée ou un kit de modification à souder soi-même. Les livraisons sont prévues pour février 2027.

Connecter la Wiimote à un Raspberry Pi

Avec l’outil open source CWiid, une Wiimote standard peut communiquer avec un Raspberry Pi via Bluetooth, sans modification matérielle. CWiid fournit des bibliothèques Linux pour interpréter les entrées de la manette et les transmettre à Home Assistant. Une vidéo tutorielle de The Raspberry Pi Guy et un dépôt GitHub avec des scripts Python illustrent le processus. Les données peuvent être relayées via l’API REST de Home Assistant ou via le protocole MQTT, permettant de déclencher des automatisations. L’outil wminput transforme aussi la Wiimote en souris, idéale pour naviguer dans une interface Home Assistant affichée sur un écran connecté au Raspberry Pi.

Une alternative sous Windows : le logiciel Touchmote, mis à jour en octobre 2026, permet d’utiliser la Wiimote comme périphérique de pointage sans matériel supplémentaire. La caméra infrarouge de la manette détecte la position d’une ou deux barres de capteurs placées devant l’écran, transformant la Wiimote en souris tactile pour interagir directement avec une interface Home Assistant dans un navigateur.
