ESP32 Matter: Display Temperature and Humidity via BME280

A guide to turn an ESP32 into a Matter-compatible sensor for Alexa, Google Home, and Home Assistant.

Read the article on the TRMNL Leaderboard →

This tutorial explains how to set up an ESP32 as a Matter node (formerly Project CHIP) to transmit temperature, humidity, and barometric pressure readings via a BME280 sensor. The Matter protocol, developed by the CSA alliance with Apple, Google, and Amazon, enables interoperability between smart home ecosystems without relying on proprietary solutions.

The node (a single Matter device) can expose multiple endpoints, each corresponding to a feature like temperature measurement. Data is transmitted locally over Wi-Fi or Thread, with built-in encryption for security. Setup is done via a QR code or an 11-digit manual code, simplifying the addition of the device to a controller like Alexa, Google Home, Home Assistant, or Samsung SmartThings. Once commissioned, the node can join multiple fabrics (logical networks) simultaneously, allowing control from multiple ecosystems.

The guide details wiring the BME280 (via I2C) to an ESP32-S3, with specific pins (SDA on GPIO 8, SCL on GPIO 9). The Adafruit_BME280 library is required to read sensor data. The provided Arduino code leverages the Matter library integrated into the ESP32 Arduino Core since version 3.1.0, avoiding additional dependencies.

Compatible ESP32 chips for Matter include S3, C3, C6, and H2, while others require manual entry of Wi-Fi credentials in the sketch. Commissioning via BLE (CHIPoBLE) allows automatic transmission of network credentials from the controller to the ESP32.
