ESP32 Matter : afficher température et humidité via BME280

Un guide pour transformer un ESP32 en capteur Matter compatible avec Alexa, Google Home et Home Assistant.

Lire l'article sur le Palmarès TRMNL →

Ce tutoriel explique comment configurer un ESP32 en nœud Matter (anciennement Project CHIP) pour transmettre des mesures de température, d’humidité et de pression atmosphérique via un capteur BME280. Le protocole Matter, développé par l’alliance CSA avec Apple, Google et Amazon, permet une interopérabilité entre les écosystèmes domotiques sans dépendre de solutions propriétaires.

Le nœud (un seul appareil Matter) peut exposer plusieurs points de terminaison (endpoints), chacun correspondant à une fonctionnalité comme la mesure de température. Les données sont transmises localement via Wi-Fi ou Thread, avec une option de chiffrement intégré pour la sécurité. La configuration s’effectue via un code QR ou un code manuel à 11 chiffres, simplifiant l’ajout du périphérique à un contrôleur comme Alexa, Google Home, Home Assistant ou Samsung SmartThings. Une fois commissionné, le nœud peut rejoindre plusieurs fabriques (réseaux logiques) simultanément, permettant son contrôle depuis plusieurs écosystèmes.

Le guide détaille le câblage du BME280 (via I2C) sur un ESP32-S3, avec des broches spécifiques (SDA sur GPIO 8, SCL sur GPIO 9). L’utilisation de la bibliothèque Adafruit_BME280 est requise pour lire les données du capteur. Le code Arduino fourni exploite la bibliothèque Matter intégrée à l’ESP32 Arduino Core depuis la version 3.1.0, évitant l’installation de dépendances supplémentaires.

Les ESP32 compatibles Matter incluent les modèles S3, C3, C6 et H2, tandis que d’autres nécessitent une saisie manuelle des identifiants Wi-Fi dans le sketch. La commissioning via BLE (CHIPoBLE) permet une transmission automatique des identifiants réseau depuis le contrôleur vers l’ESP32.
