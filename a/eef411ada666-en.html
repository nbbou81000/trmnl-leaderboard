Atmosis: An Environmental Sensor That Interprets Data for You

A DIY project using Arduino’s UNO Q to analyze air quality in real time and alert when values are concerning.

Read the article on the TRMNL Leaderboard →

Atmosis is an environmental monitoring system designed to turn raw data into actionable insights. Unlike traditional sensors that display technical values (such as 54 for PM2.5 particles), this project automatically determines whether these readings require attention. Developed by Next Builder, it leverages a dual-core architecture with the Arduino UNO Q to process information in real time.

The hardware setup includes several sensors: a DPS310 (barometric pressure and altitude), a Waveshare X6 module (gases, temperature, humidity), a dust sensor, and an LED strip for visual indicators. All components are housed in a compact and stylish 3D-printed enclosure. Atmosis stands out for its data processing capabilities, using onboard edge AI deployed via Edge Impulse. This AI analyzes sensor readings and flags anomalies without manual interpretation.

For deeper analysis, the system also integrates Google’s Gemini conversational assistant. This model can delve into the data, answer specific questions, or provide contextual explanations. Users can access results through a web interface or receive alerts via a Telegram bot. Atmosis is particularly suited for unique environments where local data is limited, such as microclimates or industrial sites exposed to dust particles.
