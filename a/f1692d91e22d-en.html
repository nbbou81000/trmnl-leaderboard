USBSID-Pico: Dual SID Chips Controlled via USB

An open-source project pairs two Commodore 64 SID chips with a Raspberry Pi Pico to interface with modern systems.

Read the article on the TRMNL Leaderboard →

The USBSID-Pico is an open-source project that combines two MOS 6581 SID chips — the iconic sound chip from the Commodore 64 — with a Raspberry Pi Pico to interface with modern hardware. The goal is to enable direct integration of these vintage components, often used for their distinctive chiptune sound, with contemporary systems.

The device supports multiple communication protocols: USB (CDC/WebUSB/WebSerial), MIDI, and ASID, a protocol designed for streaming SID register data over MIDI. While accurate software emulations exist on microcontrollers like the RP2040, some users prefer the raw, slightly imperfect sound of physical chips, arguing that the analog distortions add a unique character missing in emulations.

The project, certified as Open Source Hardware, fits into the retro-modern category of Hackaday’s retrocomputing contest. The creators note the differences between PAL and NTSC versions of the SID chips, which can affect the accuracy of the generated sounds. Modern replacements for the MOS 6581 exist, but original chips remain sought after despite being out of production for decades.
