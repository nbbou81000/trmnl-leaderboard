bare_metal: An Open-Source FPGA Badge Board with Four Bitstreams

An open-source FPGA badge board featuring four bitstreams and an iCE40 UltraPlus chip.

Read the article on the TRMNL Leaderboard →

Wenzel Labs introduces bare_metal, an open-hardware development board shaped like a badge, designed for FPGA (Field-Programmable Gate Arrays) and HDL (Hardware Description Language) beginners. The board features a Lattice Semiconductor iCE40 UltraPlus iCE40UP5k FPGA, with 5,280 four-input LUTs, 80KB of dual-port memory, and 1MB of single-port memory.

Features and connectivity

The badge format includes a lanyard slot, a rear compartment housing a lithium-polymer battery (identical to PS5 controllers) and a protective plastic case. Five directional pad buttons, including a "fire" button, are placed at the front, along with an RGB 16×8 matrix. Connectivity includes a PMOD connector for expansion, a USB Type-C port for power and data, and a slot for a desktop stand. At the back, there’s a power switch, a reset button, status LEDs, an 8MB PSRAM chip for memory expansion, and a 16MB SPI flash for storage.

The board supports up to four bitstreams, with the first being a bootloader. The other three can "boot" each other, enabling transputer-like architectures. While designed for three user bitstreams, it can technically host hundreds.

The project includes firmware examples and KiCad hardware files under the Creative Commons Attribution-NonCommercial-ShareAlike 4.0 license. Available for $137.61 from Wenzel Labs’ Lectronz store.
