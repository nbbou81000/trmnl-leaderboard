Piratage du tableau de bord d'une Renault 2014 pour régler l'heure

Un hacker contourne les restrictions d'un système embarqué Renault pour modifier l'heure du tableau de bord sans carte SD officielle.

Lire l'article sur le Palmarès TRMNL →

Sur une Renault Latitude de 2014, le réglage de l’heure du système de navigation intégré est impossible sans une carte SD d’origine contenant des données cartographiques valides. Sans cette carte, même en tant que propriétaire du véhicule, l’accès est bloqué. Rasmus Moorats a contourné cette limitation en exploitant une faille dans le système Linux embarqué du tableau de bord.

Le système permet théoriquement d’exécuter des scripts depuis la carte SD, mais avec des restrictions strictes sur leurs fonctionnalités. Après plusieurs tentatives infructueuses, Rasmus a exploité les fonctions de journalisation du script pour modifier le core_pattern du système. Ce paramètre, exécuté lors d’un plantage de processus, permet d’injecter des commandes arbitraires. En déclenchant volontairement un crash sur un binaire, il a pu exécuter des instructions pour éditer le fichier de configuration contenant l’heure.

Cette méthode illustre des techniques applicables à d’autres systèmes embarqués sous Linux verrouillés. Les commentaires soulignent que les véhicules plus récents, comme ceux équipés des systèmes R-Link avec magasin d’applications, rendent ce type de piratage encore plus complexe. Certains utilisateurs préfèrent remplacer l’unité d’origine par un système Android moderne, offrant plus de flexibilité et évitant les restrictions constructeur.
