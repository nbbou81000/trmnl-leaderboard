Cloudflare Quick Tunnels: Expose Local Servers Online with Access Control

Cloudflare offers temporary tunnels to share a local server via a random URL, with an option to restrict access by email.

Cloudflare Quick Tunnels provides a straightforward way to expose a local server online without complex setup: running cloudflared tunnel --url generates a random URL under trycloudflare.com, requiring no account, domain, or port forwarding. This temporary solution is perfect for quick tests or demos.

Setup and usage

The cloudflared open-source client from Cloudflare can be installed easily depending on your operating system. On macOS, use Homebrew (brew install cloudflared). On Debian/Ubuntu, install it via Cloudflare’s official repository (recently updated due to a changed signing key). On Windows, download an MSI, executable, or use Winget (winget install Cloudflare.cloudflared). Version 2026.9.3 or later is required for authentication features.

After installation, start your local server (e.g., on port 8080) and run cloudflared tunnel --url http://localhost:8080. Cloudflare generates a random URL like something-weird-random.trycloudflare.com, accessible from any internet-connected device. Stop the tunnel anytime with Ctrl+C.

Email-based access control

A recent addition allows restricting tunnel access to specific email addresses using the --allowed-mail option. Each guest receives a one-time code via Cloudflare Access to authenticate. Authorized emails are not displayed in the configuration, preventing personal data leaks. Multiple addresses can be added, separated by commas, or an entire domain using a wildcard (--allowed-mail '*@example.com').

This feature is useful for sharing a project with a small team or preventing an AI agent from accidentally exposing a public tunnel. Cloudflare also suggests using a PreToolUse hook to block commands without access restrictions.

Note that Quick Tunnels is designed for temporary use, not production deployment. Cloudflare does not guarantee service availability, and each tunnel is limited to 200 simultaneous requests. Server-Sent Events (SSE) are not supported. For professional use, consider creating a named tunnel via a Cloudflare account and a custom domain.
