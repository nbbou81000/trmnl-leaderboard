A Low-Cost Stereo Vision Board for Robots with Depth Sensing

An embedded board under $110 enables robots to calculate distances to objects in real time without an external computer.

High-end navigation systems not only identify objects but also measure their distance, yet solutions like LiDAR or ultrasonic sensors can be expensive. An alternative is using two cameras to mimic human vision by calculating depth through image disparity. However, this method is computationally intensive, making it difficult to integrate into embedded projects.

To make stereo vision more accessible, Ryan Walker developed a self-contained stereo vision board based on a Rockchip RV1103 SoC. This processor features an Arm Cortex-A7 core running at 1.1 GHz, 64 MB of DDR2 RAM, and a MIPI CSI-2 interface, all packed into a QFN-88 package. It also includes hardware acceleration optimized for image processing. The board pairs the SoC with two OV9281 cameras, creating a complete stereo vision system capable of running Linux. Designed as a peripheral for robots or microcontrollers like Arduino, it provides depth data via a serial connection while offloading processing tasks.

The prototype uses a four-layer PCB with controlled-impedance traces for high-speed interfaces (MIPI, USB, Ethernet). Walker identified minor design flaws: incorrectly sized lens mounting holes, undersized LED resistors, and thinner-than-intended power traces. For software, he used Buildroot to build a minimal Linux system with a bootloader, kernel, and drivers. Some components, like MIPI camera drivers and hardware acceleration support, came from Rockchip’s proprietary software package. The system exposes the cameras through the Video4Linux2 interface, while a USB-C port enables Ethernet communication and SSH access.

Depth sensing relies on the SAD accelerator (Sum of Absolute Differences) integrated into the Rockchip Video Engine. This module compares regions of images from both cameras to find matches and calculate distances. Nearby objects produce larger disparities, while distant ones yield smaller gaps. Walker has already demonstrated image capture and depth processing. Future plans include improving software performance, optimizing image processing, and adding features like SLAM (simultaneous localization and mapping) or object detection using YOLO. A small production run is planned if demand is sufficient, with an estimated selling price of $110.
