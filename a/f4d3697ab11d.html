OpenMausBot : un agent conversationnel open source avec machines virtuelles

Un agent conversationnel open source permet de dialoguer avec plusieurs IA locales ou cloud via une interface unifiée.

Lire l'article sur le Palmarès TRMNL →

Milind Soni propose OpenMausBot, un projet open source inspiré des assistants conversationnels comme Grok Bot. Chaque bot visible dans la barre latérale fonctionne comme un agent autonome, capable d’exécuter des tâches via des modèles d’IA locaux ou cloud (comme Claude ou Codex). Ces agents disposent de leur propre personnalité, d’un environnement informatique dédié et d’applications connectées.

L’interface s’apparente à une messagerie instantanée : chaque conversation conserve son historique et ses fils de discussion. Les commandes shell, les modifications de fichiers ou les questions s’affichent sous forme de cartes interactives avec des options Autoriser ou Refuser. Un système de permissions intermédiaire filtre les actions potentiellement risquées avant exécution. Les utilisateurs peuvent visualiser en temps réel l’écran d’un bureau cloud ou rediriger l’agent vers leur machine locale sous macOS.

Les connexions aux applications tierces (Gmail, Slack, GitHub, Notion, Linear, etc.) s’effectuent via un marketplace Composio. Les déclencheurs automatisent l’exécution des bots selon un calendrier, une requête web ou un événement dans une application connectée. Des versions précompilées sont disponibles pour macOS (Apple Silicon et Intel), Windows (x64) et Linux (Ubuntu 24.04 en version bêta, via .deb ou AppImage). Le code source est sous licence Apache 2.0, à l’exception du dossier dédié aux entreprises. Pour une installation depuis les sources, Node.js 24+, pnpm et au moins un CLI d’agent installé sont requis.
