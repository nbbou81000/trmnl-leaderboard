The T-Mobile Sidekick Rises Again Through Hacking and Emulation

A hacker revives the 2002 T-Mobile Sidekick by recreating its OS and defunct cloud services.

The T-Mobile Sidekick, released in 2002, pioneered features like a full QWERTY keyboard, push notifications, and instant messaging. However, its reliance on Danger’s servers—shut down in 2011—left most functions unusable. Hacker Ashe has now revived the device by recreating its operating system and cloud services.

The first hurdle was bypassing the Sidekick 3’s security. Running DangerOS, a Java-based OS, the phone only accepted applications signed by Danger or an authorized carrier. Ashe exploited a weakness in the original developer certificates, which used a 512-bit RSA key—considered weak by modern standards. Using the open source CADO-NFS tool and a cluster of seven machines (220 CPU cores), he factored the key in eight and a half hours, reconstructing Danger’s private signing key. This allowed him to install custom applications on a real Sidekick 3.

Ashe then ported the visual novel Class of '09 to the device, proving the modifications worked. He also built a browser-based Sidekick simulator that runs DangerOS via a JavaScript interpreter. This lets users explore the original interface, launch apps, and play games without owning the hardware.

To fully restore functionality, Ashe created Re:Danger, a replacement for the defunct cloud services. He has already restored basic features like clock synchronization and instant messaging, using Discord as a stand-in for the original networks. A web proxy even enables browsing modern websites from the simulator. Currently, Re:Danger only works with the simulator; connecting a real Sidekick will require further work. Ashe plans to test a software-defined GSM network to link original devices to his new servers.
