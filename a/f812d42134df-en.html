Track Birds with Raspberry Pi, Mic, and E-Ink Display

A DIY project uses AI to identify birds by their songs and displays results on an e-ink screen.

Read the article on the TRMNL Leaderboard →

The Avian Visitors project by Teddy Warner uses a Raspberry Pi and a USB microphone to track and identify birds visiting a garden using artificial intelligence. The system relies on BirdNET, an open-source deep learning model from Cornell University, which can recognize over 11,000 bird species based solely on their songs. It then generates a colorful illustration on a web interface, where the size of each bird’s image reflects its detection frequency.

A standout feature is the optional color e-ink display, which shows a 24-hour summary of detected birds in a collage format. The data can also be sent to Home Assistant or via MQTT to trigger automations based on specific bird species. The project includes a full GitHub repository and a build video to guide users through the setup.

The setup requires only a Raspberry Pi and a USB microphone. BirdNET, developed by Cornell University, is freely available and provides reliable bird identification through vocalizations. The project blends technology and art, turning raw data into an evolving mural.
