Supernova POV Pixel Poi V2: Programmable LED Poi for Midair Light Painting

Wireless programmable LED poi display crisp midair images using high-speed DotStar LEDs and a touchscreen controller for real-time control.

Read the article on the TRMNL Leaderboard →

This project turns poi—light sticks on strings—into midair drawing tools using persistence of vision (POV). Each poi features a 36-DotStar LED array driven by an Adafruit Feather RP2040 RFM69 microcontroller, capable of displaying crisp patterns, logos, or animations in motion. Version 2 streamlines the process: simply copy an image file into a folder on the microcontroller to load it, eliminating complex coding steps.

A dedicated wireless controller, built with an Adafruit TFT Featherwing touchscreen and a second Feather RP2040 RFM69, manages multiple poi at once. From up to 15 meters away, users can browse image libraries, adjust brightness and animation speed, or sync poi for coordinated performances. The system includes battery monitoring to alert when recharging is needed and an autoplay feature to automate sequences.

The poi operate independently once programmed, making them ideal for rehearsals or spontaneous use. Their RF-based wireless communication ensures perfect synchronization between sticks, while their lightweight design and battery life adapt to various applications, from live performances to interactive displays.
