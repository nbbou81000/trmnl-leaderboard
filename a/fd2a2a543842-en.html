Microsoft BASIC 1.1 for 6502 Released as Open Source with Web Version

Microsoft releases assembly source code for BASIC 1.1 for the 6502, including a browser-based emulator and live disassembly.

Read the article on the TRMNL Leaderboard →

Microsoft has published the assembly source code for Microsoft BASIC version 1.1, targeting the 6502 microprocessor. Developed between 1976 and 1978, this language was the go-to solution for making early home computers user-friendly. The 6502 powered iconic systems like the Apple II, Commodore PET, and KIM-1.

The code leverages conditional assembly, enabling the same source to build for multiple early machines by adjusting specific flags. It also includes a revision history documenting changes over time. This release provides a rare glimpse into how interpreters were crafted when memory was measured in kilobytes, and every byte mattered.

A browser-based implementation is already live at basic.nullevi.app. The site runs the Ohio Scientific build of BASIC 1.1 inside a 6502 emulator. The interface displays CPU registers, a live disassembly, and a terminal. Sample programs run automatically, while POKE and PEEK commands control virtual LEDs, switches, and a beeper.
