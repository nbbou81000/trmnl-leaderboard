Microsoft BASIC 1.1 pour 6502 en code source ouvert et version web

Microsoft publie le code assembleur de BASIC 1.1 pour le 6502, avec une version navigateur et un émulateur.

Lire l'article sur le Palmarès TRMNL →

Microsoft a partagé sur GitHub le code assembleur de Microsoft BASIC version 1.1, conçu pour le microprocesseur 6502. Ce langage, développé entre 1976 et 1978, était alors le standard pour rendre les ordinateurs personnels accessibles. Le 6502 équipait notamment l’Apple II, le Commodore PET ou encore le KIM-1.

Le code utilise une compilation conditionnelle, permettant de générer des versions adaptées à plusieurs machines de l’époque en fonction de paramètres spécifiques. Il inclut également un historique des révisions, retraçant les modifications apportées au fil du temps. Cette archive offre un aperçu rare de l’architecture d’un interpréteur conçu dans un contexte où la mémoire se mesurait en kilo-octets, chaque octet étant précieux.

Une implémentation interactive est déjà disponible en ligne via basic.nullevi.app. Ce site exécute la version Ohio Scientific de BASIC 1.1 dans un émulateur 6502 intégré au navigateur. L’interface affiche les registres du processeur, une désassemblage en temps réel ainsi qu’un terminal. Des exemples de programmes s’exécutent automatiquement, et les commandes POKE et PEEK permettent de contrôler des LEDs, des interrupteurs et un haut-parleur virtuels.
